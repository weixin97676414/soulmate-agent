# 功能清单

> 面向使用者的完整清单。README 是概览，这份是逐项对照表 —— 想知道"某件事能不能做、在哪里做"，看这里。

---

## 一、对话

| 能力 | 入口 / 说明 |
|---|---|
| 多会话 | 左侧会话列表；按「今天 / 昨天 / 最近 7 天 / 更早」分组 |
| 会话搜索 | 列表顶部搜索框 |
| 重命名 / 删除 / 清空 | 会话右键菜单（删除对话 / 清空消息） |
| 独立窗口 | 会话右键「在独立窗口打开」（900×720） |
| 消息渲染 | Markdown、代码高亮、表格、图片、公式（KaTeX） |
| 中断生成 | 生成过程中的「停止」 |
| 复制消息 | 消息操作里的「复制」（代码块另有独立复制） |
| 上下文用量 | 输入栏上方的用量标记 |
| 模型选择 | 输入栏下方；按会话记忆，也可跟随全局默认 |
| 思考强度 | 输入栏工具条；按服务商文档映射档位 |
| 权限确认档位 | 输入栏工具条；三档：**每次询问 / 自动批准 / 一律拒绝**（`interactive` / `auto_approve` / `deny`） |
| 斜杠命令 | 输入 `/` 唤起命令面板 |
| 交互提问 | 模型中途提问选项（`ask_choice`），不会自己替你决定 |
| 计划卡片 | 多步任务生成计划，显示每步状态 |
| 工具调用卡片 | 每个工具调用一张卡：运行中 / 成功 / 失败 / 被拒绝 + 耗时 |
| 执行链路抽屉 | 每个 span 的名称、耗时、token |
| 语音输入 | 麦克风按钮（需语音模型；模型按需下载） |

## 二、搭子（人格化助手）

| 能力 | 说明 |
|---|---|
| 内置 5 个 | **Buddy Manager**（建 Agent / 带团队）、**Soulmate**（深度陪伴）、**Love Buddy**（情感关系）、**Relation Buddy**（人际关系与职场杂事）、**Fortune telling Buddy**（西占 / 八字 / 梅花 / 塔罗） |
| 新建搭子 | 界面表单，或让 AI 帮你建（Buddy Manager） |
| 人格文档（六份） | `IDENTITY → SOUL → RULES → MEMORY → USER → 进化日志`，可查看可编辑 |
| 添加能力 | 两级选择：先选分类，再选具体技能 / 工具 |
| 独立模型 | 每个搭子可指定模型，也可跟随全局 |
| 独立权限 | 每个搭子可有自己的权限策略，不污染全局 |
| 演化 | 内置搭子每周自省一次、每月复盘一次，记录写在各自的 `进化日志.md`（可在人格文档里查看） |
| 头像 / 昵称 | 可改（头像历史上传过的都保留，可一键换回） |
| 导入 | 让 AI 从官网搭子库导入现成搭子（`buddy_import`）；**界面没有导出入口** |
| 防误删 | 内置搭子不可删；其他人格文档有锁定与解锁规则 |
| 删除机制 | 普通搭子可直接删；删除要经用户确认（AI 不能自己删） |

## 三、群聊

| 能力 | 说明 |
|---|---|
| 建群 | 拉多个搭子进群、定发言顺序，可建群时指定头像（没有"群主"这个字段） |
| 团队结构 | 常见做法是把 Buddy Manager 也拉进群做统筹与分工，各专职搭子执行 |
| 独立窗口 | 只读观察窗（后台讨论自动弹出、不抢焦点）与可操作窗（780×680） |
| 群记忆 | 独立成库，群内成员共享；单聊默认不读（避免串台） |
| 群内权限 | 群权限管群里每个搭子的行为，与搭子自己的设置分开 |
| 讨论中断 / 续接 | 失败可接着上一轮继续，不会全白干 |
| 群管理 | 改群名、加减成员、调发言顺序、换头像（AI 也能做） |
| 多线程 | 一个群可以有多条并行对话线 |
| 角色分配 | 每轮讨论按角色发言，避免所有搭子说同一句话 |

## 四、技能

| 能力 | 说明 |
|---|---|
| 三层合计 | **约 350 个**：107 个内置工具 + 237 个出厂技能包 + 6 类专属技能 |
| 内置工具 | **107 个**写在代码里（浏览器、电脑操作、剪贴板、文档、日历、记忆、人格、心鉴学取数…），随核心出厂 |
| 出厂技能库 | **13 类 237 个**资源包，首次启动自动播种（磁盘上另有 5 个刻意不播种） |
| 分类 | 人力 9 · 办公 5 · 医疗 14 · 媒体 61 · 学术 10 · 教育 16 · 法律 9 · 生活 3 · 电商 25 · 科技 16 · 营销 40 · 设计 12 · 金融 17 |
| 专属技能 | 6 类（Soulmate专用 · 人际关系运营 · 西占 · 八字 · 梅花易数 · 塔罗），按线路二选一，非归属搭子看不到也调不动 |
| 电脑 / 浏览器操作 | 桌面控制 10 个（窗口 / 鼠标 / 键盘 / 启动程序 / 读界面元素）+ 浏览器控制 5 个（读正文 / 看元素 / 点击填表 / 截图 / 标签页），全部 `confirm` 级 |
| 技能页 | 四个子页，顺序即界面按钮顺序：**我的技能（默认）/ 通用技能 / 内置技能 / 专属技能** |
| 开关与权限 | 单个技能可开关、可改权限级别；**内置与专属不可关**（`ALWAYS_ON_SKILLS`） |
| 导入 | 支持目录、zip、单文件；六种格式自动识别 |
| 技能密钥 | 技能里写 `{{secret:名字}}`，发请求那一刻才在本地替换成明文；模型可用 `request_secret` 向用户索要，界面只显示脱敏预览 |
| 自定义技能 | 用「技能创作指南」（`skill_creator`）让 AI 写，或手写 `SKILL.md` |
| 技能包 | 内置 / 专属技能锁定不可改；自建的技能可改可删（没有界面导出入口） |

**技能格式**（按识别优先级）：

1. `skill.json` —— 声明式（http / command 调用）
2. `SKILL.md` —— YAML frontmatter（name / description / allowed-tools）+ 正文说明
3. 规则文件 —— `AGENTS.md` / `CLAUDE.md` / `.cursorrules` / `.mdc`
4. 含 `mcpServers` 的配置
5. 可执行脚本 —— `.py` / `.sh` / `.js` / `.ps1` …
6. 通用提示词

## 五、模型

| 能力 | 说明 |
|---|---|
| 服务商预设 | **4 家开箱可用**（硅基流动 / DeepSeek / OpenAI / 通义千问）；另有 **17 家厂商的平台适配**（见下），其余填自家 `base_url` 即可 |
| 添加服务商 | 三步向导：选服务商 → 填密钥选模型 → 测试并保存 |
| 自定义端点 | 任意 OpenAI 兼容端点 |
| 本地模型 | Ollama（先试 `/api/tags`，再退回 OpenAI 兼容） |
| 测试连通性 | 真的请求一次，返回延迟与可用模型名 |
| 同步模型 | 按 `base_url` 拉取真实清单 |
| 价格配置 | 输入 / 输出 / 缓存分别配；支持**高峰时段**分时定价 |
| 默认模型 | 全局默认 + 每搭子覆盖 + 每会话记忆 |
| 备用模型 | 主模型不可用时降级 |
| 辅助模型 | 摘要 / 记忆这类轻任务可单独指定（`utility_model_id`），配错自动退回主模型 |

**平台适配覆盖 17 家**（温度范围、思考字段、用量字段按域名自动适配）：

MiniMax · 腾讯混元 · 百度文心（千帆）· 阶跃星辰 · Anthropic Claude · Google Gemini · xAI Grok ·
OpenRouter · Groq · Mistral

> 其中只有前 4 家在「模型」页有预置卡片（带可用模型清单）；其余各家在「添加服务商」里填 `base_url` 后同样享受上述适配。

## 十四、不适合用它做的事

如实说明，免得期待落空：

- **不是多用户 / 团队协作工具**：数据是本机的，没有云端同步、没有共享会话
- **没有手机端 / 网页版**：目前只有 Windows 桌面端
- **不做代码签名**：安装时 SmartScreen 会警告
- **不内置任何模型**：需要自己配服务商密钥（或用本地 Ollama）；语音与嵌入模型按需下载
- **产物预览只读**：不能在线编辑表格或 Markdown
- **`.xls` / 扫描版 PDF 不支持预览**
- **MCP 只支持 stdio**，resources / prompts 未接入
