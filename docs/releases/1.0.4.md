# Soulmate Agent 1.0.4 更新公告

> 发布版本：**1.0.4**　｜　上一版：1.0.3　｜　发布日期：2026-11-22

---

## 一句话

**这一版把搭子接进了飞书**——你在飞书里发消息，客户端里自动出现对话，两边完全同步。

---

## 一、新增：飞书机器人接入

### 它能做什么

| 能力 | 说明 |
|---|---|
| **像 openclaw 一样连飞书** | 用官方 SDK 的长连接方式，**不需要公网 IP、不用做内网穿透**，客户端开着就一直在线 |
| **指定某个搭子来接待** | 每个机器人绑定一个搭子，1:1。绑「岸」就是岸在回，绑谁就是谁 |
| **同时接多个机器人** | 每个机器人独立运行、互不干扰。一个出错不影响其他的 |
| **飞书对话自动进客户端** | 有人给机器人发消息，客户端的「对话」页**自动冒出一个新会话**，标题取飞书里的会话名 |
| **两边完全同步** | 飞书发的客户端能看到；你在客户端里接着聊，回复也会发回飞书。同一份记忆，不用重复说上下文 |

### 群聊的规矩

**群里只有 @ 机器人才会回复。** 不 @ 它就不说话——否则整个群的闲聊都会被当成提问读进去，既吵又费钱。单聊则每条都回。

### 图片和文件

飞书发来的**图片**会直接交给模型看（前提是你用的模型支持看图）；**文件**会下载到产物区，搭子可以直接读。

## 二、怎么配置（一次性，约 5 分钟）

⚠️ **前提：需要飞书「企业自建应用」的创建权限。** 飞书个人版账号建不了，得找公司飞书管理员帮忙建一个应用。

1. **创建应用**　飞书开放平台 → 开发者后台 → 创建「企业自建应用」
2. **开启机器人**　应用 →「添加应用能力」→ 添加「机器人」
3. **开通权限**（五项，缺一不可）
   - `im:message` —— 读取用户发给机器人的消息
   - `im:message.p2p_msg:readonly` —— **单聊**消息 ⚠️ 界面写「开通任一即可」，但只在单聊里说话就必须开这条
   - `im:message.group_msg` —— **群聊**消息（要在群里用才需要）
   - `im:message:send_as_bot` —— 以机器人身份回复
   - `im:resource` —— 下载图片/文件；`im:chat:readonly` —— 读群名（可不开，不开则标题叫「飞书会话」）
4. **配置事件订阅**　「事件与回调」→「事件配置」→ 订阅方式选「**使用长连接接收事件**」
   - ⚠️ 不要选「将事件发送至开发者服务器」——本机没有公网地址，填了也永远收不到
   - 同一页「添加事件」→ 添加 `im.message.receive_v1`
5. **发布版本**　「版本管理与发布」→ 创建版本 → 申请发布
   - ⚠️ **权限和事件订阅的改动，不发版不生效**。界面上显示「已开通」只代表申请过
6. **回到客户端**　左栏「飞书」→ 新增机器人 → 填 App ID / App Secret → 点「测试连接」→ 保存

### 配好之后怎么验

1. 左栏「飞书」里状态是**绿点「已连接」**
2. 在飞书给机器人发一条消息
3. 客户端「对话」页自动出现新会话，点进去能看到你的提问和搭子的回复
4. 飞书那边也收到回复

## 三、几个设计上的选择（说明一下为什么不那么做）

**飞书里没有"确认"这一步。** 搭子要删文件、跑命令这类高危操作时需要你点头，但飞书界面里弹不出确认框，所以这类操作在飞书里**一律自动拒绝**，搭子会在回复末尾告诉你"有 N 个操作需要你确认，请在客户端里再发一次"。

原因很直接：让你在看不到界面的情况下默默批准一次删除，比拒绝危险得多。

**App Secret 只存在本机。** 走 Windows DPAPI 加密，不进配置文件、不进日志、任何接口都只返回「有没有存」不返回内容。界面上看到的是掩码，要改就重新填。

**改了绑定的搭子，需要重启客户端才生效。** 长连接本身会自动重连，但「这个机器人归哪个搭子管」在会话建立时就定了。

## 四、已知限制（如实说明）

- **必须先有飞书企业自建应用**，这一条绕不过去
- **长连接需要客户端开着**。客户端退出期间飞书发的消息不会进队列，也不补收——重开之后对方需要再发一次
- **富文本消息里的图片暂不接**：只处理"纯图片"和"纯文件"两种消息类型
- **消息排队处理**，同一时刻进来的多条不会并发
- **回复超过 1.2 万字会截断**，末尾提示你去客户端看全文
- 飞书接口有频率限制（单机器人 5 次/秒），超长回复会被分成两三条发出

---

## 五、这一版还改了什么

除了飞书接入，还修了几处影响稳定性的问题：

- **工具结果不再撑爆界面**：访问网页/接口类工具的返回内容可能很大，之前点开工具气泡会卡死、内存飙升。现在界面只渲染预览（完整内容仍完整交给模型），并支持「展开全部」
- **硅基流动的模型列表全量显示**：之前只显示 deepseek-flash 一族，现在所有模型都能看到并选择（flash 族仍排在前面，作为默认）
- **新增「执行命令行」技能**（Buddy Manager 专属）：可以真的跑一条命令。**这个技能每次触发都需要你手动确认，且不能"记住"**，因为能跑任意命令就等于最高权限
- **飞书单聊权限的坑已写进设置页引导**：就是上面第 3 步里那条 `p2p_msg`，我们自己也在这里栽过

## 六、如何升级

**运行 `Soulmate-Agent-Setup-1.0.4.exe`，覆盖安装即可**，数据保留。

⚠️ 这一版核心有较大改动，**需要装完整包**，不是增量更新。

如果你装过内部测试版（版本号可能显示 1.0.5 以上），直接装 1.0.4 覆盖即可，但**更新提示可能会短暂显示异常**——那是版本号回退导致的，不影响使用。

---

## 七、反馈

遇到问题请附上 `%APPDATA%\Soulmate Agent\logs\core.log` 里**带「飞书」的行**。这一版的日志会明确标出卡在哪一步：

| 日志里出现 | 含义 |
|---|---|
| `长连接已建立（connected to wss://…）` | 握手成功 |
| `长连接已确认（收到事件）` | 事件真的到了 |
| `群消息没有 @ 机器人` | 事件到了，但被群聊策略拦了 |
| `长连接已建立，但 25 秒内未收到任何事件` | 飞书没推 → 多半是权限没开或没发版 |
