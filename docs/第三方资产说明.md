# 第三方资产说明

本仓库除自有代码外，还包含少量第三方组件与数据。这里逐项列出**来源、许可与风险**，
供使用者自行判断。凡标注"来源待确认"的，请勿在未核实的情况下用于商业分发。

## 二、来源待确认（已随仓库分发，请自行评估）

### 1. 地图数据

| 文件 | 体积 | 说明 |
|---|---|---|
| `world.json` | 约 987 KB | GeoJSON 世界地图 |
| `china.json` | 约 569 KB | GeoJSON 中国地图 |

位置：`core/src/my_agent/resources/factory_skills/设计/data-charts/assets/chart-engine/assets/`

**风险提示**：

- 两份数据的**原始出处与许可未能确认**（推测来自公开的 GeoJSON 数据集或其二次整理版本）
- ⚠️ **中国地图数据在公开使用上涉及审图号要求**。若你计划在公开场合（尤其是面向中国大陆）
  展示、分发基于 `china.json` 绘制的地图，请自行核对当地法规要求，必要时替换为带有
  合法审图号的版本
- 本项目仅将其作为"数据图表"技能的本地示例数据；技能在设计上**优先读取本地地图文件**，
  你可以直接替换成自己的合法数据

## 三、不随仓库分发的部分（已刻意移除）

以下几类**没有**包含在本仓库中，原因见括号内：

| 内容 | 原因 |
|---|---|
| 若干医疗、税务法律、学术检索类技能 | 属于需要专业资质或涉及商业数据库服务条款的领域，不随开源分发 |
| 某短剧类技能中的打包脚本（`bundle-*.js`） | 为第三方打包产物，许可不明 |
| 若干高考录取分数线数据 | 数据来源与授权不明 |
| 语音识别 / 合成模型、嵌入模型 | 体积大（数百 MB）且各有自己的许可，改为首次使用时按需下载 |
| `presets` 中引用的官方技能包（`.zip`） | 由官方站点按线路分发 |

## 四、运行时依赖

与其他开源项目一样，本仓库依赖大量第三方库（见 `core/pyproject.toml` 与
`desktop/package.json`），它们各自适用其原始许可。安装依赖即表示你接受这些许可。

主要运行时依赖：

| 组件 | 用途 |
|---|---|
| FastAPI + uvicorn | 核心 HTTP 服务 |
| pydantic | 配置与数据模型 |
| httpx | 上游模型请求 |
| openpyxl | Excel 读写（**刻意不用 pandas**，见架构文档） |
| chromadb（可选） | 长期记忆向量检索 |
| onnxruntime + sherpa-onnx（可选） | 语音识别与合成 |
| Electron + React + Vite | 桌面外壳 |
