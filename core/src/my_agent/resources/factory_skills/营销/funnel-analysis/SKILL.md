# 漏斗分析

**边界**：只做漏斗诊断（本地脚本建漏斗、流失诊断、行业对标、优化建议与漏斗对比）；增长实验 / AARRR 增长环、企业 KPI 指标树与仪表盘不在本技能范围。

## 适用场景

- 创建转化漏斗、诊断流失环节、行业对标、优化建议、分析报告、漏斗对比。
- 触发词：漏斗分析、转化漏斗、流失环节、转化率诊断、行业对标、漏斗对比、funnel analyzer。

## 步骤

1. 用「步骤名:数量,...」格式准备漏斗数据（例：`浏览:10000,加购:3000,下单:1500,支付:1200,完成:1000`）。
2. 按需运行命令：
   ```bash
   bash scripts/funnel.sh create "电商购买" "浏览:10000,加购:3000,下单:1500,支付:1200,完成:1000"
   bash scripts/funnel.sh diagnose "浏览:10000,加购:3000,下单:1500,支付:1200"
   bash scripts/funnel.sh benchmark ecommerce      # ecommerce|saas|content|app|recruitment
   bash scripts/funnel.sh optimize "注册:5000,激活:2000,留存:800,付费:200"
   bash scripts/funnel.sh report "注册:5000,激活:2000,留存:800,付费:200" "SaaS产品"
   bash scripts/funnel.sh compare "A组:1000,500,200,100" "B组:1000,600,300,150"
   ```
   纯本地 bash，无外部 API。
3. 结合方法要点与行业基准解读（见 `assets/funnel-tips.md`）。

## 输入输出

- 输入：漏斗步骤与各步数量。
- 输出：可视化漏斗、流失诊断、行业对标、优化建议、完整分析报告、漏斗对比。

## 注意事项

- 定义清晰步骤：每步必须是可量化的用户行为；关注最大流失点；分群分析；设合理的转化时间窗口。
- 优化优先级：优先优化靠近底部的步骤（越近转化终点，每提升 1% 商业价值越大）。
- 漏斗不一定线性，用户可能跳步或回退；设合理归因窗口（7 天/30 天）；对比不同时段发现趋势。
- 行业基准参考（来自 tips，**未标注来源，按参考值对待**）：电商加购率 3-8%；SaaS 试用→付费 2-5%；注册页转化率 20-40%；支付页完成率 60-85%。

## 可复用示例

```bash
bash scripts/funnel.sh report "注册:5000,激活:2000,留存:800,付费:200" "SaaS产品"
# → 各步转化率、最大流失环节定位、优化建议、完整报告

```
