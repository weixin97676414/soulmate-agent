# 品牌第一课核心方法

## 方法论主线

```
盘资源 → 经营判断 → 聚焦优势 → 品牌建构 → 产品塑造 → 营销闭环
```

## 资源三维度

### 1. 创始人
- 背景：行业经验、教育经历、人脉资源
- 能力：核心技能、领导力、决策力
- 资源：资金、渠道、供应链、用户资源
- 性格：韧性、开放性、执行力

### 2. 团队
- 能力结构：核心能力是否匹配业务需求
- 执行经验：是否有相关行业经验
- 分工配合：团队协作是否顺畅

### 3. 运营基础
- 渠道：现有销售渠道
- 供应链：生产、物流、库存能力
- 资金：现金流、融资能力
- 用户资产：现有用户量、用户数据

## 真优势三问

判断一个资源是否是真长板：

### 1. 匹配
- 资源是否匹配当前阶段？
- 是否匹配目标市场？
- 是否匹配团队能力？

### 2. 闭环
- 资源能否支撑商业闭环？
- 从获客到交付到复购，是否跑得通？
- 资源是否能产生收入？

### 3. 可持续
- 资源能否持续放大？
- 是否有时间限制？
- 是否依赖外部条件？

## 系统级判断框架

### 表面问题 vs 系统问题

| 表面问题 | 可能的系统问题 |
|----------|---------------|
| 销量下滑 | 产品价值不匹配、渠道失效、品牌老化 |
| 用户流失 | 体验不佳、竞品替代、需求变化 |
| 营销无效 | 定位不清、触点错误、预算浪费 |
| 增长停滞 | 资源分散、赛道受限、团队能力 |

### 关键因果链

找出2-3条最关键的因果链：
```
现象 → 直接原因 → 根本原因 → 系统问题
```

### 修复顺序

1. 先止血：解决最紧急的问题
2. 再治病：解决根本原因
3. 后强身：建立长效机制

## 总控分诊逻辑

### 第一轮：承接+初判+问一个关键问题

```
[承接]: 听起来你们现在的情况是……
[初判]: 这更像是关于 [X] 方向的问题。
[问题]: 我想先问你一个问题：……？
```

### 第2-4轮：承接新信息+更新判断+继续追问

```
[承接新信息]: 你刚说的这个，让我对你的情况有了新的理解……
[更新判断]: 这让我更觉得……
[继续追问]: 那我想继续问……
```

### 收束：系统级判断

- 用户现在更像在问什么
- 表面问题
- 系统问题
- 当前已知事实/判断推测/仍需确认
- 关键因果链（2-3条）
- 最卡的2-3个环节
- 修复顺序
- 主突破口
- 现在先别做什么
- 下一步建议

## 品牌叙事五层体系

### 1. 定位
你是谁？在用户心中占据什么位置？

### 2. 命名
你叫什么？名字是否好记、好传播、有联想？

### 3. Slogan
你要让用户最快记住什么？一句话说清楚价值。

### 4. 视觉符号
你用什么被识别？logo、色彩、包装、形象。

### 5. 关键触点
你在哪些地方反复兑现同一件事？产品、服务、内容、渠道。

## 最小营销闭环

### 核心原则
单渠道 + 单人群 + 单卖点 = 最小可盈利闭环

### 执行步骤
1. 选一个渠道
2. 选一个人群
3. 打一个卖点
4. 跑通转化
5. 验证盈利
6. 再放大
