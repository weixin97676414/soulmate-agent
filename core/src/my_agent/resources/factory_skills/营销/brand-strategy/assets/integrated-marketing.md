# 整合营销方法论（罗兰贝格）

## 核心定义

品牌存在于客户意识中的信息，品牌资产的作用是：创造差异性、传递信息、调节心理反应。

## 四问框架

| 问题 | 内容 |
|------|------|
| 谁 | 目标客户、主要关注对象 |
| 什么 | 品牌资产、传播战略 |
| 怎样 | 价值定位、营销计划 |
| 前景评估 | 行业/市场/客户/竞争/公司/目标 |

### 谁：目标客户群体

三层结构：
1. 战略目标
2. 首要关注对象
3. 次要目标
4. 辐射人群

### 什么：品牌资产

**战略层面**：
- 品牌定位
- 品牌个性
- 品牌核心价值

**执行层面**：
- 品牌名称
- 视觉识别
- 品牌调性

### 怎样：价值定位和营销计划

1. 价值定位：品牌为客户提供什么独特价值
2. 营销计划：如何传递这个价值

### 前景评估

- 行业状况
- 市场规模
- 客户需求
- 竞争格局
- 公司现状
- 经营目标

## 三元素定位法

```
品牌定位 = 目标消费群 + 商品独特卖点 + 竞争范畴
```

### 目标消费群
他们真正的消费心理是什么？

### 商品独特卖点
消费者为什么要买你的商品？

### 竞争范畴
你的商品会替代哪些商品？

### 定位陈述模板

> **对于**[目标消费群]，**[品牌名]是**[品类定位]，**它提供**[独特卖点]，**让消费者**[获得什么利益]。

## 品牌核心价值三层次

| 层次 | 定义 | 案例 |
|------|------|------|
| 功能性价值 | 产品的独特卖点（USP） | 农夫山泉"有点甜" |
| 情感价值 | 购买使用过程中的情感满足 | 海尔"真诚到永远" |
| 自我表达价值 | 消费者价值观、身份的表达 | 奔驰"权势、财富" |

### 功能性价值
- 产品的独特卖点（USP）
- 必须是产品独有的
- 必须是具体的承诺
- 必须能打动消费者

### 情感价值
- 购买使用过程中的情感满足
- 如"爱、真情、友情、关怀"

### 自我表达价值
- 消费者价值观、身份的表达
- 品牌个性的塑造

## 品牌主张类型

### 功能USP主张
进行产品的功能与品质诉求
- "农夫山泉，有点甜"
- "乐百氏纯净水，27层净化"

### 情感主张
进行社会或人物的情感诉求
- "娃哈哈纯净水，我的眼里只有你"
- "孔府家酒，让人想家"

### 理念主张
进行企业理念或消费理念诉求
- "海尔，真诚到永远"
- "让我们做得更好——飞利浦"

## 品牌整合营销六步流程

### 1. 市场扫描
- 市场分析：PEST、市场规模、增长趋势
- 竞争格局：竞争对手分析
- 品牌写真：品牌现状诊断
- 消费观察：消费者需求分析

### 2. 竞争策略
- SWOT分析
- 优势策略（SO）：利用优势抓住机会
- 补强策略（WO/ST）：克服劣势避免威胁

### 3. 品牌定位
- 三元素定位法
- 核心价值三层次
- 品牌主张

### 4. 整合营销策略
- 营销目标
- 品牌核心价值
- 品牌主张
- 策略原则
- 品牌调性

### 5. 推广策略
- 创意策略：广告目标、创意概念、创意表现
- 传播策略：传播目标、媒介组合、排期预算
- 公关策略：公关目标、主题概念、公关形式

### 6. 营销组合
- 产品策略：产品组合、产品进化、生命周期
- 价格策略：定价策略、调价策略、价格营销
- 渠道策略：渠道规划、渠道选择、渠道维护
- 促销策略：促销活动、促销组合

## 品牌价值公式

```
品牌溢价 = 感性价值 + 理性价值 - 价格差
```

## 应用原则

1. 品牌提案类需求：先故事线（为什么），再整合营销（怎么做）
2. 品牌升级类需求：用核心价值三层次诊断升级路径
3. 营销策略类需求：用六步流程系统规划
