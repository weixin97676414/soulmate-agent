# 品牌策略与提案

## 适用场景

- 品牌诊断、定位升级、品牌故事/叙事、整合营销、融资路演、商业计划书、注意力战术、蹭热点。
- 触发词：品牌诊断/困境/卡点/危机、品牌定位/升级/战略/资产/差异化/护城河、品牌故事/叙事/命名/slogan/核心价值/主张/架构/矩阵、品牌传播/营销/增长、消费洞察/用户画像/整合营销/营销策略/SWOT、品牌提案/路演说服/投资人演示/融资演讲/BP 商业计划书、赛道选择/市场规模/新品牌从 0 到 1/品牌全案/品牌故事线。

## 步骤（四步执行流程）

1. **问题识别**：不知道从哪开始 → 品牌第一课 → 总控分诊；不清楚定位 → 故事线方法论 → 4C 分析；要说服投资人 → 整合营销 → 路演框架；不会写 BP → 红杉框架 → 商业模式。
2. **诊断**：收集现状（产品/用户/渠道/团队）→ 用 **4C 框架**（Context 市场背景 → Corporation 品牌本体 → Consumer 目标用户 → Competition 竞品对比）→ 判断核心问题是定位不清、传播无效还是增长乏力。
3. **策略**：三层价值体系（基础价值→优秀价值→卓越价值）+ 品牌叙事五层（定位/命名/Slogan/视觉符号/关键触点）→ 生成定位/叙事/营销方案。
4. **提案**：Nancy Duarte 演示设计 → 乔布斯演讲法 → 西奥迪尼影响力 → 红杉资本框架。

## 核心方法论（11 套，按能力分组）

- **品牌建设**：品牌第一课（总控分诊/资源扫描/系统级判断）、万科故事线（4C 分析/超级场景/身份构建）、罗兰贝格整合营销（四问框架/三元素定位/核心价值三层次）。
- **投资说服**：红杉资本论证框架（市场洞察 TAM/SAM/SOM、竞争格局与护城河、商业模式与单位经济、团队论证）、西奥迪尼影响力六原则（互惠/承诺一致/社会认同/权威/稀缺/喜好）、Nancy Duarte 演示设计（对比落差/英雄旅程/谷底反转/视觉隐喻）。
- **演讲谈判**：乔布斯演讲法（一句话开场/三个关键点/数字+故事/少字多图/CTA 结尾）、卡尼曼决策心理（框架效应/损失厌恶/认知偏误/参考点依赖/峰终定律）、沃斯谈判术（BATNA/利益 vs 立场/共同利益/客观标准）。
- **注意力战术**：孙宇晨注意力收割系统（注意力套利/叙事覆盖/碰瓷/数字轰炸）——⚠️ 争议性，仅适用早期快速获取注意力/危机翻盘/短期冲刺；**禁用**于长期信任品牌、强调专业可靠业务、已有稳定口碑企业。
- **一键输出**：把品牌策略整合为完整提案结构（SMP、叙事体系、整合营销方案、路演/BP 要点），可导出为演示分页大纲。

## 品牌整合营销六步流程

1. 市场扫描（市场分析、竞争格局、品牌写真、消费观察）
2. 竞争策略（SWOT、优势策略、补强策略）
3. 品牌定位（三元素定位法、核心价值三层次）
4. 整合营销策略（核心价值、品牌主张、策略原则）
5. 推广策略（创意、传播、公关）
6. 营销组合（产品、价格、渠道、促销）

## 输入输出

- 输入：品牌现状（产品、用户、渠道、团队）、要解决的场景（诊断/建设/提案/BP/蹭热点）。
- 输出：4C 诊断结论、定位与叙事体系、整合营销方案、提案/路演/BP 结构（可导出为演示分页大纲）。

## 注意事项

- 验证标准：命中触发词；按"诊断→建设→提案"三步执行；引用六大方法论中至少 2-3 个框架；给可执行建议而非泛泛而谈。
- 孙宇晨注意力战术有争议、可能损害长期品牌信任，使用前必须提示风险并由用户确认。
- 提案交付文本/Markdown 结构稿与演示分页大纲，不做真实 PPT 文件渲染。
- 不编造市场数据、用户画像或案例；缺数据标注待补充。

## 可复用示例

输入："我们的国货个护品牌增长停滞，帮我诊断并给定位升级方案。"
做法：4C 分析（市场背景/品牌本体/目标用户/竞品）→ 判为"定位模糊"→ 三层价值定卓越价值=身份认同 → 叙事五层补齐 slogan 与关键触点 → 用西奥迪尼+Duarte 包装成提案结构。
