# 通用营销文案写作

**边界**：只做通用转化文案（AIDA/PAS/FAB：标题、正文、CTA、异议处理、信任证据与 A/B 迭代）；内容创作框架与多平台内容矩阵、创意提案 / pitch deck、战术模块路由库不在本技能范围。

## 适用场景

- 落地页、销售页、邮件、广告、产品描述等任何要以文字推动决策的文案。
- 需要写标题、CTA、卖点、异议处理、信任背书。
- 触发词：写文案、copywriting、落地页文案、标题、写销售页、广告文案、邮件文案、说服性写作。

## 核心判断

文案的四个职责，缺一即失败：**抓注意 → 造欲望 → 消摩擦 → 催行动**。
它不是创意写作，是策略写作。

## 步骤

1. **选框架**（三选一）
   - **AIDA**（Attention/Interest/Desire/Action）：落地页、邮件、销售页。
   - **PAS**（Problem/Agitate/Solution）：痛点型产品、受众已自知问题。
   - **FAB**（Feature/Advantage/Benefit）：讲清产品价值、与竞品差异化。
2. **写标题**：标题占成败 80%。用公式：承诺 / 提问 / How-to / 数字 / 负面 / 好奇心缺口 / 转变。
   - 要具体（"90天加$10K MRR" 优于 "增长业务"）；先讲结果，不讲方法。
3. **写 CTA**：公式 = 行动动词 + 得到什么 + 紧迫或省事。
   - 反面："提交""点击这里""了解更多"。正面："开始免费试用""领取模板""预约策略通话"。
   - 位置：首屏、讲完价值后、长页每个价值段后。
4. **加情绪触发器**：FOMO、损失厌恶、地位欲、省事欲、挫败、希望。先用情绪勾住，再用逻辑（功能/证据/数字）让人自我说服。
5. **预先处理异议**：太贵→算 ROI；不适合我→同类客户案例；没时间→"10 分钟设置"；万一没用→退款保证；再想想→涨价/限量。
6. **堆信任证据**：证言（带姓名头衔公司）、案例、数据、社会证明、资质。分散在页面各处，不要堆一块。
7. **A/B 测试迭代**：一次只改一个变量（标题/CTA/卖点顺序/长度/语气），跑 7–14 天或到统计显著，赢家留下再测新变量。

## 输入输出

- 输入：产品/服务、目标受众、核心 CTA、价格、关键卖点、品牌调性。
- 输出：可发布的标题、正文、CTA、异议处理段、信任证据建议；A/B 版本对。

## 注意事项

- 讲利益不讲功能；清晰胜过聪明；别用行话。
- 一页一个明确 CTA，多选项等于没选项。
- 用受众的语言，说受众的痛点与渴望的结果。

## 可复用示例（SaaS 落地页）

```
ATTENTION: 每周花 10 小时做客户报告？10 分钟自动化它。
INTEREST:  多数代理要跨 6 个工具拉数据拼一份报告。客户不在乎你的流程，只要洞察。
DESIRE:    想象每周一自动发出品牌化报告。客户保持知情，团队专注真正增长账户的工作。
ACTION:    开始 14 天免费试用——无需信用卡。
```
