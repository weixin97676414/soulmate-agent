# 增长工程

**边界**：只做增长实验与 AARRR 增长环（增长健康评分、北极星与增长指标树、ICE 实验引擎、AARRR 打法、增长环与留存规模化）；企业级 KPI 体系 / 指标树规范 / 仪表盘不在本技能范围；单点转化漏斗诊断不在本技能范围。

## 适用场景

- 从 0 用户到指数增长的系统化增长：实验引擎、病毒机制、渠道手册、漏斗优化、留存环、规模化框架。
- 增长领导决策：获客、留存、实验、增长系统。
- 触发词：增长、growth、增长引擎、增长实验、获客、病毒传播、增长循环、留存、AARRR、北极星指标、规模化、CGO、增长负责人。

## 步骤

1. **增长审计**：跑 8 维健康评分（产品市场契合 3x / 激活率 3x / 第 4 周留存 3x / 推荐与病毒 2x / 每用户收入 2x / 渠道多样性 1x / 实验速度 2x / 数据基建 1x）。68-85 = 可增长；50-67 = 先修基础；<50 = 停增长投入、修产品。
2. **PMF 验证门**：未通过前不投增长。
3. **定北极星指标（只选一个）**：按业务类型选择（SaaS 周活跃 / 市场 GMV / 媒体时长 / 电商订单 / 社交 DAU÷MAU）。配支撑指标树。
4. **实验引擎（核心增长环）**：用 ICE 评分（Impact/Confidence/Ease）排优先级，写假设、算样本量、跑整业务周期（含工作日+周末）。
5. **AARRR 分阶段手册**（获取/激活/留存/推荐/收入）。
6. **病毒机制与增长环**：设计自增强系统（用户生成内容、邀请机制、网络效应、社会证明；SEO 飞轮等）。
7. **漏斗优化（CRO）** 与 **留存再激活**。
8. **规模化**：从"跑通"到 10x；增长团队结构；技术工具栈。
9. **每周增长复盘**（用第 14 节模板），避开反模式。

## CGO 核心规则（7 条）

1. **留存先于获客**（往漏桶里灌水浪费钱；5% 留存提升可翻倍 LTV）。
2. **每个阶段只盯一个指标**。
3. **速度优于完美**（跑 10 个测试找 1 个赢家）。
4. **可持续循环优于噱头**（复利 > 一次性；病毒环 > 付费脉冲）。
5. **上游更便宜**（激活先于付费放量；$1 修 onboarding = $10 获客）。
6. **行为优于问卷**（用户不说谎，问卷会）。
7. **先 10x 再 10%**（先找对杠杆再优化）。

**阶段重点**：Pre-PMF（留存信号、激活实验、人工增长）→ Seed（找一个可扩展循环、埋指标）→ Series A（增长团队、实验速度、付费获客）→ Series B+（多循环、增长工程、国际化）。
**常见陷阱**：虚荣指标、照搬他人渠道、过早规模化、在错误的事上做 10% 优化、增长表演。
**需人工判断**：北极星选择、定价模型变更、增长 vs 盈利取舍、重大转向、合作交易结构。

## 输入输出

- 输入：当前增长数据、产品/业务类型、阶段、目标。
- 输出：增长健康评分、北极星与指标树、实验清单（ICE 排序）、AARRR 打法、增长环设计、漏斗优化建议、留存方案、规模化路线、每周复盘表。

## 注意事项

- 不编造用户数据或效果；缺失指标标注"待补充"。
- 未过 PMF 门不投增长；留存未修不放大付费。
- 关键硬信息：cgo 参考文件（acquisition/retention/experiments/metrics）见配套资产；D1/D7/D30 留存基准（社交 40/20/10、SaaS B2B 60/40/25、电商 20/10/5、休闲游戏 35/15/5）。

## 可复用示例

输入：SaaS，DAU/WAU 数据、激活率、周 4 留存。
做法：跑 8 维评分（如 54 分 = 先修基础）→ 检查 PMF 门 → 定北极星"周活跃用户" → 用 ICE 排出 5 个激活实验 → 设计推荐环 → 出每周复盘表。
