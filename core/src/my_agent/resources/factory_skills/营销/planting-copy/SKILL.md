# 种草软文成交

**边界**：只做营销侧种草软文成交（真实场景种草文、评论钩子、私信承接、质检）；小红书图文笔记的图文生成、纯舆情监控与评论回复运营不在本技能范围。

## 适用场景

- 产品种草、种草软文、小红书笔记、朋友圈内容。
- 评论区钩子、私信承接、咨询转化。
- 把「广告」写成「真实分享」：真实场景 + 边界 + 轻行动。
- 触发词：种草、种草软文、小红书笔记、朋友圈内容、评论钩子、私信承接、爆文复写、10 条种草、内容矩阵。
- 高风险行业（医疗、金融、法律、教育、命理）降承诺表达。

## 核心链路

```text
真实场景 -> 小刺痛/小尴尬 -> 误区 -> 发现 -> 产品/方法出现 -> 适合谁/不适合谁 -> 轻行动 -> 私信承接
```

## 最高原则（8 条）

1. 真实感优先于销售感。2. 场景优先于卖点。3. 边界优先于夸大。4. 证据优先于形容词。5. 轻行动优先于逼单。6. 人群心智优先于模板。7. 合规优先于刺激。8. 先定义赢家，后批量复写。

## 步骤

1. **先问清 / 补齐输入**：产品、目标用户、平台、场景、痛点、卖点、真实证据、希望动作、禁区。信息不足时基于行业常识反推并标注默认假设，最多问 3 个关键问题。
2. **任务路由**（按需求读对应参考）：
   | 需求 | 输出 | 必读参考 |
   |---|---|---|
   | 完整种草文/小红书/朋友圈 | 场景+标题+正文+评论/私信 | `assets/seeding_conversion_operating_system.md`, `assets/platform_and_private_domain_playbook.md` |
   | 旧文案太硬 | 去硬广诊断+真实感重写 | `assets/authentic_scene_engine.md`, `assets/quality_gate.md` |
   | 评论钩子/私信承接 | 低门槛动作+三轮私信+异议处理 | `assets/comment_dm_conversion_engine.md` |
   | AI 技能包/课程/咨询 | 抽象产品具体化（输入输出+边界） | `assets/seeding_conversion_operating_system.md` |
   | 高级不 low/情绪/人群 | 调语气、身份、尊重感 | `assets/emotion_audience_trust_engine.md` |
   | 医疗金融法律教育命理 | 降承诺、审慎表达 | `assets/compliance.md` |
   | 爆文复写/10 条/跨平台/转投放 | 赢家框架卡+有效咨询口径+母子版本 | `assets/winner-framework-upgrade.md`, `assets/quality_gate.md` |
   | 满分/终极/最高标准 | 100 分质检逐项复核 | `assets/quality_gate.md` |
3. **产出成稿**：先给策略判断，再给标题备选、正文、评论钩子、私信承接、不硬广检查。
4. **过 100 分质检门**（低于 90 重写，95+ 可交付）：真实场景 15 / 用户共鸣 15 / 购买理由 18 / 信任证据 12 / 不硬广 12 / 行动承接 12 / 平台适配 8 / 合规安全 8。
5. **发布后看早期信号**：不套用固定咨询数量阈值，与同账号同平台同形态基线比较；目标是「目标关系或有效咨询信号相对基线改善」。有改善→保留母框架做单变量小测；只有点赞→换场景/人群/证据；多轮无目标信号→退役框架。

## 输入输出

- 输入：极简输入即可（产品、用户、平台等）。
- 输出：可直接发布的种草成稿、标题 TOP、评论钩子、私信三轮承接、合规风险与替代表达、质检表。

## 注意事项

- 一票否决项：像广告不像分享、一上来堆功能资历口号、伪造案例/销量/反馈、承诺收益疗效排名通过率成交、没有下一步动作、高风险行业用绝对化表述。
- 涉及真实案例、销量、体验、医疗、金融、法律事实，必须由用户提供并人工确认，**不得编造**。
- 输出供人工审核后发布，不替代平台合规审核、法务审核或行业专业判断。
- 用户要求爆文复写、10 条种草、跨平台复制、投流或内容矩阵时，**必须先读** `assets/winner-framework-upgrade.md`。
