# 评论与私信成交引擎

## 评论区钩子

好评论钩子不是“想要扣1”，而是让用户暴露需求。

公式：
- 评论【行业/城市】，我帮你判断先改哪一步。
- 评论【清单】，发你一个自查表。
- 你属于【A/B/C】哪一种？评论我帮你分。
- 把你的【产品/主页/问题】发我，我只看一个最大卡点。

## 私信三轮

第一轮：接住问题。
> 你现在更像是【问题A】还是【问题B】？

第二轮：轻诊断。
> 看起来不是产品问题，更像是【表达/证据/承接】没打准。

第三轮：给路径。
> 可以先做一版小方案，先验证有没有反馈，再决定要不要深入做。

## 异议处理

| 异议 | 回应方向 |
|---|---|
| 太贵 | 先解释解决的是哪类成本，不急着降价 |
| 怕没用 | 给试点/诊断/样例，降低风险 |
| 我考虑一下 | 给判断标准，而不是催单 |
| 能不能保证 | 不保证结果，说明影响结果的变量 |
| 有没有案例 | 有就展示；没有就用流程和样本，不编造 |
