# 平台与私域适配

## 小红书

标题：具体人群 + 场景 + 轻反差。

正文前三行：必须说中处境，别先介绍产品。

结尾：评论/私信低门槛动作。避免密集使用购买、下单、成交等硬销售词。

## 朋友圈

语气：观察、复盘、客户聊天、今天的一个提醒。

不要像公告。朋友圈适合：
- 一段真实经历。
- 一个客户问题。
- 一个行业判断。
- 一个轻量案例。
- 一个可私信领取的模板。

## 私域成交

私域不是轰炸。顺序：
1. 承接具体问题。
2. 问一个筛选问题。
3. 给一个轻建议。
4. 引导下一步诊断/预约/报价。

## 视频号/熟人圈

要克制，有判断，不要太low太硬。点赞等于身份表态，所以文案要让人觉得转发有面子。
