# 情绪、人群与信任引擎

## 情绪调性

| 场景 | 语气 |
|---|---|
| 低价大众 | 快乐、轻松、占便宜 |
| 中价服务 | 温柔、解释、陪伴 |
| 高价服务 | 克制、专业、边界 |
| 初创破局 | 尖锐、反常识、替用户出气 |
| 熟人圈 | 有判断、不过度卖惨、不硬卖 |

## 人群顾虑

| 人群 | 顾虑 | 写法 |
|---|---|---|
| 老板 | 花钱无结果 | 讲试点、成本、有效咨询 |
| 宝妈 | 安全、真实、怕坑 | 讲边界、过程、体验 |
| 女性消费 | 怕掉价、怕踩雷 | 讲审美、细节、真实反馈 |
| 年轻人 | 怕麻烦、怕土 | 讲方便、反差、轻行动 |
| AI创业者 | 怕抽象、卖不出去 | 讲输入输出、应用场景 |

## 尊重感
