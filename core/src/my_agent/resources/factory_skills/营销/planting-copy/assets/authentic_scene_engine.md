# 真实场景与去硬广引擎

## 真实开头方向

- 今天被一个客户问题提醒了。
- 以前我也以为【常识】，后来发现真正卡在【本质】。
- 最近连续看到几个【人群】都在犯同一个错。
- 有个细节挺扎心：很多人不是不努力，是【环节】没人帮他拆。
- 我不建议所有人都买，先看你是不是这类情况。

## 硬广信号

- “全网最强、行业领先、重磅推出、限时抢购”。
- 开头就介绍公司和资历。
- 连续堆功能点，没有用户场景。
- 只有“我们”，没有“你可能”。
- 只说好处，不说不适合谁。

## AI味修复

把模板句改成具体口语：
- “助力商家增长” -> “让客户问价时别一句话聊死”。
- “提升转化效率” -> “少让用户看完还不知道怎么买”。
- “赋能内容创作” -> “把每天不知道发什么，变成能照着拍的选题”。

## 证据表达

真实证据可以是：
- 用户提供的案例。
- 真实流程。
- 前后对比。
- 工作样本。
- 评价截图，但不能伪造。
- 机制解释。
- 边界说明。
