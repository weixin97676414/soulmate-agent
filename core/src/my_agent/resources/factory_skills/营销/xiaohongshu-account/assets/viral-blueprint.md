# 爆款视频结构拆解手册

> **硬要求**：做本节分析前，必须先用 Read 工具逐张打开 `media/<note_id>/sheet.jpg`。
> 只凭标题和点赞数写"前 3 秒钩子强"属于编造，禁止输出。

## 1. 素材读法

```
media/<id>/cover.jpg     封面首图 → 拆封面结构
media/<id>/sheet.jpg     4×5 关键帧拼版（2 秒/帧）→ 拆分镜与节奏
media/<id>/frames/NN.jpg 单帧 → 需要细看某一镜时打开
media/<id>/video.mp4     原片 → 需要听口播/看转场时直接读视频
```

`sheet.jpg` 的读法：从左上到右下即为时间顺序，每一格约 2 秒。
观察**画面主体的变化频率**即可判断剪辑节奏：

- 连续 3 格画面几乎不变 → 该处是长镜头/口播段
- 每格都换主体 → 快剪段，通常在开头或高潮
- 出现字幕条大变化 → 信息点切换

### 钩子类型库（用于归类与复用）

| 类型 | 结构 | 示例 |
|---|---|---|
| 结果前置 | 先给结果，后给方法 | "30 天，我从 130 到 108" |
| 反常识 | 否定普遍做法 | "别再用散粉定妆了，越定越脱" |

| 冲突制造 | 对立场景 | "我妈说我败家，直到她看到账单" |
| 视觉奇观 | 画面本身抓人 | 前后对比同框 / 极端特写 |

|---|---|---|---|---|---|

**信息密度曲线**是判断视频是否"耐看"的关键：
健康曲线是「高 → 中 → 高 → 中 → 高（CTA）」，全程高会疲劳，全程低会划走。

## 4. 运镜与剪辑节奏

| 要素 | 观察点 | 常见有效模式 |
|---|---|---|
| 景别序列 | 远→中→近→特的排列 | 开场特写吸睛 → 中景说明 → 特写证明 |
| 运镜 | 固定 / 推拉 / 摇 / 跟随 / 手持 | 教程类以固定为主，vlog 以跟随为主 |
| 转场 | 硬切 / 叠化 / 遮罩 / 匹配剪辑 | 快剪段硬切，情绪段叠化 |
| 镜头时长 | 单镜平均秒数 | 教程 2-4s，口播 4-8s，vlog 1-3s |
| 字幕节奏 | 每行停留时长与换行频率 | 1.5-2s/行，每行 ≤ 15 字 |
| BGM | 有无卡点 | 卡点视频在信息切换点换镜 |

## 5. 结尾与 CTA 拆解

| 结尾类型 | 结构 | 适用 |
|---|---|---|
| 提问式 | "你更倾向 A 还是 B？" | 拉评论（评论权重高） |
| 诱导收藏 | "存下来照着做" | 拉收藏（收藏是搜索权重信号） |
| 系列预告 | "下期讲 XX" | 拉关注 |
| 私域引导 | "评论区扣 1 领资料" | 引流（注意违禁词） |
| 反转型 | 最后一句反转制造记忆点 | 拉完播 |

**对照 `comments.intent_distribution` 验证**：
如果"求链接/求购买"占比高但内容里没有承接动作 → 明确的转化缺口。

## 6. 封面拆解表

| 笔记 | 文字字数 | 文字位置 | 主体（人脸/产品/场景） | 配色 | 是否有箭头/圈注 | 点赞 |
|---|---|---|---|---|---|---|

封面规律总结要回答三个问题：

1. 该账号封面**几套模板**在轮换？（1 套 = 强记忆点，多套 = 在测试）
2. 高赞封面与低赞封面的**差异变量**是什么？（字数？人脸？对比？）
3. 封面文字与标题是**重复**还是**互补**？（互补更好，能多给一层信息）

## 7. 输出：可模仿执行的结构模板

最终必须产出一份**别人照着就能拍**的模板：

```markdown
### 模板名称：<从该账号提炼，如「痛点前置 + 三段式教程」>

**适用选题**：<哪类选题用这个模板>
**总时长**：XX 秒
**分镜表**：
| 镜号 | 时长 | 画面 | 景别 | 运镜 | 口播/字幕 |
| 1 | 0-3s | ... | 特写 | 固定 | "钩子原句结构" |
| 2 | 3-8s | ... | 中景 | 推 | ... |
...
**必备元素**：<3 个不能省的东西>
**可替换变量**：<能换的内容，保证批量复制>
**验收指标**：3 秒完播率 ≥ X%，收藏赞比 ≥ X%
```

## 8. 图文笔记的结构拆解（video_rate 低时适用）

| 要素 | 观察点 |
|---|---|
| 首图 | 是否为信息量最大的一张（清单/对比/前后） |
| 图片数量 | `formats.images_per_note`，9 图是最优上限 |
| 图片功能分布 | 封面 / 干货 / 过程 / 结果 / 引导，各几张 |
| 图内文字 | 每张图承载几个信息点 |
| 正文结构 | 是否分段、有无小标题、有无 emoji 分隔 |
