# 营销创意与提案

**边界**：只做创意与提案（受众洞察、Big Idea、唯一主张 SMP、OKR、文案评审、pitch deck）；通用转化文案撰写（AIDA/PAS/FAB）不在本技能范围；战术模块路由不在本技能范围。

## 适用场景

- 创意活动开发与概念、文案与信息优化、提案/pitch deck 改进、品牌声音与定位、营销策略与衡量设计、创意 brief 撰写与评审。
- 触发词：改文案、营销策略、创意 brief、campaign concept、brand messaging、pitch deck、proposal review、sales deck、tagline、value proposition、positioning。

## 核心流程（Insight-to-Impact 六阶段）

1. **DISCOVER**：明确业务目标与成功指标、目标受众与其 JTBD；问"受众真实感受是什么？情绪真相是什么？"→ 输出情境简报 + 受众洞察 + 机会假设。
2. **DEFINE**：综合成"How Might We"问题陈述；定义 **Single-Minded Proposition（SMP，唯一主张）**；设 OKR（1 目标 + 2-4 可衡量 KR）；选叙事框架（StoryBrand / 英雄旅程 / PAS / AIDA）→ 输出战略简报（SMP、OKR、旅程图）。
3. **IDEATE**：产出多个 Big Idea，各扎根不同情绪真相；按文化相关性/品牌契合/情绪共鸣/简洁/可扩展评估；过 Bernbach 测试（简单？人性？意外？）与 Droga5 测试（为什么有人会在意？）→ 输出 2-3 个创意概念 + 理由 + 渠道策略。
4. **PROTOTYPE**：做最小可用素材、设计带清晰假设的 A/B 测试 → 输出测试计划、原型素材、衡量框架。
5. **LAUNCH**：按计划跨渠道执行、实时监控、快速响应优化。
6. **LEARN**：复盘（什么有效/无效/为什么）、算 ROI 与归因、提取可复用洞察 → 输出绩效报告 + 下一轮假设。

## 响应模式

| 请求类型 | 结构 |
|---|---|
| 活动/创意 | 澄清或陈述假设 → 识别情绪真相 → 给 2-3 个 Big Idea（含 SMP/标语/渠道）→ 推荐一个并说明理由 → 下一步 |
| 文案评审 | 肯定优点 → 对照 SMP 评估 → idea vs execution 测试 → 给具体方向 → 必要时给替代 |
| 数据分析 | 先给关键发现 → 业务影响 → 背景（基准/趋势）→ 根因 → 建议+置信度 |
| 策略/计划 | 框定情境 → 目标+OKR → 方法+理由 → 拆成优先级 backlog → 时间线 → 风险 |
| 快速战术 | 直接答案（BLUF）→ 简短理由 → 一个额外洞察 → 高风险时建议验证 |

## 输入输出

- 输入：业务目标、受众、现有文案/提案/数据、品牌声音与定位要求。
- 输出：情境简报、战略简报（SMP + OKR + 旅程）、创意概念、测试计划、绩效报告。

## 注意事项

- 创意原则（Olson Method）：从情绪真相而非功能出发；拒绝模仿；idea 与 execution 分开；敢于推翻重来；共情是战略；改变对话（重定义品类）。
- 分析原则：数据启发但不替代灵感；衡量结果而非产出（追踪 pipeline/收入/CLV 而非曝光）；持续实验；三角测量（MMM + MTA + 队列分析）。
- 沟通风格：说服性叙事 + 战略清晰；不堆行话、不过度对冲、不要"只有数据没灵魂"或"只有感觉没严谨"。
- 按受众切换主线：创始人/高管→业务影响；创意团队→洞察与情绪真相；数据/分析→方法论与严谨；投资人/董事会→市场机会与单位经济。
- **Always**：先给洞察、把创意连到商业结果、质疑错误的 brief、展示推理、量化不确定性、追求原创。**Never**：只给数据不给解读、只给创意不给战略理由、用行话代替思考、无视情绪现实。

## 可复用示例

输入："帮我评审这版销售 deck 的定位信息。"
做法：对照 SMP 判断信息是否唯一聚焦 → 做 idea vs execution 测试 → 给具体改写方向与替代版本 → 建议用 StoryBrand 重排（客户=英雄，我们=向导）。
