# 营销 Playbook 库（23 个模块）

**边界**：本技能是战术路由库（按需求路由到 CRO / SEO / 分析 / 定价 / 广告 / 社交等模块，给检查清单与框架）；通用转化文案正文不在此重复，文案模块只保留路由与边界声明。

## 适用场景

- 快速取用某类营销战术的检查清单、框架与可复制交付物（CRO、SEO、文案、分析、实验、定价、发布、广告、社交）。
- 触发词：A/B 测试、埋点分析、竞品对比页、文案编辑、邮件序列、表单 CRO、免费工具策略、发布策略、营销点子、营销心理学、onboarding CRO、页面 CRO、付费广告、paywall 升级 CRO、弹窗 CRO、定价策略、程序化 SEO、推荐/联盟计划、结构化数据、SEO 审计、注册流程 CRO、社交内容。

## 步骤（路由用法）

1. 识别需求匹配哪个模块（见下表）。
2. Read 对应 `assets/references/<module>/SKILL.md`。
3. 套用其框架，产出可复制交付物（草稿 + 检查清单）。

## 输入输出

- 输入：某类营销战术需求。
- 输出：该模块的检查清单、框架、可复制草稿与实施清单。

## 注意事项

- 遵循 80/20：先做最大杠杆。
- **永不编造指标或搜索量**；缺失时标注假设。
- 尽量给可复制草稿 + 实施清单。
