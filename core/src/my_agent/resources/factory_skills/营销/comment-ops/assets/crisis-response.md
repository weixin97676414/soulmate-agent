# 差评与舆情危机三级回应话术库

## 定级标准（回应前必做）

| 维度 | 轻度 | 中度 | 重度 |
|---|---|---|---|
| 内容 | 调侃、抬杠、情绪宣泄，无具体指控 | 有具体质疑：质量、价格、服务、专业性 | 涉及安全、健康、欺诈、虚假宣传指控 |
| 扩散 | 单条评论，点赞 <50 | 点赞破百 / 出现跟评附和 | 被截图外传 / 多平台出现 / 有人整理「实锤」 |
| 主体 | 路人 | 疑似真实用户 | 自称受害者 / 疑似有组织带节奏 |

三个维度里**任何一个**达到更高等级，就按更高等级处理。定级宁高勿低。

## 轻度：幽默化解

目标：把杠精变成捧哏，演给围观群众看。响应时限：不着急，24 小时内即可，甚至可以等它赞多了再回（曝光更大）。

**话术模板：**
- 吐槽价格贵：「贵有贵的道理：贵在我真的不会亏本卖（小声）。不过 __ 场景下其实有 __ 平替方案，我发过一期，需要的话评论区扣 1」→ 化解 + 顺手引导互动
- 说内容水：「这期确实放水了，因为上期太干，被投诉噎着了」
- 「就这？」型：「对，就这。就这还看完了，你的时间成本已经计入我的粉丝资产，谢谢惠顾」

**禁忌**：轻度回应可以皮，但不能让对方下不来台。留台阶公式：调侃自己 70% + 调侃对方 30%，绝不 0:100。

## 中度：事实澄清三段式

目标：让围观群众看到「这个号讲道理」。响应时限：12 小时内。

**三段式结构：共情 → 摆事实 → 给出口**

1. **共情（1 句）**：先承认对方感受的合理性，不是承认指控。
   句式：「理解你的顾虑，如果我是你看到 __ 也会有疑问」「这个问题问得好，值得展开说」
2. **摆事实（2-3 句）**：只摆可验证的事实，不用形容词。有数据给数据，有资质给资质，有过程给过程。
   句式：「实际情况是：__（时间/数据/凭证）」「这期视频 __ 分 __ 秒有完整过程，可以回看」
3. **给出口（1 句）**：给对方一个不丢脸的收场方式，同时给围观者一个行动指引。
   句式：「如果还有疑问，私信我发你完整 __」「介意的朋友可以先看 __ 再决定，不着急」

**完整示例：**
质疑：「这测评肯定恰饭了，缺点一个不提」
回复：「理解，现在恰烂钱的测评确实多，警惕是对的。这期没有商务合作（简介里合作机型都会标注），缺点在 3 分 40 秒讲了续航和发热两个点，可能剪得太快了。下期我把优缺点做成表格放片尾，方便大家快进直接看。」

**中度禁忌**：不许反问（「你买了吗就说？」）、不许甩锅用户（「你不会用」）、不许删评——中度阶段删评是把中度推向重度的最快方式。

## 重度：正式公关四步

目标：止损、收敛、闭环。**立即停止一切抖机灵、玩梗、表情包。**

**第一步：黄金 4 小时首次响应**
不需要查清事实才回应，先表态「已看到、在核实」。
模板：「已关注到 __ 的反馈，我们非常重视，正在逐一核实。核实结果将于 __（给出明确时间，24-48h 内）在本评论区/置顶更新。给大家带来困扰，先说声抱歉。」
要点：给明确时间点；「先致歉困扰」不等于承认指控，但能降温。

**第二步：口径统一**
- 全平台只用一份声明文本，所有小号、员工号、客服停止自由发挥。
- 声明只包含：事实、行动、时限、渠道，四要素之外一个字不多写。
- 绝对不出现的词：「个别用户」「恶意抹黑」（在有实锤前）、「法务部已介入」（除非真的介入且准备起诉）。

**第三步：行动承诺 + 过程公开**
模板：「核实结果：__。对受影响的用户，我们将 __（退/换/补偿的具体方案与操作路径）。已完成整改：__。防止再次发生的措施：__。」
要点：补偿方案必须具体到操作步骤，「联系客服处理」是无效承诺，「私信发送订单号，48 小时内原路退款」才是承诺。

**第四步：闭环回访**
7 天后在原声明下追评处理进度（已处理 X 件 / 剩余 X 件 / 卡在哪），这一步 90% 的账号不做，做了就是口碑逆转点。

**重度阶段的三条铁律：**
1. 事实没核清之前，不否认、不承认、只承诺核实。
2. 当事人评论一律不删；带节奏的攻击性跟评可折叠，但先截图存证。
3. 若指控涉嫌诽谤或已影响人身/经营安全：全程截图录屏存证（含 URL 和时间），必要时公证，并建议用户咨询律师——话术解决舆论，解决不了法律。

## 特殊情形速查

- **对方是同行假扮用户**：不拆穿（拆穿=撕逼，围观者只看到撕逼），按真实用户的中度流程处理，用专业度碾压。
- **差评有理，我方确实错了**：跳过所有辩解，直接道歉 + 补偿 + 整改三连，认错快是唯一的加分项。
- **陈年旧事被翻出**：不装死。模板：「这是 __ 年的事，当时的处理是 __，现在回看确实 __。这几年的改进：__。」
