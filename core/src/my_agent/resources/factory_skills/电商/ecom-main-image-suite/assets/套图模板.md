## 四、提示词撰写要点

1. **文字全部用「」括起**并注明颜色，模型会按字渲染；括号外只描述画面。
2. **数字与符号**（¥9.9、①②③、·）可正常渲染，但价格贴纸文字 ≤4 字符位最稳。
3. **每张图文字元素 ≤6 处**：主标题 1 + 副标/小字 1-2 + 标签/徽章 2-3 + 底部横条 1。贪多必乱码。
4. **颜色锚点写具体色名**（深蓝色、金色、米白色、红色爆炸贴），保证 5 张成套统一。
5. **收口句固定**：结尾统一加"整体简洁干净、对比强烈、手机端 3 秒可读，商用电商设计感"。
6. **风格词按图切换**：首图"大字报"、痛点图"扁平插画风"、操作图"信息图卡片风格"、效果图"干净的信息图"、转化图"扁平大字报"。

## 五、常见问题处理

| 问题 | 处理 |
|------|------|
| 429 Throttling.RateQuota | sleep 20 后原参数重试，最多 2 次 |
| 个别汉字错字/缺笔画 | 同提示词加 `--seed` 换种子重生成该张；或把该处文字改成更短措辞 |
| 标题被裁切 | 提示词中主标题改 ≤12 字并注明"居中留白" |
| 5 张风格不统一 | 检查是否漏写背景色/横条文案，逐张补齐后重生成 |
| 需要改局部文字 | 改用编辑模式：`--images 原图.png --prompt "把「XX」改成「YY」" -m qwen-image-edit-max` |
