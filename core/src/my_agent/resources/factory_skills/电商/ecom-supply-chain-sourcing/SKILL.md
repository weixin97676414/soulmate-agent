# 1688 供应链选品与找厂（选 · 找 · 谈 · 算）

配套文件：`assets/selection.md`、`sourcing.md`、`inquiry.md`、`financial.md`、`report-template.md`；脚本 `scripts/`。

## 适用场景

- 跨境或内贸供应链选品，确定"卖什么、去哪找货源"。
- 在 1688 上找源头工厂（排除中间商），对比供应商。
- 生成询盘/砍价话术，或做单品利润核算。
- 触发词：1688、找工厂、货源、OEM、ODM、供应链、选品、拿样、砍价、跨境货源、1688 爆款。

## 步骤

1. **选品分析（选）**：输入产品链接 / 图片 / 关键词 / 需求描述，输出热点、材质工艺趋势、1688 同类爆款进价区间、竞品平台售价、推荐切入角度。
   - 判据：避开红海，只推有改良点或材质升级的潜力货源。
2. **精准找商（找）**：按供应商硬指标筛选，锁定 2-3 家。
   - 排除诚信通年限 < 3 年的店铺；优先"实力工厂/超级工厂"标签。
   - 对比维度：近 90 天成交额、复购率、发货时效、跨境证书（CE/FCC/FDA/BSCI）。
   - 识别源头工厂 vs 中间商：看是否自有产线、是否有研发能力。
3. **询盘话术（谈）**：按商业模式（精品独立站 / 低价拼团 / TikTok 直播 / 亚马逊 FBA / OEM 品牌）生成针对性话术。
   - 必含：自我介绍+业务背景（大客户形象）、具体需求（拿样/砍价/MOQ/包材/一件代发）、下单意向和时间节点。
   - 每个工厂给 2-3 套（拿样 / 价格谈判 / OEM 定制）。
4. **利润核算（算）**：
   ```
   单品毛利 = (售价 - 进货价 - 头程运费 - 平台佣金 - 损耗) / 售价 × 100%
   单品利润 = 售价 × 毛利率 × 数量
   ```
   成本项：进货价(FOB)、头程运费、平台佣金（如 Amazon 15%）、预计损耗率、平台售价与汇率。
5. **综合报告**：输出《1688 供应链落地清单》——选品结论 + 供应商对比表 + 谈判策略 + 执行时间表（模板见 `assets/report-template.md`）。

## 输入 / 输出

- 输入：产品链接或图片、关键词、目标市场与客单价、成本假设。
- 输出：结构化选品建议、工厂推荐清单、询盘话术、生意账本、供应链落地清单。

## 脚本

```bash
# 无 Key 抓取搜索结果页
python3 scripts/scraper.py products <关键词>
python3 scripts/scraper.py factories <关键词>
# 官方开放平台 API（需 AppKey，可选增强）
ALI_APP_KEY=xxx python3 scripts/ali_api.py search <关键词>
# 商品/工厂搜索、详情、利润计算、全链路
python3 scripts/search_products.py <关键词>
python3 scripts/search_factories.py <关键词> [--province 省名]
python3 scripts/product_detail.py <商品ID>
python3 scripts/calc_profit.py <进价> <售价> [--platform amazon]
python3 scripts/1688_trader.py full <关键词>
```

可选环境变量：`ALI_APP_KEY`、`ALI_APP_SECRET`（1688 开放平台，基础功能无需凭证）。
依赖：`python3`、`requests`。

## 注意事项

- 输出必须结构化，至少 1-2 个具体 1688 指标（诚信通年限/成交额/复购率），不写空话。
- 利润计算保留两位小数。
- 风险提示强制：液体/电池类提示物流风险；疑似侵权提示专利风险。
- 话术专业且强势（模拟大客户），不模拟零散买家。
- 抓取遵守平台频率限制，避免高频请求。
