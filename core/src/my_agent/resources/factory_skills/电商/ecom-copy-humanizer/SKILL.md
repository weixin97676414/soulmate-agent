# 中文电商文案去 AI 味（Humanizer）

配套文件：`assets/ai-patterns-zh.md`、`platform-guide-zh.md`、`risk-checklist-zh.md`、`output-template.md`、`rewrite-checklist.md`。

## 适用场景

- 把"AI 味重"的中文电商文案改成更像真人运营/卖货团队写的，同时保留卖点与转化意图。
- 场景：详情页润色、广告/投流素材、评论回复/私信话术、直播脚本/短视频字幕、促销文案。
- 触发词：AI 味、文案太假、去 AI 味、润色电商文案、像真人写的。
- **边界**：仅处理电商商品类文案（详情页、投流素材、评论/私信话术、直播脚本、促销文案）的去 AI 味。
- **不适用**：纯翻译、文学创作/品牌宣言、法律医疗金融等高危合规审校、从零写完整营销策略。

## 步骤

1. **诊断 AI 味来源**：
   - 结构类：每段长度相似、连接词过于工整（首先…其次…最后）、句式重复、面面俱到无重点。
   - 用词类：值得一提的是、不仅…而且、为您打造、全方位、一站式、赋能、焕新、品质之选、匠心、臻选（详见 `assets/ai-patterns-zh.md`）。
   - 语气类：太满像 PPT、过度修辞缺事实、承诺多无证据、像写作文不像卖货。
2. **确定商业任务**：提点击（Hook 短狠直接）/ 促下单（卖点具体、降风险、CTA 明确）/ 降疑虑（真实证据、具体数据、退货承诺）/ 回应异议 / 评论互动 / 直播卖货。
3. **按场景改写**（参照 `assets/platform-guide-zh.md`）：
   - 保留核心卖点、利益点、使用场景、CTA；
   - 生硬表达改口语化；空泛承诺改具体可信；
   - 保持中文平台语境，不写翻译腔；不同平台不混写；口语 ≠ 随意。
4. **合规与风险扫描**（参照 `assets/risk-checklist-zh.md`）：
   - 绝对化：最好、第一、顶级、100%、绝对、完美 → 例如 "最好的" → "我们团队用了 X 年打磨的"。
   - 虚假承诺：保证效果、立刻见效、永久、零风险 → "100% 有效" → "XX% 的用户反馈有改善"。
   - 医疗越界：治疗、治愈、药用级、医疗级。
   - 对比贬低：比 XX 品牌好、秒杀同类、吊打竞品 → "在 XX 方面我们做了不同的选择"。
5. **交付前自检**：用 `assets/rewrite-checklist.md` 逐项确认。

## 输出包

1. 问题诊断（标注具体问题句与原因）
2. 主改写版（可直接用或微调，保留核心卖点与商业意图）
3. 备选版 1-2 个（更克制 / 更种草），标注适用场景
4. 风险替换（格式 `原文 → 建议 → 原因`）
5. 使用说明（适合详情页/广告/评论区/直播哪种，是否需再按平台调整）

## 注意事项

- 目标是在"自然表达、转化效率、平台语境、风险控制"间平衡，不是只追求自然。
- 不虚构证据；不把推测写成事实。
- 输入信息太少无法判断卖点/场景/风险时，先追问最小必要上下文。

## 可复用示例

- 前（AI 味重）：> 这款面膜采用先进的玻尿酸科技，为您的肌肤带来全方位的深层滋润。不仅…更能…品质之选，值得信赖！
- 后（详情页）：> 冬天空调房脸紧绷？这片面膜敷 15 分钟，玻尿酸直接把水按进皮肤里。第二天上妆不卡粉。28 片/盒，每天不到 2 块钱。
- 后（小红书）：> 姐妹们！空调房救命面膜找到了 😭 敷完第二天妆服帖到同事问我用了什么，一盒 28 片不心疼。
