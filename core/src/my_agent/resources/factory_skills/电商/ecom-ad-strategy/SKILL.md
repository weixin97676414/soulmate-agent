# 跨平台广告策略（平台组合 · 预算分配 · 受众 · 出价）


## 适用场景

- 独立站/市场卖家做跨平台广告（Google / Meta / TikTok 等）：选平台、分预算、写 brief。
- 已有跨平台投放，需要审计并重新分配预算。
- 触发词：跨平台投放、广告预算分配、ROAS、platform mix、多平台广告、Google/Meta/TikTok 怎么投。

## 关键公式

- **ROAS = 收入 ÷ 广告花费**。
- **Break-even ROAS = 1 ÷ 利润率**：利润率 25%→4.0x；33%→3.0x；50%→2.0x；60%→1.67x；75%→1.33x。
- **Target ROAS** = Break-even ROAS + 利润缓冲，通常取 break-even 的 1.5-2 倍。
- **Max CPA = AOV × 利润率**。

平台 ROAS 基准（2025-2026，行业均值 2.87x）：

| 平台 | 平均 ROAS | Top Quartile | 最适合 |
|------|:---:|:---:|------|
| Google Ads (Shopping) | 4.5x | 6x+ | 高意图搜索 |
| Meta (FB/IG) | 2.2x | 4-5x | 视觉/冲动品、重定向(3.6x) |
| TikTok | 1.4x | 2x+ | 发现型、演示型、年轻受众 |

## 步骤

### 模式 A — 从零搭策略

1. **收信息**（关键：售价/AOV、成本或利润率、月预算、买家行为类型、站点类型、现有流量/邮件列表）。
2. **算 ROAS 框架**：Break-even / Target / Max CPA。
3. **选平台组合**（由买家行为决定）：
   - a) 搜索型 → Google Shopping 为主；b) 视觉型 → Meta 为主；c) 演示型 → TikTok 为主；d) 不确定 → 按产品类型推断并标 ⚠️。
   - 预算 >$1,000/月且有流量/邮件列表 → 加重定向；<$1,000/月 → 只投一个主平台，不铺开。
4. **分配预算**（按产品类型）：
   - 搜索意图品：Google Shopping/PMax 50-60% + Meta 拉新 20-25% + 重定向 10-15% + 测试 5-10%。
   - 视觉/冲动品：Meta 拉新 45-55% + Google Shopping 20-25% + 重定向 15-20% + TikTok 5-10%。
   - 演示/新奇品：TikTok 40-50% + Meta 20-30% + Google Shopping 10-20% + 重定向 10-15%。
5. **出平台 brief**：Google（Shopping/Search/PMax + 关键词主题 + 出价策略 + 日预算 + 关键设置）；Meta（目标 + 受众定向 + 广告组结构 + 版位 + 日预算）；TikTok（目标 + 定向 + Spark Ads/In-Feed/TopView + 内容风格 + 日预算）。
6. **出广告文案与创意方向**：
   - Google：Headline ≤30 字符（写 3-5 条）、Long headline ≤90、Description ≤90（写 2-4 条）、Display path 15×2。
   - Meta：Primary text 前 125 字符可见（上限 2200）、Headline ≤40、Description ≤30、方图 1080×1080、Reels 1080×1920、视频 15-60s（15-30s 最佳）。
   - TikTok：Ad text ≤100、Display name ≤40、9:16 竖版（≥720×1280）、9-15s；**前 2-3 秒必须抓注意力**，别用 logo/慢开场。
   - 每平台另给：创意风格（lifestyle/UGC/对比/前后）、前 3 秒 Hook、2-3 条关键信息、**不该做什么**；并给 2-3 条可直接投喂图像工具的 AI 图片提示词 + 15s 视频分镜（0-3s Hook / 3-8s 展示 / 8-12s 社会证明 / 12-15s CTA）。

### 模式 B — 审计与再分配

1. 收数据：各平台花费、ROAS/CPA、利润率、活动时长（关键）。
2. 跨平台审计表（对比 break-even 与 target，🟢🟡🔴 状态）。
3. 预算再分配：🟢 超 target → 加 20-30%；🟡 介于 break-even 与 target → 先优化再加；🔴 低于 break-even → 砍 50% 或暂停。
4. 各平台针对性优化（Google 否定词/出价；Meta 受众/素材/版位；TikTok Hook/定向/Spark Ads）。
5. 输出优先行动 + 30 天/4 周计划。

## 补充检查项

- **受众分层**：定义 ICP 细分、受众标签、排除策略、定向假设；命名明确（Meta / Google Ads / TikTok Ads / YouTube Ads / Amazon Ads / Shopify Ads / DSP）。
- **出价/节奏护栏**：按漏斗阶段给渠道角色；设 test budget 与 scale budget；给至少一条 rollback/stop-loss 条件；渠道证据弱时先给最小测试预算；受众宽时先做模块化素材 + 分层定向。

## 输入 / 输出

- 输入：产品价格/成本/利润率、月预算、买家行为、平台数据。
- 输出：平台组合 + 预算分配表 + 各平台 brief + 广告文案 + 创意方向/素材提示词 + 测试计划。

## 注意事项

- 无 API：不能读实时平台数据、不能建像素/管账户、不能生成真实图片视频。
- 每个估算必须标 ⚠️ 并说明"若能提供实际数据会如何变化"。
- 不承诺 ROAS 提升；预算决策由人审批，自动化改价/改预算不在范围内。

## 可复用示例

> "我在 Shopify 卖手工蜡烛，$34，成本 $8，月预算 $2,000，该投哪些平台、各投多少？"
> "Google Shopping ROAS 3.2x（$3,000/月）、Facebook 1.4x（$1,800/月），利润 45%，要不要挪预算？"
