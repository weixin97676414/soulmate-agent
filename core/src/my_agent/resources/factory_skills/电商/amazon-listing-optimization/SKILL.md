# 亚马逊 Listing 优化（A9 / Cosmo）

配套文件：`assets/listing-writing-guide.md`。

## 适用场景

- 亚马逊新品上架写标题/五点/描述/后台 Search Terms；老品流量低、转化差要优化。
- 多站点（美/欧/日）本地化文案。
- 触发词：亚马逊 Listing、写标题、优化五点描述、埋关键词、Search Terms、A9、cosmo、提升搜索排名。
- 边界：只做 Listing 文案与关键词，不做广告投放、不碰账号安全。

## 步骤

1. **收集输入**：
   | 输入项 | 默认 | 说明 |
   |---|---|---|
   | 产品名/品类 | 必填 | 如 wireless earbuds |
   | 核心卖点 | 3-5 个 | 差异化点 |
   | 目标关键词 | 必填 | 已有词表或需扩词 |
   | 目标站点 | 美国站 | 美国/欧洲/日本 |
   | 竞品链接 | 可选 | 参考其高频词 |
2. **标题**：品牌 + 核心词 + 关键特性 + 适用场景/型号；首字母大写；前 60-80 字符最关键，核心关键词放最前；≤200 字符。
3. **五点描述**：每点「全大写开头短语 + 冒号 + 2-3 句说明」，结构=痛点→卖点→证据→适用场景；埋次要关键词，不重复堆砌。
4. **Search Terms 与描述**：
   - 后台 Search Terms：全小写、空格分隔、不重复标题词、不含品牌词/竞品名、≤250 bytes。
   - 产品描述：补充故事感与细节，继续埋长尾词。

## 输出格式

```text
【Title】（≤200字符，前60字符预览区可见）
...

【Bullet Points】
• NOISE CANCELLATION: ...
（5 条）

【Product Description】
...

【Backend Search Terms】
...

【关键词埋点检查】
  核心词 ___ → 标题首位 ✓
  长尾 ___ → 五点 ✓
  场景 ___ → Search Terms ✓
```

## 注意事项

- 不使用违禁词（best/#1/cure 等绝对化/医疗用语，详见 `assets/listing-writing-guide.md`）。
- 关键词以真实搜索量为参考，不堆砌同义词；单复数亚马逊自动处理。
- 不承诺排名/转化；不代写竞品品牌词，不侵权；Search Terms 不含竞品名/ASIN。
- 不伪造认证、专利、评价或原产地。
- 出稿前自检：目标明确 / 口径清楚 / 风险已提示 / 可直接粘贴使用。
