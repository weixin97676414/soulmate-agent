# 电商平台规则查询与合规避坑


## 适用场景

- 查询各平台规则、识别违规风险、说明处罚标准、指导申诉、新手开店避坑、违禁词查询。
- 覆盖：淘宝/天猫、京东、拼多多、抖音电商、快手电商、小红书电商、视频号电商。
- 触发词：平台规则、虚假交易规则、违禁词、这样做违规吗、刷单处罚、被误判怎么申诉、新手开店注意什么。

## 步骤

1. **判断问题类型**：规则查询 / 违规识别 / 处罚标准 / 申诉指导。
2. **确定平台**（可多平台对比）。
3. **联网搜索最新规则**（规则更新频繁，**不可凭记忆回答**）。
4. **给出风险分析 + 规避建议**。

## 搜索策略

关键词模板：
- 规则查询：`"{平台}{违规类型}规则 最新"`、`"{平台}违规处罚标准 2025"`、`"{平台}商家规则中心"`
- 违禁词：`"{平台}违禁词列表 最新"`、`"{平台}直播违禁词"`、`"{平台}广告法敏感词"`
- 具体违规：`"{平台}刷单处罚"`、`"{平台}虚假交易判定标准"`、`"{平台}假货扣分规则"`、`"{平台}价格违规处罚"`
- 申诉：`"{平台}违规申诉流程"`、`"{平台}申诉材料要求"`

时效：用最近 30 天过滤（`--freshness=30d`）取最新规则更新。

## 常见违规速查

**高风险（可能封店）**：售假（🔴 极高，扣 48 分永久封店）、虚假交易/刷单（🔴 极高，扣分/降权/封店）、发布违禁品（🔴 极高，扣 48 分封店）、严重虚假宣传（🔴 高）、侵犯知识产权（🔴 高）。

**中风险（影响权重）**：滥用关键词、类目错放、价格虚标、售后不达标（🟡 中，下架/扣分/警告）。

**低风险（警告为主）**：信息填写不完整、图片不规范、轻微描述不符（🟢 低，警告/限期整改）。

## 违规规避建议

- 商品发布：标题避免极限词；图片真实不用过度修图/虚假对比；参数功效需有依据；类目正确。
- 价格：原价真实不虚构；促销限时真实；价格明示不隐藏附加费。
- 交易：禁止刷单/刷评/虚假发货。
- 直播：禁用医疗功效类敏感词；产品真实不夸大；价格透明不虚构原价。

## 申诉

材料清单：营业执照/身份证明、商品正品证明（品牌授权、进货凭证）、交易真实证明（物流凭证、聊天记录）、整改方案说明。
注意：时效（多数平台 7-15 天）、证据链完整、态度诚恳给整改、避免重复提交相同申诉。
