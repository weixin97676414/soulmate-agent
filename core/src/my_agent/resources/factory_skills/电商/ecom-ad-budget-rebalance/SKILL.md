# 广告预算再平衡（效率诊断 · 渠道再分配）

配套脚本：`scripts/handler.py`。

## 适用场景

- 跨多平台（Meta / Google / TikTok / Amazon / 小红书）诊断广告花费效率，做预算再分配。
- 输出月度/季度媒介预算复盘简报。
- 触发词：预算复盘、rebalance budget、渠道组合、ROAS 下降、某渠道烧钱不转化、再分配预算。

## 步骤

1. **采集**：总预算、渠道占比、活动类型（awareness/consideration/conversion/retargeting）、表现信号、受众分群、业务背景（季节/新品/清仓）、约束（最低投放/素材/平台政策）。
2. **套用效率框架**：对每个渠道与活动类型打分。
3. **找低效项**：定位低效渠道、受众分群、活动类型。
4. **给再分配建议** + 预期影响（含再分配百分比）。
5. **返回 Markdown 简报**。

## 输入 / 输出

- 输入（任意组合）：预算与渠道拆分（如 Meta 40%/Google 30%/Amazon 20%/TikTok 10%）；活动类型占比；表现信号（ROAS、MER、CPM、CPC、CPA、CTR、转化率）；受众分群笔记；业务背景；约束条件。
- 输出简报含：预算健康摘要、渠道效率记分卡（各渠道 ROAS/MER、CPM、CPC、CPA）、活动类型效率拆分、受众表现、带具体再分配百分比的建议、预期影响与风险提示、可能影响效率的创意/落地页因素。

## 注意事项

- 无实时广告平台/活动管理/分析 API；纯启发式，靠用户提供的花费笔记。
- 效率评分在数据不完整时为方向性判断；假设要显式写出。
- 不承诺 ROAS 提升或节省；预算决策由人审批，自动改价/改预算不在范围内。
- 不适合：实时出价管理、自动活动优化、实时花费控制；或多触点归因等复杂场景。

## 可复用示例

> "我们 Meta Ads 这个月 ROAS 掉了，该重新分配预算吗？"
> "$50k 月预算，帮我出一份 Q1 广告花费再平衡简报。"
> "为什么 TikTok 活动一直在烧钱却不转化？"
