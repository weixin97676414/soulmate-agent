# 国内电商 Listing 文案（标题 / 详情页 / 卖点 / 促销）

配套文件：`assets/selling-points.md`、`assets/platform-copy-rules.md`、`assets/templates.md`；脚本 `scripts/generate_title.py`（标题生成）、`scripts/engine.py`（详情页七模块生成 / 违禁词扫描 / 质量评分 / 商品档案）；知识库 `references/selling-points.json`、`references/copy-templates.json`、`references/banned-words.json`、`references/product-profile-schema.json`。

## 适用场景

- 为淘宝/天猫、拼多多、抖音小店、京东、小红书生成商品标题、详情页文案、卖点、促销文案。
- 详情页转化差、文案靠抄无结构、一套文案通投、踩广告法红线时，按七模块结构化生成 + 违禁词扫描 + 评分。
- 触发词：商品标题优化、详情页文案、写详情页文案、生成商品卖点、做高转化的宝贝描述、详情页转化差、卖点提炼、促销活动文案、双 11/618 文案、聚划算。
- **边界**：只做国内平台（淘宝/天猫、拼多多、抖音小店、京东、小红书）的商品文案与详情页七模块；跨境平台的 listing 与多语种文案不在范围内。

## 步骤

1. **标题**：公式 `【核心卖点】+ 产品名称 + 适用人群/场景 + 促销信息`；词序建议 `核心词 + 属性词 + 长尾词 + 热搜词 + 促销词`，**核心词放最前**（权重最高位置），属性词紧跟（材质/功能/风格）。
   - 技巧：前 10 字最关键（移动端展示限制）；含热搜词（季节/功能/人群）；用数字和促销词（买一送一、限时折扣）；避开违规词。
   - 可用脚本：`python3 scripts/generate_title.py '{"product_name":"保暖内衣","selling_points":["加绒加厚","发热"],"target_audience":"男士","promotion":"买一送一","platform":"taobao"}'`（辅助生成标题）。
2. **详情页文案结构（统一）**：
   ```
   1. 首屏海报文案（3 秒抓注意力）
   2. 痛点引入（引发共鸣）
   3. 核心卖点（3-5 个）
   4. 参数证明（细节/参数，硬指标一眼懂）
   5. 场景故事（使用场景展示）
   6. 信任背书（用户评价/资质/售后）
   7. 逼单话术（促销信息/行动号召）
   8. FAQ（答疑排除下单顾虑）
   ```
   - 脚本 `scripts/engine.py` 的 `generate` 自动产出其中七模块（痛点引入 / 核心卖点 / 参数证明 / 场景故事 / 信任背书 / 逼单话术 / FAQ）；首屏海报由文案或主图另行承担。
3. **卖点提炼**：功能卖点（解决什么问题）+ 情感卖点（什么感受）+ 信任卖点（为什么信你）+ 促销卖点（为什么现在买）。细则见 `assets/selling-points.md`。
4. **促销文案要素**：紧迫感（限时/限量）+ 优惠力度（具体数字）+ 行动号召 + 信任保障（退换无忧）。

## 平台风格

| 平台 | 风格 | 长度 |
|------|------|------|
| 淘宝 | 详细专业，重参数 | 长 |
| 拼多多 | 简单直接，重价格 | 短 |
| 抖音 | 场景化，重情绪 | 中短 |
| 小红书 | 种草风，重体验 | 中篇 |
| 京东 | 品质感，重服务 | 中长 |

高转化技巧：用数字说话；场景化描述；使用前 vs 使用后对比；从众心理（"10 万人已购买"）；稀缺性（"仅剩 XX 件"）。各平台标题字符、违规词与最佳发布时间见 `assets/platform-copy-rules.md`。

## 详情页文案工厂（脚本引擎）

按卖点/人群/平台风格模块化生成高转化详情页文案，纯标准库、零第三方依赖。

**处理流程**：卖点匹配 → 七模块生成 → 平台语气套用 → 违禁词扫描 → 质量评分 → 商品档案沉淀。

**平台语气**：淘宝（亲切详细）/ 抖音（节奏短句 + emoji）/ 小红书（第一人称种草）。

**违禁词扫描**：硬词（最 / 第一 / 100%…）标红拦截；软词（功效 / 治疗…）预警。违禁词库见 `references/banned-words.json`。

**质量评分**：模块完整度 + 卖点 + 合规 + 长度综合打分。

```bash
python3 scripts/engine.py selftest                         # 8 项验收自检
python3 scripts/engine.py generate --product product.json  # 生成详情页文案
python3 scripts/engine.py check   --text "行业第一 100%有效" # 违禁词扫描
python3 scripts/engine.py score   --text "..."             # 文案质量评分
python3 scripts/engine.py profile                          # 查看商品档案
```
命令：`generate` / `check` / `score` / `profile` / `selftest`。

**输入 / 输出**：输入商品标题 / 品类 / 属性 / 关键词 / 目标平台 / 场景；输出结构化详情页文案 + 卖点卡 + 评分 + 合规提示（含硬违禁词拦截结果）。

**商品档案（深度感知）**：每次生成沉淀 `used_count` / `category_pref` / `tone_pref` / `products`（字段见 `references/product-profile-schema.json`），二次生成按历史品类与语气偏好自动择模板。

**A2A 接口**：订阅 `title.optimized`、发布 `detail_page.ready`（payload 含 modules / platform / banned_free）。

## 注意事项

- 违规词禁用：最、第一、顶级、国家级、治愈、疗效、100% 有效等广告法禁词。
- 谨慎用：爆款、热销（需数据支撑）、正品、专柜（需授权）。
- 违禁词仅做提示与拦截，**不自动改写、不保证合规**；最终以平台审核与法务意见为准。
- 生成文案为辅助创作，商家对发布内容负主体责任。
- 商品档案仅本地沉淀，遵守《个人信息保护法》，不采集非必要敏感信息。
- 局限：v2.0 卖点库为通用规则，未接大模型语义理解；平台语气为模板级。
