# 辅助评论回复方法论

> 本文件是 `references/comment-reply.md`，供 AI 在回复/处理评论时查阅。目标：**回得快、回得对、不惹事，让评论区成为涨粉/转化的抓手**。

## 1. 为什么评论区重要

- 评论区是**内容冷启动与实时热度**的关键，平台会关注互动密度。
- 好的评论区运营能提升**粉丝粘性、信任、转化**，并给算法正向信号。
- 负面/杠精处理不当会引发 PR 危机，**回复速度与态度**都很关键。

## 2. 评论分类（先分类再回复）

| 类型 | 特征/可能意图 | 处理要点 |
|---|---|---|
| **提问**（怎么买/怎么用/链接） | 主动、高意向 | 优先回，给出明确指引；成交意向强可引导私信/购物车 |
| **夸赞/喜欢** | 认可内容 | 及时感谢、互动，强化人设；可顺势引导关注/系列 |
| **质疑/指正** | 有不同看法 | 先共情表达尊重，再客观回应；对的不必硬争 |
| **杠精/挑衅** | 故意挑刺、抬杠 | 不情绪化；可幽默化解或不回应；攻击性强的删/举报/拉黑 |
| **同行** | 引流、广告 | 判断是否恶意；引流/软广可按规矩处理，恶意拉黑 |
| **广告/垃圾** | 营销、引流 | 删除/举报，别浪费互动 |
| **求助/诉苦** | 有真实困扰 | 暖回 + 给建议；可引导私信深入，注意隐私与边界 |
| **催更** | 忠实粉 | 感谢 + 承诺/透露计划，强化系列感 |

## 3. 回复原则

- **及时**：越早越好，发布后 1~2 小时的评论最值得盯。
- **贴合人设语气**：专业型/生活化/幽默/真诚，跟账号调性一致。
- **具体有用**：别只说"谢谢"，给点实际信息或情绪价值。
- **引导互动**：挑几条有共鸣的评论**置顶/精选**，并回复时抛出新话题，带动更多人开口。
- **保护隐私**：不泄露/不索要用户隐私，涉及敏感信息引导私信但守住边界。
- **控制情绪**：杠精、攻击性评论，永远别在情绪下回复。

## 4. 负面/危机评论处置四步法

1. **倾听** —— 先完整理解对方到底在不满什么，别急着辩解。
2. **共情** —— 先表达理解（"理解你的感受/这个体验确实影响了你"），降低对立。
3. **解决** —— 给出可执行的解决路径（退换/补发/排查/退款/专人跟进），必要时引导私信处理细节。
4. **收尾** —— 跟进结果、表达诚意；严重情况私信或官方渠道二次沟通，避免在公开评论区纠缠。

> 原则：公开回复给**态度**，私下给**方案**；涉及产品/退款/纠纷，转客服或私信处理，不在评论区吵架。

## 5. 话术要点（见 `assets/comment-reply-bank.md`）

- 对每条评论先判断类型，再从话术库选贴合的类型模板，**替换成具体内容**（别照抄）。
- 给用户 2~3 条可选回复，注明"推荐该置顶/精选/私信"的评论。

## 6. 交付自查

- [ ] 每条评论是否已分类；
- [ ] 是否给出 2~3 条可选回复；
- [ ] 语气是否贴合账号人设；
- [ ] 是否标识出"值得置顶/精选/私信"的关键评论；
- [ ] 负面/杠精是否按"四步法"，且无情绪化表达；
- [ ] 是否涉及广告/垃圾/恶意，给出了处置建议。
