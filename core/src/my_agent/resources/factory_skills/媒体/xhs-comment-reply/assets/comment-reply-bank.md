# 评论回复话术库

> 按评论类型给可替换的话术。使用时把 `[...]` 换成该条评论的具体内容；语气贴合账号人设。每条场景给示例 + 替换说明。

## 一、提问型（怎么买 / 怎么用 / 求链接）

- 示例：「你好，这款是在[哪里买的/怎么用]？我直接回你[具体路径]~」
- 示例：「嗯嗯是对滴！你先[说明步骤]，不懂的私我，我发你详细版。」
- 处理：高意向 → 可引导私信/购物车；给明确答案，别只说"看主页"。

## 二、夸赞 / 喜欢

- 示例：「谢谢喜欢呀～[回一个具体的点]，有你们我更新更有劲了。」
- 示例：「谢谢你！[顺势] 喜欢的话可以关注我，我在做[系列]，后面会一直更。」
- 处理：感谢 + 强化人设 + 顺势引导关注/系列。

## 三、质疑 / 指正

- 示例：「谢谢指正，你这个角度我确实没想到，[客观回应] 我后面也注意下~」
- 示例：「有道理！[回应观点]。不过从我[数据/亲测]看是[说明]，可以一起探讨。」
- 处理：先共情尊重，再客观回应；对的不必硬争，能补充就更显专业。

## 四、杠精 / 挑衅

- 示例（幽默化解）：「哈哈你好严肃，咱不抬杠，[拉回内容/玩笑]。」
- 示例（不回应）：「[不回复/已拉黑]」→ 建议：明显攻击/营销可直接处置，别情绪化。
- 处理：不争辩；可幽默、可无视、可删/拉黑/举报；重点保护评论区氛围。

## 五、同行 / 广告

- 示例（判断后处理）：「[软广/引流] 不予置评，按平台规则处理。」
- 示例（合规互动）：「感谢认可，[如确非恶意] 我们各自做好内容就挺好呀。」
- 处理：恶意引流/软广删除举报；善意的可以点到为止。

## 六、求助 / 诉苦

- 示例：「抱抱，你的情况我先回你[建议]，可以私我看具体点~」
- 示例：「理解你，这个问题很多人遇到，[给 2~3 步可操作建议]。」
- 处理：暖回 + 给可执行建议；可引导私信深入；守好隐私与边界。

## 七、催更

- 示例：「在做了在做了！这周更[内容]，记得来看~」
- 示例：「感谢惦记～我[透露计划]，[系列]会一直更下去的。」
- 处理：感谢 + 承诺/透露计划 + 强化系列感（提升回访）。

## 八、评论区运营动作

- **置顶**：把"A 引导提问/干货补充"置顶，带动话题。
- **精选**：挑有共鸣/高质量的评论精选，扩大讨论。
- **回复带动**：挑评论回复时抛一个新问题，让更多人开口。
- **冷启动**：发布后黄金 1~2 小时优先回复，提升互动密度。
