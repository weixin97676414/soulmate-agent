# 网文平台配置档案

创作前先确认 `平台`，后续字数、节奏、润色风格均以此为准。

## 平台速查表

| 平台 | 平台键 | 章节字数 | 节奏单元 | 核心卖点 | 开篇重点 |
|-----|--------|---------|---------|---------|---------|
| 番茄小说 | `tomato` | 2200-2800 | 每3章「压-小扬-压-爆」 | 情绪标签、完读率、断章钩子 | 书架页前50字 |
| 七猫免费小说 | `qimao` | 2200-2800 | 同番茄 | 免费流量、情绪拉扯 | 同番茄 |
| 起点中文网 | `qidian` | 3000-4500 | 每5-10章一个小高潮 | 世界观、升级体系、长期追读 | 前三章立住金手指/核心矛盾 |
| 纵横中文网 | `zongheng` | 3000-4000 | 每3-5章一个小爽点 | 传统男频、升级打脸 | 快速入戏+明确目标 |
| 晋江文学城 | `jjwxc` | 2500-4000 | 情感递进，每2-3章关系推进 | CP张力、人设、情感细腻 | 人设+关系张力 |
| 飞卢小说网 | `feilu` | 3000-5000 | 每章或小段落必有爽点 | 极快节奏、同人/系统/无敌流 | 第一章就亮金手指 |

| 通用网文 | `generic` | 2500-3500 | 每3章一次情绪波动 | 按题材自适应 | 前3段抓住读者 |

## 各平台详细策略

### 番茄小说 / 七猫（`tomato` / `qimao`）

- **读者画像**：碎片化阅读、追求即时情绪反馈
- **算法偏好**：完读率、追读率、评论互动
- **情绪标签**：打脸爽文、极致虐恋、爆笑反套路、悬疑惊悚、治愈甜宠、脑洞大开
- **润色方向**：口语化、去 AI 味、增加可划线金句、短句节奏
- **数据反馈指标**：完读率、追读率、评论关键词
- **专用参考**：`emotion-curve.md`（番茄节）、`golden-opening.md`（番茄节）

### 起点中文网（`qidian`）

- **读者画像**：长线追更、重视设定与成长弧
- **核心结构**：开局三章（黄金三章）→ 第一个副本/第一个大爽点 → 换地图/升阶
- **润色方向**：体系清晰、战斗/博弈有层次、伏笔可回收
- **情绪标签映射**：升级逆袭、权谋智斗、热血燃向、黑暗流、群像史诗
- **数据反馈指标**：收藏、均订、段评、盟主反馈

### 晋江文学城（`jjwxc`）

- **读者画像**：重 CP、重人设、情感浓度高
- **核心结构**：关系建立 → 误会/推拉 → 情感高潮 → 和解/升华
- **润色方向**：心理描写细腻、对话有张力、避免工具人
- **情绪标签映射**：甜宠、虐恋、救赎、强强、群像
- **数据反馈指标**：收藏、营养液、长评、章评

### 飞卢小说网（`feilu`）

- **读者画像**：追求极致爽感、容忍度高、节奏极快
- **核心结构**：金手指 ASAP → 连续打脸 → 快速换副本
- **润色方向**：少铺垫多输出、系统面板可适当展示、每章必有收获
- **情绪标签映射**：无敌流、同人魔改、诸天流、神豪、签到

### 纵横中文网（`zongheng`）

- **读者画像**：传统男频、升级流、江湖/玄幻
- **核心结构**：类似起点但章节可略短，强调阶段性目标
- **润色方向**：热血、兄弟情、明确的等级/势力对比

### 豆瓣阅读（`douban`）

- **读者画像**：品质向、接受慢热、重人物
- **核心结构**：人物驱动，允许更多氛围与留白
- **润色方向**：减少套路化表达，注重叙事质感

### 知乎盐选 / 短篇（`zhihu`）

- **读者画像**：单次阅读完成，强反转预期
- **核心结构**：钩子 → 铺垫 → 反转 → 余韵
- **润色方向**：信息密度高、结尾有力、避免水文

### 通用网文（`generic`）

- 用户未指定平台或小众平台时使用
- 按题材默认节奏，字数 2500-3500
- 用户可自定义字数区间，写入 `00-大纲.md` 顶部

在 `00-大纲.md` 顶部必须写入：

```markdown
## 项目配置
- **平台**：[平台名称]（键：`platform_key`）
- **章节字数**：[min]-[max] 字
- **节奏模式**：[如：每3章压-小扬-压-爆 / 每5章小高潮]
- **情绪标签**：[用户选择]
```
