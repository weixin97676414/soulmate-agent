# 可交付设计资产类型与规格

## 1. 品牌视觉系统

### Logo设计
- **交付物**：主Logo、反白稿、单色稿、最小使用尺寸
- **格式**：SVG（矢量源文件）、PNG（透明背景）、PDF（印刷）
- **规格**：
  - 数字使用：最小宽度120px，PNG@2x/3x
  - 印刷使用：矢量文件，最小宽度30mm
  - 安全空间：Logo高度的1/4

### VI基础系统
- **交付物**：标准色、辅助色、标准字、辅助图形、品牌图案
- **格式**：AI/SVG源文件 + 使用规范PDF
- **规格**：
  - 色彩：Pantone + CMYK + RGB + HEX完整色值
  - 字体：商用授权字体或开源替代方案
  - 图形：矢量格式，可无限缩放

### 品牌手册
- **交付物**：完整品牌使用规范文档
- **格式**：PDF / 在线文档
- **内容**：Logo使用规范、色彩系统、字体规范、应用场景示例、错误示范

## 2. 平面物料

### 海报/主视觉
- **交付物**：主视觉海报、延展尺寸变体、社交媒体适配版
- **格式**：PSD/AI源文件 + PNG/JPG输出 + PDF印刷文件
- **规格**：
  - 印刷：300dpi，CMYK，含3mm出血
  - 数字：72dpi，RGB，适配各平台尺寸
  - 常见尺寸：A1(594×841mm)、A2(420×594mm)、A3(297×420mm)、
    方形(1080×1080px)、竖版(1080×1920px)、横版(1920×1080px)

### 宣传册/画册
- **交付物**：封面、内页、封底
- **格式**：InDesign/AI源文件 + PDF印刷文件
- **规格**：
  - 成品尺寸：A4(210×297mm)、A5(148×210mm)、方形(210×210mm)
  - 页数：4的倍数
  - 装订：骑马钉（≤48P）、胶装（>48P）

### 包装设计
- **交付物**：刀版图、效果图、印刷文件
- **格式**：AI源文件 + PDF印刷文件 + 3D渲染图
- **规格**：
  - 刀版图：含出血、压痕线、裁切线
  - 材质标注：纸张克重、工艺（烫金/UV/压纹）
  - 3D效果图：多角度展示，含光影

## 3. 3D资产

### 产品模型
- **交付物**：高精度模型、低精度模型、材质贴图
- **格式**：.blend / .fbx / .obj / .glb
- **规格**：
  - 高精度：用于渲染，面数不限
  - 低精度：用于实时展示，面数<10K
  - 材质：PBR材质（BaseColor/Normal/Roughness/Metallic/AO）

### 场景渲染
- **交付物**：场景模型、灯光设置、渲染图
- **格式**：.blend源文件 + PNG渲染图（4K/8K）
- **规格**：
  - 分辨率：3840×2160（4K）或 7680×4320（8K）
  - 格式：PNG（无损）或 JPG（高质量压缩）
  - 通道：可输出Alpha通道、深度图、AO图

### 3D展示
- **交付物**：可交互3D展示页面
- **格式**：HTML + Three.js / WebGL
- **规格**：
  - 支持：旋转、缩放、材质切换
  - 兼容：Chrome/Firefox/Safari/Edge
  - 加载：支持GLB/GLTF格式，<5MB

## 4. 数字内容

### 社交媒体素材
- **交付物**：帖子图、封面图、故事图、头像
- **格式**：PNG/JPG + 源文件
- **规格**：
  - 微信：朋友圈(1080×1080)、公众号封面(900×383)
  - 微博：头图(980×300)、帖子(690×任意)
  - 小红书：封面(1080×1440)
  - 抖音：封面(1080×1920)
  - Instagram：帖子(1080×1080)、故事(1080×1920)

### 动效/H5
- **交付物**：动画文件、H5页面
- **格式**：GIF/MP4/Lottie JSON / HTML
- **规格**：
  - GIF：<10MB，循环播放
  - MP4：H.264编码，<50MB
  - Lottie：JSON格式，<500KB
  - H5：自适应移动端，加载<3秒

### 短视频素材
- **交付物**：视频脚本、分镜、封面
- **格式**：Markdown脚本 + 图片分镜
- **规格**：
  - 时长：15s/30s/60s
  - 比例：9:16（竖屏）或 16:9（横屏）
  - 分辨率：1080P或4K

## 5. 空间/快闪方案

### 概念设计
- **交付物**：概念草图、效果图、材质板
- **格式**：PNG效果图 + 材质参考图 + 文字说明
- **规格**：
  - 效果图：多角度（正视/侧视/鸟瞰）
  - 材质板：实际材料小样照片+名称

### 平面布局
- **交付物**：平面布置图、人流动线、功能分区
- **格式**：CAD/PDF + 标注说明
- **规格**：
  - 比例：1:50 或 1:100
  - 标注：尺寸、材料、高度

### 施工图
- **交付物**：立面图、剖面图、节点详图
- **格式**：CAD源文件 + PDF
- **规格**：
  - 符合施工标准
  - 含材料清单与工艺说明

## 6. UI/UX设计

### 界面设计
- **交付物**：页面设计、组件库、图标集
- **格式**：Figma/Sketch源文件 + 切图资源
- **规格**：
  - 设计稿：375pt（移动端）、1440px（桌面端）
  - 切图：1x/2x/3x，PNG/SVG
  - 标注：间距、字号、色值、交互动效

### 交互原型
- **交付物**：可点击原型、交互说明
- **格式**：HTML原型 / Figma原型
- **规格**：
  - 覆盖：核心用户流程
  - 交互：点击、滑动、手势、状态变化
  - 说明：每个页面的功能描述

### 设计系统
- **交付物**：组件库、样式指南、使用规范
- **格式**：在线文档 + 设计文件
- **规格**：
  - 组件：按钮、输入框、卡片、导航、模态框等
  - 样式：色彩、字体、阴影、圆角、间距体系
  - 规范：使用场景、变体、状态、无障碍说明
