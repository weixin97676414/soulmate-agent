# 设计工作流参考

## 标准服务流程

### Phase 1: 需求认知（0-10分钟）

自动解析用户输入，提取设计需求的核心维度：

| 维度 | 说明 | 示例 |
|------|------|------|
| 商业目标 | 设计要达成的商业结果 | 提升品牌认知度30% |
| 目标受众 | 最终触达的人群 | Z世代、一线城市、潮流消费者 |
| 应用场景 | 设计的使用场景 | 快闪店、社媒传播、线下物料 |
| 输出范围 | 需交付的具体资产 | Logo+海报+3D场景+包装 |
| 约束条件 | 时间/预算/技术限制 | 两周落地、预算中等 |
| 风格倾向 | 审美方向 | 极简科技风、复古未来主义 |
| 品牌资产 | 已有视觉基础 | 现有Logo、品牌色、字体库 |
| 竞品参考 | 对标对象 | 喜茶、%Arabica、M Stand |

### Phase 2: 策略生成（10-20分钟）

输出设计策略文档，包含：

1. **设计定位**：一句话定义设计的核心差异点
2. **视觉调性**：色彩情绪、字体气质、图形语言
3. **核心概念**：设计的故事线或视觉母题
4. **资产清单**：所有需交付的设计资产及优先级
5. **排期计划**：关键节点与验收标准

### Phase 3: 并行生产（20-120分钟）

根据资产类型选择生产方式：

| 资产类型 | 生产方式 | 输出格式 |
|----------|----------|----------|
| 矢量图形 | SVG代码生成 | .svg / .pdf |
| 位图视觉 | Canvas渲染 / HTML转图 | .png / .jpg |
| 3D场景 | Three.js / WebGL代码 | .glb / 渲染图 |
| 交互原型 | HTML/CSS/JS代码 | 可交互网页 |
| 设计规范 | Markdown文档 | .md / .pdf |

### Phase 4: 交付验收（即时）

交付物结构：

```
📁 设计资产包
├── 📁 01-源文件（可编辑）
│   ├── logo.svg
│   ├── poster.ai
│   └── scene.blend
├── 📁 02-生产文件（可直接使用）
│   ├── logo_png/
│   ├── poster_print/
│   └── social_media/
├── 📁 03-规范文档
│   ├── brand_guidelines.md
│   ├── color_palette.md
│   └── typography.md
└── 📄 04-使用说明.md
```

### Phase 5: 效果追踪（持续）

提供迭代建议：

- **数据指标**：曝光量、转化率、互动率、品牌搜索指数
- **优化方向**：基于数据的视觉调整建议
- **版本迭代**：A/B测试方案与变体设计

## 关键节点检查清单

- [ ] 需求维度完整提取
- [ ] 设计策略文档输出
- [ ] 资产清单确认
- [ ] 初稿生成与自检
- [ ] 生产规格校验
- [ ] 交付物打包
- [ ] 使用说明编写
