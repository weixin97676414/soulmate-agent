# 抖音三用途脚本模板与场景规则

> 配合 SKILL.md「抖音三用途（信息流 / 直播 / 带货）」章节使用：先定用途，再套模板。

## 四段式核心模板

```
┌─────────────────────────────────────────────────┐
│ 段 1：钩子（3-5 秒） 让人停下不刷走               │
│   ① 反差/颠覆认知 ② 利益型（"教你 XX 省 XX 块"）  │
│   ③ 提问型（"你知道吗"） ④ 悬念型（"我差点亏 X 万"）│
│   ⑤ 视觉冲击（夸张表情/动作/场景）                │
├─────────────────────────────────────────────────┤
│ 段 2：痛点共鸣（5-15 秒） 让观众觉得"这就是我"      │
│   ① 描述具体场景，越细节越好                      │
│   ② 用观众的话说话（口语化、可加 emoji）           │
│   ③ 加情绪（焦虑/愤怒/委屈）                      │
├─────────────────────────────────────────────────┤
│ 段 3：解决方案（10-30 秒） 给方法/卖产品/立人设     │
│   ① 1-3 步法（步数越少越好）                      │
│   ② 对比演示（before / after）                    │
│   ③ 案例佐证（"我有个粉丝……"）                    │
├─────────────────────────────────────────────────┤
│ 段 4：行动召唤（CTA，3-10 秒）                    │
│   ① 关注（"关注我，下期继续讲"）                  │
│   ② 评论（"评论 1，我私你完整版"）                │
│   ③ 下单（"点小黄车，今晚 8 点价"）               │
│   ④ 收藏（"收藏起来，慢慢看"）                    │
└─────────────────────────────────────────────────┘
```

## 一、信息流广告脚本（30 秒）模板

```
【0-3s 钩子】
画面：女主睁大眼睛，举着两瓶面霜
口播："99% 的人都用错了乳液，难怪皮肤越来越差！"

【3-10s 痛点】
画面：失败 case 演示（皮肤干、起皮、爆痘）
口播："你是不是也这样：洁面后直接用面霜，结果脸越来越油、毛孔粗大？
       问题不是面霜，是你少了一步！"

【10-25s 解决方案】
画面：演示正确步骤
口播："正确顺序是：洁面 → 爽肤水 → 精华 → 乳液 → 面霜，
       关键是这瓶 XX 精华，含 5% XX 成分，
       (上字幕：XXX 成分检测报告)
       28 天连续用，毛孔可见缩小 32%"

【25-30s CTA】
画面：产品展示 + 二维码
口播："关注我，主页置顶有今日福利价，先到先得"
```

## 二、直播带货脚本（5 分钟段落）模板

```
【0-30s 留人】
"老铁们刚来的扣个 1 让我看看，今天主要给大家讲 XXX。
 待会儿 8 点准时开抢，错过等明天，我先给大家讲讲它好在哪里。"

【30s-2min 痛点 + 产品演示】
"你们有没有这样：每次买 XX，回家发现 …… (痛点)
 来看下这个 XXX (拿起产品)，它的不同是 …… (3 个卖点)
 (现场演示一段)"

【2-3:30min 信任建立】
"我自己用了 X 个月才推 (打开自己用的旧瓶演示)
 这是去年我们粉丝 @XX 的反馈 (展示反馈截图)
 我们这次拿到的价是全网最低 (展示比价)"

【3:30-4:30min 福利节奏】
"原价 599，我们直播间 299，今天前 100 单再送 XXX (价值 88)
 现在还剩 76 单，下一波要等 1 小时
 想要的赶紧上车 (3、2、1 上链接)"

【4:30-5min 逼单 + 复盘】
"刚才有几个老铁说漏抢了，咱们再补 30 单，但只补 10 分钟
 副播报数：现在还剩 18 单 / 12 单 / 5 单 / 没了
 下个产品是 XXX，不要走开！"
```

## 三、四大场景差异化规则

| 场景 | 黄金3秒公式 | 内容结构 | 结尾引导 |
|------|-------------|----------|----------|
| 好物分享 | "有没有姐妹和我一样..." | 痛点→产品→效果→价格 | 点击下方/橱窗 |
| 知识科普 | "90%的人都不知道..." | 问题→原因→方法→总结 | 关注我/更多干货 |
| 情感励志 | "如果你也...请看完" | 故事→共鸣→金句 | 点赞/转发 |
| 剧情演绎 | "今天遇到一件事..." | 冲突→发展→反转 | 评论区说说 |

**场景识别**：好物分享=痛点切入+产品展示+使用效果+引导下单；知识科普=抛出问题+分点讲解+总结+关注引导；情感励志=情绪铺垫+故事升华+金句+点赞引导；剧情演绎=冲突引入+发展+反转+评论互动。

**适用边界**：适合 30-60 秒口播脚本（约 100-200 字）。不适用超过 3 分钟的深度内容、多人剧情短片、纯音乐/卡点视频。建议输入格式：场景 + 产品/主题 + 目标人群，30 字以内。

## 四、5 大类钩子（前 3 秒）实战

| 钩子类型 | 模板 | 适用 |
|---|---|---|
| 反差颠覆 | "你以为 XX，其实 XX" / "99% 的人都做错了" | 知识科普类 |
| 利益直给 | "教你 3 招，月省 1000" / "1 个动作，瘦腿 5cm" | 干货类、带货类 |
| 悬念追问 | "差点亏 50 万，就因为 XX" / "再不知道这个就晚了" | 故事类、避坑类 |
| 场景代入 | "刚加入新公司怎么破？" / "今年要结婚的姐妹注意" | 垂直场景 |
| 数据冲击 | "98% 的人不知道" / "1000 个客户做完都说……" | 权威背书类 |

## 五、钩子 5 大禁忌

❌ 自我介绍（"大家好我是……"）；❌ 慢节奏环境镜头（拍天空/走路）；❌ "今天给大家分享……"；❌ 废话开场；❌ 字幕和口播不一致。

## 六、避坑指南

| 错误写法 | 原因 | 正确做法 |
|----------|------|----------|
| 开头太平淡 | 前3秒划走率高 | 直接抛痛点/悬念/情绪 |
| 中间讲太久 | 完播率低 | 30-60秒，节奏紧凑 |
| 结尾没引导 | 白拍了 | 加点赞/关注/评论引导 |
| 台词太书面 | 不像说话 | 口语化、短句 |
| 没有画面描述 | 导演没法拍 | 写清镜头、表情、动作 |

## 七、AI 执行流程与输出格式

**执行流程**

1. **摸需求**：信息流/直播/带货？时长？产品与受众？账号粉丝量（< 1 万走"立人设"，> 10 万走"带货"）？有无钩子/痛点/卖点草稿？
2. **选模板**：按场景选 4 段式 / 5 分钟直播段 / 60 秒带货段。
3. **填内容**：每段给 2-3 个备选——钩子 5 类各 1 备选；痛点 3 个切入点；解决方案 3 种风格（步骤/案例/演示）；CTA 四种召唤。
4. **合规检查**：扫违禁词（见 `douyin-compliance.md`）、检查限流元素、提示拍摄注意事项。
5. **自检 checklist**：前 3 秒有强钩子？段间过渡顺畅（无"接下来我们"废话）？总时长在范围内？无违禁词/限流元素？CTA 明确可执行？

**输出格式**

```markdown
## 你的脚本：【主题】（30 秒信息流）

### 完整脚本
【0-3s 钩子】画面：xxx  口播："xxx"
【3-10s 痛点】画面：xxx  口播："xxx"
【10-25s 解决】画面：xxx  口播："xxx"
【25-30s CTA】画面：xxx  口播："xxx"

### 备选钩子（3 个，可替换上面的）
1. 反差型："xxx"  2. 利益型："xxx"  3. 悬念型："xxx"

### 拍摄注意事项
- 字幕和口播 100% 一致
- 切镜节奏：3-5 秒一个画面
- BGM 推荐：xxx (抖音热门)

### 合规检查
- ✅ 无违禁词
- ⚠️ 第 18 秒"效果显著"建议改为"看得见的变化"
- ✅ 无限流元素

### DOU+ 投放建议
- 起投 100 元，定向"女性 / 25-40 / 一二线"
- 跑 24 小时看 完播率（目标 > 25%）、CTR（目标 > 3%）
- 达标 → 加投 500-1000；不达标 → 换钩子重测
```

**终止条件**：用户拿到完整脚本 + 拍摄说明 + 合规清单 + 投放策略。不主动写 BGM 推荐 / 服化道指南 / 后期剪辑方案——除非用户要求。
