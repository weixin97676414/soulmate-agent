# 短视频脚本创作 (short-video-script-writer)

一站式产出「能从 0 写到可拍摄」的短视频脚本包：钩子 → 口播/台词 → 分镜 → 结尾引导 → 标题/封面/标签/发布建议。

## 适用场景

- 用户给出主题/产品/关键词，要一份能直接拍或直接念的短视频脚本。
- 需要多平台适配（抖音/快手/视频号/B站/小红书/YouTube Shorts），或需要黄金3秒钩子方案、口播稿、分镜表、标题封面。
- 需要结构化输出（JSON/YAML）交给下游（口播生成、画面生成、拼接、剪辑）。

不适用：AI 视频提示词/画面提示词工程（用 `video-prompt-engineer`）、短剧剧本（用 `short-drama-writer`）、纯标题批量生成（用 `viral-title-generator`）。

## 工作流程

1. **信息收集**：主题/产品/关键词是必填；平台默认抖音，时长默认 60–90 秒，内容类型默认知识/测评，受众默认 18–35 岁，风格默认轻松活泼。信息不全时优先推断，仅在关键缺失时追问一句。
2. **选题建议**（用户只给方向时）：先给 3–5 个高互动选题让用户选，再动笔。
3. **选钩子**：从 `references/hook-formulas.md`（含十大钩子公式 + 黄金3秒数据）中挑最贴合的，并写 **3 个钩子变体**，选最好的那个。
4. **按平台与类型生成脚本**：平台风格见 `references/platform-styles.md`，内容类型模板见 `references/script-templates.md`。需要结构化数据时套用下方 YAML 结构，模板见 `assets/`。
5. **配套输出**：3 个备选标题（含关键词/数字/悬念）+ 封面主副文案 + 5–10 个话题标签 + 发布时间建议。
6. **自检**：钩子是否兑现、时长是否超、有无违规词、结尾是否有明确行动召唤。

## 脚本结构骨架

```
[0-3秒 钩子] → [痛点/悬念] → [干货/情节] → [高潮/反转] → [结尾引导(互动/留资/关注)]
```

### 开场钩子（黄金3秒）

- 用户判断内容平均 < 2 秒；抖音/TikTok 算法 3 秒检查点；3 秒留存率目标 > 65%，高留存与低留存曝光差 4–7 倍。
- 常用公式：提问式「你知道…吗？」、夸张式「99%的人都不知道…」、冲突式「年薪百万的工作居然是…」、结果前置「3分钟学会…」、直击痛点「___不敢___怎么办？」、反向输出「我们都被___骗了，其实…」。
- 十大量化公式与决策树见 `references/hook-formulas.md`。

### 口播稿标注规范

```
（停顿0.5秒）= 短停顿   （停顿1秒）= 中停顿   （停顿2秒）= 长停顿
【加重语气】= 重点词，音调上扬      [画面提示] = 对应画面
```

### 分镜脚本表格

| 镜头 | 时间 | 画面 | 字幕/台词 | BGM | 转场 |
|------|------|------|-----------|-----|------|
| 1 | 0-3s | 特写：问题场景 | 你还在为XXX烦恼吗？ | 紧张感音乐 | 硬切 |

需要给 AI 视频生成工具用时，每个分镜的提示词必须写全 8 项：镜头语言 / 景别 / 场景与氛围 / 出现角色 / 角色动作 / 表情 / 服装道具 / 台词字幕，并补「上一镜衔接」「转场效果」；英文提示词按「[景别], [运镜]: [动作], [角色+服装+表情], [场景+时间+光线], [氛围], [色调], [风格]」组织，末尾加 Negative prompt（blurry, distorted, extra fingers, watermark, text, logo, low quality）。人物形象在每条提示词里保持同一套外观关键词。

### 结构化输出（流水线对接）

```yaml
meta: {title: "脚本标题", duration: 30s, platform: douyin, template: pain-solution}
script:
  hook: "开场钩子文案"
  scenes:
    - {id: 1, type: hook,     duration: 3s, narration: "...", shot_description: "特写/中景/全景，动作，表情", visual_style: "..."}
    - {id: 2, type: pain,     duration: 5s, narration: "...", shot_description: "..."}
    - {id: 3, type: solution, duration: 8s, narration: "...", demo_insert: true, demo_action: "点击生成按钮"}
    - {id: 4, type: cta,      duration: 3s, narration: "链接在评论区", shot_description: "logo + 二维码"}
  cta: "链接在评论区 / 点击头像私信"
music_suggestion: "轻快节奏 / 紧张悬疑 / 温馨治愈"
```

场景类型 `type` 取值：hook / pain / solution / demo / result / twist / cta。

## 时长与场景分配

| 总时长 | 场景数 | 分配建议 |
|--------|--------|----------|
| 15s | 3-4 | hook(2) + core(10) + cta(3) |
| 30s | 4-6 | hook(3) + pain(5) + solution(15) + cta(3) |
| 60s | 6-8 | hook(3) + pain(8) + solution(35) + result(10) + cta(4) |

## 内容类型速查

- **知识科普**：痛点/疑问开场(5s) → 核心知识(40–60s) → 总结+CTA(5–10s)；节奏快，每 3–5 秒一个信息点。
- **情感故事**：共鸣开场(10s) → 故事展开(40–50s) → 升华+CTA(10s)；第一人称，有张有弛。
- **产品测评**：亮点/痛点开场(5–10s) → 使用展示+对比(40–50s) → 总结推荐(10s)；给具体数据。
- **带货直播**：引流暖场 → 卖点+场景 → 价格惊喜 → 逼单 → 互动；每 30–60 秒互动一次。

## 抖音三用途（信息流 / 直播 / 带货）

同一主题在三种用途下逻辑完全不同：信息流要「种草」、直播要「控场」、带货要「逼单」。先定用途，再套模板。

| 用途 | 时长 | 目标 | 节奏 |
|------|------|------|------|
| 信息流广告（DOU+ 投流） | 15–30 秒 | 跳主页 → 关注 / 跳转 | 钩子 3s + 痛点 5s + 解决 7s + CTA 5s |
| 直播间话术 | 循环，每段 30 秒–2 分钟 | 留人 / 互动 / 关注 / 加粉丝团 / 下单 | 欢迎新进 → 介绍 → 痛点共鸣 → 福利节奏 → 逼单；每 5 分钟一波小高潮 |
| 带货短视频 | 30–60 秒 | 点小黄车下单 | 钩子 5s + 痛点 10s + 产品 20s + 价格福利 15s + 召唤 10s；前 5 秒建立「这人懂」 |

**四段式骨架**：钩子（3-5s，让人停下）→ 痛点共鸣（5-15s，让人觉得这就是我）→ 解决方案（10-30s，1-3 步法 / before-after 对比 / 案例佐证）→ 行动召唤（3-10s，关注 / 评论 / 下单 / 收藏）。

信息流广告与直播带货的完整模板（30 秒信息流、5 分钟直播段逐句口播样例）、四类场景差异化规则（好物分享 / 知识科普 / 情感励志 / 剧情演绎）、5 大类钩子实战表、钩子 5 大禁忌与避坑表，见 `references/douyin-use-cases.md`。

**信息流测试逻辑**：DOU+ 投 100 元起，看 24 小时完播率（目标 > 25%）与 CTR（目标 > 3%）；达标加投 500–1000，不达标换钩子重测。

## 文案快速创作模式（单条文案 / 改写）

当用户只要一条可直接拍、可发布的文案（不是整套脚本包）时走此模式，**默认只完成一条，不扩张为账号定位 / 矩阵 / 排期 / 复盘报告**。

**三种模式**
- 快速创作（默认）：单条口播、标题或发布内容。
- 完整策划：仅在用户明确要求矩阵、发布计划或复盘时使用，输出账号定位、内容支柱、选题矩阵、发布节奏、互动承接、复盘指标。
- 文案改写：用户提供原文时，保留真实卖点、目标人群与转化目标，修正表达与风险；不擅自把销售目标改成科普或反诈内容。

**最少输入**：主题或真实产品信息、目标人群与本条目标、账号语气（时长 / 素材 / 禁区可选）。信息不足时只追问**一个**会改变成品方向的问题；可推进时只对受众、目标或语气作明示假设，**不假设可核验的商业事实**；缺失事实集中提示一次，正文不重复占位。

**快速创作固定输出**
1. 标题备选 3 条
2. 前三秒钩子 1 条
3. 指定时长的口播稿（未指定默认 30 秒）
4. 发布正文
5. 相关话题
6. 置顶评论

**质量与安全**：钩子在正文兑现；不虚构事实、数据、案例或稀缺性；不保证收入、疗效或必然结果；有风险的卖点用可验证价值替代但保留合规转化意图；互动不承诺未确认的后续动作（默认只问一个能自然回复的问题）；涉及账户写入、发布、删除、扣费或对外承诺时先获用户确认。验收样例见 `references/test-prompts.json`。

## 标题 / 标签 / 发布时间

- 标题公式：数字冲击 / 反常识 / 悬念式 / 痛点直击 / 身份认同（见 `references/hook-formulas.md`）。
- 话题标签：大话题(>1亿)1–2 个 + 中话题(1000万–1亿)3–4 个 + 小话题(<1000万)2–3 个，须与内容强相关。
- 发布时间：抖音 12:00–13:00 / 18:00–20:00 / 21:00–23:00；B站 周末 10:00–12:00、周中 18:00–20:00；小红书 8:00–9:00 / 12:00–13:00 / 21:00–22:00；视频号 8:00–9:00 / 12:00–13:00 / 20:00–22:00。

## 注意事项

- 内容要有价值，杜绝纯标题党；钩子承诺必须可兑现。
- 遵守平台规则，规避违规词与限流元素（清单见 `references/douyin-compliance.md`）——极限词、引战词、医疗/金融词、二维码与站外平台名等。
- 同一人物跨镜头的服装颜色/发型/体型描述保持一致。
- 输出前跑一遍「钩子是否在 3 秒内、有无行动召唤、时长是否超、有无违禁词/限流元素」自检。

## 示例

> 用户：帮我写一个 30 秒的短视频脚本，推广我的 AI 写作工具，目标用户是自媒体博主。

1. 确认参数：topic=AI写作工具，audience=自媒体博主，duration=30s。
2. 选模板：pain-solution（默认）。
3. 钩子变体：①「为什么你写一篇笔记要 3 小时？」②「90% 的自媒体人还在手动找选题」③「我用了这个方法，日更 10 条不累」。
4. 出稿：0-3s 直击痛点 → 3-8s 放大痛点 → 8-25s 解决方案（演示生成按钮）→ 25-30s CTA「链接在评论区」。
5. 配套：3 个标题 + 封面主副文案 + 8 个标签 + 发布时间。
