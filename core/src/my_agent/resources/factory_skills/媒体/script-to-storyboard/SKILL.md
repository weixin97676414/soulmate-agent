# Script to Storyboard（剧本转分镜表）

将剧本转换为标准分镜脚本表格，附可执行脚本 `scripts/convert.py`（纯 Python，零第三方依赖）。

## 输入格式

推荐用 Markdown 分块写剧本（脚本按标题切块，一块 = 一镜）：

```markdown
# 剧本标题            ← 用作分镜表标题
## 剧情简介           ← 元信息块，只取其中的群体人物作兜底，不产镜头
## 人物设定           ← 「名字：描述」行用于提取角色名单
### 场景1：茶馆晨景    ← 场景块（「场景N：」前缀会被自动去掉）
远景，航拍。清晨的茶馆，木桌板凳整齐排列，蒸汽升腾。
音效：茶壶沸腾声、街巷叫卖声
### 场景2：争执
中景。王老三拍案而起，茶碗震翻。
王老三：这账你今天必须还清！
镜头推近，两人隔桌对峙。
时长：8
```

会被跳过（不产镜头）的块：标题含 概述/简介/设定/人物服装/道具/风格/备注/附录 等元信息词，以及空块。
「场景5：人物特写」这类**显式场景标题不会被误判**（`场景N` 前缀优先）。

## 输出字段

- **镜号**：镜头序号（如 01, 02, 03...）
- **景别/拍摄角度**：远景/全景/中景/近景/特写，或俯拍/仰拍/平拍/航拍（运镜会追加为第三段）
- **画面内容**：画面描述，含主要视觉元素（已剔除 Markdown 标记与「音效：/时长：」指令行）
- **出场人物**：该镜头出现的角色（支持 `【角色】`、`角色：台词`、数量短语如「20多名非洲土著人」）
- **场景**：拍摄地点和环境（按块独立判定）
- **音效**：背景音乐、环境音、对白以外的声音（可按关键词推断，也可用 `音效：xxx` 显式指定）
- **时长**：镜头秒数，默认 5s，可用 `时长：8` 或 `--duration` 指定

## 转换脚本

```bash
python3 scripts/convert.py <剧本.md> [输出文件] [选项]

选项：
  --format csv|md|json   输出格式（默认 csv）
  --schema ui|pipeline   json 镜头字段方案（默认 ui=后台编辑器字段；pipeline=流水线生成字段）
  --duration 5           默认镜头时长（秒）
  --title "分镜表标题"     默认取一级标题
  --scriptId sc_001      关联剧本 ID（仅 json）
  --characters "甲,乙"    手动指定出场人物，覆盖自动提取
```

示例：

```bash
python3 scripts/convert.py script.md storyboard.csv
python3 scripts/convert.py script.md storyboard.md --format md
python3 scripts/convert.py script.md board.json --format json --title "洞庭商客·第一集"
```

脚本会自动：
1. 按 Markdown 标题切块，跳过元信息块（概述/人物服装/道具等）。
2. 每块独立判定场景名、景别、角度、运镜、时长。
3. 提取人物（角色定义 → 对白行首 → 群体短语 → 全篇兜底）。
4. 推断音效，输出 CSV（UTF-8 BOM）/ Markdown 表格 / 平台 storyboards JSON。

解析为 0 镜时脚本会退出并提示，此时检查剧本是否有分块标题或镜头指示词。

## 手动转换流程

当需要手动转换时：
1. **识别镜头边界**：查找剧本中的镜头指示词（远景、特写、切入、切出等）。
2. **提取场景信息**：从场景描述中获取地点和时间。
3. **列出出场人物**：从动作/对白中识别角色。
4. **描述画面内容**：用简洁的视觉语言描述画面。
5. **标注音效**：记录背景音乐、环境音、特殊音效。

## 示例

参考「热带海岸沙滩派对夜景」剧本结构：风格定位夜景/热闹/氛围感；运镜推拉摇移；核心画面 全景展示 → 人物特写 → 细节强化；分镜逻辑 开场全景 → 中景互动 → 特写情感 → 群体高潮 → 收尾。

| 镜号 | 景别/拍摄角度 | 画面内容 | 出场人物 | 场景 | 音效 |
|------|--------------|----------|----------|------|------|
| 01 | 远景/俯拍 | 全景俯瞰沙滩派对，灯光璀璨 | 全体 | 热带海岸沙滩 | 背景音乐 |
| 02 | 中景/平拍 | 人群舞动，香槟塔 | 派对人群 | 沙滩派对 | 音乐+欢笑声 |

可参考同目录示例：`references/示例剧本.md` 与 `references/示例分镜.md`。

## 注意事项

- 剧本需有分块标题或镜头指示词，否则会解析为 0 镜。
- CSV 输出带 UTF-8 BOM，便于在中文表格软件中直接打开。
- `scripts/convert.py` 为纯标准库脚本；**本机未实跑验证所有选项**，首次使用先用一个小剧本跑通。
