# 公众号排版预览器

把一份 Markdown 渲染成本地 HTML，用于在浏览器里模拟公众号阅读效果、快速看版式。纯本地脚本，不依赖外部 API。

## 适用场景

- 手里已有 Markdown 成稿，想先看手机端大致观感，再决定哪里要拆段、哪里要加粗。
- 需要一个不联网、不外传正文的本地预览。
- 只是轻量预览，不做完整主题排版（需要多主题、组件化卡片、发布前校验时改用 `wechat-typesetting-html`）。

## 执行步骤

1. 确认输入是一份 Markdown 文件，以及想要的输出目录。
2. 运行脚本：

   ```bash
   python3 scripts/wechat_markdown_preview.py article.md --out out/wechat
   ```

   - 位置参数：输入的 `.md` 文件。
   - `--out`：输出目录，默认 `wechat-preview-output`，不存在会自动创建。
3. 脚本在输出目录生成 `wechat_preview.html`，直接用浏览器打开查看。
4. 检查版式：标题层级是否清晰、段落是否过长、列表是否可扫读；给出具体修改建议，不要只复述渲染结果。

## 输入输出

| 项 | 说明 |
|---|---|
| 输入 | 单个 Markdown 文件（UTF-8） |
| 输出 | `<out>/wechat_preview.html`（单文件，内联 `<style>`，含标题/段落/列表的基础样式） |
| 依赖 | 仅 Python 3 标准库，无需第三方包 |

## 渲染范围与限制（照实说明）

- 脚本只处理 `# ` 一级标题、`## ` 二级标题、`- ` 无序列表和普通段落；其它 Markdown 语法（表格、代码块、引用、图片、加粗）不会特殊渲染。
- 生成的 HTML 自带 `<style>`，**是给本地预览看的，不能直接粘进公众号后台**；要粘后台请用 `wechat-typesetting-html` 生成内联样式版本。
- 该预览页不参与发布，仅用于本机检查。

## 注意事项

- 输入材料太少时，明确说明还缺哪些内容，不要编造。
- 不要承诺阅读量、涨粉等效果。
- 涉及数据、产品或内容判断时，不编造外部事实。
