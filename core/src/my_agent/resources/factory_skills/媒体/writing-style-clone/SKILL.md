# 完美复刻蒸馏 / Writing Style Clone

> 给你一个人的全部文章，还你一个想得一样、写得一样的分身。

## 核心原理

做五件事：

1. **思维蒸馏**：从文章中反向提取作者的价值观、世界观、思维习惯、身份认同——他在想什么、怎么想。
2. **风格拆解**：把文章拆成 7+1 个维度，逐一提取写作特征——他怎么写。
3. **双引擎交叉验证**：找出思维框架如何驱动写作风格——思维基因是根，写作基因是叶。
4. **格式适配**：基于风格+思维特征判断作者最适合什么写作公式（14 种）。
5. **克隆**：生成提示词和分身技能，分身内置「双重复检系统」——复检一（文风指纹：词汇/句式/结构/修辞/情感/视角/语气）必须满足指纹要求，复检二（思想一致性：立场/情绪/论证/身份/禁忌）必须符合作者思维。双检通过才输出。

与通用去 AI 化工具的区别：通用工具让文章听起来"像人写的"；本技能是作者专属克隆器，让文章听起来"**像那个人写的**"，更关键的是，让文章**想问题的方式像那个人**。分身可套用不同写作公式（PAS 写痛点文、SCAR 写故事、QUEST 写教程），风格不变、思维不变、格式随心。

## 双引擎架构

```
输入：多篇文章
        │
        ├─────────────────────┐
        ▼                     ▼
  【引擎A：思维蒸馏】    【引擎B：写作蒸馏】
   价值观体系              词汇层 / 句法层 / 篇章结构
   世界观与信念            修辞与表达 / 情感与态度
   身份认同与立场          内容倾向与视角 / 语气与节奏
   思维习惯与论证          格式适配
   对立面与禁忌
        │                     │
        └─────────┬───────────┘
                  ▼
         【双引擎交叉验证】思维基因 ← → 写作基因
                  ▼
         【写作约束系统】写前：他会怎么想？写中：跟他想的一样吗？写后：思维一致性检查
```

## 执行流程

### Phase 0：素材摄入

**Step 0.1 接收输入**：支持直接粘贴（多篇用 `---`/`===` 分隔）、文件路径（单文件/文件夹/多路径，支持 `.txt`/`.md`/`.docx`）或混合。段落有明显分隔符则自动拆分，无法拆分则询问边界。

**Step 0.2 预处理**：去重（移除高度重复段落）、清洗（移除广告、免责声明、转载声明等非正文）、统计语料库概况（总篇数、总字数、篇目清单、字数分布）。

**Step 0.3 质量检查**：最少 ≥3 篇且 ≥2000 字；理想 ≥10 篇且 ≥10000 字。低于最低要求先提醒风险并询问是否继续；低于理想条件但达标则正常进行，最终标注"语料库较小，风格画像可能有遗漏"。确认：作者名/笔名、发布平台、主要题材。

**Step 0.4 确认蒸馏模式**：完整蒸馏（推荐，思维框架+写作风格+格式适配 → 全能分身）/ 仅写作风格（7+1 维分析 → 写作分身）/ 仅思维框架（思维参考卡）。默认完整蒸馏。

**Step 0.5 信息源优先级**：用户提供的一手素材 > 本人著作/长文 > 长对话/访谈转录 > 实际文章文本（本技能核心分析对象）> 他人高质量分析。不依赖外部搜索，核心始终基于用户提供的文章文本。

### Phase 1：双引擎并行分析

先加载 `references/7-dimensions-framework.md`（全部 9 个维度分析方法，含维度九思维框架）与 `references/writing-formulas.md`（写作公式定义与适用场景）。

**引擎 A：思维蒸馏（维度九）**——5 个子维度：

| 子维度 | 核心问题 |
|--------|---------|
| 价值观体系 | 他觉得什么重要？（高频价值观词、赞美/批判对象、价值排序） |
| 世界观与信念 | 他怎么看待这个世界？（世界基调、人性假设、核心信念≥3次出现、因果归因） |
| 身份认同 | 他觉得自己是谁？（自我定位、群体归属、立场倾向、同理心半径） |
| 思维习惯 | 他怎么想问题？（论证方式、思维工具、矛盾处理模式、确定程度） |
| 对立面与禁忌 | 他绝对不接受什么？（情绪触发点、底线、沉默地带、盲区提示） |

原则：从文章提取，不猜测文章之外的想法；区分"明确说的"（高可信度）与"推断的"（中等可信度）；发现矛盾保留矛盾；给一段 100-150 字思维画像概括。

**引擎 B：写作风格蒸馏（维度一~八）**——按依赖分四组：

- 第一组（同时进行）：词汇层（高频词 TOP30、指纹词 10-15 个、词性分布、固定搭配）、句法层（平均句长及标准差、句式比例、连接词密度、标点模式）、语气层（语气词密度、口语化指数、句长波动、词汇多样性）。
- 第二组：篇章结构（开头/结尾类型、段落长度分布与节奏、逻辑推进方式）。
- 第三组（同时进行）：修辞与表达、情感与态度、内容倾向与视角。
- 第四组：格式适配（结构惯性、能力匹配、公式三级推荐）。

**分析输出格式**（每维度写入同一报告）：`## 维度X：名称` → 核心发现（2-3 句）→ 数据与分析 → 典型原文摘录（≥1 段佐证）→ 可操作结论。

原则：有数据不臆测（能统计就统计，不能统计标"基于人工判断"）；有摘录不空谈；发现矛盾就保留；区分"惯用的"vs"偶尔用的"（高频/中频/偶发）。

### Phase 1.5：分析质量检查点

暂停展示分析质量摘要（引擎 A/B 维度数与关键发现、矛盾点、信息不足维度）。用户确认 OK → Phase 2；觉得某维度不够 → 补充分析后再继续。

### Phase 2：双画像合成 + 双引擎交叉验证

**Step 2.1 思维画像合成**：世界观、价值观（3-5 个含排序）、身份认同、思维习惯、情绪触发点与禁忌。

**Step 2.2 写作风格画像合成**：逐维精炼 → 格式适配推荐 → 写作维度交叉验证（提炼写作基因）。

**Step 2.5 双引擎交叉验证（最关键一步）**：寻找思维框架驱动写作风格的映射关系，例如：

| 思维特征 | → 写作物证 |
|---------|---|
| 批判型态度 | 高频反问句 + 负面情感词多于正面 |
| 人性默认不信任 | 故事中人物总被背叛 + 极少直白信任表达 |
| 看重"体面" | 高频"体面""丢人" + 冲突围绕面子展开 |
| 用故事思维 | 抽象词密度低 + 开头总是具体场景 |
| 确定性高/不犹豫 | 短句比例高 + 极少"也许/可能" |

提炼 3-5 条 **思维基因**：一句话概括 + 思维层面影响 + 写作层面影响 + 反例测试（违背它会产生什么违和感）。写作基因描述"他怎么写"，思维基因描述"他为什么这样写"；思维基因是根，写作基因是叶。

**Step 2.6 生成禁用清单**：写作禁用（≥5 条具体写法）+ 思维禁忌（≥3 条不能碰的话题/立场/论证方式）。

**Step 2.7 输出双画像卡**：组装为结构化的"作者思维+写作风格卡"，作为 Phase 3 基础。

### Phase 2.5：提炼确认检查点

暂停展示提炼摘要（思维基因 N 条、写作基因 N 条、格式适配三级、核心张力、诚实边界）给用户确认。确认 OK → Phase 3；某个基因不对 → 回 Phase 2 调整。

### Phase 3：输出生成（双产出）

**Step 3.0 写作模式预装**：确认思维画像、写作风格画像、格式适配、思维基因+写作基因、每个公式的"作者适配写法"已就绪。原则：公式 = 骨架，风格 = 血肉，**思维 = 灵魂**。

**产出 A：思维+写作风格提示词**（独立提示词，含思维约束）。结构：

```
# [作者名] · 思维+写作风格提示词
## 你是谁（50-100 字，用作者语气写）
## 你的思维方式 —— 你怎么看世界 / 你在乎什么 / 你受不了什么
## 写作铁律（5-8 条，每条：做什么+怎么做+因为什么）
## 风格参考卡 —— 词汇 / 句式 / 结构 / 修辞 / 情感 / 视角 / 语气
## 格式适配推荐 —— 🔥 天生适合 / ✅ 可以驾驭 / ⚠️ 不太适合
## 写作模式选择（适配 TA 风格+思维的 PAS / SCAR / QUEST 写法，各 50-80 字）
## 禁用清单 —— 写作禁用 / 思维禁忌
## 写前必读（三问：这件事他会怎么想？写到这里他的第一反应？跟他想的是否一样？）
```

**产出 B：思维+写作分身子技能**：

1. 读取 `references/persona-template.md`（含双重复检系统 + 思维框架 + Agentic Protocol）。
2. 将 Phase 2 的双画像结论填入模板。
3. 双重复检系统（复检一：文风指纹 / 复检二：思想一致性）基于思维基因和写作指纹具体化。
4. 把分身技能文件写到用户指定目录（默认 `skills/[作者名]-style/SKILL.md`）。

**交付格式**：思维基因速览 → 写作模式推荐 → 产出清单（提示词、分身子技能、双重复检系统、14 种写作模式）→ 语料库信息（篇数、总字数、分析维度）。

### Phase 4：双引擎盲测验证

**Step 4.1** 写三段 200-300 字测试短文：默认模式（作者最自然的写法）、公式模式（选一个"可以驾驭"级公式测边界）、思维挑战模式（选作者立场复杂/矛盾的话题测思维一致性）。

**Step 4.2** 从语料库随机选一段原文并排展示。

**Step 4.3** 盲测分析：按维度对照原文特征与仿写表现，给匹配度（90%+ 出口即是；70-89% 核心抓住细节有偏差；50-69% 方向对但辨识度不足；<50% 回 Phase 2）。

**Step 4.4 质量自检**（6 项）：思维基因数量 3-5 条且每条有思维+写作映射；每个基因写明失效条件；100 字能认出是谁；诚实边界≥3 条具体局限；内在张力≥2 对矛盾；一手文章文本占比 >80%。不通过回 Phase 2 迭代，**迭代上限 2 次**，仍不通过则标注薄弱维度交付当前最优版本。展示验证结果给用户确认后才算完成。

### Phase 5：双 Agent 精炼（标准后置工序）

并行启动两个 Agent：**A（使用者视角）** 对分身 SKILL.md 做 6 维可用性评估、干跑 3 个典型 prompt，输出最弱 2 维度的具体改进建议（含改后文本示例）；**B（skill-creator 视角）** 评审触发条件覆盖度、双重复检系统可操作性、缺失信息，输出 2-3 处文本改动建议。主 Agent 综合两份报告，应用不冲突的改进并展示变更摘要请用户确认。精炼标准：让分身"激活即执行"。

## 更新已有分身

用户说"更新 XX 的分身/XX 最近有新文章"时：读现有分身 SKILL.md 的「诚实边界」找到分析时间 → 只分析新增文章（Phase 1）→ 对比新旧（强化则补案例、矛盾则标注变化并更新基因、新特征则考虑新增基因）→ 更新「最新动态」与分析时间 → 不整体重写，只增量更新。

## 特殊场景

- **素材太少**（<3 篇或 <2000 字）：不拒绝，明确告知风险，生成时标注"⚠️ 语料不足"。
- **文章类型混杂**：标注"风格分离"，让用户选择蒸馏哪种风格。
- **同名不同人**：Phase 0 就标注风格不一致信号并提醒。
- **蒸馏自己**：身份描述用"你就是你自己"，额外帮其发现无意识的写作习惯。
- **冷门作者**：思维基因减至 2-3 条，每条标"基于有限信息推测"，诚实边界加大篇幅。
- **主题风格蒸馏**（输入是主题而非个人，如"小红书爆款文风"）：先搜该主题 3-5 个典型作者再按作者分配分析，Phase 2 改为提炼"主题共识特征 + 作者分歧"，不提炼个人思维基因，改提炼"主题风格基因"。

## 品味守则

| 原则 | 一句话 |
|------|--------|
| 多篇 > 单篇 | 10 篇比 1 篇更能揭示稳定风格 |
| 习惯 > 偶然 | 反复出现 ≥3 次的才是真特征 |
| 矛盾有价值 | 不一致的写法保留，不强行调和 |
| 具体 > 抽象 | "平均句长 12 字，30% 句子少于 8 字"比"喜欢短句"有用 |
| 否定 > 肯定 | "他从不做什么"更能定义风格边界 |

绝不做的事：凭空猜测作者背景动机；把通用技巧包装成"独门秘笈"；忽略文章中的不完美（那恰是最有区分度的特征）；语料不足时强行生成"完整"画像。
