# 知乎排版规范与合规边界

成稿后的终检文件。分三部分：排版规范、引流合规边界、社区红线与免责话术。

## 一、排版规范

知乎是五大内容平台里排版审美最"性冷淡"的，克制即高级。

### 段落

- 单段不超过 5 行（移动端显示约 100-150 字），大段必拆。
- 多用单句成段制造节奏，尤其在情绪点和金句处。
- 段与段之间知乎自动留空，不需要手动空行两次。

### 分割线与小标题

- 分割线（知乎编辑器自带的水平线）用于**大板块切换**：故事→干货、干货→反转。一篇 3000 字文用 2-4 条，多则碎。
- 小标题两种做法：编辑器 H2 标题（硬核长文用）或"一、二、三"+加粗（经验帖用）。全文风格统一，不混用。
- 清单用编辑器的有序/无序列表功能，不要手打"1、2、3"混排。

### 加粗

- 每屏最多 1-2 处加粗，加粗的是**结论句**而不是形容词。
- 全文加粗率超过 10% 等于没有加粗，且显得营销腔。
- 不用下划线、不用彩色字（知乎不支持也不需要）。

### 禁用项

- **emoji 禁用**：正文出现 emoji 是"营销号"识别信号，会直接影响老知友的点赞意愿。语气词（"哈哈""笑死"）在严肃回答中同样慎用。
- 不用夸张符号连打（"！！！""？？？"），情绪靠内容而不是标点。
- 图片：说明性图表加分（数据图、流程图、对比表），表情包在严肃话题减分。每张图下建议配一行说明文字。

### 特殊格式

- 引用格式（>）用于：引用问题描述、引用他人观点准备反驳、引用文献原文。
- 参考来源统一放文末，格式："参考资料：1. {来源名+可检索的标题}"。给不出处的数据要标注"个人经验估算"。

## 二、引流合规边界

知乎对站外引流是**高压线级**管控，处罚从删除内容到永久封号。以下为红线与合规替代。

### 绝对禁止（碰=处罚）

1. 正文/评论/个人签名中的微信号、QQ 号、手机号，包括谐音变体（"薇信""V❤""+v"）和拆字变体。
2. 二维码图片，包括藏在长图末尾的二维码。
3. "私信我领资料/进群"类钩子——私信导流被举报同样处罚。
4. 站外链接导流（公众号文章链接反复出现、网盘链接配"关注后可见"话术）。
5. 评论区小号互动引流（自问自答"求资料"→"私你了"）。

### 灰色地带（不建议）

- 个人简介写公众号名称：目前容忍度较高，但配合正文反复提示"看我简介"会被判定引流意图。
- 文末"我的其他回答"合集：站内引流合规，但堆砌超过 3 条显得功利。

### 合规做法

- 引流靠**内容资产**：把"领资料"改成"资料清单我直接贴在下面"，把干货全放正文里——知乎生态里全给反而涨粉最快。
- 站内沉淀：引导关注、赞同、收藏是完全合规的，结尾一句"觉得有用点个赞同，我看到数据会更新后续"即可。
- 商业变现走官方通道：好物推荐、品牌任务、盐选专栏、付费咨询，均为平台认可路径，不需要也不应该导私域。

## 三、社区红线

### 内容红线

1. **编造经历**：知乎用户的考据能力极强，时间线矛盾、专业细节出错都会被评论区扒出，一次人设崩塌全账号内容被连坐质疑。原则：没有的经历不写，模糊的细节宁可写模糊。
2. **医疗健康**：不给出诊断性、处方性表述（"你这是XX病，吃XX药"）；可以分享个人经历+就医过程，必须附"个体情况不同，请以医生诊断为准"。
3. **法律/财税/投资**：可以科普规则原文与一般逻辑，不对具体个案给出行动指令；投资内容不做收益预测、不荐股。
4. **争议话题**：民族、宗教、性别对立话题不写挑动性内容；时政话题非专业资质不碰。
5. **数据与引用**：给出的统计数据必须可溯源；文献引用不编造（编造引用一旦被查证，反对+举报双杀）。
6. **抄袭与洗稿**：知乎维权氛围浓，段落级相似会被原作者公开挂出。参考他人观点必须注明。

### 行为红线

- 不刷赞、不互赞团（风控识别后限流）。
- 不在竞争回答下恶意点反对+评论区拉踩。
- 被杠时的回复纪律：只回应有信息量的质疑，情绪性攻击不回复不拉黑（拉黑会被截图做文章），高质量回应本身能涨赞。

## 四、免责话术模板（直接取用）

- 医疗类："以上是我的个人经历与公开资料整理，不能替代医生的当面诊断。如有症状请及时就医。"
- 法律类："以上为一般性规则科普，不构成法律意见。具体个案请咨询执业律师，各地执行口径可能不同。"
- 投资类："以上仅为个人思考记录，不构成投资建议。市场有风险，决策请独立判断。"
- 经验类："我的方法基于{具体前提}，不同条件下未必适用，请结合自身情况取舍。"
- 数据类："文中数据来自{来源}，统计口径为{口径}，引用请自行核实原文。"
