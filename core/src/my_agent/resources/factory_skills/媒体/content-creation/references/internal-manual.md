# 内容创作专家 — 内部参考手册

## 1. 写作心理学基础

### 1.1 认知流畅性（Cognitive Fluency）
- 人们偏爱容易理解的信息。文案越流畅，读者越觉得"有道理"
- 短句 + 主动语态 + 具体词汇 > 长句 + 被动语态 + 抽象词汇
- 排版比文笔更影响阅读体验

### 1.2 峰终定律（Peak-End Rule）
- 读者对内容的记忆 = 最强烈的情感点（峰） + 结尾感受（终）
- 创作策略：在文章中间设置 1-2 个情绪高潮点（金句/反转/数据冲击），结尾用强 CTA 或金句

### 1.3 承诺一致性
- 人们倾向于保持言行一致
- 在内容中先让读者认同一个小观点 → 再递进到核心观点 → 最后引导行动，转化率更高

### 1.4 社会认同
- "大家都在用"比"这个产品很好"更有说服力
- 使用数据（"已有 10 万人"）、证言（"XX 公司也在用"）、社群标签（"同行都在读"）

## 2. 框架选择决策树

```
用户需求
├─ 需要用户立刻行动（购买/注册/下载）
│   ├─ 短文案（≤500字）→ AIDA
│   ├─ 中长文案（500-2000字）→ PAS
│   └─ 长文案（2000+字）→ 4P
├─ 需要建立品牌认知/好感
│   ├─ 品牌故事 → Hero's Journey 简化版
│   ├─ 转型/改变 → BAB
│   └─ 案例展示 → Before-After-Bridge
├─ 需要传递专业知识/建立权威
│   ├─ 观点分析 → SCQA
│   ├─ 产品功能 → Feature-Advantage-Benefit
│   └─ 行业趋势 → SCQA + 对比矩阵
└─ 需要引发讨论/传播
    ├─ 反常识观点 → PAS（P=常见误解）
    ├─ 争议话题 → SCQA（C=挑战共识）
    └─ 情绪共鸣 → Hero's Journey 简化版
```

## 3. 常见创作误区与对策

| 误区 | 表现 | 对策 |
|------|------|------|
| 信息过载 | 一篇文章想塞 10 个观点 | 一篇文章只讲 1 个核心观点 + 3 个支撑点 |
| 自嗨式写作 | 堆砌行业黑话和炫技表达 | 写完读三遍，每遍删掉一个不必要的术语 |
| 开头拖沓 | 前三段还在铺垫背景 | 第一句话就给结论/钩子/故事 |
| 虎头蛇尾 | 正文很精彩，结尾草草了事 | CTA 必须具体：要关注/要评论/要转发/要购买 |
| 缺乏证据 | 全是观点，没有数据或案例 | 每个核心论点至少配 1 个数据点或案例 |
| 语气不一致 | 一会儿"我们调研发现"一会儿"我试了一下巨好用" | 确定风格后全篇检查替换 |
| CTA 模糊 | "欢迎关注"太弱 | "如果你也遇到过这种情况，评论区告诉我，我们一起找答案" |

## 4. 不同内容类型的创作要点

### 4.1 品牌故事
- 核心公式：初心 → 挣扎 → 转折 → 成果 → 愿景
- 必须回答："为什么是你来做这件事？"
- 关键：放一个真实的脆弱时刻（挣扎阶段的细节），比全程高光更有说服力
- 示例结构：
  1. "2019 年，我做了一个周围人都不理解的决定……"（初心）
  2. "前 6 个月，0 收入，每天醒来的第一个念头是……"（挣扎）
  3. "直到有一天，一个用户的留言改变了一切……"（转折）
  4. "3 年后，我们服务了 5000+ 客户……"（成果）
  5. "但这只是开始，我们想……"（愿景）

### 4.2 小红书种草笔记
- 核心：个人体验 + 场景化 + 细节
- 黄金结构：我的问题 → 我发现了什么 → 使用感受 → 效果对比 → 购买建议
- 关键：真实感 > 专业感；一个细节胜过十个形容词
- 避免："超级好用""强烈推荐"空泛赞美 → 改为"用了 3 天，下巴的闭口消了"

### 4.3 公众号深度文章
- 核心：1 个核心观点 + 3 个分论点 + 各配案例
- 节奏控制：每 300 字左右插入一个"爽点"（金句/反转/数据冲击）
- 信息密度：每 500 字至少 1 个读者不知道的新信息
- 视觉呼吸：3-4 段文字后插 1 张图，防止阅读疲劳

### 4.4 产品落地页
- 遵循 F 型阅读模式：用户会先看标题，然后扫左侧列表
- 结构：核心价值主张 → 社会认同 → 功能亮点 → 价格 → CTA
- A/B 测试优先级：标题 > CTA 按钮文案 > 价格呈现方式 > 配图
- 移动端优先：手机屏幕宽 375px，每行 ≤ 20 字

## 5. 创作效率提升技巧

- **先写烂再改好**：第一稿只管写，不删不改；第二稿再精炼结构调整；第三稿润色语言
- **标题最后定**：正文写完才知道最打动人的点是什么
- **朗读检验**：写完大声读一遍，卡顿的地方就是需要改的地方
- **隔夜再看**：写完后放 24 小时再看，会发现很多盲区
- **反向大纲**：写完正文后提取 H2/H3 标题，只看大纲是否逻辑顺畅
