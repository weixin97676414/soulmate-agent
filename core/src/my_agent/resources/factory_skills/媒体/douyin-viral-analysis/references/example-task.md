# 示例任务

## 示例输入

- 资料：视频链接或数据表、时间范围和账号目标
- 目标：在明确时间范围内获得可直接评审的结果
- 受众：抖音运营、编导和数据分析团队

## 推荐调用

> 使用 `$douyin-viral-analysis`。输入是视频链接或数据表、时间范围和账号目标；请产出爆款特征、内容变量、异常点与测试计划。区分已知事实、推断和未验证项，列出风险、负责人建议与验收信号。

## 验收要点

- 输入、产出、受众和时间范围明确
- 关键结论可以追溯到资料或计算
- 不虚构数据、案例、功效或已完成状态
- 主交付物可以直接进入评审或执行
