# 一人公司自媒体矩阵作战台 / Self-Media Matrix

输入你的领域、时间、内容，输出可直接执行的一周作战计划：平台取舍 → 选题评分 → 一鱼多吃 → 7 天排期 → 数据复盘 → 变现动作。核心就一句：**把有限的时间摊到对的地方，还不被平台规则吃掉。**

## 触发场景

- "我想做自媒体，不知道选哪些平台"
- "我每周能投入 10 小时，帮我规划一下内容策略"
- "我有一篇深度长文，帮我拆成多平台版本"
- "帮我生成本周自媒体作战计划"
- "我这个月各平台数据怎么样，哪个最该加码"
- "我有 5000 粉丝，怎么变现"
- "我的账号是不是被限流了"

## 核心心法：把内容做成飞轮，而不是流水线

```
        做厚一条母内容
              │
              ▼
   按平台调性拆成不同形态
              │
              ▼
   投到最契合的 2–4 个平台
              │
              ▼
   回收数据 → 反哺下一条母内容
              │
              └── 放大跑通的，砍掉不行的
```

母内容越厚，能拆出的版本越多；版本越契合平台，回收的数据越真实；数据越真实，下一条母内容越准。

## 核心工作流

1. **诊断** → 识别领域、offer、目标客户、每周可投入时间、现有平台、受众规模和变现目标
2. **选平台** → 推荐主平台/辅助平台，明确暂缓哪些
3. **产内容** → 将核心选题或长内容拆解为各平台适配版本
4. **排日程** → 构建 7 天内容日历，适配每周可用时间
5. **看数据** → 如有数据（CSV/手动输入），跨平台对比，明确加码方向
6. **做变现** → 推荐近期转化动作和长期产品路径

## 模块一：矩阵规划器

按用户领域匹配最优平台组合。内置领域配置（编程技术 → B站/知乎；知识付费 → B站/公众号；职场效率 → 小红书/知乎；美妆护肤 → 小红书/抖音；本地生活 → 抖音/小红书；其他/通用按形态推荐）。

**一人公司特殊规则（精力硬天花板）**：

- 每周 < 6 小时 → 最多运营 2 个平台
- 每周 6–12 小时 → 最多 3 个平台
- 每周 > 12 小时 → 最多 4 个平台
- 优先选择"一鱼多吃"适配成本低的组合

**先按内容形态倒推平台**（比查大表更快）：

- 写得动长图文/问答 → 知乎、公众号、今日头条、百家号（吃搜索和信任，做长期资产）
- 做得动中长视频/教程 → B站、西瓜视频
- 擅长短视频/口播 → 抖音、视频号、快手
- 擅长图文卡片/种草 → 小红书
- 爱聊观点/顺手接热点 → 微博、豆瓣

**平台特性（精简）**：

| 平台 | 内容形态 | 核心定位 | 冷启动 | 广告接单门槛（参考） |
|------|---------|---------|--------|--------------------|
| B站 | 中长视频 | 系统教程、长期搜索资产 | 中 | 1万粉（花火） |
| 知乎 | 长图文/问答 | 专业回答、搜索流量、信任背书 | 中 | 无门槛 |
| 公众号 | 长图文 | 私域沉淀、长期复购 | 高 | 500粉（流量主） |
| 小红书 | 图文/短视频 | 攻略卡片、收藏型内容 | 中 | 1000粉（蒲公英） |
| 视频号 | 短视频 | 1分钟可转发资产、微信生态 | 低 | 100粉 |
| 抖音 | 短视频 | 强钩子、强节奏 | 高 | 1000粉（星图） |
| 微博 | 短图文/热点 | 热点借势、观点扩散 | 低 | 1000粉（微任务） |

完整平台规则、变现门槛、黄金时段见 `references/platform-rules.md`。

**精力预算示例（每周 10 小时）**：选题策划 1.5h、核心内容生产 4.5h、拆解改写 2.0h、分发互动 1.0h、数据复盘 1.0h。脚本的 `MatrixPlanner.calculate_energy_budget` 会按真实小时数换算并给关键项兜底，不会把必做项排到 0 小时。

## 模块二：选题与排期引擎

**选题评分公式（修正版）**：

```
分数 = 搜索热度(1-5) × 互动潜力(1-5) × (6 - 创作难度(1-5)) / 125 × 100
```

分级：≥80 优先创作；60–79 本周备选；40–59 放入题库；<40 暂不投入。低难度、高潜力的"低垂果实"优先。

**挖题三步**：① 翻内置行业选题库（脚本 `TOPIC_DATABASE`，多领域）；② 库里没有就用 **痛点 × 人群 × 形式** 交叉生成（痛点=不会/踩坑/浪费时间；人群=小白/职场人/宝妈；形式=清单/对比/避坑/案例）；③ 每条跑分排序。每个领域内置"支柱主题"，每周挑 1–2 个做系列化（清单体/对比体/避坑体/案例体/问答体/复盘体）。

**内容日历模板**：

| 日期 | 任务 | 平台 | 产出 | 指标 |
|------|------|------|------|------|
| 周一 | 选题确认+素材整理 | 全平台 | 确定角度和资料包 | 评分≥60 |
| 周二 | 核心内容生产 | 主平台 | 长文/视频脚本初稿 | 完整度 |
| 周三 | 核心平台发布 | 主平台 | 发布并置顶引导 | 收藏率 |
| 周四 | 搜索平台改写 | 搜索平台 | 问答或长图文 | 阅读完成率 |
| 周五 | 辅助平台拆片 | 辅助平台 | 短内容/图文卡片 | 互动率 |
| 周六 | 互动与私域承接 | 全平台 | 回评、收集问题 | 私信领取数 |
| 周日 | 数据复盘+下周实验 | 全平台 | 记录指标、决定加码 | 下周清单 |

## 模块三：内容中央厨房（一鱼多吃）

**一鱼多吃不是复制粘贴，是换壳不换核**：只动四样——形态、钩子、封面、转化入口，主题和价值纹丝不动。

拆解模板（原始素材 3000 字长文 / 15 分钟视频）：

```
├── B站：8-12 分钟教程视频 + 资料包
├── 知乎：2000 字专业回答 + 案例 + 资料包入口
├── 公众号：长文 + 产品说明 + 领取入口
├── 小红书：6-9 页攻略卡片 + 清单式正文
├── 视频号：60 秒短视频 + 评论区资料引导
├── 抖音：30-60 秒强节奏短视频
└── 微博：短图文 + 九宫格要点
```

每个平台最终给九项产出：标题、Hook（前 3 秒或首句）、封面思路、结构大纲、交付物、预计耗时、发布目标、黄金时段、行动号召。标题与 Hook 的 12 平台写法见 `references/title-hook-library.md`。

## 模块四：数据复盘看板

不接任何平台 API，只吃你从后台导出的 CSV。

**CSV 模板**：

```csv
日期,平台,内容标题,播放量,点赞数,评论数,收藏数,分享数,粉丝增长,完播率
2026-05-20,B站,Python自动化办公教程,45000,2800,450,1200,350,320,0.55
2026-05-20,知乎,Python自动化办公解析,12000,650,180,420,95,85,0.72
```

衍生指标：**互动率 =（点赞+评论+收藏+分享）÷ 播放量**；涨粉率 = 粉丝增长 ÷ 播放量。

判断逻辑：互动率 ≥ 平台平均 × 1.5 或完播率 ≥ 平台平均 × 1.2 → 加码；互动率 < 平均 × 0.7 或完播率 < 平均 × 0.7 → 优化/降频；其他 → 保持测试。跨平台比时，有基准的平台按此判断；**微博这类没有稳定基准的，只展示数据、标"保持观察"，不参与加码判断**。

变量实验模板见 `references/experiment-templates.md`（一次只改一个变量）。对标：拆同行的选题/形式/标题/更新频率/变现方式，输出"你能抄哪 1–3 条、别硬抄哪几条"。

## 模块五：变现路径规划器

| 粉丝总量 | 阶段 | 本周动作 |
|---------|------|---------|
| < 1000 | 验证期 | 用免费资料包换私信/社群线索，验证痛点和表达 |
| 1000-10000 | 小产品期 | 上线 9.9-99 元模板/小册，测试付费意愿 |
| > 10000 | 产品矩阵期 | 低价小产品 + 中价训练营 + 高价咨询/陪跑 |

分层模型：引流层（免费资料包）→ 低价层（9.9-99 元模板/小册）→ 中价层（199-499 元训练营/系统课）→ 高价层（1000 元+ 咨询/陪跑/企业服务）。从第一天就往私域导。

## 模块六：平台规则雷达

发布前过一遍合规词库（最/第一/100%/稳赚/包过/加微信/私加/绝对/国家级/万能/根治/零风险），金融健康教育尤其容易踩强审核。命中 ≥ 3 个判高风险，逐个替换绝对化承诺与站外引流表达。

## 反模式与常见误区

| 错误用法 | 正确用法 | 为什么 |
|---------|---------|--------|
| 一上来全平台铺开日更 | 先 2–3 个做深 | 一人精力有限 |
| 每个平台都从头创作 | 一鱼多吃 | 单篇创作成本已很高 |
| 同时测试多个变量 | 每次只改一个变量 | 多变量无法归因 |
| 只看播放量/粉丝数 | 关注互动率、完播率、收藏率 | 互动数据更能反映质量 |
| 有几百粉就想接商单 | 先验证方向与变现模型 | 粉丝少时优先做产品和信任 |
| 数据差就立刻换方向 | 同方向发满 10–15 条再判断 | 单条波动正常 |

## 30 天启动路线

- 第 1 周｜定盘 + 只开 2 个平台：发 3 条母内容，先把发布流程跑顺。
- 第 2 周｜稳定节奏 + 一源多发：每条末尾埋私域入口，攒私域线索。
- 第 3 周｜第一次认真复盘 + 试变现钩子：达标平台加码，放免费资料包测留资。
- 第 4 周｜放大跑通的 + 补常青内容：定下个月方向。

更细的周动作、话术、check 清单见 `references/launch-playbook.md`。

## 安全边界

- 只给运营决策参考，不代运营、不替你写、不替你发。
- 本技能负责矩阵规划、排期与变现作战计划；具体文案写作与创作框架生成不在本技能职责内。
- 平台规则/算法/变现门槛变化快，商业决策前以官方后台为准。
- 数据分析只基于你提供的 CSV 或手动输入，不调任何 API。
- 变现建议不作收入承诺；绝不建议买粉、刷量、搬运、抄袭。
