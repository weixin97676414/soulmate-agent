# 标题与 Hook 模板库

写标题和开头（Hook）最容易被忽略，却最影响点击。下面按平台风格给出**可套用模板**，把 `{t}` 换成你的核心选题即可。

## 平台风格差异

| 平台 | 标题偏好 | Hook（前 3 秒 / 首句）要点 |
|------|---------|--------------------------|
| B站 | 保姆级、实战、从入门到精通 | 先抛真实场景痛点，再承诺「看完能做」 |
| 知乎 | 提问式、理性对比、结论先行 | 先给结论，再拆步骤，最后给模板 |
| 公众号 | 实战手册、可复制、体系化 | 把散点经验整理成流程，强调长期价值 |
| 小红书 | 攻略、清单、避坑、可直接照做 | 封面突出「结果」：省时/少踩坑/可复制 |
| 视频号 | 1 分钟看懂、前后对比 | 一个前后对比展示价值，承接微信转发 |
| 抖音 | 反常识、真相、痛点前置 | 前三秒展示痛点和结果差异，强节奏 |
| 微博 | 观点摘要、行业讨论、热点接法 | 用一句话观点接热点或争议 |
| 快手 | 实在、接地气、老铁信任 | 真人出镜，先给结果再讲方法 |
| 今日头条 | 结论先行、数据、资讯感 | 标题直接点出结论或争议点 |
| 西瓜视频 | 完整演示、深度、案例 | 一个完整案例把事讲透 |
| 百家号 | 干货、关键词、搜索友好 | 从搜索意图出发给答案 |
| 豆瓣 | 态度、氛围、长尾讨论 | 真诚开头，引发同好共鸣 |

## 通用模板（按内容形式）

- **清单体**：`{t}的 N 个关键点` / `{t}保姆级清单📌`
- **避坑体**：`别再踩坑！{t}正确姿势` / `{t}最常见的 3 个误区`
- **对比体**：`{t}到底值不值得做？` / `关于{t}，这是我见过最清晰的回答`
- **结果体**：`用{t}解决一个真实问题` / `一个视频讲清{t}`
- **反差体**：`90%的人都不知道{t}` / `{t}的 3 个真相`

## 钩子写法（前 3 秒 / 首句）

1. **痛点前置**：「你是不是也……」「每次做{t}都……」
2. **结果前置**：「我用{t}把 3 小时活儿压到 10 分钟」
3. **反常识**：「别再……，{t}真正重要的是……」
4. **提问钩子**：「{t}到底该不该做？先看完这 3 点」
5. **身份代入**：「如果你也是……，这条一定要看」

> 每次只测一个变量：标题钩子 OR 封面 OR 时长 OR 结尾转化入口，不要同时改。
