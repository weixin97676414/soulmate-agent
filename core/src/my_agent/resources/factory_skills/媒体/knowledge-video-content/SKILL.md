# 双平台知识类内容生产（抖音 + 小红书）

核心命题：做一个负责任的知识翻译者——先深刻理解，再精准表达。

## 一、账号定位

| 平台 | 人设定位建议 | 语气风格建议 |
|:---|:---|:---|
| 抖音 | 决策/判断力方向 | 共情式 + 互动式 |
| 小红书 | 思维模型/认知升级方向 | 真诚式 + 品味式 |

使用者应按自身品牌定位自定义具体人设名称、简介和语气风格。核心赛道：决策力提升 | 思维陷阱避坑 | 认知升级 | 博弈策略 | 信息甄别 | 人性洞察。

## 二、内容生产完整路线图

```
第一步：选择内容起点（路径A 书籍驱动 / 路径B 困惑驱动）
↓
第二步：深度理解三问（强制执行）
↓
第三步：选择视频时长（阶梯式）
↓
第四步：提炼核心观点（地铁测试法）
↓
第五步：选择叙事结构（6 种模板）
↓
第六步：搭建情绪曲线（情绪钩子）
↓
第七步：填充案例细节（电影感叙事）
```

## 三、深度理解三问（动笔前强制执行）

> 跳过这步 = 不负责任的内容生产。

1. **观点溯源**：这个观点最初在什么背景下提出？作者用什么实验/案例证明？论证站得住脚吗？
2. **边界划定**：它解决什么类型问题？什么情况不适用？有反例吗？
3. **换位思考**：如果有人用它解释不相关的现象，我能看出问题在哪吗？

理解三层：知道观点（表层）→ 理解论证（中层）→ 识别边界（深层）。完整解读从层次三出发倒叙展开。内容中体现边界：给方法加适用条件；引经据典加前置背景；解释现象加理论盲区。

## 四、内容起点选择器

**路径 A：书籍驱动** —— 从书籍出发提炼核心观点，匹配用户痛点。详见 `references/book-driven.md`。

**路径 B：困惑驱动** —— 从生活/工作中的困惑或现象出发，反向寻找能解释它的书籍、理论。四种模式：

| 模式 | 特点 | 示例 |
|:---|:---|:---|
| 日常困惑型 | 共鸣最强 | "为什么越想睡越睡不着" |
| 热点现象型 | 自带流量 | "为什么大家都在抢购XX" |
| 经典问题型 | 厚度最深 | "人真的能改变吗" |
| 类比穿透型 | 认知冲击最强 | "减肥和存钱竟是同一个问题" |

## 五、时长选择

- **抖音**：短版 60-90 秒（300-450 字）| 标准版 120 秒（600 字）| 长版 150-180 秒（750-900 字）
- **小红书**：短视频 15-30 秒（75-150 字）| 标准版 120-150 秒（600-750 字）| 长版 150-180 秒（750-900 字）

短版追完播率（≥35%），长版追收藏率（≥5%），标准版平衡。

## 六、核心创作原则

### 地铁测试法（做减法）

1. 用户只能记住**一件事** → 核心观点保留。
2. 删一句话不受影响 → 删掉。
3. 最像"正确的废话" → 删掉或换具体场景。

### 情绪钩子（建节奏）

| 时间段 | 情绪任务 | 用户心理 |
|:---|:---|:---|
| 0-5 秒 | 认知失调 | "什么？真的假的？" |
| 5-30 秒 | 情绪松绑 | "说的就是我，原来不是我的错" |
| 30-60 秒 | 权威震撼 | "原来如此！有科学依据" |
| 60-90 秒 | 希望赋能 | "这个我也能做到" |
| 90-120 秒 | 行动召唤 | "我要试试" |

短版等比例压缩；长版延长"权威震撼"和"希望赋能"。

### 电影感叙事

公式：**场景钩子 + 数字细节 + 转折反转**。

- 高光/至暗时刻：创业/投资/重大选择
- 慢性病瞬间：拖延/内耗/纠结
- 硬知识软化：心理学效应/认知偏差

## 七、6 种叙事结构模板

详见 `references/narrative-templates.md`。

| 模板 | 核心 | 适用 |
|:---|:---|:---|
| 强冲击型 | 先颠覆常识，再给科学解释 | 《思考快与慢》《反脆弱》 |
| 强共鸣型 | 先共情痛点，再给亲测方法 | 《情绪勒索》《掌控习惯》 |
| 强故事型 | 先讲好故事，最后提炼道理 | 《乔布斯传》《人类简史》 |
| 强干货型 | "就三步"，清晰可执行 | 《搞定》《番茄工作法》 |
| 强观点型 | 先抛核心观点，再层层拆解 | 《原则》《穷查理宝典》 |
| 强关联型 | 先讲热点，再用原理解读 | 任何能关联热点的书 |

## 十、封面与视觉规范

## 十一、标签策略

小红书 68% 流量来自搜索。关键词四层：核心大词 → 场景词 → 人群词 → 长尾词。植入位置：标题 > 正文首句 > 标签区 > 封面文字。抖音 3-5 个标签，小红书 5-8 个（通用大词+精准小词+书名/热点/人群词）。

## 十二、数据复盘

核心指标合格线：

- 封面点击率 ≥3% | 5s 完播 ≥30% | 2s 跳出 ≤30%
- 整体完播 ≥25%（短版 ≥35%）
- 收藏率 ≥5%（双平台）| 评论率 ≥1% | 点赞率 ≥3% | 涨粉率 ≥0.5%
- 小红书搜索流量占比 ≥30%
