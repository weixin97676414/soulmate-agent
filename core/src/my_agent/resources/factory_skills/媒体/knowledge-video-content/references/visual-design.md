# 封面与视觉设计规范

## 通用规范
- 统一比例：3:4竖版（1080×1440px）
- 必须包含：标题文字（≥画面1/3）+ 生活痕迹元素
- **绝对禁止**：完美AI感场景 / 标题字号过小 / 真人出镜

## 双平台视觉差异

| 维度 | 抖音 | 小红书 |
|:---|:---|:---|
| 色调 | 冷调清晰 | 暖灰调 |
| 字体 | 粗黑体 | 粗宋体 |
| 配色 | 深蓝+白+亮黄 | 灰白+深灰+暗橙 |
| 切换节奏 | 快切（15秒） | 慢节奏（20秒） |
| 生活痕迹 | 科技感/数据/图表 | 书本/咖啡/笔记本 |

## 封面标题写法
- 抖音：痛点前置 + 数字 + 反转
  - 例："90%的人不知道的决策陷阱"
- 小红书：搜索关键词 + 结果承诺
  - 例："读完这3本书，再也不怕做决定"

## AI配音选择
- 抖音：沉稳青年音/知性男声
- 小红书：沉稳男声/磁性中音

## 画面切换节奏
- 抖音：每15秒切换画面，保持注意力
- 小红书：每20秒切换，允许更长的画面停留

## 金句定格
- 视频末尾金句定格≥2秒
- 字体加大+居中+简洁背景
- 这是收藏率的关键触点
