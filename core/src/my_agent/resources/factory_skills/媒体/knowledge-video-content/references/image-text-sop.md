# 图文爆款内容SOP

## 一、书单合集型（爆款率最高）

**内容公式**：数字 + 痛点人群 + 主题 + 每本1句话推荐理由

### 标题公式
- "读了100本书后，这[N]本让我彻底变了"
- "这[N]本书，[痛点人群]一定要读"
- "[年份]最值得读的[N]本[主题]书"

### 封面
- 书籍封面拼图（3×3或2×3）
- 大字标题 + 暖色调
- 小红书：搜索关键词前置 + 结果承诺可视化

### 正文结构
```
开头：痛点共鸣（1-2句）
书单：每本书 = 封面图 + 1句炸裂推荐理由 + 适合谁读
结尾：互动CTA（"你最想读哪本？"）
```

### 推荐理由写法
❌ "这本书很好，推荐大家阅读"
✅ "读完这本书，我终于理解为什么越努力越焦虑"
公式：[读完/用了后] + [具体改变/顿悟时刻]

## 二、读书笔记/摘抄型（收藏率最高）

**内容公式**：1句炸裂金句 + 书名出处 + 1句个人感悟 + 精美排版

### 三种形式

**1. 单金句卡片**
- 纯文字排版，字体设计感
- 配色：暖灰底+深色字 或 深色底+浅色字
- 金句居中，书名右下小字

**2. 书评摘抄混排**
- 3-5条金句，每条配1句感悟
- 间隔用简约分割线
- 最后一张图放书封+评分

**3. 手写笔记风**
- 模拟手写体排版
- 重点标记/划线效果
- 贴纸/便签装饰元素

## 三、治愈系情绪表达规范

| 层次 | 作用 | 表达示例 |
|:---|:---|:---|
| 情绪松绑 | 化解挫败感 | "这个问题我困了好几年，后来才放过自己" |
| 温暖赋能 | 给改变希望 | "只需要你先迈一小步" |
| 身份认同 | "这说的就是我" | "我们这种人，总是习惯性先否定自己" |

## 四、小红书图文发布规范

- 图片数量：6-9张（算法偏好6+）
- 首图决定点击率：标题字号≥画面1/3
- 正文：前2行决定搜索推荐，核心关键词前置
- 结尾：开放式问题引导评论
- 标签：5-8个，含搜索词
