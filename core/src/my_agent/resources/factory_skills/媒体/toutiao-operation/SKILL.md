## 场景一：内容创作指导

1. **确认创作类型**：图文文章 / 微头条 / 带货文 / 视频脚本。
2. **确认领域**：科技/职场/生活/历史/情感……
3. **提供标题方案**：套用"爆款标题 8 大技巧"——蹭热点、用对比、反常识、数字、设问、共鸣、权威转嫁、总分总结构。
4. **提供内容结构**：开头钩子 → 信息增量正文 → 结尾互动引导。
5. **审核检查**：是否有标题党风险？是否合规？

输出格式：

```
## 内容方案
### 标题建议
[3-5 个标题，标注推荐指数]
### 文章结构
- 开头：[钩子设计]
- 正文：[核心内容/信息增量]
- 结尾：[互动引导]
### 优化要点
[图片建议 / 关键词嵌入 / 发布时间建议]
### 合规检查
[是否有违规风险提醒]
```

## 场景二：推荐与审核诊断

**排查推荐问题**：消重策略（内容是否与他文重复）→ 同类竞争（同领域是否饱和）→ 内容质量与垂直度 → 指标异常（点击率/完读率/互动率是否偏低）→ 冷启动问题（新号权重不足）。

**审核问题排查**：是否触及 8 类违规红线（违法、色情、标题党等）→ 是否有营销推广违规 → 是否被判定为低质内容。

输出格式：

```
## 推荐/审核诊断报告
### 问题定位
### 原因分析（从推荐机制/审核规则角度解释）
### 解决方案（分 1.2.3. 列出）
### 预防建议
```

## 场景三：变现路径规划

1. **评估账号基础**：粉丝量、内容领域、阅读量水平。
2. **匹配变现方式**：
   - 图文广告分成（门槛最低，有收益开关即可）
   - 巨量星图商单（需一定粉丝和内容质量）
   - 内容电商/带货（适合种草类内容）
   - 付费专栏（需专业知识沉淀）
   - 直播带货（需人设和粉丝基础）
3. **提供启动步骤**：从开通权限到接单提现。写"广告主青睐的内容"遵循 ROY 原则：相关性（Relevance）、原创性（Originality）、影响力（Yield）。

## 场景四：账号定位与起号

1. **定位诊断**：用"三圈定位法"（我喜欢 / 我擅长 / 我应该）找方向。
2. **账号包装**：昵称、头像、简介、主页设计。
3. **内容规划**：日更频率、领域垂直度、内容形式配比。
4. **冷启动策略**：前 30 天的发布节奏和目标。

适合新手的 4 类定位：写自己故事、写兴趣领域、写正在做的事、写专业技能。

## 工作流示例

**新手想做头条号**：三圈定位法梳理方向 → 推荐 4 类新手定位 → 账号包装建议 → 起号前 30 天内容计划 → 提醒审核红线与避坑。

**文章没推荐**：询问领域/标题/发布时间 → 从 5 个维度诊断 → 查违规或标题党风险 → 给优化建议（标题、内容结构、发布时间）→ 给长期获得推荐的建议。

**想靠头条号赚钱（如 1 万粉）**：确认领域与内容类型 → 评估各变现方式匹配度 → 推荐从图文广告+星图商单起步 → 给星图注册开通流程 → 讲如何写"广告主青睐的内容"（ROY 原则）。

## 重要提示

- **方法论检索**：按 `references/content-index.md` 的 6 大模块索引定位本文件未展开的方法论。
- **时效性补充**：平台规则和算法会更新，最新政策变化辅以网络搜索确认。
- **实操落地**：建议要具体到可执行（如"标题用数字+对比结构"），不要"标题要写好"。
- **合规红线**：帮用户把审核关，避免标题党、虚假宣传、抄袭搬运、违规推广。
- **适度乐观**：不泼冷水（"现在做太晚了"），也不画大饼（"轻松月入过万"）。
