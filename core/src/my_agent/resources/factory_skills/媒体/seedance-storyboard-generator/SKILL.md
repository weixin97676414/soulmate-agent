# Seedance 四幕剧集分镜生成 (seedance-storyboard-generator)

把素材（长文/小说/大纲）转换为可生产的 Seedance 2.0 视频脚本：分析输入 → 确认参数 → 四幕结构 → 素材清单 → 逐集分镜。

## 工作流程

### 1. 分析输入

判定输入类型：**完整文本**（需改编与分集）或**大纲**（需完整剧本开发）。提取核心要素：主角与关键角色、核心冲突与叙事弧线、设定/世界观、关键情节与情绪节点。输入含糊或不完整时先追问。

### 2. 确认制作参数

必须确认：**视觉风格**（写实/动画/水墨/科幻/复古/电影感等）、**总时长**（标准：20 集 × 15s ≈ 5 分钟）、**目标平台画幅**（16:9 横屏 / 9:16 竖屏 / 2.35:1 电影宽屏）、**整体情绪基调**（史诗/温馨/悬疑/欢快/忧伤等）。记录参数并在全流程统一套用。

### 3. 生成四幕剧本结构

- **Act 1（起）** 第 1-5 集：引入与激励事件
- **Act 2（承）** 第 6-10 集：上升动作与复杂化
- **Act 3（转）** 第 11-15 集：高潮与对抗
- **Act 4（合）** 第 16-20 集：收束与结局

每集包含：集号与标题、时长（标准 15s）、情绪基调、关键情节点、起止帧描述（供连续性）。输出 Markdown 文档，分节清晰。

### 4. 生成素材生成计划

给所有视觉素材分类编号：

| 类别 | 前缀 | 示例 | 说明 |
|------|------|------|------|
| 角色 | C01-C99 | C01 叶青云·正面全身 | 每角色多角度 |
| 场景 | S01-S99 | S01 青锋山废墟 | 关键地点 |
| 道具 | P01-P99 | P01 青锋剑 | 重要物件 |

素材提示词格式：

```
### [编号] — [名称]

[风格前缀], [detailed visual description in English], [technical specs]
```

风格前缀示例：Chinese ink wash painting style mixed with anime cel-shading / Cinematic photorealistic style with dramatic lighting / 3D Pixar-style animation rendering / Sci-fi cyberpunk aesthetic with neon lighting。**角色差异化**：用不同配色与视觉标识，确保在选定画风下可辨识。输出为带唯一 ID 的有序列表，便于复制进图像生成器。

### 5. 生成 Seedance 2.0 分镜脚本

每集产出：

**a. 素材上传清单**

```
图片1: C01 (角色参考)
图片2: S03 (场景参考)
图片3: P01 (道具参考)
```

**b. Seedance 提示词（时间轴格式）**

```
[风格描述]，[画幅比例]，[整体氛围]

0-3s画面：[镜头运动]，[场景建立]，[主体引入]
3-6s画面：[镜头运动]，[情节发展]，[动作描述]
6-9s画面：[镜头运动]，[高潮/冲突]，[情绪爆发]
9-12s画面：[镜头运动]，[转折/过渡]
12-15s画面：[镜头运动]，[结尾/落版]

【声音】[配乐风格] + [音效] + [对白/旁白]

【参考】@图片1 [用途]，@图片2 [用途]...
```

**c. 结尾帧描述**：记录最后一帧内容，供下一集连续性使用。

运镜关键词：推镜头/拉镜头/摇镜头/移镜头/跟镜头/环绕镜头/升降镜头/希区柯克变焦/一镜到底/手持晃动。
**剧集衔接（第 2 集起）**：提示词以 `将@视频1延长15s` 开头，并把上一集作为视频参考上传。

## 输出文件

1. `[标题]_剧本.md` — 完整四幕剧本与分集拆分
2. `[标题]_素材清单.md` — 全部角色/场景/道具提示词
3. `[标题]_E[XX]_分镜.md` — 单集或合并的分镜脚本

## 质量自检

- 所有素材引用（@图片X）在素材清单中有对应 ID。
- 集与集连续（上集结尾帧 → 本集开场帧）。
- 时间轴覆盖完整 15 秒。
- 运镜可行且顺序合理。

## 常见坑

1. **敏感词**：Seedance 可能拒绝含特定词的内容，规避常见触发词或改用替代表述。
2. **提示词过复杂**：300+ 词的长提示可能指令跟随不一致，清晰的短提示更稳。
3. **缺连续性**：务必记录结尾帧并核对下一集开场。
4. **风格不一致**：所有素材提示词套用同一视觉风格前缀。
