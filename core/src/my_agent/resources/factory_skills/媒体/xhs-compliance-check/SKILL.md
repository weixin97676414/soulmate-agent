# 小红书内容合规与敏感词自查

发布前把笔记过一遍，查出高危词，把「踩雷」挡在发布之前。核心信条：**合规不是束缚，是最低成本的长期运营策略。**

## 一、何时使用

- 用户要写或已写好小红书笔记 / 种草文案 / 爆款标题 / 封面文案，想先确认会不会限流、踩违禁词
- 用户要批量起号 / 做品牌矩阵号，需要发布前的统一合规闸口
- 用户笔记被限流 / 下架 / 灰显，想定位违规措辞
- 用户准备发布内容时先完成风险提示（本技能不执行发布，发布须另行授权）

## 二、核心步骤：跑离线自查脚本

```bash
python3 scripts/xhs_sensitive_check.py 笔记.md
# 输出：命中的违禁词 + 类别 + 位置 + 替换建议 + 2026 平台审核提示

python3 scripts/xhs_sensitive_check.py 笔记.md --json   # JSON 输出，便于 agent 消费
```

- 纯标准库，无 API key，离线可跑；无需联网。
- 输入是 `.md / .txt` 笔记文件路径。
- 示例：`python3 scripts/xhs_sensitive_check.py assets/sample_note.md`（`assets/sample_note.md` 故意埋了违禁词，用于演示检出效果）。
- 脚本还会用 `最 + 形容词` 前缀模式提示广告法绝对化（如「最近」这类日常口语可人工忽略）。

## 三、输出解读

脚本逐行扫描，输出每处命中的 `类别 + 词 + 所在行 + 替换建议`，并给出一组 2026 平台审核提示。**命中不等于平台一定会判违规**——它是启发式提示，要结合语境（带货 / 测评语境的高危词更严），最终仍需人工复核平台最新规则。

## 四、覆盖的十三类红线

| 类别 | 典型违禁词 | 替换方向 |
|---|---|---|
| 广告法极限词 | 最、第一、顶级、国家级、唯一、100%、永久、史无前例、蕞有效、彻底 | 较好 / 领先 / 少数 / 绝大部分 / 长期 |
| 医疗绝对化 | 根治、治愈、永不复发、无副作用、增强免疫力（无资质） | 改善 / 缓解 / 副作用少；保健功能需蓝帽子或药品资质 |
| 金融投资诱导 | 稳赚、保本、零风险、月入过万、躺着赚钱 | 收益有波动 / 不保证本金（此类内容建议不发） |
| 引流导流 | 加微信、加V、薇信、丝我、私我、淘宝、二维码、私信领资料、完整版移步主页 | 删除（2026 谐音 / 变体 / 暗示性引流均可识别） |
| 教育培训夸大 | 包过、保过、押题、命中率100%、包上岸 | 助你通过 / 高频考点 |
| 网络热词极限宣传(2026) | yyds、天花板、封神、神级、绝绝子（带货语境） | 带货 / 测评语境勿用 |
| 竞品拉踩(2026) | 吊打、碾压、完爆、秒杀同行、别家垃圾 | 删除（贬低竞品零容忍） |
| 美妆护肤红线(2026) | 祛斑、防脱、医美级、食品级、无激素、干细胞 | 需特证则改「提亮肤色 / 养护头皮」；无检测报告禁标「无激素 / 0 刺激」 |
| 焦虑营销/虚假福利(2026) | 免费领、万人疯抢、错过再无、必买、手慢无 | 改写为「库存不多，喜欢可尽早入手」等 |
| 三品一械禁分享(2026) | OTC、非处方药、保健食品、医疗器械、医用敷料、医疗健康服务 | 2026-02-10 起禁止在笔记与直播间分享推广 |
| 炫富/虚假人设(2026) | 月入10w、三个月收入六位数、挑战一天花光100万、伪造创业人设 | 删除（判宣扬奢侈浪费） |
| 金融生态公约(2026-09) | 荐股、带单、跟单、喊单、股票代码、崩盘、唱衰、保本保息、银行背书、炒币、进群 | 八类禁内容，零容忍 / 从严处置 |
| 金融网络营销办法(2026-09-30) | 低风险、低门槛、秒到账、秒批、高收益、低利率、零成本、首期仅需、日息、财富管理、资产管理、融资、贷款、征信、信托 | **国家强制规范**，删除；涉金融属性字样无资质禁用于账号名称 |

## 六、2026 平台审核要点（发布前必读）

- **AI 生成内容必须标注「AI 辅助创作」**；《人工智能生成合成内容标识办法》将显式 / 隐式标识写进强制国标，发布侧不得移除、篡改、伪造或隐匿平台添加的 AI 标识，未主动标注会被平台辅助加标并可能降权。
- **谐音 / 拼音 / 符号隔断 / 拆字**等规避手段 2026 年已可被识别，直接合规表达。
- **搬运 / 同质化**：图文或文案相似度超 50% 可能被判搬运；「一篇通稿改十版」在算法侧等同重复内容，触发低质标记。
- **三品一械**（OTC 药品 / 保健食品 / 医疗器械 / 医疗健康服务）自 2026-02-10 起禁止分享推广。
- **可识别友商品牌名**出现在对比性内容里即属违规（2026-07 社区公约修订），改为「之前用过的另一款同类产品」。
- **金融内容**：《社区金融生态公约》（2026-09-15）八类禁内容 + 须风险提示 + 营销须持牌与平台资质认证；《金融产品网络营销管理办法》（2026-09-30，央行等八部门）为强制规范，含话术负面清单与账号命名 27 词清单。
- 封面勿重度 P 图、勿用夸张前后对比；账号昵称 / 简介 / 头像同样适用违禁词规则。
- 聚光 / 商业推广另设高风险词库（医美、K12 教培、大健康、医疗器械、减肥），投放素材需单独自查。

2026 平台规则时间线（1-19 社区公约 2.0 → 2-10 三品一械 → 5-09 打击炫富 → 6-10 搜索生态 → 7 社区公约修订 → 9-01 合规风暴 → 9-15 金融生态公约 → 9-30 金融网络营销办法）与逐条要点见脚本输出与 `references/compliance-checklist.md`。

## 七、边界与红线

- 不代写医疗 / 金融 / 教育的绝对化承诺；涉及这些领域必须标注「非专业建议」。
- 三品一械不生成分享推广型内容；不生成金融荐股 / 带单 / 跟单类内容，不伪造金融资质或投资业绩。
- 不生成炫富、伪造人设、刻意凸显消费水平的内容；对比型内容不出现可识别友商品牌名。
- **违禁词库是「提示」不是「免责」**，发布前仍要人工复核平台最新规则。
- **本技能不执行发布**；发布须交给独立的小红书发布工具并经用户确认。
