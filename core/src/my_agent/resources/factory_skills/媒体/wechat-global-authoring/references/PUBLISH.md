# 发布交付规则

## 发布包建议

```text
article.md
article.html
cover/
images/
metadata.json
quality-report.md
```

## 最终人工确认

发布前确认：

- 标题与摘要是否为最终版本；
- 封面、图片顺序是否正确；
- 作者、来源、转载声明是否正确；
- 是否设置原文链接、免责声明或其他必要声明；
- 是草稿、定时还是立即发布。

## 授权边界

平台后台操作只能通过用户已有的合法授权环境完成。没有授权时生成发布包，不声称已经完成后台发布。

不要在日志、示例、配置和发布包里输出真实账号信息、访问令牌、会话信息或密码。
