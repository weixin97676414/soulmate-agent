# 内容再创作规则

## 定位

本工作单元用于编辑、信息重组和平台适配，不用于隐藏复制关系或规避原创审核。

## 四种模式

### 1. Clean
保留原意，修正表达与逻辑漏洞。

### 2. Reframe
重新设计切入点、结构和论证顺序。

### 3. Expand
基于新证据增加案例、背景、数据和解释。

### 4. Repurpose
将长文转成摘要、FAQ、短帖、口播或图文卡片。

## 不得改变

关键事实、数据口径、引用关系和必要归因。

## 可以改变

标题、段落顺序、例子组织、导语、表达方式与说明粒度。

不要模拟特定在世作者的标志性写法，也不要把大量原文换词后当成独立原创。
