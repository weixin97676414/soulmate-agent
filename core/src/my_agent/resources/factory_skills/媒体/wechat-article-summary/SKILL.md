# 公众号文章摘要

对公众号文章或长文章生成结构化摘要：核心观点、关键数据、行动建议。纯本地处理用户提供的文本，不访问网络、不抓取付费内容。

## 能力边界

能做：

- 把用户粘贴的全文（或已保存到本地的正文）转换为结构化摘要。
- 自动识别文章类型（观点型／数据型／教程型／故事型）并据此组织摘要。
- 提取关键数据（金额、百分比、日期、数量等）。
- 对不确定项给置信度提示（≥90% 直接输出／85–90% 建议复核／<85% 标注「需核实」）。
- 支持批量处理（最多 10 篇／次）与输出格式切换（markdown／json／csv）。

不做：

- 不访问网络或外部服务，只处理用户提供的文本。
- 不访问付费内容，不抓取需登录或付费墙后的文章。
- 不生成超出输入范围的推测性结论。
- 不保证绝对准确，低置信度会标注。

## 执行步骤

1. 收集最小信息集：输入来源（文本 / 文件）、输出格式、期望完整度（快速骨架 / 详细成品）。
2. 运行脚本：

   ```bash
   # 直接输入文本
   python3 scripts/main.py --text "文章正文……"

   # 从文件读取
   python3 scripts/main.py --file article.md --format markdown

   # 关闭关键数据 / 关闭行动建议 / 自检
   python3 scripts/main.py --file article.md --no-data --no-action
   python3 scripts/main.py --selftest
   ```

   - `--format`：`markdown`（默认）／`json`／`csv`。
   - `--no-data`：不提取关键数据；`--no-action`：不生成行动建议。
   - `--verbose`：显示修改/提取明细。
3. 整理结果为约定格式输出，自查字段完整性与置信度标注。

## 异常处理（错误码）

| 错误码 | 场景 | 处理 |
|---|---|---|
| E001 | 输入为空 | 请用户提供正文或文件路径 |
| E002 | 无法识别输入来源 | 确认是链接还是全文；本工具只处理文本，链接需用户先提供正文 |
| E003 | 输入格式错误 | 展示正确格式并请用户重发 |
| E004 | 超出能力边界 | 说明原因，建议替代方案或人工处理 |
| E005 | 置信度过低 | 建议提供更完整原文或人工复核 |
| E006 | 批量超过 10 篇 | 分批处理，每批 ≤10 篇 |
| E007 | 输出格式不支持 | 仅支持 markdown／json／csv |
| E008 | 文本超长 | 超长输入会截断并标注，建议分段处理 |
| E009 | 关键数据提取失败 | 降级为只提取数字与单位组合，并标注需人工复核 |
| E010 | 参数配置错误 | 展示默认参数表并引导修正 |

## 输入输出示例

输入：一段公众号长文正文。

输出（三段式）：

```markdown
## 核心观点
- ……

## 关键数据
- ……

## 行动建议
- ……（基于文章类型的模板生成，非原文提取）
```

## 注意事项

- 行动建议是基于文章类型的模板生成，不是原文提取，交付时要说明。
- 关键数据以原文为准；低置信度结果务必人工复核。
- 输入片段过短（<50 字）会导致置信度偏低。
- 不处理付费墙内容；不访问网络。
