# 热门内容分析模板

> 用本模板输出热门内容分析。无数据/不确定就标注"建议联网核实/待确认"，不虚构热度。

## 一、热点概况

- **热点内容**：<是什么 / 关键词 / 大致现象>
- **热度与阶段**：<上升 / 爆发 / 峰值 / 回落；建议标注来源或"待确认">
- **生命周期**：<长时效 / 中期 / 短时效，及大约持续多久>
- **来源**：<从哪里看到/核实到>

## 二、可蹭性判断

| 维度 | 评估 | 说明 |
|---|---|---|
| 热度 | <高/中/低> | 是否在上升/爆发期 |
| 相关性 | <高/中/低> | 能否自然接回账号领域 |
| 承载能力 | <强/中/弱> | 你能否产出独特角度/干货 |
| 风险 | <低/中/高> | 是否敏感/争议/不合适 |

**结论**：<值得蹭 / 谨慎 / 放弃>，理由 <一句话>。
