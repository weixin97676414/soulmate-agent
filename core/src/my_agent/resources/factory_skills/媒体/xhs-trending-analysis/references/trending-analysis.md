# 热门内容分析方法论

> 本文件是 `references/trending-analysis.md`，供 AI 分析热门内容、判断可蹭性、给选题时查阅。目标：**找对热点、判断值不值得蹭、找贴合定位的切入点、从爆款笔记里学框架**。

## 1. 为什么做热门内容分析

- 追热点是**低成本获取流量**的路径之一，平台会为热话题导流。
- 但盲目蹭会出戏、掉粉、被判低质；所以关键是 **"判断可蹭性"+"贴合自身定位"**。
- 分析爆款笔记不是为了照抄，而是学它的**框架与选题逻辑**。

## 2. 怎么找热点（信息源）

- 平台内：小红书**搜索页/发现页热门、话题广场、飙升榜**；笔记下"热门评论"也常藏话题。
- 平台外：微博热搜、抖音热榜、百度指数、微信指数、新闻热点，预判可能在小红书发酵的话题。
- 结合**时间节点**（节日/节气/大促/社会事件）预判。

## 3. 判断"可蹭性"（蹭不蹭）

对每个热点打分，避免无脑蹭：

| 问题 | 说明 |
|---|---|
| **热度** | 是否正处于上升/爆发期，还是已过峰？ |
| **生命周期** | 是长时效（如"冬季保湿"可持续）、中期（如"考试季"一周）、还是短时效（如某事件 1~2 天）？ |
| **与定位相关性** | 能否自然接回你的领域？相关性弱就别硬蹭。 |
| **承载能力** | 你能产出什么角度？是否有独特观点/干货？ |
| **风险** | 是否涉及敏感/争议/不合适话题？会不会适得其反？ |

**结论：** 热度高 + 相关 + 你有角度 + 无风险 = 值得蹭；缺任一，谨慎或放弃。

## 4. 找切入点（怎么蹭得自然）

- **用自己的领域解释/回应热点**（蹭话题但回到你专业）。
- **借热点讲方法/干货**（"从 xx 热搜，聊聊我们该怎么做"）。
- **反套路/补充视角**（大家都这么说，你给不同/更高阶的角度）。
- **把热点做成系列/测评/清单**（承接热度，延展价值）。
- **结合人设讲故事**（从你个人经历切入热点，更有代入感）。

## 5. 拆解爆款笔记（学框架，不抄袭）

从一篇高互动笔记提炼六要素：

| 要素 | 看什么 |
|---|---|
| **选题** | 戳中了什么痛/好奇/情绪？ |
| **封面/首图** | 视觉吸引点、标题字、信息量 |
| **标题** | 用了什么钩子/公式？ |
| **正文结构** | 怎么开头、怎么给价值、怎么收尾 |
| **标签** | 大流量/垂直/精准的配比 |
| **互动** | 评论区在聊什么、作者怎么引导 |

> 学它的"结构 + 逻辑"，再换成你自己的内容与差异化角度。

- [ ] 是否做了可蹭性判断（分数或结论）；
- [ ] 是否给出了贴合账号定位的 2~3 个选题；
- [ ] 是否拆解了 1~2 篇标杆爆款笔记的框架；
- [ ] 是否有"风险/别踩坑"提示；
- [ ] 是否虚构了热度数据（联网核实就标来源，否则明说）。
