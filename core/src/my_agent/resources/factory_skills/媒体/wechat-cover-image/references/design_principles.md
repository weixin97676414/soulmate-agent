# 设计原理（Design Principles）

封面是公众号的「门面 + 广告位」。以下原则用于保证成片**高点击、缩略可辨、标题清晰、品牌一致**。全部内建知识，无需外网。

## 1. 点击率心理学（为什么用户会点）

| 心理杠杆 | 封面运用 | 示例 |
|----------|----------|------|
| 痛点直击 | 标题点出「我也这样」的窘境 | 「天天加班却没产出？」 |
| 好奇缺口 | 给结论一半，留一半勾人 | 「这 3 个习惯，第 2 个最反直觉」 |
| 利益明确 | 一眼看懂「看了能得到啥」 | 「5 分钟搞懂养老金」 |
| 社会证明 | 数字/权威背书 | 「10w+ 收藏的排版法」 |
| 情绪共鸣 | 画面+文案共振 | 暖光场景 + 「下班后的自由」 |
| 稀缺/紧迫 | 限时/独家感 | 「仅此一篇的避坑指南」 |
| 视觉冲击 | 强对比/非常规构图抢眼 | 暗黑逆光主体 |

> 原则：封面只解决「**让人想点**」，正文解决「让人看完」。两者分工，别在封面塞过多信息。

## 2. 配色心理学

| 情绪 | 主色建议 | 适用赛道 |
|------|----------|----------|
| 信任/专业 | 蓝、藏青 | 财经、职场、科技 |
| 活力/行动 | 橙、红 | 健身、促销、干货 |
| 治愈/温柔 | 奶油、浅绿、粉 | 情感、育儿、家居 |
| 高级/神秘 | 墨黑+金、深紫 | 国风、数码、时尚 |
| 清新/自然 | 青绿、天蓝 | 健康、旅行、美食 |
| 喜庆/国潮 | 朱红+墨 | 节日、文化 |

- **对比度优先**：标题与背景对比 ≥ 4.5:1（WCAG AA）。
- **≤ 3 主色**：超出显杂乱。用「1 主色 + 1 辅色 + 中性底」。
- **蒙版保读**：浅底图压白字时，底部加 40–60% 黑渐变蒙版。

## 3. 字体层级（标题精排）

| 层级 | 字号比 | 字重 | 作用 |
|------|--------|------|------|
| 主标题 | 1.0（基准） | 粗体 700–900 | 信息重点，≤14 字最佳 |
| 副标题 | 0.5–0.6 | 常规 400 | 补充说明 |
| 栏目标签 | 0.28–0.35 | 中粗 600 | 角标/色块，如「干货」「深度」 |
| 公众号名 | 0.3 | 常规 | 可选角标，强化品牌 |

- 中文主标题优先**无衬线粗体**（黑体/思源黑体/系统粗体）；国风/读书可换**宋体**显雅。
- 行距 1.1–1.2，字间距略收紧更紧凑有力。
- **绝不**让 AI 直接生成中文标题（易错字乱码）；标题由排版引擎合成。

## 4. 构图网格与安全区

- **标题安全区**：默认底部 1/3（或顶部 1/4 高亮区）。主体沉在中/上，避免被标题遮挡。
- **三分法**：主体落在线交点，画面更稳。
- **中心聚焦**：缩略图（108px）下，中心强主体 > 分散元素。
- **留白**：主体外留 15–25% 呼吸空间，避免满。
- **裁切适配**：2.35:1 主封面在 1:1 缩略时上下被裁，重要信息居中防丢。

## 5. 缩略图识别度（最关键却最易被忽略）

公众号列表里封面被压成小图。自检：

1. 缩到 **108×108** 仍能认出主体？
2. 标题在缩略下可读（字号够大、对比够强）？
3. 有没有关键元素被圆角/裁切吃掉？
4. 主体是否够「大」——小远景点缩略后等于没有。
5. 配色是否在信息流里「跳」出来（与邻图区分）？

## 6. 多尺寸适配清单

| 尺寸 | 标题位置 | 主体处理 |
|------|----------|----------|
| 900×383（主） | 底部 1/3 蒙版 | 居中偏上，留标题位 |
| 1080×1080（方） | 底部或对角 | 主体放大居中，防裁 |
| 1080×1350（朋友圈） | 上 1/3 或下 1/3 | 竖构图，主体占 60% |

## 7. 常见翻车与规避

- ❌ AI 写中文错字 → ✅ 标题精排合成，底图无字。
- ❌ 满屏信息看不懂 → ✅ 一图一重点。
- ❌ 缩略糊成一团 → ✅ 中心大主体 + 大标题。
- ❌ 与竞品撞色 → ✅ 选差异化主色/风格家族。
- ❌ 标题压在脸上 → ✅ 遵守标题安全区。
- ❌ 字体侵权风险 → ✅ 用系统/开源字体（思源黑体、站酷系列、系统黑体）。
