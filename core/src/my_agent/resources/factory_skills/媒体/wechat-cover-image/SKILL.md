# 公众号封面与配图工坊（WeChat Cover & Image Studio）

从文章主题、参考图或已认可草稿出发，完成一张重点清晰、点击率高的公众号封面。复用对话中已经明确的决定，沿最短路径交付用户需要的成片。

## 🎯 设计哲学（与同类工具的核心差异）

1. **零配置 · 开箱即用**：仅使用平台内置的图像生成与图像理解能力完成全流程，打开即用。
2. **视觉底图 × 标题精排分离**：先生成「无文字」的高质感视觉底图，再用排版引擎把中文标题清晰合成到「标题安全区」。彻底规避 AI 直接写中文经常出现的错字、乱码、糊字问题。
3. **风格库 + 点击心理学驱动**：内置 `references/styles.md` 风格库与 `references/design_principles.md` 设计原理，方法论内建于 skill，纯本地知识驱动。
4. **多尺寸一体产出**：主封面 `900×383`（2.35:1）、方形缩略 `1080×1080`（1:1，用于次条/会话缩略）、朋友圈分享图按需生成。
5. **可交互精修闭环**：方案对比 → 用户选择 → 单点聚焦修改 → 重生成变体，避免一次性付费/耗时后大幅返工。

## 📋 触发规则

| 场景 | 处理方式 |
|------|----------|
| 用户提供主题/赛道/参考图/草稿 | 执行完整任务流程 |
| 用户要求生成封面方案、配图、标题入图 | 执行完整任务流程 |
| 用户询问技能功能/用法 | 仅介绍技能（见文末「技能简介」） |
| 用户未给明确主题 | 仅介绍技能并询问主题/赛道 |

## 🧩 能力来源

- 全部图像能力来自平台内置工具（图像生成、图像理解），无需额外配置即可使用。
- 所有风格与设计知识来自本 skill 的 `references/`，不依赖外部数据接口。
- 若用户主动粘贴了「爆款数据/竞品封面链接」，可将其作为参考输入，但不强制、不默认联网抓取。

## 🔄 操作流程

### 步骤 1：意图解析（5 维度）

结构化解析用户需求，提取 5 个维度：

| 维度 | 说明 | 示例 |
|------|------|------|
| 内容主题 / 赛道 | 优先领域词 | 护肤、穿搭、美食、职场、育儿 |
| 内容类型 | 内容形式 | 干货、测评、种草、故事、盘点 |
| 目标人群 | 受众画像 | 职场新人、宝妈、学生党、精致白领 |
| 情绪调性 | 视觉/语气 | 专业可信、情绪共鸣、极简治愈、炫酷科技 |
| 标题策略 | 标题入图 or 留白安全区 | 主标题+副标题+栏目标签 / 纯视觉无字 |

- 标题策略默认：**标题入图**（中文标题清晰排版在成片内），除非用户要求「无字背景」。
- 缺失决定只会实质改变结果时才询问；其余用合理默认并合并到一次确认中。

### 步骤 2：风格匹配

读取 `references/styles.md`，按「内容赛道 → 推荐风格」与「视觉风格家族」两个轴为用户挑选 **2–3 套差异化方案**，并给出每套的推荐依据（为什么贴合该赛道/人群）。

- 若用户已指定风格/赛道，直接复用，不另设访谈式断点。
- 若用户未指定，主动推荐 2–3 套，说明差异（如「极简大字报 vs 实拍质感 vs 3D 等距」），让用户快速选向。
- 风格库覆盖：30+ 视觉风格家族（极简大字报 / 实拍质感 / 3D 等距 / 扁平插画 / 渐变流体 / 杂志拼贴 / 手绘涂鸦 / 国潮水墨 / 科技赛博 / 治愈小清新 / 复古胶卷 / 高对比暗黑 / 卡通萌系 / 信息图表 / 电影感运镜 / 微缩场景 / 霓虹渐变 / 东方留白 / 故障艺术 / 蒸汽波 / 低多边形 / 新拟态 / 黏土 3D / 孟菲斯 / 波普艺术 / 剪纸镂空 / 街头涂鸦 / 几何包豪斯 / 黑金奢华 / 双色调 / 像素 8-bit / 森系手作），横跨 17 大内容赛道。

### 步骤 3：形成可执行的封面简报（Brief）

复用用户已给背景，围绕以下要点展开，写成一段结构化简报：

- **一个信息重点** + 缩到 108×108 缩略仍清楚的视觉钩子；
- **一个主视觉主体**，辅助细节只服务于它；
- **明确画布**（默认 `900×383`，次条/缩略 `1080×1080`）；
- **标题策略**：准确短标题（≤14 字优先）+ 可选副标题 + 可选栏目标签（如「干货」「深度」）；
- **风格/配色/构图/光线**：从所选风格家族取配色与构图要点；
- **参考图**（如有）：有序保留必须保留的人物/商品/Logo/颜色。

### 步骤 4：生成视觉底图（无文字）

使用平台**内置图像生成能力**生成「无文字」视觉底图：

- **尺寸**：主封面 `width=900 height=383`（2.35:1）；方形缩略 `1080×1080`；朋友圈 `1080×1350`（4:5）。
- **提示词**：基于 `references/prompt_recipes.md` 的结构化配方，混合中英文关键词，并**明确要求画面不含任何文字/字母/数字**（避免 AI 生成错乱字符）。
- **一次出 2–4 个变体**：用略微不同的构图/光线/主体角度，便于 A/B 对比（见步骤 6）。
- 若用户给了参考图，先用平台**内置图像理解**分析其主体、配色、构图，再据此约束底图生成。

> 注意：不要试图让 AI 直接「把标题写进图里」。标题在步骤 5 用排版引擎精排，质量远高于 AI 写中文字。

### 步骤 5：标题精排（compose）

把中文标题清晰合成到视觉底图的「标题安全区」（默认底部 1/3，留足缩略识别空间）：

- **优先**：调用 `scripts/studio.py compose`，用 Pillow 将标题以清晰中文字体合成到底图，输出最终成片 PNG（自带渐变蒙版保证可读性）。脚本自动探测系统 CJK 字体。
- **降级**：若环境无 Pillow，先 `pip install pillow`（托管环境）；若仍不可用，生成**自包含 HTML 封面**（CSS 排版标题 + 嵌入底图），用户截图即成品。
- 支持：主标题（粗体大号）、副标题（小一号）、栏目标签（角标/色块）、公众号名（可选角标）。
- 标题颜色默认白字 + 底部暗化蒙版；浅色背景时切换深色字 + 顶部高亮。

### 步骤 6：预览方案册（preview）

调用 `scripts/studio.py preview`，读取本次生成的底图/成片清单（Agent 组装为 JSON），产出**自包含 HTML 方案册**：

- 每套方案展示：风格名 + 适用赛道 + 视觉底图 + 标题成片 + 可折叠的生图提示词 + 差异说明；
- 支持 A/B 变体并排对比；
- 模板见 `references/cover_preview_template.html`，脚本注入数据后写 `./封面方案_{主题}.html`。

### 步骤 7：输出前自检（check）

调用 `scripts/studio.py check` 或人工核对清单：

| 检查项 | 标准 |
|--------|------|
| 画布尺寸 | 主封面 900×383(±2px)、方图 1080×1080、朋友圈 1080×1350 |
| 标题安全区 | 标题落在底部 1/3 或顶部高亮区，缩至 108px 仍可辨 |
| 缩略识别度 | 主体在中心、强对比、无被裁关键元素 |
| 层级焦点 | 一眼可见信息重点，标题>副标题>装饰 |
| 标题可读性 | 中文无错别字、无 AI 乱码、对比度足够 |
| 必须保留项 | Logo/人物/商品/品牌色均已保留 |

### 步骤 8：交付与精修

- 用 `present_files` 交付：HTML 方案册 + 最终成片 PNG/JPG。
- 仅提出**一次**聚焦且尚未执行的修改建议（如「换暖色调」「标题再大一号」「主体右移」）。
- 用户要求修改时：仅重生成受影响变体，不整体返工；尺寸/画布变化属新一次生成，需新确认。

## 📐 尺寸规范

| 用途 | 画布 | 比例 | 说明 |
|------|------|------|------|
| 首条主封面 | 900×383 | 2.35:1 | 公众号主页大图 |
| 次条/缩略 | 1080×1080 | 1:1 | 会话、历史列表缩略 |
| 朋友圈分享 | 1080×1350 | 4:5 | 分享到朋友圈/看一看 |
| 双封面（新） | 900×383 + 1080×1080 | — | 一套两用，避免裁切翻车 |

> 容器展示统一用 `object-fit: cover; object-position: center` 自适应截取；HTML 预览模板已内置防盗链 meta `<meta name="referrer" content="no-referrer">`。

## 🛠 工具调用约定

- **图像生成**：平台内置图像生成工具，`width/height` 按上表，`prompt` 用 `references/prompt_recipes.md` 配方，强调「无文字」。
- **图像理解**（参考图分析）：平台内置图像理解能力，逐张提取主体/配色/构图。
- **标题合成 / 预览 / 自检**：`python3 scripts/studio.py {compose|preview|check}`。

## ⚠️ 错误处理与降级

| 情况 | 处理 |
|------|------|
| 无图像生成能力/被限流 | 明确告知，降级为「纯标题排版 HTML 封面」方案（CSS 精排，用户截图即用） |
| Pillow 缺失 | 在托管环境 `pip install pillow`；失败则走 HTML 覆盖层降级 |
| 用户未给主题 | 仅介绍技能并询问，不臆造 |
| 参考图无法访问 | 提示用户提供本地图片路径，不盲目外链 |

## 🧩 大小封面兼容（公众号封面图专用）

公众号封面只上传一张图，但大封面 2.35:1 与小封面 1:1 同时存在。用户只说"公众号封面图"时，优先做 `1283 × 383` 兼顾大小封面：

1. 左侧 `900 × 383` 作大封面主视觉，可承载标题、卖点与氛围。
2. 右侧 `383 × 383` 必须能独立成立，放主体/关键词/图标，不依赖左侧文字。
3. 分区生成再拼接，不要直接生成 `1283 × 383` 整图；两张图保持统一风格。
4. 生成后必须检查最终尺寸正好是 `1283 × 383`，否则不要交付。
5. 若用户明确不需要兼顾小封面，则退回 `900 × 383` 大封面方案。

拼接命令：

```bash
python3 scripts/stitch_compatible_cover.py left.png right.png --output final.png
```

更多图片类型与尺寸见 `references/sizes.md`。
