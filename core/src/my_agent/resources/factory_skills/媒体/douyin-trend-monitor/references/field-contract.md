# 字段合同

## 最低输入

- 日期或时间范围
- 时区，默认采用用户所在地时区
- 榜单类型：热搜、热点、作品、音乐、挑战或用户指定榜单
- 可选赛道、关键词和监控频率

## 推荐字段

| 字段 | 说明 |
| --- | --- |
| collected_at | 实际采集时间，含时区 |
| source | 数据源名称 |
| source_url | 可复核链接或页面位置 |
| rank | 原始排名 |
| object_id | 作品、话题或榜单对象 ID |
| title | 原始标题，不擅自改写 |
| author | 作者或发布账号 |
| heat_value | 数据源展示的热度值 |
| published_at | 原始发布时间 |
| likes/comments/shares/saves/views | 数据源实际提供的互动字段 |

## 计算规则

- 排名变化：`上期排名 - 本期排名`；正数表示上升。
- 热度变化率：`(本期热度 - 上期热度) / 上期热度`；上期为 0 时标为不可计算。
- 新晋：当前存在且上期不存在。
- 掉榜：上期存在且当前不存在；必须确保两期榜单范围一致。
- 连续上榜：同一去重键在连续采样期内出现的次数。

## 验收

- 记录榜单是否截断、是否只展示 Top N。
- 对无法确认单位的热度值保留原值，不转换成播放量。
- 同一作品多链接时优先使用作品 ID 去重；无 ID 时使用规范化链接和标题组合，并标记低置信度。
