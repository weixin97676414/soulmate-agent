# 标题导语生成与AB测试框架

多版本标题自动生成系统、吸引性导语创作技巧、AB测试框架设计，以及数据驱动优化建议生成方法。

---

## 标题生成系统

### 五种标题类型

基于平台热词库和点击率数据，标题分为以下五种类型：

#### 1. 悬念型（Suspense）

制造好奇心和未完成感，让读者必须点进来才能知道答案。

**公式**：
- [反常事件] + [疑问/未完成]
- [隐藏信息] + [暗示有料]

**示例**：
- 《结婚三年，我才知道老公的另一个身份》
- 《那条匿名短信，改变了我的一生》
- 《她消失的那天，所有人都收到了同一条消息》

**适用题材**：悬疑、反转、身份错位

#### 2. 情绪型（Emotional）

直接触发读者情绪（愤怒、委屈、爽、虐），让读者产生「这说的就是我/我想看TA怎么了」的感觉。

**公式**：
- [情绪词] + [人物关系] + [冲突]
- [极端状态] + [反转预期]

**示例**：
- 《被全网骂小三的那三年，我一句话都没解释》
- 《重生后，我看着前夫娶了绿茶，笑出了声》
- 《女儿婚礼那天，我把手里的检查报告撕了》

**适用题材**：复仇、重生、世情、甜宠

#### 3. 反转型（Reversal）

在标题里暗示「事情没那么简单」，让读者期待反转。

**公式**：
- [表面事实] + [暗示相反]
- [开头很A] + [结尾是B]

**示例**：
- 《所有人都以为我嫁给了爱情，直到那天我翻到了他的手机》
- 《我以为他是老实人，结果整个局都是他布的》
- 《新手妈妈？不，她是国际刑警卧底》

**适用题材**：悬疑、反转、系统、穿书

#### 4. 身份认同型（Identity）

让读者觉得「这就是我/我想成为的人」，产生强烈代入感。

**公式**：
- [特定人群] + [共鸣场景]
- [身份标签] + [痛点/爽点]

**示例**：
- 《30岁，一线城市，单身，我过得比谁都好》
- 《作为豪门最不起眼的继女，我悄悄继承了外婆的遗产》
- 《职场小透明逆袭成总监，我只做对了一件事》

**适用题材**：职场、豪门、校园、现实向

#### 5. 热点借势型（Trending）

借助热点话题、流行梗、社会现象，快速捕获注意力。

**公式**：
- [热点事件/梗] + [故事化改写]
- [社会现象] + [极端案例]

**示例**：
- 《「躺平」一年后，我悄悄买了套新房》
- 《全公司都在卷，只有我在「摸鱼」，结果我升得最快》
- 《当「原生家庭」成了万能背锅侠，真正的凶手反而被忽略了》

**适用题材**：现实向、职场、社会派

## 导语（Hook/Intro）创作技巧

导语是读者点进来后看到的第一段（或前 50-100 字），决定了读者会不会继续读下去。

### 好导语的三个标准

1. **3 秒锁定目标读者**：对的人一眼就知道这是给他看的
2. **建立阅读承诺**：暗示「继续读，你会得到 X」
3. **不留未完成感**：不是完整故事，但有一个「钩子」

### 导语创作公式

#### 公式一：冲突前置法

把故事中段的关键冲突场景放到导语里，让读者先看到「最精彩的部分」，再用「倒叙」展开。

**示例**：
```
那封离婚协议书，我被压在行李箱最底层。
三年后，前夫跪在我面前，求我签个字。
「林小姐，只要你肯复婚，我什么都答应你。」
我笑了笑，把协议书拿出来，当着他的面撕了。
```

#### 公式二：悬念制造法

从「反常事件」切入——主角收到了不该收到的消息、看到了不该看到的场景。

**示例**：
```
手机亮了，是闺蜜发来的消息。
点开前我还笑着——她昨天刚跟我说，终于怀上了。
点开后，我愣在原地。
发来的不是孕检报告，是一张她和我老公的合照。
```

#### 公式三：情绪爆发法

把结尾的高潮情绪（愤怒、委屈、震惊、狂喜）放到导语，让读者被情绪抓进去再慢慢解释。

**示例**：
```
我妈把我的录取通知书撕了。
一边撕一边说：「女孩子读那么多书有什么用？早点嫁人比什么都强。」
我捡起地上碎片的时候，手在抖。
不是因为委屈，是因为我那一刻真的想杀人。
```

## AB 测试框架

### 测试矩阵设计

为一篇稿件设计 AB 测试时，建立以下矩阵：

| 测试组 | 标题类型 | 标题文案 | 导语版本 | 测试指标 |
|--------|---------|---------|---------|---------|
| A | 悬念型 | [标题A] | [导语A1] | 点击率、完读率 |
| B | 情绪型 | [标题B] | [导语B1] | 点击率、完读率 |
| C | 反转型 | [标题C] | [导语C1] | 点击率、完读率 |
| D | 身份认同型 | [标题D] | [导语D1] | 点击率、完读率 |
| E | 热点借势型 | [标题E] | [导语E1] | 点击率、完读率 |

> 实际操作时，可先选 2-3 个类型做小样本测试，数据出来后再选最优类型生成更多变体。

### 指标追踪

AB 测试需追踪以下核心指标：

| 指标 | 定义 | 优秀基准 |
|------|------|---------|
| **点击率（CTR）** | 看到标题的人数 vs 点击进入的人数 | 盐言：>8%；番茄：>12% |
| **完读率** | 点击进入的人数 vs 读到结尾的人数 | 盐言：>60%；番茄：>45% |
| **互动率** | 评论+点赞+分享 vs 读者总数 | 盐言：>5%；番茄：>3% |
| **加书架率**（番茄专属） | 点击进入的人数 vs 加入书架的人数 | >8% |

### 测试流程

1. **生成候选**：为稿件生成 5-10 个标题（覆盖 3-5 种类型），每个标题匹配 1-2 个导语版本
2. **小样本投放**：选 2-3 组标题导语组合，在小范围读者中测试
3. **数据收集**：追踪 24-48 小时的点击率、完读率、互动率
4. **数据分析**：用以下公式计算综合得分：
   - 综合得分 = 点击率 × 0.3 + 完读率 × 0.5 + 互动率 × 0.2
5. **优胜选择**：选综合得分最高的组合，进行全量推送
6. **迭代优化**：根据全量数据，继续微调标题或导语

## 数据驱动优化建议生成

基于 AB 测试数据，生成以下优化建议：

### 点击率低（< 基准）

**可能原因**：标题没有信息量或好奇心缺口；标题太泛；标题像概括不像挑逗

**优化建议**：
- 把「概括型标题」改成「悬念型标题」
- 加入具体细节（人名、地点、数字），增加真实感
- 用「否定式」或「反常事件」制造好奇

### 完读率低（< 基准）

**可能原因**：标题过度承诺；开篇不够吸引人；导语和正文脱节

**优化建议**：
- 调整标题，降低过度承诺感
- 优化开篇，确保前三段能留住人
- 确保导语是正文的有效「预告」，不是虚假宣传

### 互动率低（< 基准）

**可能原因**：结尾没有「讨论点」；情绪不够强烈；没有评论区诱导设计

**优化建议**：
- 在结尾加入「开放性问题」或「争议点」
- 强化情绪表达，让读者有「想说两句」的冲动
- 在情绪高点或悬念处，埋「让读者想评论」的触发点

## 标题导语优化检查清单

- [ ] 标题有没有信息量和好奇心缺口？（不是概括，是挑逗）
- [ ] 标题能不能在 3 秒内锁定目标读者？
- [ ] 导语前 50 字有没有「钩子」？（冲突、悬念、情绪至少有一个）
- [ ] 导语和正文有没有「承诺一致」？（不该骗读者点进来）
- [ ] 结尾有没有「讨论点」？（让读者想评论、想分享）
- [ ] 有没有避开点击诱饵？（标题可以夸张，但不能虚假承诺）

---

## 注意事项

- 标题导语生成时，避免使用点击诱饵或虚假承诺
- AB 测试需要足够样本量（建议每组的曝光量 >500）
- 不同平台的优化策略不同（盐言重完读率，番茄重加书架率），需灵活调整
- 标题优化是一个持续过程，根据数据不断迭代
