# 番茄小说审稿指南

番茄小说平台生态、读者偏好、章节结构规范与审稿评分要点。

---

## 平台生态与读者画像

| 特征 | 描述 |
|------|------|
| 核心年龄 | 18-35 岁，男女比例约 6:4，覆盖下沉市场与一二线城市 |
| 阅读场景 | 碎片化阅读，通勤、午休、睡前，单章阅读时长 3-8 分钟 |
| 内容偏好 | 快节奏、强情绪、高反转密度；不喜欢慢热和冗长描写 |
| 消费模式 | 免费读前 N 章 → 看广告解锁 / 会员畅读，付费转化窗口极短 |
| 互动特征 | 评论区活跃，喜欢催更、猜剧情、讨论反转；高互动率有助于推荐加权 |

---

## 章节结构规范

番茄小说以「章」为最小消费单元，每章必须是一个完整的情绪单元。

### 字数要求

| 章节类型 | 推荐字数 |
|---------|---------|
| 正文章节 | 2200-2800 字（最佳阅读长度） |
| 开篇第 1 章 | 2000-2500 字（快速建立钩子） |
| 高潮/反转章 | 2500-3000 字（可适当超出） |

> ⚠️ 少于 2000 字会被系统判定为「内容过薄」，影响推荐；多于 3500 字单章阅读完成率下降。

### 每章必备要素

- **开篇黄金三行**：第一章前三行必须有冲击——冲突、悬念、反常事件至少其一
- **章节末尾悬念钩子**：每章结尾留一个「必须看下一章」的理由（悬念、情绪高潮、反转前夜）
- **每章至少 1 个情绪爆点**：甜/虐/爽/痛至少一个，不能全章平铺
- **评论区诱导设计**：在情绪高点或悬念处，埋「让读者想评论」的触发点（槽点、共鸣点、猜剧情点）

## 番茄专属七维评分要点

在通用七维评分基础上，番茄平台额外关注以下要点：

| 维度 | 番茄侧重点 |
|------|------------|
| **开篇钩子** | 第三章（免费试读最后一章）必须留有悬念，否则试读转化率极低 |
| **人设吸引力** | 主角必须「有爽点」——男主要有苏感/虐感，女主要有代入感/爽感 |
| **情绪拉扯** | 密度要求更高，每章至少 1 个情绪切换点，不能出现超过 800 字无情绪变化的平静区 |
| **反转设计** | 鼓励「多层反转」——不止一层，每 3-5 章至少一个小反转，每 10-15 章一个大反转 |
| **节奏掌控** | 张弛有度，但「弛」不能太长——冷却呼吸段不超过 200 字 |
| **对话质量** | 对话要「有爽感」——打脸、怼人、撒狗粮，不能只是推进剧情 |
| **平台适配度** | 题材是否符合番茄当前热门赛道（霸总、甜宠、重生、复仇、系统、玄幻） |

## 审核红线

以下内容会导致稿件被驳回或下架：

- **政治敏感**：涉及真实政治人物、事件、体制的影射或讨论
- **露骨色情**：直接的性行为描写（暗示/侧写可以，细节不行）
- **极端暴力**：详细的血腥暴力场景描写
- **违法引导**：涉及犯罪手法的详细描述、诱导违法行为
- **未成年人不当内容**：涉及未成年人的恋爱或性相关内容
- **抄袭洗稿**：查重率过高（与平台已有作品相似度 >30%）

## 推荐算法逻辑（简化版）

番茄的推荐机制比盐言更算法驱动，了解机制有助于优化稿件：

1. **冷启动期**（新书前 3 天）：系统给少量曝光，根据点击率、阅读完成率、互动率决定是否加大推荐
2. **点击率**（封面+标题决定）：前三章尤其重要，点击率低直接限流
3. **阅读完成率**（核心指标）：读者有没有读完这一章？完读率低于 40% 推荐锐减
4. **互动率**（加权项）：评论、点赞、打赏、加书架，高互动触发「人工审核 + 加大推荐」
5. **章节末尾钩子**直接影响「下一章点击率」——这是番茄推荐算法最看重的连续阅读指标

## 常见稿件问题与修改建议

| 问题 | 表现 | 修改建议 |
|------|------|------------|
| 开篇慢热 | 前三章还在介绍背景，冲突没出来 | 冲突前置，把第八章的打脸场景移到第一章 |
| 章节末尾无钩子 | 每章结尾是「平静收尾」，读者没有理由点下一章 | 在结尾前 100 字植入悬念/情绪高潮/反转前夜 |
| 情绪密度不足 | 大段描写无情绪波动，读者走神 | 每 500 字检查一次：这段有没有情绪？没有就加对话/内心戏/小冲突 |
| 人设工具化 | 配角只是推进剧情的工具，没有独立动机 | 给配角加「自己的目的」，让 TA 的行动有时和主角冲突 |
| 对话没爽感 | 对话平铺直叙，没有打脸/撒糖/怼人 | 检查每句对话——能不能让读者「啊！」一声？不能就改 |
| 字数不合规 | 单章 <2000 或 >3500 | 拆解或合并章节，目标 2400-2600 字/章 |
