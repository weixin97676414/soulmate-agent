# 七维评分卡

盐言短篇审稿的标准化评分体系，七个维度各 0-10 分，每档有明确锚定描述。

---

## 维度一：开篇钩子（0-10 分）

核心问题：前三段能不能让人停下来？

| 分数 | 锚定描述 |
|------|---------|
| 9-10 | 第一句就制造了强烈的好奇或情绪冲击，读者无法滑走。冲突、悬念、反差三者至少有两个瞬间建立。 |
| 7-8 | 前两段内建立了明确的悬念或冲突，读者有继续阅读的欲望。 |
| 5-6 | 有钩子意识但不够锋利，要靠第三段甚至更后面才让人进入状态。 |
| 3-4 | 开篇平淡，信息堆砌，「先是介绍了一大堆背景然后故事才真正开始」。 |
| 0-2 | 开篇不知所云、劝退。大段环境描写、内心独白、或无关人物出场。 |

---

## 维度二：人设吸引力（0-10 分）

| 分数 | 锚定描述 |
|------|---------|
| 9-10 | 主角一出场就有强烈的记忆点和共情点——读者一秒就「站队」，想跟 TA 走完整个故事。 |
| 7-8 | 主角有明确的性格标签和动机，能让读者产生好感或好奇。 |
| 5-6 | 人设能用但不够锋利，有标签但缺乏令人印象深刻的细节。 |
| 3-4 | 人设模糊，做的事和性格对不上，或者太工具化。 |
| 0-2 | 看不出主角有什么特点，像个路人。 |

---

## 维度三：情绪拉扯（0-10 分）

| 分数 | 锚定描述 |
|------|---------|
| 9-10 | 情绪曲线如过山车，甜虐爽痛反复切换，密度高且每次切换都有铺垫，读者被反复拿捏。 |
| 7-8 | 有明显的情绪起伏，有高潮有低谷，读者能感受到情绪的推动力。 |
| 5-6 | 情绪有变化但切换生硬或密度不够，中间有大段情绪真空区。 |
| 3-4 | 情绪平铺直叙，从头到尾一个调，没有拉扯感。 |
| 0-2 | 情绪完全没调动起来，读者全程冷静脸。 |

---

## 维度四：反转设计（0-10 分）

| 分数 | 锚定描述 |
|------|---------|
| 9-10 | 反转打到了读者的认知盲区，回头一看全是伏笔。反转不止一层，层层递进。 |
| 7-8 | 有至少一处有效反转，有铺垫，读者会有「原来如此」的感觉。 |
| 5-6 | 有反转但比较套路化，读者可能提前猜到。 |
| 3-4 | 反转生硬，缺乏铺垫，像凭空冒出来的。 |
| 0-2 | 没有反转，或者所谓的反转完全是逻辑硬伤。 |

---

## 维度五：节奏掌控（0-10 分）

| 分数 | 锚定描述 |
|------|---------|
| 9-10 | 张弛有度，高潮分布合理，没有一处让人想跳过的段落。信息密度和情绪密度都在点上。 |
| 7-8 | 整体节奏在线，偶尔有小的拖沓但不影响阅读体验。 |
| 5-6 | 有明显的拖沓段落或节奏断裂处，读者会走神。 |
| 3-4 | 节奏失控，要么太快没展开，要么太慢让人想弃。 |
| 0-2 | 像一个大纲或者流水账，完全没有节奏意识。 |

---

## 维度六：对话质量（0-10 分）

| 分数 | 锚定描述 |
|------|---------|
| 9-10 | 每句对话都有信息量、有人物感、有潜台词。去掉「XX 说」只看台词，能分辨是谁在说话。 |
| 7-8 | 对话自然有信息量，能推动剧情或塑造人物。 |
| 5-6 | 对话能用但不够有辨识度，偶尔沦为推进剧情的工具。 |
| 3-4 | 对话苍白，「你好」「在吗」「好的」类无效对话占比较高。 |
| 0-2 | 几乎没有对话，或者对话完全失真，像机器人在念台词。 |

---

## 维度七：盐言适配度（0-10 分）

| 分数 | 锚定描述 |
|------|---------|
| 9-10 | 这就是盐言读者想看的那种故事——题材对、节奏对、情绪对，放在平台上大概率能跑起来。 |
| 7-8 | 适合盐言平台，题材和写法都在目标读者的审美范围内。 |
| 5-6 | 放盐言也行，但不是最对口的平台，可能需要微调写法。 |
| 3-4 | 和盐言主流读者口味有明显错位，题材或写法不太匹配。 |
| 0-2 | 完全不适合盐言，应该换平台投稿。 |
