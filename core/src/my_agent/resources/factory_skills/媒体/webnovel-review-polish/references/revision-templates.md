# 改稿指令模板

常用改稿指令的标准化模板，确保每次改稿建议都具体可执行。

---

## 1. 开篇钩子强化指令

**诊断信号**：开篇评分 ≤ 5 分，前三段没能建立悬念或冲突。

**改造方向**：
- **冲突前置法**：把故事中段的关键冲突场景移到开头，让读者先看到「最精彩的部分」，再用「倒叙/闪回」展开
- **悬念制造法**：删掉所有背景交代，直接从「反常事件」切入——主角收到了不该收到的消息、看到了不该看到的场景
- **情绪爆发法**：把结尾的高潮情绪（愤怒、委屈、震惊、狂喜）放到第一段，让读者被情绪抓进去再慢慢解释

**示范改写格式**：
```
【原文】
{引用原文开篇}

【问题】
{具体问题分析}

【修改方案】
{改写后的开篇，2-3 个版本可选}
```

---

## 2. 情绪曲线调优指令

**诊断信号**：情绪评分 ≤ 6 分，读者反馈「太平了」「没感觉」。

**改造方向**：
- **情绪密度检查**：标注全文情绪强度变化点，找出超过 500 字无情绪波动的「真空区」
- **反差注入**：在「甜」后面立刻接「虐」的伏笔，在「虐」后面埋「反转甜」的可能
- **节奏呼吸**：连续高强度情绪段之间插入 1-2 句「冷却呼吸句」（环境描写/动作细节），让读者有喘息的空间

---

## 3. 反转节点重构指令

**诊断信号**：反转评分 ≤ 5 分，反转太套路或被提前猜到。

**改造方向**：
- **信息不对等法**：给主角的信息和给读者的信息制造差异——读者以为知道真相，实际上被作者「藏了牌」
- **多重解释法**：同一个事件，在不同段落给出不同的解释，直到最终反转揭露真正的原因
- **预期折叠法**：先让读者建立预期 A，再给一个冲击力更大的 B，再反转成完全没想到的 C

---

## 4. 对话节奏优化指令

**诊断信号**：对话评分 ≤ 5 分，对话像旁白或缺乏人物辨识度。

**改造方向**：
- **去旁白化**：检查每句对话——如果把引导外的全部旁白/动作描写去掉，只读台词，能不能看懂情节？
- **潜台词注入**：每句对话加一层「没说出来的话」——角色嘴上一套心里一套，读者能感受到那种张力
- **话轮压缩**：删掉所有「嗯」「哦」「好的」类无信息量的过渡语，让对话像乒乓球一样来回弹

---

## 5. 删减冗余描写指令

**诊断信号**：节奏评分 ≤ 5 分，有读者跳过的段落。

**改造方向**：
- **三行规则**：任何环境描写/心理描写/背景交代如果超过三行，标记为「待压缩」
- **信息密度加法**：一段描写里同时做三件事——推进剧情 + 塑造人物 + 制造氛围
- **删减测试**：删掉这个段落，读者会不会看不懂？不会 → 可删；会 → 保留但压缩
