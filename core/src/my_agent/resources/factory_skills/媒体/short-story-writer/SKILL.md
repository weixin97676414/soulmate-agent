# 短篇小说工坊——知乎·番茄风格创作助手

帮你写出在知乎和番茄小说上有人看的短篇——不是教「怎么写小说」，是教写出这两个平台读者愿意追完的作品。


| 平台 | 风格 | 叙事 | 字数 | 看家本领 |
|------|------|------|------|----------|
| 知乎 | 「我」第一人称·真实口吻 | 第一人称 | 3000-8000 | 反转·细思极恐·情感暴击 |
| 番茄 | 快节奏网文 | 第三人称 | 2000-5000 | 爽感·甜度·每章钩子 |

## When to Use

- 「帮我写一篇知乎短篇，悬疑反转那种」
- 「想要番茄风格的甜宠文，女主掉马」
- 「给我一个重生逆袭的故事框架」
- 「这段开头不够抓人，帮我改得有知乎味」
- 「帮我检查这个设定能不能写——[你的设定]」

Don't use for：长篇小说连载（单章 OK）；学术论文/报告文学；含真实在世人物的虚构。

## 30 秒上手

```bash
# 第一步：用一句话说你想写什么
python scripts/story_outline.py -t 悬疑 -p "独居女孩发现邻居每天深夜往她门缝塞纸条"

# 第二步：看生成的大纲，选一个开头钩子
# 第三步：从 references/story_templates.md 找同类型的完整范文，感受节奏
# 第四步：写第一稿 → 用改稿清单自查 → 发布
```

**不知道怎么跟 AI 说？用这个句式**：

> 「帮我写一篇知乎风格的 [悬疑/甜宠/复仇/重生/催泪] 短篇。
> 设定是：[一句话说清谁 + 发生了什么反常的事]。

## 6 种类型速查

> 📖 完整范文（6 篇，每篇 2000-4000 字）→ `references/story_templates.md`

| 示例 # | 类型 | 字数 | 风格 |
|--------|------|------|------|
| 1 | 悬疑反转 | 3200 | 「我老公每天凌晨三点起床」 |
| 2 | 复仇逆袭 | 2800 | 「婚礼上，闺蜜穿着我的婚纱」 |
| 3 | 甜宠掉马 | 2500 | 「他穷得婚戒都是塑料的」 |
| 4 | 重生打脸 | 2200 | 「再睁眼，我回到了婚礼当天」 |
| 5 | 系统爽文 | 2000 | 「恭喜宿主激活社畜逆袭系统」 |
| 6 | 现实催泪 | 3500 | 「我妈是个清洁工」 |

### 悬疑反转（知乎王牌）

```
开头公式：[日常事物] + [不合理细节]
情节：日常异常 → 调查深入 → 震惊 → 反转 → 终极真相 → 余味结尾
结尾：最后一句话推翻所有认知
```

### 复仇逆袭（双平台通吃）

```
开头公式：[公开羞辱] + [主角反常平静]
情节：伤害 → 隐忍布局 → 第一次出手 → 对方反扑 → 致命一击 → 胜利独白
```

### 甜宠掉马（番茄爆款）

```
开头公式：[平凡日常] + [一个破绽暴露身份]
情节：甜蜜日常 → 发现破绽 → 身份揭露 → 闹别扭 → 追妻火葬场 → 甜蜜2.0
```

### 重生打脸（番茄流量密码）

```
开头公式：[惨死闪回] + [回到关键时间点]
情节：惨死 → 重生 → 第一次改命 → 反派落魄 → 新人生 → 巅峰对比
```

### 系统爽文（番茄专属）

```
开头公式：[社死时刻] + [系统激活提示]
情节：绑定 → 新手任务 → 连续任务 → 遇对手 → 系统升级 → 终极逆袭
```

### 现实催泪（知乎高赞）

```
开头公式：[具体物件/气味] + [日常感]
情节：日常 → 隐藏情感 → 关键事件 → 真相揭露 → 悔恨和解 → 余味
核心：不要刻意煽情——细节自己会哭
```

## 开头钩子公式（5 种）

| 类型 | 公式 | 一句话示例 |
|------|------|-----------|
| 反常发现 | [日常] + [不合理细节] | 「我家猫每晚 11 点蹲门口。我家在 18 楼。」 |
| 时间倒流 | [回到过去] + [我知道未来] | 「再睁眼，我回到了 2018 年。这一次我不会救他。」 |
| 身份反差 | [普通人] + [隐藏身份] | 「我老公是送外卖的。昨天他箱子里掉出一份 CIA 文件。」 |
| 危险降临 | [平静] + [一个细节打破] | 「手机震了。一条陌生短信：'你老公在说谎。'」 |
| 惨烈对比 | [美好表象] + [残忍真相] | 「婚礼上所有人都在笑。新郎口袋里有份离婚协议。」 |

## 段落节奏规则

```
知乎体：每段 2-3 句 | 偶尔 1 句一段制造呼吸 | 对话不超 3 来回
番茄体：对话 1-2 句即换段 | 「……」独立成段 | 每章结尾留钩子
```

## 对白技巧

| 技巧 | 示例 | 为什么有效 |
|------|------|-----------|
| 潜台词 | 「你吃了吗？」=「我想你了」 | 不说出来的话更有力 |
| 重复变奏 | 开头「我恨你」→ 结尾「我不恨你了」 | 同一句话，不同重量 |
| 答非所问 | 「你爱过我吗？」「下雨了。」 | 回避本身就是答案 |
| 沉默 | 「……」独立成段 | 比台词更有冲击力 |
| 口语中断 | 「我就是……算了。」 | 真人会犹豫、吞回去 |
| 称呼变化 | 「陆总」→「子骞」→「姓陆的」 | 称呼 = 关系温度计 |

## 改稿优化流程

### 第一轮：结构

```
□ 开头 3 句内进入故事？（无天气/背景/人物介绍铺垫）
□ 每一幕都有情绪变化？（不能连续两幕情绪持平）
□ 结尾有余味？（不是「就这样结束了」）
□ 字数在目标范围？
```

### 第二轮：节奏

```
□ 有没有连续 3 段超 4 行？→ 拆分
□ 对话段落有没有超 3 行？→ 拆分
□ 知乎体：有没有「然而」「因此」「值得注意的是」？→ 全删
□ 番茄体：每 2000 字内有爽点吗？
```

### 第三轮：去 AI 味

```
□ 有没有「不是……而是……」句式？
□ 有没有「从X到Y」虚假拔高？
□ 有没有破折号超过 2 个？
□ 有没有「总而言之」「综上所述」？
□ 读出来像不像真人跟你聊天？
```

## 知乎发布教程

### 渠道选择

| 渠道 | 门槛 | 流量 | 适合 |
|------|:---:|:---:|------|
| **回答** | 无 | ⭐⭐⭐ | 新手首选。搜 10 万+关注的问题，以回答形式发布 |
| 文章 | 无 | ⭐⭐ | 有粉丝基础后，可设付费 |
| 盐选专栏 | 编辑邀请 | ⭐⭐⭐ | 签约作者，平台主动推流 |

### 回答发布（新手推荐，六步走）

1. **找问题** — 搜「你经历过最细思极恐的事」「有什么短篇甜文推荐」等 10 万+关注的问题
2. **写标题** — 回答第一行用问句或悬念：「如果你的老公每天凌晨三点起床——」
3. **直接开始** — 第二行就进入故事正文，不要写「谢邀」「我来回答一下」
4. **结尾引导** — 故事结束后另起一行：「（全文完）更多故事戳主页」
5. **配图** — 1-2 张氛围图即可，不要超过 3 张
6. **自评** — 发布后前 1 小时，在自己回答下评论一句引导互动

### 发布时间

- 工作日晚 8-10 点（流量高峰）
- 周末下午 2-5 点（用户刷手机高峰）
- 避开节假日（流量分散）

### 如果没流量

- 检查开头 3 句是否够抓人
- 检查回答的问题是否真有流量（看关注数和最新回答时间）
- 换一个更热门的相关问题重新发布

## FAQ

- **大纲生成器输错类型了怎么办？** 支持中文名模糊匹配；不支持的类型会列出全部可用类型。
- **设定太简单了怎么办？** 生成器会自动预检；改成「[人物] + [具体的反常事件]」格式。
- **6 种类型选哪个？** 新手从「悬疑反转」或「现实催泪」开始；有网文阅读经验的从「重生打脸」或「甜宠掉马」开始。
- **范文在哪里？** `references/story_templates.md`，6 篇完整范文。
- **对话怎么写才不像 AI？** ① 有没有答非所问 ② 有没有「……」沉默 ③ 读出来像不像朋友在微信上跟你聊天。
- **能写长篇吗？** 不能。专注 2000-8000 字短篇。

## Common Pitfalls

1. **开头铺垫太长** — 前 3 句没进入故事 → 读者划走。
2. **段落太长** — 手机屏 5 行+ → 阅读疲劳。3-4 行即换段。
3. **知乎体写番茄套路** — 知乎要真实感，番茄要爽感。一篇选定一个平台。
4. **结尾平淡** — 最后一句必须有余味：反转/悬念/情感暴击/会心一笑。
5. **对白太干净** — 真人会犹豫、吞回去、答非所问。
6. **用户设定未清洗** — 人物名/情节素材写入前须清洗（见 `references/content-sanitization.md`）。

## Verification Checklist

- [ ] 开头 3 句内进入故事
- [ ] 段落 ≤ 4 行（手机标准）
- [ ] 知乎体：第一人称 + 真实口吻；番茄体：对话驱动 + 每章钩子
- [ ] 结尾有余味
- [ ] 对白有中断/沉默/潜台词
- [ ] 无「然而」「因此」「值得注意的是」
- [ ] 破折号 ≤ 2 个
- [ ] 用户素材已清洗；未触碰内容红线
- [ ] 字数在目标范围

## 安全底线

用户素材写入前须清洗；涉政 / 涉黄 / 暴力煽动 → 自动拒绝。详见 `references/content-sanitization.md`。
