# 常见问题 FAQ

制作中卡住时的速查。按场景查,找不到就回到「异常与修正」原则:停下→问清差异→只改差异。

## 1. 角色前后长得不一样(最高频)

- **原因**:每个镜头重新写了外貌描述,或没用定妆参考图
- **修正**:
  1. 锁一张定妆图,后面所有镜头用"参考图 + 镜头描述",不重新文生图
  2. 外貌描述只用角色卡里的锚点句,原样复制,不换词
  3. 负面提示词固定加 `inconsistent character, off-model`
- **预防**:每个角色只维护一份锚点句,改也只改这一处

## 2. 画面生成失败 / 工具报错

- **原因**:提示词超长、负面词冲突、工具限流、比例不匹配
- **修正**:
  1. 先降负:去掉 3 个以上负面词,只留最关键的
  2. 拆长句:主体/场景/风格拆成三行拼
  3. 换比例或尺寸与分镜标注一致(竖屏 9:16)
  4. 工具限流 → 重试或换备用工具
- **保留**:已成功生成的镜头先存档,不因一个镜头失败重做全片

## 3. 用户中途改需求(换题材/加角色/改平台)

- **只回退受影响步骤**,不动已完成且不受影响的部分:
  - 换题材 → 步骤 2(剧本)起重做,角色卡若兼容可复用
  - 加角色 → 只加步骤 3 的角色卡 + 涉及该角色的镜头
  - 改平台(如抖音→视频号)→ 检查时长/比例约束,改分镜时长列,不重写剧本
- **告知影响面**:明确告诉用户"改动会波及哪些文件",再动手

## 4. 输出不符合预期(风格/语气/内容不对)

- 停下,问清三个差异:哪里不对 / 期望是什么样 / 有没有参考
- 只改差异点,不整段重写;改完让用户确认一次再继续

## 5. 单集时长超了 / 不够

- 超了 → 删非关键镜头(优先删无台词空镜),或压缩每镜头时长
- 不够 → 补"冲突升级"段镜头或加一个反转前的铺垫镜头
- 改完重新核对镜头数:1 分钟约 20~35 镜

## 6. 平台审核不过 / 被限流

- 先查 review-checklist 合规项:AI 标注、违禁内容、版权
- 常见:真实人物/品牌未规避、擦边文案、无 AI 生成标识
- 修正对应项后重审,不要整片重做

## 7. 不知道什么时候该触发本技能

- 用户提到"AI 短剧/漫剧/剧本/分镜/角色一致性/画面提示词"即触发
- 不确定时:从快速开始表选入口,或从步骤 1 询问目标(平台/时长/类型/风格)

## 8. 多集连做,怎么保持前后一致

- 建立项目级 `drama-project/<剧名>/` 档案:角色卡、风格锚点、场景设定都在里面
- 每集开做前,先读项目档案,复用锚点,不新写
- 新集只新增该集独有内容(新角色/新场景),老设定一律引用
