# 角色卡与一致性 (Character Card & Consistency)

AI 短剧最大的技术痛点是"角色前后长得不一样"。一致性靠**锚点描述 + 参考图**解决,且锚点必须全流程复用。

## 角色卡字段(每角色一份)

```
角色名:
身份/定位:
年龄:
外貌锚点(必须具体,可被文生图理解):
  - 脸型/五官:如"鹅蛋脸、杏眼、高鼻梁、薄唇"
  - 发型发色:如"黑色齐肩短发、刘海"
  - 身材:如"瘦高"
服装(默认套装):如"白色衬衫+黑色西裤+黑框眼镜"
标志性特征:如"左眉一颗痣""戴银色耳钉"
性格:
语气/说话风格:
口头禅:
AI 一致性锚点语句(一段固定描述,每次生成复用):
```

## 一致性锚点写法

写一段"只要加在提示词里就能锁住长相"的固定句子,例如:

> 一位 25 岁亚裔男性,鹅蛋脸、杏眼、高鼻梁、薄唇,黑色齐肩短发,白衬衫黑西裤黑框眼镜,左眉一颗痣,写实风格,正面肖像。

要点:
- **外貌描述放最前**,用确定性词汇(避免"帅气""漂亮"等主观词)
- 每次生成该角色都原样复用锚点句,不加不减
- 锚点句单独存一个文件(`character-card` 内),全项目引用

## 一致性策略(分阶段)

### 1. 定妆阶段(文生图)
- 用角色卡生成 2~3 张半身/正面定妆图
- 挑最符合的一张锁定为**参考图**
- 参考图提示词 = 锚点句 + 风格 + 负面提示词

### 2. 逐镜头阶段(图生图/参考图)
- 用"定妆图做参考/垫图" + 镜头描述,而不是重新文生图
- 镜头描述只改:场景、动作、表情、机位,不改外貌部分

### 3. 检查阶段
- 用审校清单逐镜头比对:脸型/发型/服装是否漂移

## 常见一致性失败与对策

| 失败 | 对策 |
|---|---|
| 脸变了 | 固定锚点句 + 参考图,禁止只写"同一个人" |
| 服装乱了 | 默认套装写死;换装镜头单独建"变装卡" |
| 画风漂移 | 风格词固定(同一段),不换同义词 |
| 漫剧串画风 | 风格锚点(如"国漫厚涂风")全流程固定 |

## 角色数量建议

- 单集主推 2~4 个主要角色,角色越多一致性成本越高
- 配角(路人)不建卡,用通用描述
