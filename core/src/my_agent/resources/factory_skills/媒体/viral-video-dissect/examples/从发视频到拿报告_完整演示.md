# 从发视频到拿报告 · 第一次完整演示

## 0. 你手里有什么、要干啥

- **一条视频**：某智慧停车头部账号的爆款《物业为什么宁愿花 20 万也要上智慧停车》（45 秒，竖屏，单人主讲）
- **你的目标**：拆它的框架 → 出 3 条能直接拍的同款脚本（讲给"想做停车代理的老板"听）

> 你只需要做一件事：**把视频发出来 + 说一句你要干啥**。剩下的 AI 带着你走。

---

## 1. 你发视频，AI 先问归属（步骤 0 · 归属确认门）

```
你： 「拆解这条，给我 3 条能直接拍的二创脚本」＋（发送视频文件）

AI： 「收到。先确认一下走哪条线——
      ① 拆别人爆款 → 二创脚本；
      ② 给你自己的视频做八维体检、指出哪里能改。
      这条是别人的爆款、你要二创，对吧？」

你： 「对，走①」
```

> 💡 **小技巧**：如果你抢先说了"拆解 / 二创 / 帮我按 8 维看看"，AI 会跳过这轮直接走对应线，省一轮对话。

---


AI 自动执行，**无需你操作**：

2. **信息抽取**：抽帧 + ASR 转写 + 视觉/OCR + 语气表情 + 高光定位

**本步产出**（AI 会展示给你看）：

- **逐字稿片段**：
  > 「…物业为什么宁愿花 20 万上智慧停车？因为表面省了 3 个岗，实际省的是 3 次扯皮、5 次投诉、1 次安全事故…」
- **镜头表（前 3 镜）**：

  | 时间 | 画面 | 口播 / 字幕 | 动作 |
  |------|------|------------|------|
  | 0–3s | 主播直面镜头 | "物业为什么宁愿花 20 万" | 手势强调、字幕贴脸 |
  | 3–12s | 停车场实拍 + 数据字幕 | "省 3 个岗 / 省 5 次投诉" | 镜头推近车牌识别区 |
  | 12–25s | 对比图：传统岗亭 vs 智能道闸 | "不是省人，是省风险" | 左右分屏 |

## 3. 说话人配置（步骤 1.95）

```
AI： 「这条是 S1 单人主讲，我建一张角色卡——
      🗣️ 主角 = 停车行业老兵（语气：笃定、带行业黑话）」
```

> 如果是双人 / 多人对话，这一步会把每个人编号建角色卡，二创写稿时强制按角色分段，不会塌缩成独白。

| 2 | 3–12s | 主角 | 车场实拍 | 省 3 个岗、省 5 次投诉 | 数据条动画 |
| … | … | … | … | … | … |

## 5. 钩子观点 + 结构框架（步骤 3 + 步骤 4）

- **开头钩子**：「物业为什么宁愿花 20 万」——数字冲击 + 反常识
- **核心观点**：「智慧停车不是省人，是省风险」
- **结构框架**：内容功能链
  `圈人 → 留人 → 建立信任 → 证明结果 → 反问纠偏 → 给方法 → 推动行动`

> 这一步拆的是"**为什么有效**"，不是"讲了什么"——这才是拆解的底层目的。

---

## 6. 8 维量化评分（步骤 5）

AI 给出 8 维量化表（表头三列固定为 `维度 / 得分 / 说明`）：

| 维度 | 得分 | 说明 |
|------|------|------|
| 选题穿透力 | 9 | 直击物业经营痛点，数字开场 3 秒留人 |
| 开场钩子力 | 9 | 反常识数字"20 万"制造认知冲突 |
| 结构完整度 | 8 | 功能链闭环清晰，缺一个"反向案例" |
| 观点犀利度 | 8 | "省风险"一句话立住差异化主张 |
| 情绪共振度 | 7 | 偏理性，缺业主视角情绪钩子 |
| 信任背书力 | 8 | 行业黑话 + 数据，可信但无第三方背书 |
| 互动/转化设计 | 8 | 结尾"你小区装了吗"引导评论，CTA 明确 |
| 落地可执行 | 9 | 结构可复制，换行业即可改拍 |

**总评**：成色卡 **8.3 分**；四基因 = **干货型 + 工具型**（信息差 × 行动）。

---

## 7. 二创方向草案 + 多选题确认（步骤 5.5）

```
AI： 「基于这条，我给你 10 个候选二创角度（候选角度池）。
      你想拍给哪类人？勾选你想要的（可多选）：

      □ A 想做停车代理的老板（照搬行业）
      □ B 物业公司采购（换痛点：招标/合规）
      □ C 小区业主（换视角：停车难/收费贵）
      □ D 政府/街道（换场景：智慧社区考核）
      □ E 传统岗亭保安（换身份：会被替代吗）
      …（共 10 个）

你： 「选 A 和 B」

AI： 「好。围绕 A+B，我用「反常识型」+「身份代入型」结构各出 1 条方向草案，
      先给你看框架再写稿——你看这俩方向 OK 吗？」
```

> 🔑 **这就是"二创增加多选题供用户自由选择"**：候选角度池 8–12 个 + 可多选确认，AI 不会自作主张替你定方向。

---

## 8. 二创脚本生成（步骤 6）

你确认方向后，AI 按 **12 种爆款结构速查索引** 定结构类、再定句式，产出 **3 条带分镜的二创脚本**。

展示其中 1 条（A 类 · 反常识型）：

```
【标题】做停车代理第一年，我最想劝退的一类人
【结构】反常识型：先泼冷水 → 再给判断 → 甩数据 → 收行动
【分镜】
0–3s  直面镜头：「别听人说停车代理躺赚，我先泼盆冷水」
3–15s 车主实拍：「真正赚的，是搞得定物业招投标的那批人」
15–30s 数据字幕：「一个中型小区，道闸年费 + 维保 = 稳定现金流」
30–45s 口播：「想入行，先问自己一句——你搞定得了物业吗？」
【BGM】紧凑鼓点 + 低频铺垫
【CTA】「评论区打『代理』，发你一份避坑清单」
```

## 9. 选题库确认（步骤 7）

```
AI： 「这 3 条脚本要不要存进选题库（结构化 JSON + MD），方便以后复用、二创不重来？」

你： 「存」

AI： 「已入库 → video-script-dissect_选题库/。下次直接调，不用重新拆。」
```

> 进选题库这一步**必须你确认**，AI 不会自动存。

## 10. 文档格式选择 + 拿到报告（步骤 8 + 步骤 9）

```
AI： 「报告要什么格式？
      📄 PDF（存档）／🌐 HTML（速览）／📝 DOCX（协作首选）」

你： 「DOCX」

AI： 「生成中…」→ 交付 video-script-dissect_报告_20260917.docx
```

**报告包含**：结论摘要 / 运行证据 / ASR 逐字稿 / 拆解台账 / 8 维评分表 / 二创脚本 / 选题库回链。
（完整长啥样 → 看 `examples/示例报告_脱敏.md`）

## 11. 归属② 简版对照（自己的视频做八维体检）

如果你发的是**自己的视频**、数据不好想优化：

```
你： 「帮我按 8 维看看这条哪里能改」＋（发你的视频）

AI： 走 0→1→2→3→4→5→9，只给「优劣 + 合理化建议」，不给二创脚本。
```

- 诊断完，可经 **「异角脚本选择门」** 确认是否额外给相反/不同角度的拍摄文案（换立场重写，非二创）
- 如需开拍前的活人感拍摄建议，走 **「活人感拍摄建议确认门」**（仅自有原创视频）
- 两道门都**须你确认**，AI 不预设
