# 小众场景错误速查手册（v2.21 新增 · 异常处理易读化）

> 回应可靠性优化项「异常处理 4.1」：「某些小众情况报错提示比较技术化，普通用户可能看不懂」。
> 本表把 13+ 类典型边缘场景的报错统一改成「❌ 发生了什么 → 💡 怎么办 → [tech] 原始异常」三段式，配中文场景说明与排错路径。
> 配套随包脚本的 `_friendly_error.py` 已接管所有 stdout/stderr 错误输出，自动按本表规则翻译。

## 使用方式

遇到任何报错，按下面任一方式定位：
1. **看错误顶部两行**：「❌ {场景} · {人话标题}」就是直接答案，「💡 怎么办」列出可执行动作。
2. **搜本表关键字**：复制错误里的中文标题（如「找不到文件」「依赖缺失」）搜本文档。
3. **看 [tech] 行**：进阶用户 / 排错时看原始异常类型 + message。
4. **回到 `references/faq.md`**：常见 8 类问题在那，本文补 13+ 类小众场景。

## 一、文件 / 路径类（最常见）

### 1.1 找不到文件（FileNotFoundError）
- **症状**：❌ 找不到文件 · 路径不存在或拼写有误：`<path>`
- **场景**：传错路径、相对路径工作目录不对、文件被移动 / 删除 / 改名、长中文路径在 PowerShell 下被截断
- **怎么办**：
  1. 用文件管理器打开目标目录，确认文件名（含扩展名）
  2. 路径含空格或中文时整段加引号：`--md "D:\我的报告\存款拆解 2026.md"`
  3. 改用绝对路径，避免相对路径歧义
- **进阶**：macOS/Linux 用户注意 `/` vs `\`；本技能已自动按 OS 适配。

### 1.2 路径指向的是文件夹（IsADirectoryError）
- **症状**：❌ 路径指向的是文件夹 · 你可能传了一个目录
- **场景**：`--md ./reports/`（漏掉文件名）、脚本被符号链接误导
- **怎么办**：补完整文件名；批量处理时先列出文件再逐个传入。

### 1.3 文件名或路径太长（ENAMETOOLONG）
- **症状**：❌ 文件名或路径太长 · 系统无法处理
- **场景**：报告名带日期+多级目录+中文+空格，总长超 260 字符（Windows 限制）
- **怎么办**：
  1. 把报告移近根目录，如 `D:\reports\存款.md`
  2. 用英文或拼音重命名：`cunkuan.md` 比 `《存款》拆解_最终版_2026-08-26.md` 短一半
- **预防**：约定文件命名 ≤ 30 字，避免多级子目录嵌套。

### 1.4 权限被拒（PermissionError / EACCES）
- **症状**：❌ 权限不足或文件被占用 · 无法读取/写入
- **场景**：Word / PDF 阅读器 / 微信传输助手锁住文件；系统目录（如 `C:\Program Files\`）需管理员
- **怎么办**：
  1. 关闭所有打开该文件的程序
  2. 右键文件 → 属性 → 取消勾选「只读」
  3. 系统目录操作时右键命令提示符 → 「以管理员身份运行」

### 1.5 磁盘空间不足（ENOSPC）
- **症状**：❌ 磁盘空间不足 · 无法写入文件
- **场景**：C 盘只剩几百 MB 时输出大 PDF / 视频文件
- **怎么办**：
  1. 清理回收站 / 临时文件夹 / 微信缓存
  2. 输出路径换到剩余空间大的盘
  3. 优先选 HTML（零依赖、文件最小）作为临时方案

## 二、依赖 / 环境类

### 2.1 缺少依赖库（ModuleNotFoundError）
- **症状**：❌ 缺少依赖库 · 本机没装 `<module>`（如 reportlab / python-docx / faster-whisper）
- **场景**：新机器 / 换了电脑 / 隔离 venv 重建后第一次跑
- **怎么办**：脚本会自动询问确认；确认后从官方 PyPI 安装固定版本（不污染系统、不上传数据）。
- **非交互环境**：脚本会拒绝自动安装并打印手动命令，照着跑就行。
- **预防**：按 `SKILL.md`「环境与依赖」节走标准 venv 初始化流程。

### 2.2 自动安装失败（pip 网络 / 编译错误）
- **症状**：❌ 自动安装 reportlab 失败 · ConnectionError / subprocess error
- **场景**：公司网络封 PyPI、SSL 证书过期、Python 版本过低
- **怎么办**：
  1. 检查网络代理 / 防火墙设置
  2. 用镜像源（仅个人环境）：`pip install reportlab==4.2.5 -i https://pypi.tuna.tsinghua.edu.cn/simple`
  3. 升级 Python 到 3.10+（旧版本装不上最新版 reportlab）

### 2.3 隔离 venv 拒绝运行
- **症状**：⛔ 必须在隔离 venv 内运行（拒绝系统 Python）
- **场景**：误用系统 Python 直接跑脚本
- **怎么办**：按提示用 `<venv>\Scripts\python.exe`，或先激活 venv 再跑。

## 三、编码 / 内容类

### 3.1 文件编码不是 UTF-8（UnicodeDecodeError）
- **症状**：❌ 文件编码不是 UTF-8 · 读到第 N 字节时无法识别
- **场景**：从 Office / Word 复制内容粘到记事本保存；或 GBK 编码的旧文件
- **怎么办**：
  1. 记事本打开 → 另存为 → 编码选 UTF-8
  2. VS Code 打开 → 右下角编码 → 「Save with Encoding」→「UTF-8」
  3. Office 内容先粘贴到记事本去格式，再粘到 Markdown 编辑器

### 3.2 报告内容缺少必要字段（KeyError）
- **症状**：❌ 报告内容缺少必要字段 · 找不到键 `xxx`
- **场景**：Markdown 缺必含章节，或 8 维表头列名拼错
- **怎么办**：
  1. 运行 `python scripts/verify_report_structure.py <报告.md>` 看 human_readable 字段
  2. 对照 `references/index.md`「报告骨架」节确认章节层级
  3. 8 维评分列名固定为「维度 / 得分 / 说明」，不能改字

### 3.3 报告表格行列对不上（IndexError）
- **症状**：❌ 报告表格行列对不上 · 读取位置 N
- **场景**：Markdown 表格行内单元格数不一致（部分行少一列）；分隔行 `|---|` 写错
- **怎么办**：
  1. 表格每行 `|` 数应一致（含首尾）
  2. 分隔行严格用 `|---|---|`（与表头列数一致）
  3. 跑 verify 看具体行号

## 四、渲染 / 字体类

### 4.1 未找到中文字体（AssertionError / 渲染方框）
- **症状**：❌ 未找到中文字体 · 渲染 PDF 时找不到可用中文字体
- **现象**：PDF 里中文显示为 □□□ 方框
- **场景**：Windows 精简版 / 容器镜像无中文字体；Linux 服务器无 `noto-cjk`
- **怎么办**：
  1. Windows：装「微软雅黑」或复制 `C:\Windows\Fonts\msyh.ttc` 到 Fonts 目录
  2. Linux：`apt install fonts-noto-cjk` 或 `fonts-wqy-microhei`
  3. macOS：自带苹方 / 冬青黑体，应无需额外安装
- **临时方案**：先用 HTML 版（CSS 由浏览器渲染中文字体，依赖机器字体）。

### 4.2 TOC 锚点冲突 / 重复键
- **症状**：PDF 生成时 `KeyError` 或目录页空白
- **场景**：报告里有重复 `## xxx` 标题，或标题含特殊字符
- **怎么办**：把重复章节改名（哪怕加一个「（续）」），目录自动按层级生成。

### 4.3 docx 表格列数不匹配
- **症状**：❌ Word 生成失败 · 表格行单元格数与首行不一致
- **场景**：Markdown 表格有的行少 `|` 或多 `|`
- **怎么办**：用 `verify_report_structure.py` 校验报告；修齐所有表格。

## 五、网络 / 资源类

### 5.1 网络超时（TimeoutError）
- **症状**：❌ 网络超时 · 等待响应超时
- **场景**：抓视频号链接 / yt-dlp 下载公开视频时
- **怎么办**：
  1. 检查网络 / WiFi
  2. 重试一次（脚本已内置 3 次重试）
  3. 把视频文件直接发给我，更稳

### 5.2 网络连接失败（ConnectionError）
- **症状**：❌ 网络连接失败
- **场景**：公司网络封视频平台 IP、SSL 握手失败
- **怎么办**：
  1. 换网络环境（手机热点试一下）
  2. 把视频文件下载到本地再发，避免在线抓取

### 5.3 视频号链接登录墙
- **症状**：提示「微信闭环，我无法直接抓取视频和字幕」
- **场景**：用户粘贴视频号链接
- **怎么办**（**不是脚本 bug，是平台限制**）：
  1. 把视频文件发给我（直接发文件比链接成功率高）
  2. 或粘贴逐字稿（带时间码更好）
  3. 不要反复尝试不同的视频号链接，结果都一样

## 六、内存 / 性能类

### 6.1 内存不足（MemoryError）
- **症状**：❌ 内存不足 · 机器内存不够
- **场景**：4GB 以下机器跑 large 模型；超长视频（>2h）一次性转写
- **怎么办**：
  1. 关浏览器多标签、大表格软件，腾出内存
  2. ASR 模型换 tiny 或 small（4GB 机器跑 medium / large 会卡死）
  3. 超长视频分段转写（每 ~10min 一段）

### 6.2 数据嵌套过深（RecursionError）
- **症状**：❌ 数据嵌套过深 · 递归深度超限
- **场景**：Markdown 标题层级跳级（如 `##` 直接跳到 `######`）；HTML 表格嵌套
- **怎么办**：检查 Markdown 标题层级规范（## / ### / ####）。

### 6.3 ASR 转写极慢
- **症状**：跑了 10 分钟还没出结果
- **场景**：large 模型 + CPU 机器 + 长视频
- **怎么办**：
  1. 改用 small / medium 模型（精度的损失有限）
  2. 硬件自适应：脚本会按内存自动选模型，可手动指定 `--model small`
  3. 切 GPU 加速（需 CUDA 环境）

## 八、协作 / 流程类

### 8.1 二创脚本自动跑出来，没问用户
- **症状**：用户没说要二创，AI 已经把脚本写到磁盘
- **场景**：违反「二创脚本是否生成 = 决策确认门管」铁律
- **怎么办**：agent 端必须先抛选项问用户（要 / 不要 / 先看大纲再决定 / 本次跳过），不得预设。

### 8.2 PDF / HTML / Word 选错了格式
- **症状**：用户要 PDF，AI 给了 Word
- **怎么办**：删除错版，重新跑步骤 9.5 的对应命令。

### 8.3 入选题库未经确认
- **症状**：报告刚出，二创直接进选题库
- **场景**：违反「内容是否进选题库 = 决策确认门管」铁律
- **怎么办**：agent 端必须抛「是否进选题库」选项问用户。

## 九、错误处理铁律（agent 端）

无论执行层触发哪类降级或失败，**错误信息必须普通人能看懂**：

| 维度 | 写法 | 禁止 |
| --- | --- | --- |
| 标题 | ❌ 找不到文件 · 路径不存在或拼写有误 | ❌ FileNotFoundError: [Errno 2] No such file or directory: 'xxx' |
| 动作 | 💡 怎么办：<br>· 检查路径<br>· 加引号 | 抛 traceback 让用户自己 Google |
| 分类 | 区分 用户输入 / 依赖缺失 / 环境配置 / 内部错误 | 所有错误统称「出错了」 |
| 退路 | 至少给 2 个可选下一步 | 「请联系管理员」 |

> 自检：本手册自身所有报错举例，agent 端必须 1:1 还原成普通人话，禁止用 traceback 砸用户。
