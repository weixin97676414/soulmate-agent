## 一、拍摄脚本镜头表

按时间轴逐镜拆解。步骤 2（原片拆解）与步骤 6（二创）共用同格式：

| 镜号 | 🗣️ 说话人 | 时间/时长 | 景别 | 运镜 | 画面内容 | 台词/字幕 | BGM/音效 | 备注（来源/手法/建议） |
|------|-----------|-----------|------|------|----------|-----------|----------|----------------------|
| 1 | 甲 | 0:00–0:03 | 近景 | 固定 | 主播正视镜头 | "我敢打赌你绝对不知道……" | 无/轻垫乐 | 钩子；字幕放大关键词 |
| 2 | 甲 | 0:03–0:12 | 中景 | 轻微推 | 主播讲述 | "……" | 铺垫 BGM | 痛点引入 |
| 3 | 乙 | 0:12–0:18 | 过肩 | 固定 | 乙接话抬杠 | "这话我可不信" | 鼓点进 | 回合1；黄字居右 |

**🗣️ 说话人列（v2.25.0 强制新增 · 多角色视频不再无主）**
- 取值：步骤 1.95 判定的角色编号——**甲 / 乙 / 丙 / 丁**（中文轨默认）或 **A / B / C**（字母轨，原片用英文姓名条或跨语言协作时）；画外音写 **VO**，群声/群演写 **众**，无台词空镜/B-roll 写 **—**。
- **同一份文档只用一套编号**，禁止甲/乙 与 A/B 混用。
- **S1 单人口播该列全填「甲」**（列在、值统一，读者一眼确认"就一个人说"）。
- 与台词列联动：该镜谁说话，台词列就是谁的台词；无台词镜填 `—`，不许留空让人猜。
- 详见 `references/speaker_notation.md` 四节。

**字段约定**
- 景别：全景 / 中景 / 近景 / 特写 / 大特写 / 过肩。
- 运镜：固定 / 推 / 拉 / 摇 / 移 / 手持 / 升降 / 航拍。
- 备注列三要素：① **画面来源**——原片拆解标【实测帧 0:24】，无画面反推测【推测】；② **可复用手法**——若含可继承的拍摄技法，写"低角度产品 B-roll""画框构图收尾"等（词汇见 `references/shooting_techniques.md`）；③ **拍摄建议/优先级**——"手机中景固定可拍""需广角+三脚架"。
- 二创镜头表每条必须标**镜头来源**：`沿用原片0:24手法` / `原创（二创）`，并给一句拍摄可行性与成本提示。

## 二、口播文案模板与气口标注

文案以"可念的逐字稿"产出，保留短视频口播节奏。气口标注约定：

- `【停顿】` — 换气 / 给观众反应时间
- `【重音】` — 关键词加重
- `【升调】` — 疑问 / 制造悬念尾音上扬
- `【笑】` `【沉】` `【轻声】` — 情绪/音量提示

**模板骨架（对应结构模块库）**
```
【钩子】<前 3–5 秒抓人句>
【停顿】
【痛点】<放大问题，引发共鸣>
【观点】<核心主张一句话>
【论据1】<案例/数据>
【论据2】<故事/对比>
【反驳】<常见误区，先破后立>
【方法】<给行动建议>
【金句】<可截屏句>
【互动】<引导评论/关注>
```

**示例（片段）**
> 【钩子】你每天加班到十点，为什么还是没成长？【升调】
> 【停顿】
> 【痛点】因为我以前也是这样，忙得要死，年底复盘却说不出做了啥。
> 【观点】不是你不努力，是你把"忙"当成了"成长"。

二创脚本必须沿用此格式，保证产出可直接用于拍摄。

### 二点一、多人对话版 · 按角色分段（v2.25.0 强制 · 原片为 S2/S3/S4 时必用）

单人口播（S1）用上面骨架即可（全段写 `甲：`）；**两人/三人对话、VO 串群戏必须按角色一行一段**，否则谁在说、镜头切给谁全糊在一起，拍摄时根本没法用。

**① 双人对话（S2）**

```
【0:00-0:04 · 钩子｜语气：突然】
甲：你说这活儿，干到最后到底图个啥？【升调】
【0:04-0:09 · 回合1｜语气：装傻】
乙：图钱呗，还能图啥。【停顿1秒】
甲：错。图的是——你走了以后，还有人愿意叫你一声师傅。【重音：叫你一声师傅】
【0:09-0:12 · 空镜｜语气：—】
（无台词，工地空镜 3s，BGM 起）
【0:12-0:30 · 回合2 · 冲突点｜语气：激动】
乙：那要是没人叫呢？
甲：【停顿】那我这二十年，就当是给自己砌了堵墙。
```

**② 三人对话（S3）**

```
【0:00-0:05 · 钩子｜语气：悬疑】
甲：这单我们不接。【停顿】
乙：为啥啊？钱都不赚？
丙：（笑）你们俩啊，都没说到点上。
【0:05-0:18 · 三方交锋｜语气：渐快】
甲：这活儿干完要背十年的锅。
乙：可是客户给得真多。
丙：锅是咱背，钱是老板拿——这账，你们算过吗？【重音：背/拿】
```

**③ VO 串多受访者（S4）**

```
【VO 旁白 · 0:00-0:06｜语气：平缓】（画面：工地全景缓推）
VO：干了二十年弱电，他第一次在工地上发了火。
【受访者1（甲）· 0:06-0:14｜语气：憋着】
甲：不是我脾气大，是这活儿真不能这么干。
【VO 转折 · 0:14-0:17｜语气：转沉】（画面：空镜 3s）
VO：可让他发火的，其实不是活儿。
【受访者2（乙）· 0:17-0:25｜语气：无奈】
乙：是我跟他说，我下个月就要走了。
```

**格式铁律（缺一即返工）**

1. **一行一角色**：同一段内换人必须换行重起 `乙：`/`丙：`/`VO：`，禁止把几个人的话挤进一行。
2. **段头元数据照旧**：`【起始-结束 · 段落名｜语气：X】`（copywriting_craft §6/§7 规范不变），角色名写在段内第一行。
3. **气口归本人**：`【停顿X秒】` / `【重音：X】` / `【升调】` / `【笑】` 写在对应角色那一行。
4. **VO 独立**：画外音段标 `VO：`，画面同步提示写段尾 `(画面：xxx)`，不占角色编号。
5. **空镜不留白**：无台词段写 `(无台词，<画面描述> <时长>s)`。
6. **编号不混用**：全文统一甲/乙/丙 或 A/B/C，二者不共存。
7. **镜头表同步**：每个角色段对应镜头表「🗣️ 说话人」列同一编号（谁说话切谁，字幕按角色分色）。

> 完整规范、角色卡模板与反模式见 `references/speaker_notation.md`。

## 三、🎬「可沿用原片拍摄手法」小节模板（步骤 6 必填）

每个二创方案在镜头表之前，先列出可复用的原片真实镜头/技法（从步骤 1.8 继承），让二创"站在爆款肩膀上"。格式：

```
🎬 可沿用原片拍摄手法：
1. 沿用原片 0:24「低角度车头 B-roll」——建立产品高级感（原片维度：信息结构5/情绪4.5）
2. 沿用原片 1:04「Hero shot：蓝调时刻全车+城市天际线」——做收尾视觉高潮
3. 沿用原片 0:18「钟表框前景遮挡构图」——做视觉钩子，强化代入
4. 原创（二创）：车内雨窗特写——本方案新增，承接"稳"的主张
```
- 每条注明**来源时间码 + 原片技法名 + 复用目的**。
- 若无对应原片可沿用，写"原创镜头：本方案全部为二创原创分镜"。
- 技法名词沿用 `references/shooting_techniques.md`（保持术语一致，便于沉淀与复用）。

## 四点五、🎵「BGM 设计建议」小节模板（步骤 6 要素 4.5 · v2.8 必含）

每个二创方案必须配套 BGM 设计，不写"用热门 BGM 就行"。依据 `references/bgm_design.md`（先定情绪再选曲风、音量跟内容走、卡点对高光来）：

```
🎵 BGM 设计建议：
- 曲风/情绪基调：<Lo-fi 轻电音 · 清爽信息感>（依据：叙事类型 + 步骤 1.9 情绪基调）
- 配器/节奏：<钢琴 + 电子鼓 + 白噪音 · 中速偏快>
- 四段音量曲线：钩子 20%（前 1s 留白）→ 中段 15% → 高光 0:12/0:38 顶到 35% 并卡点 → 金句 0:52 抽空 → 收尾 25% 上扬
- 卡点位置（对齐高光时间轴 Top 3）：<0:12 反转卡点 · 0:38 高潮卡点 · 0:52 金句停顿>
- 平台适配备注：<抖音→热门 BGM 硬卡点；视频号→保留温暖氛围；小红书→压低音量>
- AI 生成指令（可选，可复制进即梦AI/豆包/Suno）：<按 bgm_design.md 第 5 步模板，曲风/配器/情绪/时长/无人声/音量垫底全指定>
- 音效点缀：<晒过程型：打孔声/盖章声；讲故事型：环境音淡入>
```

> 镜头表 BGM/音效列（每镜）与本节（全片）的关系：镜头表列标"该镜头的 BGM/音效动作"（如"铺垫 BGM""留白""音效：打孔声"），本节给"全片 BGM 的整体设计"——两者不重复，镜头表是落点、本节是设计。

## 五、📐 形态自适应三模板（步骤 6 必选，按原片时长/结构）

二创不能一律套 60 秒单人 VO。先按原片时长选定模板，再写分镜。

### 模板 A — 短视频单幕型（原片 ≤60s，口播/干货）
- 结构：单场景、单人、强钩子 → 干货/观点 → 金句 → 互动。
- 时长建议：30–60s；镜头 5–8 个，多为中近景固定/微推。
- 适用：代运营定价类干货、金句独白。
```
【钩子】→【痛点/观点】→【论据×1-2】→【金句】→【互动】
```

### 模板 B — 中视频双幕型（原片 1–3min，对比/教程）
- 结构：问题幕 → 转折幕（含演示/对比）→ 方法 → 收尾。
- 时长建议：60–120s；镜头 8–14 个，含 1–2 组 B-roll 对比。
- 适用：方法对比、前后反差。
```
【钩子】→【问题幕】→【转折/演示】→【方法】→【金句】→【互动】
```

### 模板 C — 中长视频多幕故事型（原片 >3min，人物故事/品牌叙事）
- 结构：身份锚定 → 困境深化 → 转折点（品牌揭示）→ 蜕变成果 → 社会证明。
- 时长建议：原片 60–90%；镜头 12–20+，多场景、多角色、含对白/分屏。
- 适用：华为坤灵"老沈的生意经"类人物故事品牌片。
```
【身份锚定】→【困境】→【转折/品牌揭示】→【蜕变成果】→【社会证明/证言】→【收尾升华】
```

## 五点五、🗂️ 四类叙事结构骨架（步骤 6 必选，叙事逻辑维度 · 与形态 A/B/C 正交）

> **为什么加这一层**：形态 A/B/C 回答"**做多长、几幕**"（时长维度）；四类叙事骨架回答"**按什么逻辑讲**"（叙事维度）。二者正交——先定形态，再定叙事类型，双维度共同锁定脚本结构。四类脚本结构，按本技能门禁体系收编。

**四类叙事类型 + 固定结构链**（步骤 6 每个二创方案必须标注叙事类型并套对应结构链）：

| 叙事类型 | 结构链 | 适合内容 | 典型平台/场景 |
|----------|--------|----------|----------------|
| **教知识型** | 开篇钩子 → 引出问题 → 要点讲解 → 价值升华 → 引导互动 | 干货/避坑/方法论 | 知识科普、行业经验 |
| **聊观点型** | 开篇钩子 → 观点阐述 → 案例支撑 → 价值升华 → 引导互动 | 评论/态度/认知 | 口播观点、热点锐评 |
| **讲故事型** | 开篇钩子 → 背景铺垫 → 冲突展开 → 高潮转折 → 价值升华 → 引导互动 | 人物故事/品牌叙事/逆袭 | 中长视频、IP 人设 |
| **晒过程型** | 开篇钩子 → 过程展示 → 亮点强调 → 信任背书 → 引导转化 | B端施工/手艺展示/安装改造/实测 | 源头工厂、设备类、招商加盟 |

**应用规则**：
- 步骤 6 每个方案在形态（A/B/C）之外，**强制标注「叙事类型：教知识 / 聊观点 / 讲故事 / 晒过程」**，正文结构链严格套用上表，禁止"标了类型却自由发挥"。
- 叙事类型与形态的典型搭配：教知识/聊观点 → 多配 A/B 形态；讲故事 → 多配 C 形态；**晒过程 → A/B/C 均可**（短过程秀用 A，含前后对比用 B，完整改造记录用 C）。
- **晒过程型（v2.5 新增能力，B 端必看）**：尤其适合安防施工、停车改造、设备安装、手艺展示——"过程展示→亮点强调→信任背书→引导转化"天然是 B 端成单结构，二创时把原片过程环节拆出"开工前→施工中→完工后"三段，每段一个可验证亮点（如"打孔位置画了线""线材做了标签"），收尾引导询单/预约。
- 与「类型感知拆解侧重」（步骤 5）区分：拆解侧重管"拆什么"，叙事类型管"二创怎么组织"，两者独立不冲突。

## 六、🗣️ 访谈 / 对白 / 分屏 镜头模板（原片含多人结构时必用）

原片若出现"对坐访谈""旁白+采访剪辑""分屏证言"，二创须用对应结构，不能只写单人 VO。

### 6.1 对坐访谈（双人）
| 镜 | 景别 | 运镜 | 画面 | 台词 |
|----|------|------|------|------|
| A | 过肩（拍受访者） | 固定 | 主持人肩前景，受访者中景 | 受访者回答 |
| B | 过肩（拍主持人） | 固定 | 受访者肩前景，主持人中景 | 主持人提问 |
| C | 双人全景 | 固定/微摇 | 两人对坐 | 共鸣瞬间/笑 |
> 节奏：问答交替，每轮 ≤8s；情绪高点给单人特写。

### 6.2 旁白 + 采访剪辑（VO 串起多段采访）
```
[VO 旁白铺陈] → [采访片段1 特写] → [VO 转折] → [采访片段2] → [原片空镜/B-roll 过渡] → [VO 收尾]
```

### 6.3 分屏证言（多客户/多人背书）
| 区域 | 内容 | 字幕 |
|------|------|------|
| 左 | 客户 A 证言 + 姓名条 | "用了 X，业绩+40%" |
| 右 | 客户 B 证言 + 姓名条 | "终于不靠砍价了" |
> 分屏收尾常叠"鸣谢名单"或品牌 logo 墙，二创可沿用此收束法。

### 6.4 说话人编号对照（v2.25.0 · 多人结构先编号再写稿）

原片/二创为 S2/S3/S4 时，**必须先出这张对照表，再写镜头与口播**（编号贯穿全文档，中途不得改名换号）：

| 编号 | 角色代称 | 身份与立场 | 台词占比 | 镜头基准 | 字幕样式 |
|------|----------|------------|----------|----------|----------|
| 甲（A） | 老张 | 主叙述·吐槽输出观点 | 55% | P02 对话过肩 | 白字居左 |
| 乙（B） | 小徒弟 | 追问/抬杠·冲突发动机 | 30% | P03 情绪特写 | 黄字居右 |

## 七、🎯 成本等级与爆款潜力（步骤 6 落地标注 + 报告汇总）

每个二创方案必须标注：

- **💰 拍摄成本等级**：
  - ★ 手机可拍（单人、固定机位、自然光）
  - ★★ 需三脚架/补光灯（低角度、运镜稳定、简易布光）
  - ★★★ 需设备+演员/场地（多角色、分屏、棚拍、B-roll 外拍）
- **🔥 爆款潜力(1–5)**：基于钩子强度、赛道热度、共鸣广度预估。
- **📌 用途标签（v2.7 新增 · 三分法：赌爆 / 稳涨 / 矩阵测试）**：每方案三选一——
  - **赌爆**：高成色（≥32）、高风险高收益，适合主号首发冲流量（对应"最爆"）；
  - **稳涨**：低风险、稳定涨粉/涨信任，适合日常时段填充（对应"最稳"）；
  - **矩阵测试**：不同钩子/人群版，适合小号/多账号批量试角度，胜出者回流选题库升级（对应"矩阵测试"）。
  - 判定建议：成色卡 ≥35 且赛道热度高 → 赌爆；成色 30–34 但受众广、制作成本低 → 稳涨；同框架多人群/多钩子变体 → 矩阵测试。

**报告第七节目末「拍摄优先级排序表」**（示例，含用途列）：
| 优先级 | 方案 | 形态 | 用途 | 成本 | 潜力 | 一句话理由 |
|--------|------|------|------|------|------|------------|
| 1 | 方案5 零售重生 | C 多幕 | 赌爆 | ★★ | 5 | 场景易获取、共鸣最强 |
| 2 | 方案1 餐饮突围 | C 多幕 | 赌爆 | ★★ | 4 | 餐饮老板痛点普适 |
| 3 | 方案3 工厂觉醒 | C 多幕 | 稳涨 | ★★★ | 4 | 需进车间拍摄，成本偏高 |
| 4 | 方案2 教培转型 | C 多幕 | 矩阵测试 | ★★ | 3 | 赛道受限（教培敏感） |
| 5 | 方案4 诊所升级 | C 多幕 | 稳涨 | ★★★ | 3 | 医疗合规风险，慎拍 |

> 创作者一眼决定"先拍哪条、是否需要外援"，把选题库从"条目堆"变成"可执行的拍摄计划"。

## 七点五、🎭 拍摄形式三维正交（步骤 6 必标 · v2.12 新增）

> **为什么单列**：本技能已有「形态 A/B/C」（管**做多长、几幕**）+「叙事类型」（管**按什么逻辑讲**），但缺一个独立维度回答**"几个人、怎么演"**——即**拍摄形式（呈现层）**。三者正交：同一条脚本可"单人口播"也可"情景演绎"，效果天差地别。完整方法论见 `references/presentation_form.md`。

### 7.5.1 三维关系图

```

  一个二创方案 =                                         （时长维度）

            │                                        （逻辑维度）
            └──────── 🎭 拍摄形式 F1–F6 ────────┘  几个人、怎么演
                                                 （呈现维度）
```

### 7.5.2 六类拍摄形式速查

| 编号 | 形式 | 定义 | 与叙事类型强绑定 |
|------|------|------|------------------|
| **F1** | 单人口播 | 一人正对/侧对镜头讲述，无对手戏 | 教知识 / 聊观点（主） |
| **F2** | 多人对话 | 2+ 人同框互动（问答/拌嘴/对谈） | 聊观点（辩论）/ 讲故事（对话内核） |
| **F3** | 情景演绎 | 设定小场景+角色，演一段短剧情 | 讲故事 / 晒过程（含对比） |
| **F4** | 旁白 + VCR | 画外音 VO 串起实拍/素材画面 | 教知识（边做边讲）/ 晒过程 |
| **F5** | 对坐访谈 | 主持人 × 受访者正式/半正式对谈 | 讲故事（揭秘）/ 教知识（专业背书） |
| **F6** | 分屏证言 | 多画面同帧（客户/用户/专家齐说） | 晒过程（信任背书）/ 聊观点（多点并列） |

### 7.5.3 二创方案头部「落地标注」完整模板（含拍摄形式）

每个二创方案头部一行式标注（与 script_template 第七节成本等级并列）：

```
📐 形态：A 短视频单幕 ｜ 🗂️ 叙事类型：聊观点 ｜ 🎭 拍摄形式：F2 多人对话（主）·替代 F1 分饰两角
🗣️ 说话人配置：S2 双人对话（甲=主叙述 / 乙=抬杠方）· 替代：S1 单人分饰两角
📌 用途标签：矩阵测试 ｜ 💰 拍摄成本：★–★★ ｜ 🔥 爆款潜力：4
```

**说话人配置标注三要素（v2.25.0 新增 · 缺一不可）**
1. **S 编号 + 角色说明**：如 `🗣️ 说话人配置：S3 多人对话（甲=师傅 / 乙=徒弟 / 丙=路人老板）`。
2. **角色分工表**（紧跟头部）：编号 / 演什么人 / 立场与功能 / 台词占比 / 镜头基准 / **谁来演（可替换性）**——写清哪个角色非本人不可、哪个随便拉人就能上。
3. **替代方案**：拍不了多角色时怎么降级（S2→S1 分饰两角换装硬切 / S3→S2 合并丙的台词并注明丢失的视角 / S4→S1 口播描述+注明损失画面证据力）。
> **默认沿用原片人数**——改人数必须写论证，禁止把多人对话默默塌缩成独白（那是丢魂）。

**拍摄形式标注三要素（缺一不可）**：
1. **F 编号 + 名称**：如 `🎭 拍摄形式：F2 多人对话`，禁止只写"口播/对谈"。
2. **选型理由（双向推导）**：
   - 内容推导：从文案结构判断（一人连贯独白→F1；有来有回回合→F2/F3；解说词→F4；多方并列→F6）。
   - 继承推导：原片用了什么形式、为什么火，二创是否沿用（沿用/改编/全新）。
3. **替代方案**：拍不了主形式时最简降级（如 F2→F1 分饰两角剪辑；F3→F1+字幕卡演绎）。

### 7.5.4 与原片形式对齐规则

- 原片是 F1 且火 → 二创优先沿用 F1（可复制性强），除非赛道/人设不适应。
- 原片是 F2/F3 且火 → 火点常在"角色反差/表演冲突"，二创**必须保留该形式内核**，不能塌缩成单人独白（丢了魂）。
- 原片是 F4/F5/F6 → 二创按同为"多元素/多人物"结构处理，避免退化为单人 VO。
- 任何改编都须在「选型理由·继承推导」里说明"为什么改形式"（如单人 IP 改 F2 需搭档，成本权衡后选 F1 分饰两角）。

## 八点五、🎯 转化结尾按目标分类（CTA 三型）

> **为什么单列**：把"转化结尾"按**目标**分成 涨粉 / 带货 / 引流 三类，比泛泛一句"关注我"更可落地。本技能八维自分析（D6 互动/转化设计）常判"结尾无互动引导 / 弱"，但只给"加个提问"还不够——应让用户**先定目标，再选结尾类型**。二创（步骤 6）与八维自分析原片整改（步骤 5.8）通用。

| **涨粉型** | 做 IP / 涨信任 / 涨关注 | "如果你也[痛点]，点个关注，我接下来[持续价值承诺]" ＋ 金句横幅可截图转发 | 强化"可转发理由"（金句/价值观/身份认同，见 `platform_rules.md` §五 D9 社交链适配度） |
| **带货型** | 卖货 / 引流到店 / 留资 | "想要[具体利益]的，评论区扣[关键词]，我把[资料/链接]发你" ＋ 评论区置顶写明利益点 | 评论区置顶写清利益；视频号/抖音避开"不转不是…""点赞过万就…"等诱导话术（见 `platform_rules.md` §八 红线速查） |
| **引流型** | 加私域 / 进群 / 到店 | "想[深度/陪跑]的，主页加我，备注[来源]领[福利]" ＋ 口播重复一遍微信号/群入口 | 主页简介/置顶留入口；抖音规避"诱导关注/私信"类限流词 |

**应用规则**
- 八维自分析（归属②）诊断出 D6 < 3 时：**先问用户"这条片你主要想涨粉 / 带货 / 引流？"**，再在整改单的「互动/转化」段给出对应一型模板 + 配套动作，而不是只写"补互动钩子"。
- 分平台改进诊断（步骤 5.8）的 §6 评论区置顶文案须与所选 CTA 类型对齐：涨粉→关注引导；带货→扣关键词领福利；引流→私域入口。
- 三型可叠加（如"涨粉 + 带货"），但单条视频结尾**只放 1 个主 CTA**，避免分散完播注意力。

## 九、🔁「内容反写」思路说明模板（L3，步骤 6.3 二次确认门前输出）
