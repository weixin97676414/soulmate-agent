# 说话人配置与角色标注规范（speaker_notation）

> 供 `video-script-dissect` 在**步骤 1.95（原片判定）** 与 **步骤 6（二创输出）** 使用。
>
> **这一层解决什么病**：技能早期默认"一条视频 = 一个人说"，于是拿到两人对话 / 三人对话的原片时，口播稿被写成一大坨连贯独白——**谁在说、说的立场是什么、镜头该切给谁，全糊在一起**，用户拿来根本没法拍。
> 现在把「几个人在说」升级为**独立的第五维度**：先判配置（S1–S4），再给每个说话人编号建角色卡，最后**按角色分段写口播、按角色出镜头**。拆解报告与二创脚本共用同一套编号，从头到尾不乱。
>

---

## 零、一句话纪律

> **先定"几个人说"，再写"说了什么"。**
> 任何时长 >0 的分析与产出，起手必须先给「🗣️ 说话人配置」结论；没有这一步，后面的镜头表、口播稿、字幕全部是无主的。

---

## 一、说话人配置四档（S1–S4）

| 编号 | 配置 | 判定标准 | 典型形式（对应 F） | 口播稿形态 |
|------|------|----------|--------------------|------------|
| **S1** | 单人口播 | 全程 1 个稳定声线，无对手戏 | F1 单人口播 / F4 旁白+VCR | 单人独白，一气到底 |
| **S2** | 双人对话 | 2 个声线交替，有明确回合（问→答→追问 / 拌嘴 / 抬杠） | F2 多人对话 / F5 对坐访谈 | **甲 / 乙 交替分段** |
| **S3** | 多人对话 | 3 个及以上声线，含群聊、圆桌、多受访者 | F2 多人对话 / F6 分屏证言 | **甲 / 乙 / 丙 交替分段** |
| **S4** | 旁白 + 群戏 | VO 画外音串联多个受访者/片段（旁白不参与对话） | F4 旁白+VCR / F6 分屏证言 | **VO 独立成段 + 受访者按受访人编号** |

> **混合型写法**：主配置 + 括号说明，如 `S4 旁白+群戏（含 S2 双人对话内核）`。
> **判定依据优先级**：① 抽帧数出镜人数（最硬）→ ② 步骤 1 说话人分离声线数 → ③ 逐字稿的问答/回合结构 → ④ 用户描述。四者冲突时以 ① 为准，并在报告记一行"判定依据"。

## 二、角色编号规范（双轨 · 禁止混用）

### 2.1 两套编号，选一套用到底

| 体系 | 记号 | 什么时候用 |
|------|------|------------|
| **中文轨（默认）** | **甲 / 乙 / 丙 / 丁** | 中文口播稿、给国内团队看的镜头表、拍戏现场喊人——**首选** |
| **字母轨** | **A / B / C / D** | 表格密集的技术文档、跨语言协作、原片本身用英文名条时 |
| **旁白** | **VO**（画外音） | 任何不出现在画面里的解说声，统一叫 VO，不占角色编号 |
| **群演/合声** | **众** | 三人以上齐说、背景音、群众反应，不单独编号 |

> 🚫 **铁律：同一份文档（报告或单条二创）内只能出现一套编号。** 甲/乙/丙 和 A/B/C 混用 = 直接返工。
> 若原片已用 A/B/C 姓名条（画面 ground truth），二创沿用字母轨，并在角色卡注明"沿用原片姓名条"。

### 2.2 编号顺序规则（谁当甲）

1. **甲 = 主叙述者**：承担开场 Hook、抛出核心观点、台词占比最高的人。
2. **乙 = 对立面或提问者**：负责追问、抬杠、抛反例、制造冲突的人（冲突的发动机）。
3. **丙 / 丁 = 补充方**：第三方视角、和稀泥、补刀、给证言。
4. **VO = 串场**：只在 S4 出现，负责铺陈与转折，不参与对话。

> 判断不清时按**台词占比降序**编号，并在角色卡写"按台词量排序"。

## 三、角色卡（每个说话人一张，五必填）

判完配置后，给每个角色建卡，**五要素缺一不可**：

| 字段 | 写什么 | 示例 |
|------|--------|------|
| **编号/代称** | 甲 / 乙 / 丙（或 A/B/C）、可加昵称 | `甲（老张·干了20年弱电）` |
| **身份与立场** | 一句话说清他是谁、代表什么立场 | 乙 = 质疑方，"我只信便宜的" |
| **人设关键词** | 2–3 个词，定表演调性 | 甲：沉稳、带点无奈 / 乙：直爽、爱抬杠 |
| **台词占比** | 全片台词百分比 | 甲 55% / 乙 30% / 丙 15% |
| **镜头基准** | 他的默认景别与机位（配 P 码） | 甲：P02 对话过肩 / 乙：P03 情绪特写 |

> 角色卡写在报告「🗣️ 说话人配置」节与每条二创方案头部（二创可给简称版）。

## 四、拆解报告怎么用（步骤 1.95 产出）

### 4.1 报告新增节：「🗣️ 说话人配置」

每份拆解 / 八维报告，在「基本信息」之后、拍摄脚本之前，强制给出这一节：

```markdown
## 二之三、🗣️ 说话人配置

**配置判定：S2 双人对话**（依据：抽帧见 2 人同框 + 声线分离 2 路 + 逐字稿含问答回合）

| 角色 | 身份与立场 | 人设关键词 | 台词占比 | 镜头基准 | 出自 |
|------|------------|------------|----------|----------|------|
| 甲（姐） | 主叙述，吐槽型输出观点 | 泼辣、语速快 | 60% | P02 对话过肩 | 0:00–1:20 全程 |
| 乙（妹） | 追问/抬杠，负责抛反例 | 慢半拍、装傻 | 40% | P03 情绪特写 | 0:08 起接话 |

- **回合节奏**：平均 6s 一轮（甲 4s 抛 → 乙 2s 接），全片 12 轮；
- **冲突发动机**：乙（每次乙一抬杠，甲语速提 20%，播放曲线抬头）；
- **字幕样式**：甲=白字居左，乙=黄字居右，姓名条仅在首次出场出现 2s；
- **对后续的影响**：二创须保留双角色内核，禁止塌缩成单人独白（丢了魂）。
```

### 4.2 镜头表加「🗣️ 说话人」列

步骤 2 拆解镜头表与步骤 6 二创镜头表，**在原列基础上强制增加一列**：

| 镜号 | 时间/时长 | 🗣️ 说话人 | 景别 | 运镜 | 画面内容 | 台词/字幕 | BGM/音效 | 备注 |
|------|-----------|-----------|------|------|----------|-----------|----------|------|
| 1 | 0:00–0:04 | **甲** | 近景 | 固定 | 甲正视镜头抛问题 | "你说这活儿能干吗？" | 无 | 钩子 |
| 2 | 0:04–0:09 | **乙** | 过肩 | 固定 | 乙愣住、接话 | "啊？不能干也得干啊" | 轻鼓点进 | 回合1 |
| 3 | 0:09–0:12 | **VO** | 空镜 | — | 工地全景过渡 | （无台词） | BGM 起 | 缓冲 |

> 单人口播（S1）该列全填「甲」即可——列在，值统一，读者一眼确认"就一个人说"。

## 五、二创输出怎么用（步骤 6 强制）

### 5.1 方案头部加「🗣️ 说话人配置」行

落地标注行扩为四维并列（形态 / 叙事 / 形式 / **说话人**）：

```
📐 形态：B 中视频双幕 ｜ 🗂️ 叙事类型：聊观点 ｜ 🎭 拍摄形式：F2 多人对话
🗣️ 说话人配置：S2 双人对话（甲=主叙述 / 乙=抬杠方）· 替代：S1 单人分饰两角
📌 用途标签：赌爆 ｜ 💰 拍摄成本：★★ ｜ 🔥 爆款潜力：4
```

### 5.2 角色分工表（二创必给，紧跟头部）

| 角色 | 演什么人 | 立场/功能 | 台词占比 | 镜头基准 | 谁来演（可替换性） |
|------|----------|-----------|----------|----------|--------------------|
| 甲 | 干了 20 年的老师傅 | 主叙述+观点输出 | 55% | P02 对话过肩 | 本人出镜（必需） |
| 乙 | 刚入行的小徒弟 | 追问/抬杠/抛反例 | 45% | P03 情绪特写 | 搭档/同事即可（易替） |

> **可替换性**是给用户减负：写清哪个角色非本人不可、哪个随便拉个人就能上。

### 5.3 口播稿按角色分段（核心产出格式 · 强制）

**双人（S2）标准格式**：

```
【0:00-0:04 · 钩子｜语气：突然】
甲：你说这活儿，干到最后到底图个啥？【升调】
【0:04-0:09 · 回合1｜语气：装傻】
乙：图钱呗，还能图啥。【停顿1秒】
甲：错。图的是——你走了以后，还有人愿意叫你一声师傅。
【0:09-0:12 · 空镜｜语气：—】
（无台词，工地空镜 3s，BGM 起）
【0:12-0:30 · 回合2 · 冲突点｜语气：激动】
乙：那要是没人叫呢？
甲：【停顿】那我这二十年，就当是给自己砌了堵墙。
```

**三人（S3）标准格式**：

```
【0:00-0:05 · 钩子｜语气：悬疑】
甲：这单我们不接。【停顿】
乙：为啥啊？钱都不赚？
丙：（笑）你们俩啊，都没说到点上。
【0:05-0:18 · 三方交锋｜语气：渐快】
甲：这活儿干完要背十年的锅。
乙：可是客户给得真多。
丙：锅是咱背，钱是老板拿——这账，你们算过吗？【重音：背/拿】
```

**VO 串场（S4）标准格式**：

```
【VO 旁白 · 0:00-0:06｜语气：平缓】
VO：干了二十年弱电，他第一次在工地上发了火。
【受访者1（甲）· 0:06-0:14｜语气：憋着】
甲：不是我脾气大，是这活儿真不能这么干。
【VO 转折 · 0:14-0:17｜语气：转沉】
VO：可让他发火的，其实不是活儿。
【受访者2（乙）· 0:17-0:25｜语气：无奈】
乙：是我跟他说，我下个月就要走了。
```

**格式铁律**：

1. **一行一角色**：同一时间码段落内，换人必须换行重起 `乙：` / `丙：`，禁止把三人的话挤进一段。
2. **段头元数据保留**：每段仍是 `【起始-结束 · 段落名｜语气：X】`（copywriting_craft §6 规范不变），角色名紧跟在段内第一行。
3. **气口照旧**：`【停顿X秒】` / `【重音：X】` / `【升调】` 等标注继续写在对应角色那一行。
4. **VO 独立**：画外音段标 `VO`，不占角色编号；画面同步提示写在段末 `(画面：xxx)`。
5. **空镜/无台词段**写 `(无台词，<画面描述> <时长>s)`，不许留空白让读者猜。
6. **单人口播（S1）** 全部行写 `甲：`，格式不变，只是多一个角色前缀——**保持全技能输出格式统一**。

### 5.4 镜头表按角色给切换规则

| 配置 | 切换规则 | 字幕区分 |
|------|----------|----------|
| S2 | 回合切：甲说完切乙，每轮 ≤8s；冲突点给说话人特写 | 甲白字居左 / 乙黄字居右 |
| S3 | 谁说话切谁 + 每 3 轮给一次三人全景收拢 | 三色字（白/黄/青），首次出场配姓名条 2s |
| S4 | VO 段铺 B-roll，受访者段切人物特写，VO 与受访者交界处空镜缓冲 | VO 白字居中 / 受访者配"姓名·身份"条 |
| S1 | 每 8–12s 插 1 次 B-roll 或景别变化，防视觉疲劳 | 白字居中，金句放大 |

## 六、与原片对齐规则（角色数量怎么定）

1. **原片几人，二创默认就几人**：原片 S2 火在"双人化学反应"，二创塌缩成 S1 独白 = 丢魂（与 presentation_form 2.2 一致）。
2. **可以改数量，但必须论证**（写在选型理由里）：
   - **增人**（S1→S2）：想加"抬杠方"制造冲突，成本 +★，需搭档；
   - **减人**（S3→S2）：把丙的台词合并给甲/乙，须注明"合并后丢失的视角是 ___"；
   - **换壳**（S2→S1 分饰两角）：一人换装/换背景演两边，硬切呈现对话感（成本最低的降级路径）。
3. **禁止无理由改人数**：不写理由直接把三人片改成独白，步骤 8.8 验证不通过。
4. **编号沿用**：原片用 A/B/C 姓名条的，二创沿用字母轨并在角色卡注明"沿用原片姓名条"。

## 七、与其它四个维度的关系（五维正交）

```
一个二创方案 =
  📐 形态 A/B/C        → 做多长、几幕      （时长维度）
  🗂️ 叙事类型 四类      → 按什么逻辑讲      （逻辑维度）
  🎭 拍摄形式 F1–F6    → 几个人、怎么演    （呈现维度）
  🗣️ 说话人配置 S1–S4  → 谁在说、说什么    （角色维度）← 本库
  🎬✂️ 手法配方+剪辑     → 怎么拍、怎么拼    （执行维度）
```

| 说话人配置 | 强绑定拍摄形式 | 说明 |
|------------|----------------|------|
| S1 单人口播 | F1 / F4 | 一人到底；F4 时口播即 VO 解说词 |
| S2 双人对话 | F2 / F5 | 两人同框对谈或问答 |
| S3 多人对话 | F2 / F3 / F6 | 三人及以上：群戏/演绎/分屏证言 |
| S4 旁白+群戏 | F4 / F6 | VO 串多受访者，典型纪录片结构 |

> 说话人配置是**角色层**（谁在说），拍摄形式是**呈现层**（怎么演）：S2 既能用 F2（真实对谈），也能用 F3（演出来的对话），二者正交但要一致——**F3 情景演绎 + S2 双人对话 = 演一段吵架**，标注时两个都写。

## 八、反模式（见到即返工）

- ❌ **多人原片写成一坨独白**：三人对话的二创稿通篇没有角色前缀，读者分不清谁在说——最常见也最致命。
- ❌ **编号混用**：同一份文档里既有甲/乙，又有 A/B。
- ❌ **角色无立场**：给乙编了号，但乙的台词只是重复甲的观点——角色失去了存在意义（冲突发动机没了）。
- ❌ **台词占比失衡**：标了 S3 三人，结果丙只有一句"对对对"——要么给丙真台词，要么老实标 S2。
- ❌ **镜头表有角色、口播稿没角色**：两处不同步，等于没标。
- ❌ **VO 占角色编号**：把画外音叫成"甲"，后面真出镜的甲就撞车了。
- ❌ **无理由改人数**：三人原片默默改成独白，且不写理由。
- ❌ **字幕不分色**：S2/S3 多角色共用一种字幕样式，观众分不清谁在说话（完播杀手）。

## 九、速查卡（贴墙用）

```
1. 判配置：S1 单人 / S2 双人 / S3 三人+ / S4 旁白+群戏（看抽帧人数优先）
2. 定编号：中文稿用 甲/乙/丙，字母轨用 A/B/C，VO 单独叫，一套到底不混用
3. 建角色卡：编号·身份立场·人设关键词·台词占比·镜头基准（五必填）
4. 报告出节：「🗣️ 说话人配置」+ 镜头表加「🗣️ 说话人」列
5. 二创头部：🗣️ 说话人配置（含替代方案）+ 角色分工表（含可替换性）
6. 口播稿：一行一角色，段头元数据照旧，VO 独立，空镜写"（无台词…）"
7. 改人数必须论证：增人/减人/换壳，各写清代价
```
