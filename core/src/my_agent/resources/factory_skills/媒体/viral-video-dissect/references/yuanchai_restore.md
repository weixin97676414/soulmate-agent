# 元拆解 · 原编导视角还原双轴交织方法论（yuanchai_restore）

> 本文件供 `video-script-dissect` 在 **步骤 6.7「元拆解视频互动门」用户选"是"** 时参考，专攻**元拆解视频的文案角度与编排**——把"原编导视角还原"与"第三方结构拆解"两路交织，让新视频既能承载原视频核心表达，又能教观众可复用的方法。
> **铁律前置**：本文件是 **v2.19 新增**，是对 v2.18 元拆解环节的**增强而非替代**——v2.18 的"讲我们怎么拆这条爆款"结构拆解（轴 B）**完整保留**，本文件只负责补上"原编导视角还原"（轴 A）并规定两轴如何交织。原结构拆解 / 8 维评分 / 成色卡逻辑一律不删、不变。

## 一、为什么需要"原编导视角还原"（问题诊断）

v2.18 的元拆解脚本（步骤 6.7 第 691 行"元拆解脚本轻量结构"）是**纯第三方结构分析**：只站在"我们（拆解者）"立场讲"这条爆款为什么爆、结构怎么搭"。

它的短板：
- 只讲"结构骨架"，没讲"原编导当时脑子里在想什么"——观众看完知道"招式"，却没代入"创作现场"，共鸣浅；
- 对原视频的**文案金句、转折设计、人物场景**只是被当"证据"引用，没有被"拆开讲它为什么这么写"；
- 容易变成"自说自话的教学"，与原视频的情感内核割裂，难以"承载并延续原视频的核心表达"。

**本文件的修复方向**：在结构拆解之前，先站到**原编导的立场**，把"他为什么这么开头 / 这个转折想戳中什么 / 人物场景安排背后的表达意图"还原出来，用第三方"娓娓道来"的口吻讲给观众听，再自然穿插原视频重点内容。结构拆解（轴 B）承接这层理解，上升为方法。

---

## 二、双轴交织总览

元拆解视频 = **轴 A（原编导视角还原·理解层）× 轴 B（结构拆解·方法层）** 交织，由我们（拆解者）统一以第三方口吻叙述。

```
[开场] 原视频名场面/神转折切入，制造共鸣
   │
   ▼
[轴 A · 原编导视角还原]  ← 新（v2.19）
   "站在他的立场，还原他当时怎么想"
   · 创作意图还原      · 转折设计拆解
   · 人物场景解析      · 自然穿插原视频重点
   │
   ▼
[轴 B · 结构拆解]  ← 既有（v2.18 保留）
   "把他想表达的，翻译成你能学的结构"
   · 八维哪维最炸      · 反转点位置
   · 成色卡 Top1       · 方法论可视化
   │
   ▼
[收尾] 元视角收束 + 结尾互动钩子（关注 + 下期预告）
```

**两轴关系（不是并列、是递进）**：
- 轴 A 回答 **"他想表达什么 / 为什么这么设计"**（情感 + 意图）；
- 轴 B 回答 **"这招对应什么结构 / 我怎么学"**（方法 + 可复制）；
- 顺序固定 **轴 A 在前、轴 B 在后**——先让观众"懂他"，再教观众"学招"，否则方法会悬空、完播掉。

## 三、轴 A · 原编导视角还原（4 步方法）

> 核心口吻：**第三方"娓娓道来"**——像坐在原编导对面、替他把创作思路讲给观众听，而不是替原编导"发声"、也不是 dissection 自夸。

### 步骤 A1 · 创作意图还原
- 从原视频的**开头钩子**出发，推演原编导"想先抓住哪类情绪 / 先抛什么悬念"；
- 从**主线推进**推演"他真正想让观众带走的一个核心观点是什么"（一句话提炼，如"这视频本质是想说：普通人也能靠 X 翻身"）；
- 表述范式："从这条视频的编排看，他大概率是想先……再……，最后把观众引到『……』这个念头上来。"

### 步骤 A2 · 转折设计拆解
- 锁定原视频的**神转折 / 反转点**（可源自步骤 1.85 高光检测 + 成色卡"反转点落 78–85%"指标）；
- 讲清"这个转折在情绪曲线上承担了什么角色——是把人从平静拽到惊讶，还是把共情推到顶点"；
- 表述范式："注意 0:25 那一下，他没按常理接话，而是突然……，这一下把前面铺垫的……一下子点破了。"

### 步骤 A3 · 人物场景解析
- 解析原视频**人物设定 / 场景选择**背后的表达意图（谁出镜、为什么是这个场景、镜头离人物的距离意味着什么亲密度）；
- 若涉及说话人分离（步骤 1.7），可点出"破冰者 / 接话者 / 收金句者"的角色分工如何服务叙事；
- 表述范式："他让主角一直站在厨房这种生活化场景里，不是在演，是在让你觉得'这事就发生在我隔壁'。"

### 步骤 A4 · 自然穿插原视频重点内容
- 在 A1–A3 讲述中，**自然带出原视频重点**：引用原文金句（口播复述，不篡改原意）、用授权/二次创作标注的原片画面作举例；
- "穿插"原则：原视频内容是**被讲解的对象**，不是**被搬运的素材**——服务于"讲清他的思路"，而非凑时长；
- 受既有红线约束：用原片画面须授权或二次创作标注（见第六节省规），纯口播复盘最稳。

## 四、口吻规范（红线 · 必须守）

轴 A 是"还原意图"，**不是"代表原编导发言"**。三条不可越界：

1. **不冒充**：不得出现"原编导亲口跟我说 / 他当时就是这么想的（断言式）"——必须表述为"基于视频内容的合理推演"；
2. **不编造**：不得替原编导补写他视频里**没有表达过**的观点、数据、经历；推演只基于可见的文案 / 转折 / 人物场景；
3. **标注推演性质**：轴 A 开场或结尾须有一句声明，例如"以下是我基于这条视频的编排，对原编导创作思路的合理推演，不代表原编导本人表述"——既诚实又护合规。

**娓娓道来 vs 自说自话 对照**：
- ✗ 自说自话："这条视频结构很好，我们来看看它怎么搭的。"（只有"我们"）
- ✓ 娓娓道来："你当时刷到这条，是不是被 0:25 那一下整愣了？其实他前面 20 秒都在埋这个雷——咱们今天就把他怎么埋的，拆开揉碎讲给你听。"（站在观众+原编导中间，带人进创作现场）

## 五、轴 B · 结构拆解（既有 · 承接轴 A）

轴 A 讲完"他想表达啥"，轴 B 立刻接"这招怎么学"——把轴 A 还原出的意图翻译成 8 维可复用结构：

- 引用本次拆解的 **8 维评分**（哪维最炸）、**反转点位置**（成色卡指标）、**成色卡 Top1**；
- 方法论可视化：录屏拆解台账 / 画"钩子→转折→收尾"结构图；
- 让观众得到"一套能直接用的骨架"，而非只听一个故事。

> 轴 B 内容直接复用 v2.18 步骤 6.7 第 691 行的既有结构（我们拆出了什么 / 拆解思路可视化 / 下期反手做内容），**不重述、不删改**。

## 七、合规红线（与既有纪律一致）

1. **推演标注**：轴 A 必须含"基于内容的合理推演，非原编导自述"声明（第四节第 3 条）；
2. **非搬运画面**：用原片画面须授权或二次创作标注，否则纯口播复盘；侵权红线不变；
3. **不触发查重**：元拆解是"关于拆解的内容"，不重发原片，与视频号指纹系统无关（沿用步骤 6.7 边界）；
4. **过合规门**：元拆解脚本属成品文案，**须过步骤 6.5 合规检测**（违禁词 / 授权 / AI 标识等）；
