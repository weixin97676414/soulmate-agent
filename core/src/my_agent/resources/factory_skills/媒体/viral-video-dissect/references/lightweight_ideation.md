# 轻量选题入口方法论（lightweight_ideation · top-down 发散）

> 本文件是 `video-script-dissect` 的「纯文字灵感」入口配套方法论（**步骤 0.5**）。它把"用户只有一句话想法、没有视频素材"的轻量场景，从"被强制走全套 9 步视频拆解"里解放出来：**从灵感出发（top-down）速出角度池**，再无缝接入本技能既有的成色检测与二创管线。
> 把五钩子发散、三段式输出与去 AI 味工程，按本技能「四基因 + 成色卡 + 决策确认门」的门禁体系收编扩容，统一为「」资产。

**一句话定位**：拆爆款是"从结果反推图纸"（bottom-up，证据扎实）；轻量选题是"从想法直接出题"（top-down，极轻极快）。二者在「选题 / 钩子」层天然衔接：轻量线发散的候选角度，可原样流入步骤 5.5 角度池继续走人机共创与成色立项。

---

## 第 1 步：抓取用户灵感里的 3 个核心信息

读用户输入，先提炼三要素（缺哪个就一句话追问，除非用户明确说"直接出 5 个"）：

1. **主体**：是谁在说（身份 / 行业 / 角色，如"做了 5 年自媒体的"）
2. **受众**：说给谁听（人群 / 痛点 / 使用场景，如"想涨粉但没方法的创作者"）
3. **落点**：最终想让人知道什么 / 做什么（认知 / 行动，如"选题比努力更重要"）

> 输入过短（<20 字）时先补一句追问（"这个想法你是想讲给谁听？想让他们看完做什么？"），避免凭空乱出题。

---

## 第 2 步：五钩子发散（每个钩子出一道，禁同质）

从下面 5 类情绪钩子各选 1 个最贴灵感的角度，组成 5 道题。**5 道题里至少 1 道是「反常识颠覆」或「刺痛共鸣」**，其余从剩余钩子里挑，保证多样性；同一灵感最多允许 2 道共用同一钩子，**禁止 5 道全是一个套路**。

| # | 钩子 | 典型句式 | 适合场景 |
|---|------|----------|----------|
| 1 | **反常识颠覆** | "你以为……其实……" | 推翻大众认知，制造冲突 |
| 2 | **数字冲击+身份点名** | "XX 的人，90% 都做错了 N 件事" | 强获得感，人群精准 |
| 3 | **刺痛共鸣+质问** | "为什么 XX 你总是坚持不下来？" | 戳痛点，逼人点头 |
| 4 | **反问/抬杠** | "XX 真的有用吗？我劝你别再试了" | 引战，评论区爆炸 |
| 5 | **揭秘/内幕** | "做 XX 3 年，今天说点得罪人的真相" | 行业内幕，权威感 |

> **开口底稿（v2.24.1 新增关联）**：出完 5 道题后，给每道题配一句「可直接改写念出口的真实开场白」作底稿——从 `references/hook_opener_examples.md`（按心理机制 **A 悬念 / B 共鸣 / C 代入 / D 反常识** 分桶的 16 句真实话术）挑最贴的一句，套成自己的口播。五钩子 ↔ 机制映射速查：

| 五钩子（本步） | 对应机制（hook_opener_examples） | 可直接改写的第一句底稿示例 |
|---------------|-------------------------------|--------------------------|
| ① 反常识颠覆 | **D 反常识** | "你以为 XX 是这样的，但我告诉你完全不是" / "做了 X 年，我发现一件反常识的事" |
| ② 数字冲击+身份点名 | **C 场景代入（身份点名）** | "早上六点，我已经在路上了" / "今天是 X 月 X 号，是一个特别的日子" |
| ③ 刺痛共鸣+质问 | **B 情绪共鸣** | "今天发生了一件事，我到现在还没缓过来" / "今天是我做这行以来，最崩溃的一天" |
| ④ 反问/抬杠 | **D 反常识 / B 共鸣（带对立）** | "你以为 XX 其实根本不是 YY" / "我做了一个决定，可能很多人都不理解" |
| ⑤ 揭秘/内幕 | **A 悬念（秘密）** | "这件事我身边没有人知道，但我想告诉你" / "有个事我一直没敢拍，但今天决定拍了" |

> ⚠️ 底稿是「可改写底稿」不是「照抄」。每句须过 `copywriting_craft.md` §1 六测（具体 / 口语 / 不剧透 / 合规…），且「99%」属限流词（标题硬规则禁），钩子底稿里出现要改。

> 与主流程的关系：这里发散的 5 道题 = 步骤 5.5 候选角度池的"轻量来源"之一。用户从中勾选 / 补充后，进入第 6 步成色检测，再走决策确认门。

## 第 3 步：标题硬规则（必须全部满足，对齐主流程发布包装）

1. **疑问句** 或 **带数字**（二选一，可叠加）
   - ✅ "为什么你做的短视频，永远只有 200 播放？"
   - ✅ "月入 5 万的剪辑师，常用的 3 个工具"
   - ❌ "如何做好短视频"（太抽象、太书生气）
2. **首句不超过 14 个字**（手机一屏能看完；标题字段同样适用 ≤14 字硬约束）
3. **口语化、去书名号**：不用"我们""其实""或许"这类书面词
4. **过限流词词库（不出现标题党/平台限流词）**：命中以下任一即重写——震惊 / 99% 的人不知道 / 速看 / 删前速看 / 再不看就没了 / 必看 / 重磅 / 紧急通知 / 惊天 / 吓傻 / 不转不是XX / 第一 / 唯一 / 100% 有效 / 稳赚 / 包过。完整 30+ 条分类词库与替换方向见 `references/compliance_checklist.md` 二·F（限流词/标题党）
5. **带具体身份/场景**："做 XX 的人""宝妈""30 岁""刚毕业"——越具体越戳人

**20 个已验证标题公式速查**（详细反例见技能外参考）：疑问句（"为什么 XX 你总是 YY？""XX 真的有用吗？我劝你别再 YY 了""是不是只要 XX，就 YY？""凭什么 XX 就能 YY，你就不行？""你真的懂 XX 吗？3 个问题测一测"）；数字冲击（"XX 的人，YY 千万别做的 N 件事""做了 N 年 XX，我总结出 YY 个真相""月入 X 万的 XX，常用的 N 个 YY""N 个 XX 小技巧，第 3 个 YY""XX 天，从 YY 到 ZZ，我只做了 N 件事"）；反常识（"你以为 XX，其实根本不是 YY""别再 XX 了，真正 YY 的人都在 ZZ""XX 根本没用，YY 才是关键""为什么 XX 越努力越 YY？答案很扎心""XX 的人，90% 都死在了 YY"）；揭秘（"做 XX N 年，今天说点得罪人的真相""XX 行业不会告诉你的 N 件事""为什么 XX 都不愿意告诉你 YY？""XX 背后的 YY，看完你就懂了""今天得罪人，讲讲 XX 的 YY"）。

**分平台字数硬约束（v2.43.0 新增 · 发布前逐条量字数）**
> 超字数会被平台截断，钩子直接看不见。**平台标题字段**按本表卡；本文件第 3 步第 2 条的"首句 ≤14 字"是**口播开场白**的约束（更严），两者不同、发布前分别卡。

| 平台 | 上限 | 黄金区间 |
|---|---|---|
| 朋友圈正文首句 | 22 字 | 12–18 字 |
| 小红书标题 | 20 字 | 14–18 字（emoji 占 2 字） |
| 公众号标题 | 28 字 | 18–24 字 |
| 视频号标题 | 22 字 | 15–20 字 |

**组合纪律**：5 道题的标题至少 3 个用疑问句、至少 2 个带数字；数字优先奇数（3/5/7 优于 2/4/6）；数字+单位具体化（"3 句话""5 步"比"3 个方法""5 个技巧"更戳人）；**反问不给答案（反问类标题不在标题里给答案——"答案放视频里"，标题带答案会掉点开率与完播）**。

## 第 4 步：三段式输出（每条选题三件套）

每条选题严格按以下格式输出（对齐本技能选题标准，也是「为什么用户会想看」动机环的落点）：

```
## 选题 N：[标题]
**核心观点**：[1 句话观点，不超过 30 字]
**为什么用户会想看**：[1-2 句话，点明动机环]
```

**动机环四类（写"为什么用户会想看"时按此归类，写不出一律返工）**：
- **认知缺口**：制造"等等，原来是这样？"的信息差 / 反常识，看完觉得自己比人明白一点。
- **情绪共鸣**：戳中"说的就是我"的痛点 / 委屈 / 不甘，忍不住点头、对号入座。
- **实用价值**：有能直接抄的清单 / 方法 / 避坑点，"存了就有用"。
- **社交货币**：转发出去显得自己内行 / 有态度 / 关心对方，是"帮我说出心里话"。

> 动机环与步骤 5.5 爆款四基因（情绪钩子 / 信息差 / 身份标签 / 行动触发）一一对应，可交叉校验：**写不出"为什么想看" = 四基因命中 <2 = 直接淘汰**。

## 第 5 步：去 AI 味统一词库（最后必过的一关）

写完后逐句检查，命中以下任意一条就重写（**判定标准**：把标题和核心观点念出来，像不像你跟朋友在饭桌上吹牛/吐槽？不像就改）。

**黑名单 + 替换表**（与 `copywriting_craft.md` §3 书面→口语映射表**共用一套**，两处互为补充，不得各写各的）：

| 类别 | 黑名单 | 替换 |
|------|--------|------|
| 学术/书面词 | 在当今社会 / 随着 XX 的发展 / 综上所述 / 因此 / 然而 / 此外 / 值得注意的是 / 毋庸置疑 | 删 / "说白了" / "所以" / "但是" / "还有" / 删 / 删 |
| 鸡汤/空洞词 | 值得深思 / 引发思考 / 触动人心 / 感悟 / 愿你 / 温柔以待 | "你琢磨琢磨" / "我跟你讲" / "当时我就……" / "我最大的感受是" / 删 / 删 |
| 互联网黑话 | 赋能 / 抓手 / 底层逻辑 / 破局 / 打法 / 闭环 / 链路 / 颗粒度 | "帮到" / 删 / "到底怎么回事" / "搞定" / "方法" / 删 / 删 / 删 |
| 结构化 AI 味 | 首先…其次…最后… / 它不仅…而且… / 作为一个 XX，我… / 请大家 / 希望对大家有帮助 | "第一…还有…最狠的是…" / 拆成两句 / "我做了 XX 这行，" / 删 / 删 |
| 标点 AI 味 | 排比句+3 个感叹号 / "？？？" / "！"单独成段 | 改成 1 个感叹号 / 用 1 个问号 / 删 |
| 句式 | 连续 3 个以上逗号的长句 | 拆成 2-3 句 |

**最有效的一招**：把所有抽象词换成"具体动作 + 具体场景"——❌"提升效率" → ✅"今天 6 点下班"；❌"建立认知" → ✅"你下次再被忽悠，就不会上当了"。

## 第 5.5 步：八大爆款元素扫描（选题自带流量属性）

> 四基因（第 6 步门禁）管"**为什么有人转**"（传播心理），八元素管"**这个选题天生带不带流量**"（素材流量属性）。每个选题在过门禁前，先勾选命中的 **1–2 个爆款元素**标注（如"元素：成本+反差"），帮用户一眼看出每条选题吃的是哪种流量，也防 5 条选题元素重叠。

| 元素 | 核心逻辑 | 示例 |
|------|----------|------|
| **成本** | 用户对价格/花费敏感 | "一年换一次亏了多少""这套方案省了 3 万" |
| **人群** | 圈定特定群体产生代入感 | "做安防的老铁注意了""宝妈注意了" |
| **猎奇** | 满足好奇心 | "25 年不换工艺的秘密""为啥都是蓝色的" |
| **反差** | 颠覆认知制造冲突 | "越贵的反而越省""打药多的反而坏得快" |
| **最差** | 展示最坏结果触发恐惧 | "选错一季白干""边角先破的通病" |
| **头牌** | 展示最强/最好的一面 | "本地 25 年老厂""A 级翻了一倍" |
| **怀旧** | 唤起情感记忆 | 老物件、老街、当年的味道 |
| **荷尔蒙** | 触发强烈情绪反应 | "你信不信""想想都可怕" |

**应用规则**：
- 勾选以"选题角度实际自带"为准，不硬凑；命中 2 个以上为高流量属性选题（可作 Top 候选参考）。
- 与五钩子（第 2 步）互补：五钩子管"**用什么情绪开口**"，八元素管"**这个题吃哪种流量**"。
- 与四基因映射参考：人群→身份标签；猎奇/反差→信息差；荷尔蒙→情绪钩子；成本/最差→行动触发。
- B 端/工厂/招商类选题优先看「成本/最差/头牌」三元素（搭配 `references/b2b_hook_formulas.md` 公式 1/3/4 使用）。
- **元素不绑行业（v2.35.0）**：八元素是行业无关的"情绪燃料"——同一元素可整包迁移到另一行业吃信息差红利（如"成本"在副业赛道是避坑清单、搬到停车招商就是"选品牌先看 3 份文件"）。跨行业打法流程见 `framework_rubric.md` §二「换壳换行业迁移」。

## 第 5.6 步：批量出题模式（出 N 个 · 可选）

> 默认出 5 个。用户明确要"多出几个 / 出 10 个 / 批量出题"时启用，适配日更矩阵号、矩阵化测试选题。

- **扩展方法**：以五钩子为骨架 × 八大元素（成本/人群/猎奇/反差/最差/头牌/怀旧/荷尔蒙）× 目标人群网格交叉发散，出 N 个选题（10/20…）。每个钩子可出多道，但**同一钩子占比 ≤ N×40%**（防 10 道里 6 道都是揭秘）；元素与人群尽量拉开不重叠。
- **门禁不变**：全部候选仍过第 6 步同一套门禁（四基因 ≥2 → 成色卡 ≥30 → 12 心法亮灯），不合格照常淘汰/补强。
- **产出分层**：Top 5 标「⭐进步骤 5.5 衔接」走人机共创与决策确认门；其余标「备选池」——直接可用作矩阵号批量测试素材（不同钩子/人群版错开发），测试胜出的角度可回流入选题库升级。
- **批量纪律**：批量出题时每条仍严格三段式 + 动机环 + 元素标注 + 去 AI 味，**不得因量大而降质**；宁可 12 条精品也不要 20 条水货。

## 第 5.7 步：热点拆题四层公式（业务向扩张轴 · v2.53.0 新增）

> **适用**：用户给的是一个**正在被讨论的热点 / 行业事件 / 大主题**（而不是一句话灵感、也不是一条爆款视频），要把它拆成一批**贴自己业务**的选题时启用。
> **一句话定位**：**一个热点 ≠ 一个选题**。热点只是入口；人群、痛点、解决方案，才决定它能不能长成一条有价值的内容。

**拆题四层公式**：

```
🔥 热点（正在被讨论什么）
 × 👥 人群（这件事对谁最相关）
 × 😣 痛点（他们在意什么 / 最具体的困扰）
 × 💡 解决方案（你能给出的判断或方法）
 = 一批可落地的选题
```

| 层 | 填什么 | 自问 |
|---|---|---|
| **热点** | 近期正在被讨论的事（政策 / 行业大事 / 平台规则 / 节气 / 争议事件） | 现在大家在聊什么？ |
| **人群** | 这件事真正相关的**具体**人群（越窄越好，忌"所有人"） | 这个变化影响了谁？ |
| **痛点** | 这群人**最具体**的困扰（不是抽象的"效率低"，而是"哪个环节漏了"） | 他们现在最具体的痛点是什么？ |
| **解决方案** | 你基于自身经验能给的判断 / 方法 / 案例 | 我能提供什么解决思路？ |

**三换拆法（同一热点批量裂变）**：
- **换人群** → 就有新选题（同一热点，讲给"老板"和讲给"执行岗"，是两个题）。
- **换痛点** → 就有新角度（同一群人，痛点落在"流程乱"还是"成本高"，是两种落点）。
- **换解决方案** → 就有新内容（同一痛点，给"标准化"还是给"用工具替代"，是两种打法）。
- 三维排列组合，一个热点可长出十几个甚至几十个**具体问题**。**先问三问再落题**，避免直接写"XX 时代该怎么办"这类正确的废话。

**与传播向轴的分工（两条扩张轴，互补不替代）**：

| 扩张轴 | 维度 | 产出偏向 | 存放位置 |
|---|---|---|---|
| **传播心理向**（已有） | 五钩子 × 八大元素 × 人群网格 | 用什么情绪开口 / 这个题吃哪种流量 | 第 2 步 / 第 5.6 步 |
| **业务向**（本步） | 热点 × 人群 × 痛点 × 解决方案 | 和我的业务、用户痛点贴不贴 | 本步 |

> **实操**：**先用业务向轴把"值得做的方向"框出来**（哪些人群 / 痛点真的和我相关），**再用传播向轴把每一条打磨成"会有人停、会有人转"的开口**。两条轴都跑，量足且不空——只跑传播向容易出一堆"标题很爆但跟我没关系"的题。

**产出接入**：本步拆出的候选选题，与五钩子发散结果**合并进同一候选池**，统一过第 6 步门禁（四基因 ≥2 → 成色卡 ≥30 → 12 心法亮灯），不合格照常淘汰 / 补强。

> **心法**：不要追着热点跑，要让热点为你的业务服务——热点是手段，你的用户和业务才是目的。

## 第 5.8 步：共情向选题轴（共同情绪四方向 + 3 连问 · v2.58.0 新增）

> 本文件此前已有两条扩张轴：**传播心理向轴**（§5.6，五钩子 × 八元素 × 人群）与**业务向轴**（§5.7，热点 × 人群 × 痛点 × 解决方案）。本条补第三条：**共情向轴**——不切热点、不切业务，切"用户心里本来就有的东西"。它回答的是"这条选题**凭什么能打动人**"，另两轴回答"凭什么能传播 / 凭什么能转化"。

**选题判断 3 连问（过不了三问就不立项）**

| # | 自问 | 答案要具体到的程度 |
|---|---|---|
| 1 | 这是不是很多人都经历过？ | 要说清处境（"35 岁被优化后不敢告诉家里"），不能答"打工人" |
| 2 | 这是不是很多人说不出来？ | 若人人都能一句话讲清，说明情绪已被说透，无"被说中"空间 |
| 3 | 这是不是一看就会代入？ | 观众要能在 3 秒内把自己放进去 |

**四条共情选题方向（按 §1.9 归属层落）**

| 方向 | 覆盖情绪 | 归属层 | 示例 |
|---|---|---|---|
| **成长类** | 迷茫、孤独、选择、和解 | L2 群体 | "一边想自由，一边不知道去哪" |
| **关系类** | 亲情、友情、爱情、告别 | L2 群体 | "我妈这辈子没说过累" |
| **处境类** | 职场压力、代际矛盾、普通人的难 | L2 群体 | "每月还房贷那天最难受" |
| **时代类** | 毕业季、节日节点、群体记忆、时代情绪 | L3 集体 | "毕业照上那排人，现在都不联系了" |

**使用规则**
- **顺序不能反**：先有情绪（§1.9 判层）→ 再找场景（落到具体人/事/时刻）→ 再找一句核心表达 → 最后才选形式。本文件的轻量线本就要求"选题先于结构"，本条把"表达先于形式"也强制进来。
- **与其他两轴并用，不替代**：同一条选题可既过业务向轴（贴不贴我的业务）又过共情向轴（打不打动人）。两轴都过 = 最佳；共情向不过而业务向过 = 只能做转化型，做不成爆款；反之则只能做爆款做不了转化。
- **收敛闸门不变**：过 3 连问只是进候选，最终集合仍须过四基因 ≥2 + 12 心法亮灯 + 成色卡三道门禁；社交货币按 §1.10 五类挂（共情向选题通常挂「被说中」）。
- **合规红线**：时代类 / 民族情绪类题材敏感度最高，只走"具体故事 + 克制表达"，不写口号，不碰政策与历史定论。

## 第 5.9 步：问题矿脉轴（自我真实问题选题源 · 第四条扩张轴 · v2.60.0 新增）

> 本文件已有三条扩张轴：传播心理向（§5.6）/ 业务向（§5.7）/ 共情向（§5.8）。前三条的选题源头都从"外部爆款 / 热点 / 情绪"出发；本条补第四条：**从"你自己和你的用户真实遇到的问题"出发**——这是最稳的矿脉，因为需求已经被验证过（有人在抱怨、在反复问）。

**三条矿脉（按可信度排序）**

| 矿脉 | 怎么挖 | 信号强度 |
|------|--------|----------|
| ① 评论区 / 私信反复被问 | 同一问题被问 ≥3 次 | 最强——需求已显形，且是你的用户 |
| ② 自己当前的卡点 | 你最近也在纠结 / 踩坑的事 | 中——真实但不一定普适 |
| ③ 行业里人人都在抱怨的痛点 | "这行最坑的就是 XX" | 中——需验证是否有人愿意解决 |

**铁律**：每条从矿脉长出的选题，必须能回答"**解决了谁的什么问题**"；抱怨最多的地方 = 需求，反复被问的 = 选题也是你的产品线雏形（与 §5.5 资产匹配公式、步骤 8.8 验收三问打通——问题本身就是产品线索）。

**身份反差角度发生器（与矿脉②联动）**：你凭什么讲这个？最有力的设定是"外行但踩过坑 / 不是专家但吃过亏"——把"我是局中人不是旁观者"做成二创角度（如亏过钱的人讲避坑、被割过的人讲防割）。它和 §1.7 身份层、§1 身份代入钩子同源，但强调"反差"这个发生器，专治"我没什么资格讲这个"的怯场。

**使用规则**
- 与另三条轴并用：矿脉解决"从哪挖题"，三轴解决"挖出来怎么打磨成会传播 / 会转化 / 会打动人的开口"，不替代。
- 收敛闸门不变：过 3 连问只是进候选，最终仍须过四基因 ≥2 + 12 心法亮灯 + 成色卡三道门禁。
- **选题护栏 · 先开枪再瞄准**：矿脉和拆解都是"为行动攒弹药"，不是拖延的安全屋。定好一个角度就先出一条再迭代，别等"想透"——行动会自己长出信息和动机，学太多、准备太久常常只是逃避。

## 第 6 步：接入成色检测门禁（衔接主流程，强制）

轻量线发散的选题**不是直接交付**，须过与主流程同一套成色门禁，不合格的当场淘汰 / 补强：

1. **爆款四基因 ≥2**（步骤 5.5 红线）：情绪钩子 / 信息差 / 身份标签 / 行动触发 命中 ≥2 条，<2 直接淘汰。
2. **二创成色卡 ≥30**（步骤 5.55 立项门禁）：情绪强度 / 转发动机 / 独家信息差 / 身份匹配 / 时效红利 / 传播锚点 / 视觉钩子 / 行动触发 8 维打分，总分 ≥30 才立项；24–29 补强后复打；<24 淘汰。
3. **12 心法亮灯**（步骤 5.5 前置筛）：尤其 ⑥化繁为简（一个角度只服务一个观点）、⑩立场安全（不站队不引战）、⑫合规可上线（版权/肖像/广告法/平台规则）三条红线，亮 ❌ 直接换角度。

**产出形态**：Top 1–3 按成色排序置顶标「⭐最推荐拍这条」，其余标「次级备选」；经「决策确认门」询问用户是否生成二创脚本、是否进选题库（两条交互铁律不变，不自动产出）。
