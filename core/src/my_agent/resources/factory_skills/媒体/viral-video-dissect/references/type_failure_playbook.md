# 类型感知失败预案库（v1.3，配合 C2 执行层降级链）

本文件在 `SKILL.md`「降级链（执行层）」的 6 类通用失败之上，按**视频号内容类型**进一步细化"典型失败点 + 标准回退动作"，提升不同类视频的拆解稳健性。类型判断见 `SKILL.md`「类型感知拆解侧重」节。

> 原则：每条回退动作都必须记录到报告「本次运行证据」节的 `degraded` / `confidence` 字段（C1 证据契约）。

---

## 1. ASMR 手艺展示（布线 / 监控 / 收纳 / 清洗）

- **典型失败**
  - 口播极少（常 < 100 字）→ ASR 几乎为空，纯画面驱动
  - 画面高度相似（同机柜不同位置）→ 场景检测可能高估切点或抽帧重复
  - 字幕层常是"金句横幅"而非逐字稿 → 不能当口播反推
- **标准回退**
  - 以**视觉分析为主轴**，ASR 仅作辅证；允许进入"无逐字稿模式"——用画面描述 + 字幕层文字组成"伪逐字稿"，步骤 1 标注【画面驱动·无口播稿】
  - 抽帧上限提到 ~30（细节密度高），场景检测阈值降到 0.2（慢变镜头）
  - 二创重心锁"沿用手法 + 系列化复制"，不强求口播结构
- **证据节记**：`画面驱动型，ASR 贡献低；抽帧策略：场景检测(阈值0.2)`

## 2. 口播观点 / 干货

- **典型失败**
  - 长口播 + 专业术语 → ASR 错专名率高
  - 语速快 / 停顿少 → 分段转写边界错位
  - 信息密度高 → 易漏"隐含钩子"
- **标准回退**
  - `medium` 模型重跑 1 次（C2）；屏幕文字优先校正专名（步骤 1.8）
  - 长视频分段转写（每段 ~10min），接缝处人工核对重叠句
  - 二创重心锁"补互动钩子 + 方法论可操作化"
- **证据节记**：`口播型，ASR 为主；专名已按画面文字校正`

## 3. 品牌故事 / 企业叙事

- **典型失败**
  - 延迟身份揭示 → 前段无姓名条，易误判主角（曾把极狐片误判为"老丁独白"）
  - logo 小 / 角标易被漏读
  - 价值主张抽象 → 框架提炼易空泛
- **标准回退**
  - 抽帧后强制读字层**重点扫姓名条 / logo / 尾屏鸣谢**，身份以画面文字为准
  - 若前段仍缺身份，标【存疑主角】不强行定论，并在二创提示"原片可复制性低，需轻量化改编"
  - 二创重心锁"用案例素材转译到自身赛道"
- **证据节记**：`人物型，身份依赖画面文字确认；延迟揭示已识别`

## 4. 人物纪录 / 访谈

- **典型失败**
  - 多人对话 → ASR 分不清 speaker，易张冠李戴
  - 分屏两侧信息密集 → 单侧漏读
  - 情绪节点靠语气 → 纯文本丢失
- **标准回退**
  - 按"谁在说话"分段标注【推测 speaker：甲/乙】，不强行合并
  - 分屏两侧各自记录（左/右），二创用"对坐访谈模板"（见 `script_template.md` 第六节）
  - 建议用户补访谈提纲以校准，标【speaker 待核】
- **证据节记**：`多人型，speaker 待核；分屏两侧已分别记录`

## 5. 热点混剪 / 盘点

- **典型失败**
  - 素材快切 → 场景检测过密，抽帧噪声大
  - 版权素材混入 → 二创直接复用侵权
  - 时效强 → 保鲜期 S，二创窗口极短
- **标准回退**
  - 抽帧上限降到 ~16 避免噪声；只取关键转场帧
  - 二创强制"替换原素材为原创/已授权"，标注【二创须原创素材·避侵权】
  - 平台规则备忘强制标"时效热点 S 档，建议 24–48h 内发"
- **证据节记**：`混剪型，二创须原创素材；保鲜期 S`
