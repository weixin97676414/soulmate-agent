# 平台规则知识库（微信视频号）

> 本文件为 `video-script-dissect` 技能增强模块 **R10** 的配套知识库。每次拆解报告须在「平台规则备忘」节按视频类型匹配相关规则要点，让用户每次拆解都顺带熟悉一条平台规则，沉淀为"平台手感"。

---

## 一、视频号分发机制基础

- **社交推荐为主、算法推荐为辅**：冷启动池 = 粉丝 + 作者好友 → 高互动（转发/完播/赞）进入"朋友的朋友"社交裂变层 → 再进入公域算法推荐池。
- **信号权重（从高到低）**：转发 > 完播率 > 点赞 > 评论 > 关注。转发是视频号最强信号（撬动微信社交链）。
- **完播率**对短视频（<30秒）权重极高；**收藏率**对中长视频（>3min）权重上升。
- **内容指纹查重**：上传时平台提取画面特征向量 + 音频指纹生成唯一 hash，与历史库比对。重复/高度相似内容 → **降权 / 限流**。**隐藏 ≠ 删除**：隐藏只让用户不可见，平台侧指纹记录、历史互动数据、账号-内容关联通常保留，重发时仍会被识别为"见过的内容"。
- **冷启动阈值随时间提高**：平台成熟后破池门槛（完播率/点赞率/转发率要求）通常上升。

---

## 二、按视频类型匹配的规则要点

| 视频类型 | 平台规则要点 |
|---------|-------------|
| 短视频（<30秒） | 完播率权重极高；查重严格；社交裂变敏感；适合强视觉/强解压/强反差 |
| 中视频（1–3min） | 前 5 秒决定生死；信息密度要求高；评论区运营重要 |
| 长视频（>3min） | 需强钩子撑住；收藏率权重上升；适合深度/故事/方法论内容 |
| 技能/手艺展示 | 解压感=核心资产；金钱锚定放尾部效果最佳；"从乱到有序"闭环显著提升完播 |
| 口播/观点型 | 金句截图转发率决定长尾；争议/提问驱动评论 |
| 品牌/故事型 | 身份揭示延后效果显著；B-roll 三明治结构最优；可复制性常偏低 |

## 三、二次发布 / 查重规避清单（R9）

**触发信号**：用户提及"之前发过""重发""再发一遍""隐藏后重发""以前90w""这条老视频"等。

**动作（报告须含「二次发布风险评估」节）**：
1. **查重风险提示（⚠️ 高危）**：视频号内容指纹会识别重复内容，即使原片已隐藏指纹留存，重发大概率降权/限流，初始推荐池可缩小 50–80%。
2. **去重改造清单（至少改 3 项）**：
   - [ ] 加/改片头片尾（≥3 秒新内容）
   - [ ] 调整播放速度（0.95x 或 1.05x）
   - [ ] 更换 BGM / 调整音量
   - [ ] 修改字幕样式 / 位置 / 颜色
   - [ ] 加新的画中画 / 贴纸 / 水印
   - [ ] 裁切或扩展画面比例
   - [ ] 加新的口播旁白（哪怕一句）
3. **改造后预期三档**：保守 / 中性 / 乐观。
4. **最佳替代方案**：把"重发"升级为"二创/复盘"（如"我来拆解为什么这条 90w 的视频会火"），100% 绕过查重，且能吃"平台规则 / 数据复盘"类稀缺流量。

**运营建议**：不要隐藏原爆款（保留社交证明与搜索收录，可设"仅自己可见"）；重发间隔建议 ≥ 8 个月；避免短期内重复同类角度。

## 四、内容保鲜期分级（强化 R5）

| 档位 | 保鲜期 | 适用内容 | 二创策略 |
|------|--------|---------|---------|
| **S** | 1–2 周 | 时效热点 / 节日 / 突发事件 | 抢时效，快出快发 |
| **M** | 1–3 月 | 季节话题 / 轻度时效 | 蹭季节窗口 |
| **L** | 3–6 月 | 手艺展示 / 解压类（新鲜感衰减快） | 不适合一次制作长期复用，需系列化更新 |
| **XL** | 6 月+ | 方法论 / 观点 / 底层逻辑 | 值得重投入打磨，可长期复用 |

二创发布包装须标注：**保鲜期档位 + 最佳重发窗口 + 季节性标注**。

## 五、社交链适配度（D9，可选第 9 维）

**含义**：内容被用户主动转发到朋友圈 / 群的动机强度（"转发 = 表态 / 代表我"）。

**评分标准**：
- **5**：有金句 / 价值观 / 身份认同素材可截图转发（如"外行看热闹内行看门道"横幅）
- **3**：有趣但不够"代表我"，看完乐一下
- **1**：纯消费无转发动机

**用法**：D9 ≥ 4 的内容，二创时可强化"可截图转发"元素（金句横幅 / 对比图 / 数据卡）；D9 ≤ 2 需补强转发动机。

## 六、四平台差异化适配规则（二创必按平台分化，R11）

> 视频号 / 抖音 / 小红书 / 公众号 受众与算法逻辑差异极大。**同一个二创角度，必须按平台改内容风格、时长、标题、互动方式**，否则"一稿多发"必然哑火。每个二创方案须在「📡 平台适配」节标注依据本表的规则要点 + 适配人群。

### 6.1 平台对比总表

| 平台 | 核心受众 | 内容风格偏好 | 时长偏好 | 标题/封面逻辑 | 互动方式 | 算法强信号 |
|------|----------|--------------|----------|---------------|----------|------------|
| **视频号** | 熟人+泛中龄（25–50，职场/家庭/生意人） | 有温度、有观点、可转发代表"我"；偏干货/故事/人情味 | 30s–3min 均可，中视频吃香 | 标题像"给朋友的一句话"，封面用金句大字/真人笑脸 | 转发到朋友圈/群（最强）、评论区站队 | 转发 > 完播 > 点赞 > 评论 > 关注 |
| **抖音** | 泛年轻（18–35，追新/爱梗/看图快） | 强节奏、强钩子、前 3 秒必须有"哇点"；爽感/反差/猎奇优先 | ≤60s 最佳，快剪 | 标题=悬念/冲突/利益点，封面高对比+大字+人脸 | 完播（滑走即死）、点赞、评论玩梗 | 完播率 > 点赞 > 评论 > 转发 |
| **小红书** | 女性偏高（18–40，种草/攻略/情绪价值） | 真诚分享感、干货清单体、"避坑/教程/测评"；重图文 | 图文为主，视频 30–90s 轻量 | 标题=痛点+数字+情绪（"3 个被低估的…"），封面精致统一风 | 收藏（最强）、评论求链接、赞 | 收藏 > 点赞 > 评论 > 转发 |
| **公众号** | 微信存量读者（深度阅读偏好，职场/行业/观点） | 长文逻辑链、深度拆解、可沉淀；重"导语文+小标题" | 文章（非短视频），可嵌视频 | 标题=信息密度高+悬念（"为什么…"），封面稳重 | 在看/分享（朋友圈）、留言精选 | 分享(朋友圈) > 在看 > 留言 |

### 6.2 各平台二创调整要点（写进每个方案）

- **视频号**：结尾必埋"可转发理由"（金句/价值观/身份认同）；语气可慢可暖，强调"人情味+信任"；标题像私聊。
- **抖音**：前 3 秒必须有强钩子（冲突/反常识/利益）；语速偏快、剪辑点密；标题短狠、封面人脸+大字；互动靠"评论区玩梗/投票"。
- **小红书**：改成"清单体/教程体/避坑体"，封面统一精致风、加关键帧图；标题带数字与情绪词；互动靠"收藏+评论求链接"；可单独出图文版。
- **公众号**：扩成深度长文，加导语文+小标题+数据/案例；视频号同源内容可嵌文内；互动靠"在看+留言精选"；标题信息密度高。

### 6.3 跨平台同发改造清单（一稿多发时）

同一角度想多平台发，**至少按平台改 3 项**：
- [ ] 改标题/封面文案（各平台逻辑不同，见 6.1）
- [ ] 改时长与剪辑节奏（抖音快剪 / 视频号中视频 / 小红书轻量 / 公众号长文）
- [ ] 改互动引导话术（转发 / 玩梗 / 收藏 / 在看）
- [ ] 小红书额外出图文版封面与关键帧
- [ ] 公众号额外写导语文与小标题

> 改造后预期：单平台定制 > 一稿直发；宁可少发平台也要保"像本平台原生内容"。

### 6.4 一鱼多吃 · 形态裂变矩阵（v2.43.0 新增 · 🔀 可选 · 默认关闭）

> **定位**：6.3 是「**载体不变**」——同一条视频改到不同平台；本节是「**换载体**」——同一个爆款内核裂变成不同内容形态，**一次拆解吃三遍流量**。
>
> **触发铁律（不可默认执行）**：本节**默认关闭**。拆解报告交付后，**必须经用户明确确认**才展开裂变建议；未确认时**一句不提**，不主动推销。理由：本技能边界是"拆解 + 短视频二创"，其他形态各有专属技能，**不越界代做**。
>
> **不产出别家形态成稿**：本技能只给"这个内核还适合哪些形态 + 该交给哪个技能"，**不代写图文卡文案 / 公众号成稿**。

**裂变路径（同内核 → 3 种载体）**

| 载体 | 适用内核特征 | 交给哪个技能 | 转换要点 |
|---|---|---|---|
| **短视频**（视频号 / 抖音） | 所有内核（本技能主战场） | 本技能步骤 6 | 钩子 + 结构选型 + 口播 |
| **小红书图文卡 / 九宫格** | 清单型 / 观点型 / 避坑型（能拆成 N 个独立小点） | `xhs-9grid-notes` | 每点独立可截图；红调竖屏；内页文字卡 |
| **公众号长文** | 故事型 / 深度拆解型 / 有完整论证链 | `multi-angle-writer` / `wechat-article-security` | 钩子段 + 小标题数字化 + 金句海报 |

**时机（一鱼多吃的时间轴）**：短视频首发（2–12h，吃热点黄金期）→ 同内核转图文卡（次日上午，吃搜索长尾）→ 发酵成大选题后转公众号长文（次日或周末，吃深度收藏）。

> 与 6.3 的分工：6.3 管"同一条视频怎么改到 4 个平台"，本节管"同一个内核怎么换成 3 种形态"——**两者叠加，才是"一鱼多吃"的完整版**。
> 与主流程关系：本节只在**交付后**作为可选项出现，不影响步骤 0–9 任何主流程与门禁。

## 七、各平台数据洞察（最佳时长 / 发布时间窗 / 标签策略 · 步骤 5.8 用）

供「分平台改进诊断」的「数据洞察」三项输出（最佳时长 / 发布时间窗 / 标签策略）取数，结合平台对比总表（6.1）使用。

| 平台 | 最佳时长 | 发布时间窗（受众活跃） | 标签策略 |
|------|----------|------------------------|----------|
| **视频号** | 30s–3min 中视频吃香；<30s 完播权重极高 | 午休 12–13 点、晚 20–22 点（熟人社交高峰） | 3–5 个泛话题 + 行业词，少堆砌；强调"可转发" |
| **抖音** | ≤60s 最佳，快剪；前 3 秒定生死 | 晚 18–22 点（年轻用户高峰）、午 12–13 点 | 2–4 个热词 + 挑战话题，蹭当下热度 |
| **小红书** | 视频 30–90s 轻量；图文为主 | 早 8–9 点、晚 21–23 点（女性用户高峰） | 5–10 个长尾词 + 场景词（"职场穿搭 小个子"），重搜索 |
| **公众号** | 文章（非短视频），可嵌视频 | 早 8–9 点、晚 20–22 点（深度阅读时段） | 标题信息密度高，文内自然带关键词，不强堆标签 |

> 数据为通用经验值，须结合账号实际复盘数据微调（见步骤 8 复盘回授）。

## 八、四平台合规红线速查表（R12 · 步骤 6.5 配套）

> 二创方案按主平台对照本节；多平台同发时逐平台过一遍。细节词库与三段式检测输出模板见 `references/compliance_checklist.md`（检测门执行细则在 SKILL.md 步骤 6.5）。

| 平台 | 红线重点 | 典型命中示例 | 替换策略 |
|------|----------|--------------|----------|
| **公众号** | 广告法绝对化用语、医疗功效断言、收益承诺、投资建议、侵权（图片/字体/肖像）、未标注广告 | "全网第一""根治""月入百万""稳赚" | 绝对化→口碑类；功效→改善/缓解类；收益→"有机会/很多人反馈"；推广依法标"广告" |
| **小红书** | 禁宣/夸大、极限词、虚假种草、诱导互动、"亲测有效"无凭证、医美/减肥过度承诺 | "效果立竿见影""人手必备""不买后悔""亲测 3 天瘦 10 斤" | 体验化+注明"个人体验"；删"必/最/第一"；种草须真实、功效表述留余地 |
| **抖音** | 限流词/标题党、口播敏感、诱导点赞关注、搬运侵权、未成年人出镜 | "震惊！""删前速看""点赞过万就直播""不转不是XX" | 去标题党；删诱导互动；原创声明；未成年人不当出镜直接改 |
| **视频号** | 标题党/诱导转发、裂变敏感（道德绑架式转发）、夸大宣传、AI 生成未标识 | "不转不是中国人""转发保平安" | 删道德绑架话术；AI 内容按《人工智能生成合成内容标识办法》标注 |

**用法**：步骤 5「平台规则备忘」节（R10）在分发机制要点之外，按本片主平台补一句红线对照；步骤 6 发布包装「📡 平台适配」须标注本表对应平台的红线要点；步骤 6.5 检测回执按本表做平台红线核对。
