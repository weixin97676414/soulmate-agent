# 发布前自检清单（Release Checklist · v2.11 引入）

> **用途**：本技能面向公开分发。任何版本升级收尾，必须在打包前逐条打勾，全绿才可宣布完成、才打包发布。
> **触发**：每次走完步骤 1–9 主流程 + 改动任意技能文件后，作为「发布门禁」执行（引用见 SKILL.md 步骤 8.8 末尾）。
> **原则**：公开技能的质量不是"功能够用"，而是"任何第三方拿去审计都不会挑出意外"。本清单就是审计口径。

---

## 一、安全合规（永久红线 · 不得复发）

- [ ] **1. 依赖来源可审计**：任何 `pip install` 均固定版本 + 限定官方源 `-i https://pypi.org/simple`（build_pdf.py / 首次运行说明 / 环境节均已写明）；无"自动联网装任意包"的裸调用。
- [ ] **2. 外链 / 抓取有白名单 + 用户确认**：yt-dlp 等下载器仅在你主动粘贴 URL 时触发；执行前打印链接与平台域名让你确认；下载仅落本地 `downloads/`，不外发；无静默抓站。
- [ ] **3. 隐私承诺精确化（无边界差异）**：SKILL.md 顶部隐私承诺为三段式（默认零上传 / 公网下载仅你触发且只落本地 / 可选上传默认关闭需勾选）；无"100% 不上传"式绝对句。
- [ ] **4. 对外文案无绝对化承诺**：技能简介 / README / 功能介绍中禁"100%爆款""保证流量""必上热门"等极限词；广告法极限词、收益承诺自查同样适用于技能自身文案。

## 二、可发现性不回退（v2.9 资产）

- [ ] **5. 快速入门卡在**：SKILL.md 头部「🚀 快速入门卡」三入口分流表存在且未删减。
- [ ] **6. faq.md / index.md 在**：两篇可发现性文档仍登记于资源节且可访问；用户遇阻第一站仍是 faq。



## 四、版本号三处同步

- [ ] **9. 三处同号**：frontmatter `version` / `VERSION.txt` / `CHANGELOG.md` 顶部条目版本号完全一致（含本次新增的 vX.Y.0 条目与日期）。

## 五、依赖锁版本 + 官方源（重申）

- [ ] **10. 环境节声明齐全**：SKILL.md「环境与依赖」含"固定版本 + 限定官方 PyPI 源 + 隔离 venv + 诚实降级"总声明，覆盖 `faster-whisper` / `imageio-ffmpeg` / `yt-dlp` / `reportlab` 四包。

## 六、公开化附加项

- [ ] **11. README / 对外简介审慎**：公开简介不暴露内部封印指纹之外的私密信息；功能描述与真实能力一致，无夸大。
- [ ] **12. 变更可追溯**：CHANGELOG 本次条目写清"为什么改 / 改了哪几个文件 / 对用户有何影响"，便于公开审计。
