
# 批量拆解流水线（N 条视频标准 SOP）

> **解决什么痛点**：用户反馈"组合使用多个功能时需要自己串联，批量拆好几条视频的流程不够一目了然"。
> 本篇给出**接 N 条视频的标准流水线**：不用猜先干啥后干啥，照着走就行。
> **它不替代主流程**——是把九步地图在"多条视频"场景下**预排好顺序**，并明确每一步产出与"下一步去哪"。

---

## 0. 开始前先定三件事（一次性，避免中途返工）

| 要定什么 | 怎么定 | 不定的后果 |
|----------|--------|-----------|
| **归属**：拆别人爆款 / 八维自分析自己的 | 逐条确认，混着来会乱 | AI 给错东西 |
| **目标**：要二创脚本 / 只要共性框架 / 要进选题库 | 一句话说清 | 漏产出或多产出 |
| **范围**：一次几条（建议 ≤5，多了先拆 Top 3） | 按精力定 | 注意力稀释、浅拆 |

> 拿到第一条视频，AI 仍会走**归属确认门**问你走哪条（强制）。批量只是把"之后的 N 条"按同口径自动沿用，不跳过确认。

---

## 1. 标准流水线（照这张表走）

| 阶段 | 动作 | 对每条视频做 | 产出 | 下一步 |
|------|------|--------------|------|--------|
| **① 建档** | 给每条视频一个编号（V1/V2/V3…），存原始文件 + 逐字稿 | ✅ | `视频台账_<主题>_<日期>.md`（编号/来源/归属/状态） | → ② |
| **② 逐条拆解** | 走主流程 1→2→3→4→5（抽取/脚本/钩子/结构/8维评分） | ✅ | 每条一份拆解卡 | → ③ |
| **③ 跨视频洞察** | 提炼 N 条的**共同框架 / 差异点 / 可复用零件** | 一次性（汇总） | 共性框架报告（见 `cross_video_insight.md`） | → ④ |
| **④ 发散选题** | 用共性框架 + 热点拆题四层公式，扩出选题池 | 一次性 | 选题卡 N 张 | → ⑤ |
| **⑤ 二创 / 入库**（须确认） | 经「二创脚本门」「选题库门」确认后才产出 | ✅/🔀 | 二创脚本 / 入库回执 | → ⑥ |
| **⑥ 复盘** | 验证清单 + 发布门禁（步骤 8） | 一次性 | 验证清单 | 完 |

> **关键纪律**：④⑤ 的"二创脚本"和"进选题库"**仍然走四道决策门**——批量不等于自动产出，AI 在 ⑤ 处会停下来问你。

## 2. 一句话指令模板（直接复制用）

| 你的意图 | 直接说 |
|----------|--------|
| 拆 3 条竞品，只要共同框架 | "把 V1/V2/V3 三条同赛道爆款各拆一遍，最后给我它们的共同框架和差异点，不用二创脚本" |
| 拆 1 条 → 出 3 条二创 → 进库 | "拆解这条，给我 3 条能直接拍的二创脚本，二创方向确认后帮我进选题库" |
| 10 条先拆 Top 3 再扩选题 | "这 10 条我先看前 3 条，拆完提炼共性框架，再用四层公式扩出一批贴业务的选题" |
| 长录音(60min) → 拆成多条 → 逐条二创 | "这段 60 分钟录音按三维打分拆成 5 条独立短视频素材，逐条走完整流程出二创脚本"（走步骤 0.9 拆条门） |

## 3. 批量特有的坑（提前避）

- **别一次性喂 10 条再要"综合报告"**：先拆 Top 3，看 AI 的拆解口径对不对，再批量铺开，避免 10 条全跑偏。
- **台账要留痕**：每条的状态（已拆/待二创/已入库）记在 `视频台账` 里，断点续跑不丢上下文。
- **跨视频洞察≠逐条拼凑**：③ 是"抽象出能复用的骨架"，不是把 N 份报告粘一起。
- **二创仍须逐条确认方向**：多选题机制（步骤 5.5 候选角度池 + 四选一可多选）在批量下照常生效。

## 4. 与新能力的挂接

- 共性框架提炼 → `cross_video_insight.md`
- 选题扩张 → `lightweight_ideation.md`（五钩子 / 热点拆题四层公式）
- 二创方向确认 → 步骤 5.5（候选角度池 + 四选一可多选）
- 环境自检 → `scripts/check_env.py`（首次批量前跑一次，确认依赖齐）
