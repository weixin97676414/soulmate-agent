# 发布前合规检测词库（compliance_checklist · 步骤 6.5 配套）

> 本文件是 `video-script-dissect` 的「发布前合规检测门」（**步骤 6.5**）配套词库与输出模板。
> 本文件提供官方词库实测、三段式输出（命中词标记 / 替换建议 / 优化文案）与长文案分批策略，并按本技能「本地隐私优先 + 生产期柔化（copywriting_craft §5）」的既有工艺收编扩容，统一为「」资产。

**一句话定位**：生产期靠 §5 柔化工艺"先防"，交付期靠本词库"后检"——两条腿走路，缺一不可。检测范围 = 每条二创的【口播全文 + 标题 + 发布文案 + 标签】四件套（可选纳入屏幕文字台账 / 封面大字，来自步骤 1.8）。

## 二、本地违禁词/限流词分类词库（默认检测范围）

> 默认按以下 8 类逐项扫描。**红级（H）命中→ 不提供优化版，直接改换角度或拒做；黄级（A–G）命中→ 就地替换后发布。** 命中词优先走 `copywriting_craft.md` §5 的替换词表，两边共用一套替换方向，不得各写各的。

### A 绝对化用语（黄级 · 广告法）
- 常见词：最 / 第一 / 唯一 / 100% / 百分之百 / 顶级 / 极致 / 全网 / 全国 / 国家级 / 史上 / 巅峰 / 无敌 / 绝无仅有 / 首屈一指 / 行业领先
- 替换方向：口碑很好 / 我觉得很管用 / 很多人反馈 / 我做过 N 家对比

### B 医疗功效断言（黄级 · 高危）
- 常见词：治愈 / 根治 / 药到病除 / 包治 / 抗癌 / 减肥神器 / 三天见效 / 永久祛除 / 断根
- 替换方向：改善 / 缓解 / 个人体验 / 身体不适请就医（事实词如"失眠/益生菌/甲状腺结节"本身不违规，保留，勿过度柔化）

### C 收益承诺（黄级 · 高危）
- 常见词：月入XX万 / 年入百万 / 稳赚 / 躺赚 / 暴富 / 包赚 / 回本快 / 躺平也有钱
- 替换方向：有机会 / 很多人反馈 / 仅供参考 / 不构成投资建议

### D 教育承诺（黄级 · 高危）
- 常见词：包过 / 保录取 / 保就业 / 包拿证 / 不过退费 / 包上岗
- 替换方向：删除承诺类表述，自查块提醒"教育类不可做保过承诺"

### E 极限词/夸大（黄级）
- 常见词：秒杀 / 极品 / 最强 / 之王 / 神器 / 人手必备 / 万能 / 立竿见影 / 无与伦比
- 替换方向：实用 / 好用 / 我常用 / 有惊喜

### F 限流词/标题党（黄级 · 平台限流）
- 常见词：震惊 / 99% 的人不知道 / 速看 / 删前速看 / 再不看就没了 / 必看 / 重磅 / 紧急通知 / 惊天 / 吓傻 / 看哭 / 不转不是XX / 不点赞不是朋友
- 替换方向：换成疑问句 / 带数字 / 具体身份场景（对齐 lightweight_ideation.md 第 3 步标题硬规则）

### G 诱导互动（黄级）
- 常见词：点赞抽奖 / 转发必中 / 不点赞不是朋友 / 关注送XX / 评论领XX（未经平台活动备案）/ 转发送XX
- 替换方向：正常 CTA——"你怎么看？评论区聊聊""有用的话转给需要的人"

### H 红线级（出现即拒做/改写，不提供优化版）
- 政治敏感 / 涉政解读 / 低俗擦边 / 暴力血腥 / 谣言 / 人身攻击 / 性别·地域·贫富·代际对立煽动 / 未成年人不当出镜 / 未授权搬运抄袭 / 虚假宣传（已含 A–D 中恶性的）
- 处理：直接改换安全角度或放弃该条，与主流程「红线例外」一致（12 心法 ⑫ / 步骤 6.3 合规红线）

## 三、三段式检测输出模板（交付物格式 · 强制）

> 每条二创交付物固定输出「合规检测回执」小节，放发布包装之后、📋发布前自查块之前。未命中时仅输出检测结果板块。

```
🔍 合规检测回执（步骤 6.5 · 发布前必读）
- 检测方式：本地词库自检（零上传，不调用外部 API）
- 检测对象：口播全文 + 标题（3 候选）+ 发布文案 + 话题标签
- 命中数量：N 处（红级 X / 黄级 Y）｜ 主平台红线对照：<公众号/小红书/抖音/视频号> 命中情况
- 违禁原文：<命中词在原文中以 **加粗** 标出>

💡 替换建议
| 命中词 | 类别 | 建议替换 | 理由（结合上下文） |
|--------|------|----------|--------------------|
| <原文词> | <A 绝对化用语> | <替换词> | <为什么这样换> |

📝 优化后版本
<四件套就地替换版；替换处以 *标记*；红级命中不输出本板块，直接标注"改换角度">
```

**输出规则**：① 替换词须结合上下文，语义通顺，不重写文案、不加 emoji、不动语气；② 替换后仍过末尾「📋发布前自查」块（AI 标识 / 广告标注 / 授权等人工项，不自动替用户承诺）；③ 0 命中时仅输出"未检测到违禁词，四件套合规"。

## 五、本地检测 vs 可选 API 增强（隐私权衡 · 必读）

| 维度 | 本地词库自检（默认） | API 增强（第三方违禁词检测 API，可选） |
|------|----------------------|-----------------------------------|
| 词库 | 本文件 8 类 + §5 柔化表 | 官方违禁词库（更新及时，覆盖新词/长尾/平台新规） |
| 平台 | 四平台速查表（一） | 公众号 / 小红书 / 抖音 独立词库 |
| 数据去向 | **零上传**（不调用任何外部接口） | **会把文案上传第三方检测服务**（HTTPS 加密，不本地持久化） |
| 触发条件 | 默认自动 | **必须用户明确同意**才可触发 |

> **隐私铁律**：本技能承诺"视频与逐字稿仅本地处理、不上传任何第三方服务器"——本地检测不违反该承诺；API 增强的检测对象是**文案**（非视频/逐字稿），但仍须用户知情同意，默认不触发。

## 六、与 copywriting_craft §5 的衔接（闭环）

1. **替换词互通**：检测命中的词优先查 §5 替换表（根治→缓解、最→口碑好、100%→个人觉得…），两处共用，不另起炉灶。
2. **柔化边界一致**：只柔化违规表述（功效承诺/绝对化/收益承诺），正常事实词（失眠/益生菌/便秘等）照保留，替换后朗读无"被阉割感"。
3. **自查块照常**：检测替换 ≠ 替用户承诺合规——末尾「📋发布前自查」块（AI 标识 / 广告标注 / 授权）是发布者自行确认项，不因检测通过而省略。
4. **红级不绕过**：H 类命中不提供"优化版"，与步骤 5.5 12 心法 ⑫、步骤 6.3 合规红线一致——红线不商量，直接换角度。
