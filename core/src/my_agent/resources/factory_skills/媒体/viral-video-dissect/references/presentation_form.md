# 拍摄形式库（presentation_form）

> 本文件供 `video-script-dissect` 在「步骤 6」二创脚本中参考，用于**显式定义每条二创的「拍摄形式」维度**——即"几个人、怎么演、镜头前是什么状态"。
>
> **为什么单独建这一层**：技能已有"形态 A/B/C"（管**做多长、几幕**）+"叙事类型"（管**按什么逻辑讲**），但缺一个独立维度回答**"用什么表演形式呈现"**。形态与叙事类型是结构层，拍摄形式是**呈现层**，三者正交——同一条脚本可以"单人口播"，也可以"情景演绎"，效果天差地别。本库把"拍法"从隐含在分镜里，升级为**每个方案头部显式标注 + 给出选型理由**的强制字段。
>

---

## 一、拍摄形式分类（6 类主型 + 衍生）

| 编号 | 形式 | 一句话定义 | 典型画面 | 适用脚本特征 |
|------|------|------------|----------|--------------|
| **F1** | 单人口播 | 一人正对/侧对镜头，坐/站讲述，无对手戏 | 中近景固定、手势辅助、字幕卡 | 观点/干货/方法论，文案以"我"为主语连贯输出 |
| **F2** | 多人对话 | 2+ 人同框互动，问答/拌嘴/对谈 | 双人半身固定、过肩切、反应镜头 | 文案天然含"你来我往"的回合、有角色反差（闺蜜/夫妻/师徒） |
| **F3** | 情景演绎 | 设定小场景+角色，演一段短剧情（含表演、道具、转场） | 多镜分切、动作+对白、现场音 | 文案是"故事/冲突/反差"，需靠表演把情绪演出来 |
| **F4** | 旁白 + VCR | 画外音 VO 串起实拍/素材画面（空镜、过程、采访） | VO 铺陈 + B-roll/实景穿插 | 晒过程/品牌故事/测评，文案是解说、画面是证据 |
| **F5** | 对坐访谈 | 主持人 × 受访者的正式/半正式对谈（可单受访或多人） | 过肩双人、单人特写补情绪 | 行业揭秘/人物故事/专业背书，文案偏问答结构 |
| **F6** | 分屏证言 | 多画面同帧（客户/用户/专家齐说），或左演右评 | 画中画、字幕条、姓名条 | 信任背书/矩阵证言/对比，文案是多点并列的"都说 X" |

> **衍生与混合**：F3 情景演绎可叠加 F2 对话内核（"演出来的对话"）；F4 旁白+VCR 可嵌 F5 采访片段；F6 分屏常配 F1 单人收尾。标注时写**主形式 + 说明**（如"F3 情景演绎（含 F2 式拌嘴内核）"）。

## 二、选型决策树（核心：从"文案内容 + 参考视频"双向推导）

> **铁律**：拍摄形式不是凭空选的，必须**双向对齐**——既看"这条二创文案本身适合怎么演"，也看"参考原片用了什么形式、为什么火"。二创可沿用原片形式，也可因赛道/人设差异改形式，但**必须给出理由**。

### 2.1 从「文案内容」推导（看素材本身）

```
问 1：文案是"一个人连贯讲"，还是"有来有回的回合"？
  ├─ 一人连贯（"我发现…""其实…""所以…"）         → 偏向 F1 单人口播
  └─ 有回合（提问→回答→追问 / 抬杠 / 神逻辑）      → 进问 2

问 2：回合之间是"真实对话感"还是"表演出来的冲突"？
  ├─ 真实对话感（闺蜜闲聊/师徒问答/夫妻拌嘴）        → F2 多人对话
  └─ 表演冲突（演一段被坑/反转/装傻）               → F3 情景演绎

问 3：文案是"解说词"还是"角色台词"？
  ├─ 解说词（"这一步很关键…""我们来看…"）          → F4 旁白+VCR（画面当证据）
  └─ 角色台词（"什么是存款？""那我得有老板"）        → 回问 2

问 4：文案是"多方并列证言/背书"吗？
  └─ 是（"客户 A 说…客户 B 说…" / 左演右评）        → F6 分屏证言
```

### 2.2 从「参考视频」继承（看原片为什么火）

- **原片是 F1 单人口播且火**：二创优先沿用 F1（成本低、可复制性强），除非赛道/人设不适应（如二创改 B 端晒过程→改 F4）。
- **原片是 F2 多人对话且火**：火点往往就在"角色反差/化学反应"——二创必须保留 F2 内核，不能退成单人独白（丢了魂）；若单人拍不了，给"替代方案"（见 2.4）。
- **原片是 F3 情景演绎且火**：火点在"演出来的冲突"——二创保留 F3，但换场景/换角色，不能只留台词。
- **原片是 F4/F5/F6**：二创按同为"多元素/多人物"结构处理，避免塌缩成单人 VO（除非明确要低成本版）。

### 2.3 与「叙事类型」的强绑定建议（正交但不冲突）

| 叙事类型 | 首选拍摄形式 | 说明 |
|----------|--------------|------|
| 教知识 | F1 / F4 | 干货独白（F1）或"边做边讲"（F4 旁白+VCR） |
| 聊观点 | F1（主）/ F2（辩论型） | 观点大多单人输出；若要"抬杠感"用 F2 |
| 讲故事 | F3 / F5 | 人物故事靠演（F3）或对谈揭秘（F5） |
| 晒过程 | F4（主）/ F3 | B 端施工/手艺=旁白串实拍（F4）；含前后对比演可利用 F3 |

> 形式服务于叙事，不是反过来。标注时叙事类型与拍摄形式可以同时存在、互为印证。

### 2.4 替代形式与降级（拍不了主形式时）

每条二创在标注主形式后，**必须给一句"若条件不允许的替代方案"**，降低执行门槛：
- **F2 多人对话拍不了**（只有一人/无搭档）→ 替代：F1 单人口播 + "分饰两角"剪辑（同一人换衣服/换背景演两边，硬切呈现对话感）；或改文案为独白版。
- **F3 情景演绎拍不了**（无场景/无演员）→ 替代：F1 口播 + 关键情节用字幕卡/图标演绎（"演不出来就画出来"）。
- **F4 旁白+VCR 没素材** → 替代：F1 口播 + 口播中描述过程（损失画面证据力，注明）。
- **F5/F6 没受访者** → 替代：F1 口播 + 用"用户留言截图/行业数据卡"替代真人证言（F6 的图文版）。

## 三、二创方案「拍摄形式」标注模板（步骤 6 必填）

每个二创方案头部，在"形态 / 叙事类型 / 用途标签"之外，**强制加一行拍摄形式**，并给选型理由：

```
🎭 拍摄形式：F2 多人对话（主） ｜ 替代：F1 单人口播分饰两角
   · 选型理由：① 文案本身含"提问→神逻辑回答"的回合结构（内容推导：问1→问2）；
               ② 原片即 F2 闺蜜对话且火点在"角色反差"，二创须保留对话内核（继承推导）；
               ③ 人设偏"中年重启实录"单人 IP，但本角度用"师徒/夫妻"双人更出戏，成本★手机可拍。
   · 参考原片形式：F2（双人户外并排，固定机位），二创沿用其"固定双人半身"骨架。
```

**字段解释**：
- `🎭 拍摄形式`：主形式编号 + 名称。
- `替代`：拍不了主形式时的最简降级（必填，不能空）。
- `选型理由`：必须包含**内容推导**（从文案结构）+ **继承推导**（从原片形式）两点，否则视为未论证。
- `参考原片形式`：与原片形式的关系（沿用/改编/全新），呼应步骤 1.8 视觉分析。

## 四、拍摄形式 × 成本等级 × 门槛速查

| 形式 | 最少人数 | 典型成本 | 设备/场地门槛 | 新手友好度 |
|------|----------|----------|---------------|------------|
| F1 单人口播 | 1 | ★ 手机可拍 | 自然光/手机支架 | 高（最易起步） |
| F2 多人对话 | 2 | ★–★★ | 手机+支架（固定机位两人同框） | 中（需搭档+走位） |
| F3 情景演绎 | 1–2+ | ★★–★★★ | 场景/道具/可能剪辑 | 低–中（表演门槛） |
| F4 旁白+VCR | 1（拍摄）+素材 | ★★ | 实拍素材/空镜积累 | 中（需素材库） |
| F5 对坐访谈 | 2 | ★★ | 固定双人机位+安静环境 | 中 |
| F6 分屏证言 | 1–多 | ★★ | 多段素材拼贴/剪辑 | 中（剪辑门槛） |

> 与 script_template 第七节的「💰拍摄成本等级」联动：拍摄形式是"怎么演"，成本等级是"花多少"，二者共同决定"这条能不能今天拍"。

## 五、常见误用（反模式）

- ❌ **只写"口播/对谈"不标 F 编号**：形态里写的"B 对谈/口播"是时长维度暗示，不是拍摄形式字段；必须显式标 `🎭 拍摄形式：F2 多人对话`。
- ❌ **形式与文案结构打架**：文案是连贯独白却标 F3 情景演绎，或文案是神逻辑对话却退成 F1 单人——形式须服务内容。
- ❌ **沿用原片形式但不论证**：只写"沿用原片 F2"不给"为什么火点就在对话"——须补选型理由。
- ❌ **不给替代方案**：标注主形式后空着"替代"——降低执行门槛是工程化技能的义务。
- ❌ **把 F4 旁白+VCR 当万能兜底**：无素材时硬写 F4 却没画面，不如诚实降级 F1 并注明损失。

## 六、与「🗣️ 说话人配置」配套（v2.25.0 新增 · 形式管"怎么演"，角色管"谁在说"）

拍摄形式（F1–F6）回答"几个人、怎么演"，**说话人配置（S1–S4）回答"谁在说、说什么"**——两层配套，缺一脚本就会糊：只标 F2 不给角色编号，口播稿仍是一坨分不清谁在说的独白。

| 说话人配置 | 配套拍摄形式 | 二创标注示例 |
|------------|--------------|--------------|
| **S1 单人口播** | F1 / F4 | `🎭 F1 单人口播 ｜ 🗣️ S1（甲 100%）` |
| **S2 双人对话** | F2 / F5 | `🎭 F2 多人对话 ｜ 🗣️ S2（甲 55% / 乙 45%）` |
| **S3 多人对话** | F2 / F3 / F6 | `🎭 F3 情景演绎 ｜ 🗣️ S3（甲/乙/丙）` |
| **S4 旁白+群戏** | F4 / F6 | `🎭 F4 旁白+VCR ｜ 🗣️ S4（VO + 受访者1/2/3）` |

**判别口诀**：F 看画面里几个人在演，S 听声音有几个人在说。F3 情景演绎 + S2 双人对话 = "演一段两人吵架"；F1 单人口播 + S1 = 独白；两者不一致时（如 F3 演绎里只有一人独白）如实标注 `F3 ｜ S1`。

> 完整规范（配置判定、角色编号双轨、角色卡五必填、口播稿按角色分段格式、改人数论证、反模式）见 **`references/speaker_notation.md`**。
