# 拍摄手法词汇库与画面配方（shooting_techniques）

本文件供 `video-script-dissect` 技能在「步骤 1.8 视觉分析」与「步骤 6 二创沿用」中参考。
- **前半部分（一~六节）**：标准化**名词字典**——把抽帧看到的真实技法命名，让二创脚本能准确写"沿用原片 X 手法"。
- **后半部分（七~九节 · 本次升级核心）**：把名词拼成**画面配方**——"中景/远景"只是零件名，配方才是"装配图"。二创脚本不再只写"中景"，而是写"中景+固定+三分法+暖调"这种**可一键执行**的画面指令。

> 设计理念：手法层（本文件）与形式层（`presentation_form.md` 的 F1–F6）、剪辑层（`editing_design.md`）共同构成「形式×手法×剪辑」三维体系——形式管"几个人怎么演"、手法管"每个镜头怎么拍"、剪辑管"镜头怎么拼成节奏"。

## 一、景别（Shot Size）
| 词 | 含义 | 复用场景 |
|----|------|----------|
| 大远景 / 远景 | 人物极小，环境为主 | 品牌片 Hero shot、意境收尾 |
| 全景 | 人物全身入画 | 空间展示、人物登场 |
| 中景 | 腰部以上 | 口播主力景别、对话 |
| 近景 | 胸部以上 | 情绪特写、产品与人同框 |
| 特写 | 面部/局部 | 表情张力、产品细节、金句字幕 |
| 大特写 | 眼睛/手部等极致局部 | 情绪高潮、符号放大 |
| 过肩 | 越过肩拍对方 | 对话、代入视角 |

## 二、运镜（Camera Movement）
| 词 | 含义 | 复用场景 |
|----|------|----------|
| 固定 | 机位不动 | 口播、访谈、稳定感 |
| 推 / 拉 | 镜头向主体靠近/远离 | 强调、情绪收束 |
| 摇 | 水平转 | 环境展示、转场 |
| 移 / 跟 | 平行移动/跟随 | 行走叙事、沉浸 |
| 手持 | 轻微晃动 | 真实感、临场感 |
| 升降 | 垂直运动 | 宏大场面、升华 |
| 航拍 | 空中俯拍 | 大场景、品牌气场 |
| 慢动作 | 升格 | 情绪/产品高光 |

## 三、构图（Composition）
| 词 | 含义 | 复用场景 |
|----|------|----------|
| 中心构图 | 主体居中 | 权威、对称 |
| 三分法 | 主体落三分线 | 自然、平衡 |
| 对称构图 | 左右镜像 | 仪式感、高级感 |
| 留白 | 大量负空间 | 意境、思考、品牌 |
| 前景遮挡 | 前景物框住主体 | 视觉钩子、层次、神秘感 |
| 画框构图 | 用门窗/车窗框住主体 | 收束、窥视感、电影感 |
| 引导线 | 道路/光线引向主体 | 纵深、产品引导 |

## 四、色调与光线（Mood）
| 词 | 含义 | 复用场景 |
|----|------|----------|
| 暖调 | 橙黄光 | 温情、居家、怀旧 |
| 冷调 | 蓝青光 | 理性、科技、高级 |
| 高对比 | 明暗强烈 | 戏剧、冲突 |
| 低饱和 | 灰调 | 文艺、克制 |
| 暗调电影感 | 侧光打亮轮廓 | 品牌片、人物质感 |
| 蓝调时刻 | 黄昏/晨曦蓝调 | Hero shot、氛围高潮 |
| 明亮通透 | 自然光充足 | 空间、清爽、可信 |

## 五、转场与空镜（Transition & B-roll）
| 词 | 含义 | 复用场景 |
|----|------|----------|
| 失焦转场 | 画面虚化过渡 | 情绪切换、艺术化 |
| 匹配剪辑 | 相似构图/动作接镜 | 流畅、高级 |
| 硬切 | 直接切换 | 快节奏、信息密集 |
| 产品 B-roll | 产品空镜穿插 | 品牌片、种草 |
| 环境空镜 | 城市/自然/车流 | 意境、节奏缓冲 |
| 字幕卡 | 关键词放大/变色 | 钩子强化、金句 |
| Hero Shot | 产品全貌+环境高潮镜 | 收尾、记忆点 |
| 画中画 / 分屏 | 多画面同帧 | 对比、信息增量 |

## 六、标注示例（写进镜头表备注列）
- `【实测帧 0:24】低角度车头 B-roll（运镜:固定 / 色调:冷调金属）`
- `【实测帧 1:04】Hero shot 蓝调时刻全车+城市天际线（升格可选）`
- `【实测帧 0:18】前景遮挡构图（钟表框）+ 品牌标题卡`
- 二创沿用写法：`沿用原片0:24手法：低角度产品 B-roll` / `原创（二创）：雨窗特写承接"稳"主张`

> 技巧：步骤 1.8 抽帧时，把"可复用手法"顺手打标签；步骤 6 直接引用，二创即获得原片的视觉基因，而非凭空 redesign。

## 七、🎬 画面配方体系（核心 · 名词→可执行指令）

**配方 = 景别 + 运镜 + 构图 + 光线 + 机位 的固定组合**，直接回答"这一镜怎么拍"。脚本写配方而非单一名词，拍摄者无需二次解读。

### 7.1 基础配方库（12 个高频配方，覆盖 90% 短视频镜头）
| 配方码 | 组合 | 适用时刻 | 成本 |
|--------|------|----------|------|
| P01 口播中景 | 中景+固定+三分法+自然光 | 单人讲述主体段 | ★手机 |
| P02 对话过肩 | 过肩+固定+三分法+平光 | 双人对话回合 | ★★三脚架 |
| P03 情绪特写 | 近景/特写+固定或缓推+中心+暖调侧光 | 金句/动情点 | ★手机 |
| P04 产品定妆 | 特写+固定+中心+亮调通透 | 产品/细节展示 | ★手机 |
| P05 环境空镜 | 全景/远景+固定或慢摇+留白+冷调 | 转场缓冲/开场定调 | ★手机 |
| P06 行走跟拍 | 中景+手持/移跟+三分法+自然光 | 过程记录/沉浸 | ★★稳定器 |
| P07 悬念遮挡 | 中景+固定+前景遮挡+低饱和 | 钩子/视觉钩子 | ★手机 |
| P08 对比分屏 | 双近景+固定+对称+平光 | 观点对峙/前后对比 | ★★剪辑合成 |
| P09 高潮升格 | 特写/大特写+慢动作+中心+高对比 | 情绪/产品高光 | ★★升格拍摄 |
| P10 电影收尾 | 远景/大远景+固定或升降+留白+蓝调时刻 | 升华/Hero shot | ★★★场景+调色 |
| P11 访谈对坐 | 双人中景过肩交替+固定+三分法+平光 | 对坐访谈 F5 | ★★三脚架 |
| P12 现场原声 | 中景+手持+引导线+现场光 | 晒过程 B 端现场 | ★★现场收音 |

### 7.2 按拍摄形式（F1–F6）的默认配方基线
> 形式决定"基本盘"，叙事类型做微调。二创脚本每个方案须从下表选基线配方，再按 7.3 调情绪。

| 形式 | 默认机位 | 默认景别 | 默认光线 | 推荐配方组合 | 忌 |
|------|----------|----------|----------|--------------|----|
| **F1 单人口播** | 手机支架平视 | 中景为主、金句切近景 | 自然光/暖调 | P01 + P03 + P05（开场定调） | 全程一个景别到底（呆板） |
| **F2 多人对话** | 双机位或单机过肩 | 过肩+中景交替 | 平光 | P02 + P03 + P08（观点对比） | 只拍一人、另一人画外音（失衡） |
| **F3 情景演绎** | 按场景走位 | 中景叙事+特写反应 | 自然光/戏剧光 | P06 + P03 + P09 + P10 | 演绎像念稿（无反应镜） |
| **F4 旁白+VCR** | 旁白固定+素材混剪 | 旁白中景+素材全景/特写 | 旁白暖调+VCR 原色 | P01（旁白）+ P04/P05（VCR） | 旁白与素材割裂（不呼应） |
| **F5 对坐访谈** | 双人中景过肩机位 | 过肩交替+特写反应 | 平光/暗调电影感 | P11 + P03 + P05 | 机位不换、像监控录像 |
| **F6 分屏证言** | 多机位或后期分屏 | 多近景同帧 | 平光 | P08 + P03 + P12 | 多人不同光线/色调（杂乱） |

### 7.3 按叙事类型的情绪微调
| 叙事类型 | 配方倾向 | 光线/色调加料 |
|----------|----------|---------------|
| 教知识 | P01/P04 为主，干净通透 | 明亮通透、低饱和，突出信息清晰 |
| 聊观点 | P03 金句特写 + P08 对比 | 高对比或暗调电影感，强化态度 |
| 讲故事 | P06 沉浸 + P09 高潮升格 + P10 收尾 | 暖调怀旧或蓝调时刻，情绪化 |
| 晒过程 | P12 现场原声 + P04 细节 | 现场光优先、保留真实质感，禁过度滤镜 |

### 7.4 反模式（写了等于没写 / 写了拍不出）
- ❌ "中景"单独出现 → 必须带运镜+构图+光线（写 `中景+固定+三分法+自然光`）。
- ❌ "大气一点" → 虚词，改成 `远景+固定+留白+蓝调时刻`。
- ❌ 全片同一配方到底 → 至少钩子/高潮/收尾三处换配方（见剪辑层切点规则）。
- ❌ 光线与环境矛盾（户外写"暗调电影感"无打光设备）→ 改为"自然光+侧光勾勒轮廓"或标注需补光。

## 八、🎬 分镜标注模板（二创脚本直接用）
每个镜头在镜头表"拍摄手法"列写**配方码 + 一句话说明**：

```
| 镜号 | 时间 | 画面内容 | 拍摄手法（配方） | 来源 |
|------|------|----------|------------------|------|
| 1 | 0:00-0:03 | 主角直视镜头抛钩子 | P07 悬念遮挡（中景+固定+前景遮挡+低饱和） | 原创 |
| 2 | 0:03-0:18 | 观点展开 | P01 口播中景（中景+固定+三分法+自然光） | 沿用原片0:24 |
| 3 | 0:18-0:22 | 金句 | P03 情绪特写（近景+缓推+中心+暖调侧光） | 原创 |
```

> 配方码（P01–P12）让拍摄者一眼知"这镜怎么架机"，无需懂术语也能执行；资深拍摄者可照码自由升级（如 P01 改 P03 推近）。

## 九、与剪辑层（editing_design.md）的衔接
- 本文件管"单镜怎么拍"，`editing_design.md` 管"镜头怎么拼"——两者通过**切点位置**衔接：
  - 配方切换点（如 P01→P03）= 剪辑硬切点（见 editing_design §2）。
  - P09 升格 / P10 电影收尾 = BGM 高光卡点对齐位（见 bgm_design + editing_design §3）。
  - P05 环境空镜 = 转场缓冲位（失焦/匹配剪辑插入处）。
- 二创脚本须**同时**填"拍摄手法配方"与"剪辑设计"两列，缺一不可（步骤 6 强制）。
