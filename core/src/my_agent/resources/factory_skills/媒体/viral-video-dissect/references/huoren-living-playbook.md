# 活人感拍摄 · 案例库（我们的内容类型样板）

> 配套 `SKILL.md` 使用。每条都按「场景口诀 / AI 备课 / 情绪锚点 / 设备 / 即兴留白」拆解，并给正反样板。
> 记住：活人感 ≠ 反专业、≠ 随手拍、≠ 必须手机。用户要看"大咖放松地融入环境演精彩内容"。

---

## 类型一 · 中年重启 A 号（短视频 · 中年重启实录）

**常见主题**：下岗/转行感悟、陪读日常、夜市摆摊、老厂区回忆。

| 维度 | 建议 |
|---|---|
| 场景口诀 | 优先**走着拍**（下班路过老厂区/菜市场夜市边走边说）、**晚上拍**（夜市灯光有氛围、半即兴）；别坐书桌前念。 |
| AI 备课 | 去前问 AI：这老厂区哪年建/当年什么产业/现在空置率？这菜市场日客流大概多少？备 2–3 个"能说点事"的数据点。 |
| 情绪锚点 | 真实感慨/顿悟——看到老同事、闻到夜市味被"刺激"出"时间真快"的喟叹。先"唉"再"说事"。 |
| 设备 | 放松有对象感→**手机**边走边举最自然；若某段要对着镜头讲观点，换 pocket 让家人抓拍。 |
| 即兴留白 | 故意留一个"被摊主搭话/认出熟人"的临时互动，不剪掉。 |

**反面样板**：坐着对白墙说"今天想跟大家聊聊中年重启" → 预制感高危。改法：走到老厂区门口，第一句"我以前就在这栋楼上班，昨天又路过"→ 立刻活。

## 类型二 · 安防老板访谈（《安防100位老板真心话》）

**常见主题**：老板创业血泪、行业潜规则、踩坑实录、转型焦虑。

| 维度 | 建议 |
|---|---|
| 场景口诀 | 必须去**真实经营场景**（老板办公室/工地/监控机房/仓库），别在民宿绿幕前访谈。 |
| AI 备课 | 去前问 AI：这细分（如停车场系统）近 3 年市场规模/集中度？标杆企业毛利区间？备"能说点事"的行业数字。 |
| 情绪锚点 | 老板讲到"最难那年被断供"时的真实疲惫/哽咽——别打断，留着。这是活人感核弹。 |
| 设备 | 访谈常用机位固定→用 pocket/微单架好，但**抓拍老板起身指墙上的图/翻合同**的瞬间，那是半即兴。 |
| 即兴留白 | 留一个"老板突然想起某事离题两句"的毛边，比剪辑干净更有真人感。 |

**反面样板**：双方坐沙发念提纲问答 → 像新闻通稿。改法：跟着老板走进机房，他边指设备边骂"这玩意儿坑死我"→ 活。

## 类型三 · 停车招商（宜泊云智慧停车）

**常见主题**：车位荒、招商政策、回报率、选品牌避坑。

| 维度 | 建议 |
|---|---|
| 场景口诀 | 去**真实停车场/招商会现场**拍，别坐办公室讲 PPT。晚上拍满场停车的灯光更有说服力。 |
| AI 备课 | 去前问 AI：城市核心区车位缺口数据/周转率行业均值/常见招商骗局话术。备"能说点事"的数字。 |
| 情绪锚点 | 看到满场停满→"哇这周转率"的兴奋；或看到烂尾车场→"又一家"的唏嘘。 |
| 设备 | 现场走动讲解→手机；要拍数据大屏特写→pocket 稳定。 |
| 即兴留白 | 留一个"保安凑过来问这是不是又要涨停车费"的真实搭话。 |

## 类型四 · 宠物群（宠物资本/政策新闻）

**常见主题**：行业乱象、政策解读、门店经营、养宠痛点。

| 维度 | 建议 |
|---|---|
| 场景口诀 | 去**门店/猫舍/展会展位**拍，别坐书房念稿。 |
| AI 备课 | 去前问 AI：这品种近期价格走势/某政策具体条款/行业投诉高发点。备"能说点事"的事实。 |
| 情绪锚点 | 看到毛孩子互动→真实"心化"的喜；讲到乱象→真的气。 |
| 设备 | 手机贴近拍最活；要稳拍环境用 pocket。 |
| 即兴留白 | 留宠物突然闯镜/叫一声的毛边。 |

## 类型五 · 副业理性入场（方向 A）

**常见主题**：副业踩坑、理性劝退、信息差红利、时间分配。

| 维度 | 建议 |
|---|---|
| 场景口诀 | **晚上**在咖啡馆/书房拍（夜拍有私密感、半即兴）；别白天坐工位念。 |
| AI 备课 | 去前问 AI：该副业近 1 年投诉/退费数据/真实收益区间（区间！别给绝对数）。 |
| 情绪锚点 | 劝退时的认真/看到有人被割韭菜的怒。 |
| 设备 | 手机对镜自说最自然。 |
| 即兴留白 | 留一个"手机弹通知打断"的真实瞬间。 |

---

## 通用「预制感」自检红绿灯
- 🔴 高危：固定背景坐播 + 念稿 + 白天 + 无场景关联 → 必改。
- 🟡 中危：场景对但念稿感重 → 加 AI 备课"说点事" + 留即兴毛边。
- 🟢 安全：高关联场景 + 真情绪 + 知识备好 + 一处即兴 → 发。

> 每次出方案，先把计划场景套这盏灯，再写 6 段建议。
