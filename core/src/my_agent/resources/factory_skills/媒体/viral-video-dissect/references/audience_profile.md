# 受众画像模板（audience_profile）

> 本文件供 `video-script-dissect` 技能在「步骤 5（框架分析）」与「八维自分析（归属②）」中参考，输出一节「受众画像」。
> 受众维度思路：不只看"内容好不好"，还要看清"拍给谁、TA 为什么动"。

---

## 一、四栏结构（每条视频须填）

| 栏 | 要回答的问题 | 推断依据 | 示例 |
|----|--------------|----------|------|
| **① 人口统计** | 这条大概率被谁刷到？年龄段 / 城市线 / 职业阶段 / 身份标签 | 四基因的「身份标签」+ 内容主题 + 平台受众画像（见 `platform_rules.md` 6.1） | "30 岁沪漂""二胎妈妈""小县城体制内" |
| **② 核心痛点** | TA 刷到这条时，正在焦虑 / 渴望什么？ | 内容命中的情绪钩子类型（痛点共鸣 / 利益承诺） | "怕 35 岁被优化""想搞副业没方向" |
| **③ 购买·关注信号** | 什么会触发 TA 点赞 / 收藏 / 转发 / 关注？ | 四基因的「行动触发」「情绪钩子」「社交链适配度 D9」 | "存好这份清单"（收藏）/ "说的就是我"（转发） |
| **④ 关注动机** | TA 为什么愿意花时间在这条上？ | 认同感 / 有用性 / 情绪价值 / 社交货币 | "显得内行"（社交货币）/ "能照做"（有用） |

---

## 二、怎么推断（不瞎编）

1. **从内容反推人群**：钩子类型 + 案例主角 + 用词（"咱们打工人""宝妈"）直接指向人群。
2. **从平台反推**：同一内容在视频号（熟人/中龄）vs 抖音（年轻/爱梗）vs 小红书（女性/种草）受众不同，画像须随平台调整（八维自分析做分平台诊断时尤其要改）。
3. **从四基因反推**：身份标签（谁）+ 情绪钩子（什么情绪）+ 行动触发（做什么）+ 信息差（凭什么信）。
4. **存疑标【推测】**：无明确信号时不硬编人口统计数字，写"泛职场人群，25–40 为主（推测）"。

---

## 三、两种用法

- **二创（归属①）**：每个二创方案在「受众画像」基础上明确"本片拍给谁、TA 获得什么"，确保角度精准命中对的人；也用于校验四基因「身份标签」是否落地。
- **八维自分析（归属②）**：用画像反推"原片是否精准命中对的人"——若内容好但播放差，常是画像错位（拍给 A 却推给了 B），给出"换人群 / 换平台 / 改标题钩子"的整改方向。

---

## 四、输出示例（写进报告「受众画像」节）

```
【受众画像】
· 人口统计：28–38 岁新一线职场人，多为"想跳槽但不敢"的沉默多数。
· 核心痛点：怕被动失业、对当下平台没安全感。
· 购买·关注信号：收藏"面试话术清单"、转发给同为打工人的朋友（社交货币=清醒）。
· 关注动机：认同（"有人替我把话说出来"）+ 有用（"能抄的跳槽动作"）。
```
