## 1. 一句话：这技能干什么

把一条视频拆成「可复用的内容图纸」，再用图纸做两件事之一：

- **① 拆爆款 → 产出几条能直接拍的同款脚本**（归属①）；
- **② 给自己的视频做八维体检**，指出哪里能改（归属②）。

## 2. 三入口：先对号入座

| 你手里有什么 / 想干啥 | 走哪条线 | 主步骤 | 你只需说的一句话 |
|----------------------|----------|--------|------------------|
| 只有**一句话想法 / 一个主题**，要选题或标题 | **轻量选题线**（不抽帧、不写分镜） | 0.5 | "帮我围绕『副业踩坑』出 5 个选题" |
| 有**别人的爆款视频**，想复制同款 | **拆解 + 二创主流程** | 0→1→2→3→4→5→5.5→6→7→8→9 | "拆解这条，给我 3 条能直接拍的二创脚本" |
| 有**自己的视频**，数据不好想优化 | **八维自分析** | 0→1→2→3→4→5→9 | "帮我按 8 维看看这条哪里能改" |

> 收到视频时 AI 会**先问你走哪条**（归属确认门，强制）。你也可以抢先说，省一轮。

## 5. 四个决策门（AI 必须问你才动，不会替你决定）

| 门 | 触发时机 | 问什么 | 不问就动的后果 |
|----|----------|--------|----------------|
| **归属确认门** | 收到视频的第一时间 | 拆解二创 / 八维自分析？ | 靠猜，可能给错东西 |
| **二创脚本门** | 步骤 5.5 出草案后 | 要不要生成二创脚本？ | 自动产出，违反铁律 |
| **选题库门** | 步骤 7 之前 | 要不要进选题库？ | 自动入库，污染资料库 |
| **文档格式门** | 步骤 9.5 | 要 PDF / HTML / Word？（**可多选**） | 只给 Markdown |

> 这四道门是硬规矩。AI 跳过任何一道直接产出，属于违规，你可以直接叫停重来。

## 6. 两条线的产出物对照（防混淆）

| | **归属① 拆解 + 二创** | **归属② 八维自分析** |

| 能分平台改进诊断 | — | ✅ 能（步骤 5.8，确认后执行） |

## 7. 文档导出怎么选（步骤 9.5 速查）

| 你的场景 | 选哪个 | 理由 |
|----------|--------|------|
| **资料库入库 / 多人编辑** | **Word 首选** + HTML 备选 | .docx 可批注修订、可改排版；PDF 不可编辑 |
| 存档 / 打印 | PDF | 带封面、目录、每页页码，最稳 |
| 对外转发 / 内网挂载 | HTML | 单文件零依赖，浏览器双击即开 |
| 单位要可编辑的正式文档 | Word | 原生目录域，打开自动更新页码 |
| 全都要 | `build_docs.py --formats pdf,html,word` | 一次出三份，逐份独立、互不影响 |

## 10. 12 种爆款结构速查 + 选用决策树（v2.40.0 新增）

**决策树 · 4 步定类**：
1. **看目的**：教育 → 01/02/10；共鸣 → 09/04；转化 → 03/11/08；完播 → 12/06
2. **看时长**：<30s → 01/12；30–60s → 02/04/05；>60s → 10/11
3. **看人设**：理性专家 → 03/10/02；情感共振 → 09/04/08；清单干货 → 06/07
4. **看素材**：数据方法论 → 10；真实案例 → 11；冲突事件 → 05；情绪切片 → 09

**同族提醒**（别挑错）：04 + 12 同族（情感反转用 04、信息差揭秘用 12）；05 + 10 同族（讲差距用 05、讲流程用 10）；03 + 11 同族（讲自己用 03、讲别人用 11）。

**共通底层**：任何热点套结构都走 4 步——找热点切入 → 改开头 → 改中段 → 改结尾。**禁止跳过第 1 步直接套骨架**（那是生搬硬套，同质化头号成因）。详见 `framework_rubric.md` §六。

## 11. 二创打分不够？按这张表补（v2.43.0 新增）

**成色卡 8 维提分手册**（任一维 ≤3 分 → 按对应动作补强后复打；分数不是为了排名，是为了知道改哪里）：

| 短板维度 | 一句话补强动作 |
|---|---|
| ① 情绪强度弱 | 加冲突点："XX 现象" → "XX 但 YY" |
| ② 转发动机低 | 加身份标签：受众缩到具体人群（"30 岁未婚沪漂"） |
| ③ 独家信息差低 | 加个人视角：前缀"我做了 X 年 Y 才发现" |
| ④ 身份匹配低 | 缩小受众：宁可 100 万人精准戳，不要 1000 万人无感 |
| ⑤ 时效红利低 | 蹭最近 7 天热点 / 节气 / 行业大事件，忌日抛热点 |
| ⑥ 传播锚点弱 | 造一个截图点：对比图 / 数字卡 / 金句，写进脚本 |
| ⑦ 视觉钩子弱 | 把听觉信息改成视觉：能拍出来就别只用嘴说 |
| ⑧ 行动触发弱 | 砍理解成本：3 步压到 1 步，首屏 3 秒讲清"能得到什么" |

> 补强优先级：**①情绪 / ④身份 / ⑥锚点最易补、收益最高**。完整对照（含改写示例）见 `SKILL.md` 步骤 5.55。

**七种情绪档案**（选题时先定"吃哪种情绪"）：

| 情绪 | 传播力 | 危险度 | 触发词（口播可直接用） |
|---|---|---|---|
| 共鸣 | ★★★★★ | 低 | 懂的都懂 / 我也是这样 / 每次都这样 |
| 愤怒 | ★★★★★ | **高**（转建设性表达） | 凭什么 / 被忽悠了 |
| 治愈 | ★★★★ | 低 | 终于 / 原来 / 那一刻 |
| 焦虑 | ★★★★ | **中**（不贩卖绝望） | 来不及 / 错过 / 被淘汰 |
| 惊讶 | ★★★★ | 低 | 居然 / 竟然 / 真相是 |
| 爽感 | ★★★ | 中 | 反杀 / 扳回 / 赢麻了 |
| 优越 | ★★★ | 低 | 内行才看懂的 |

**基因组合配方**：情绪+身份=**共鸣型**｜信息差+行动=**干货型**｜情绪+信息差=**颠覆型**｜身份+行动=**工具型**｜**四基因全开=核弹型**（优先排 Top 1）。详见 `SKILL.md` 步骤 5.5。

## 12. 写口播卡壳？先用这两个自查（v2.51.0 新增）

> 选好 12 种结构里的哪一类之后，一句话一句话怎么写，用下面两个工具补。**它们是"结构选型之前的底层骨架"，不替代 12 种结构。**

**① 通用口播最小骨架：结论→理由→例子→行动（CREA）**

| 段 | 一句话 | 短口播（30–60s）配比 |
|---|---|---|
| 结论 | 先立住核心判断（别写成摘要） | 5s |
| 理由 | 给因果关系，不是堆数据 | 10s |
| 例子 | 具体场景 / 故事，10 秒内回扣结论 | 15s |
| 行动 | 给一个看完就能做的动作 | 5s |

**② 搭结构前四动作自检**（写脚本前逐条过）：
1. **先找问题**——这条到底在回答什么问题？
2. **先有结论**——你真正想表达的核心判断是什么？
3. **先搭主线**——先讲什么、再讲什么、重点放哪、怎么收？
4. **先替读者着想**——看完能看懂、记住、用上吗？

> 还有一张「堆信息式 vs 搭结构式」诊断对照表（问题感 / 结论感 / 推进感 / 记忆感 / 行动感），用于自查自己的视频——见 `twelve_dimension_map.md` 结构层。详见 `framework_rubric.md` §1.5 与 §2。

## 13. 常见组合场景一句话入口（v2.54.0 新增）

> 用户反馈"复杂组合场景要多次确认、分支容易找不到下一步"。下面把**高频组合需求**直接翻译成"你只需说的一句话"，AI 收到后会按对应流水线自动串联，不用你拼步骤。

| 你想干啥（组合需求） | 直接甩这句话 | AI 走哪条线 |
|----------------------|--------------|-------------|
| 拆 3 条竞品，只要共同框架 | "把 V1/V2/V3 三条同赛道爆款各拆一遍，最后给我共同框架和差异点，不用二创脚本" | 逐条拆解 → 跨视频洞察（`cross_video_insight.md` + `batch_pipeline.md` §1） |
| 拆 1 条 → 出 3 条二创 → 进库 | "拆解这条，给我 3 条能直接拍的二创脚本，确认后帮我进选题库" | 主流程 → 步骤 5.5 多选题 → 选题库门 |
| 10 条先拆 Top 3 再扩选题 | "这 10 条我先看前 3 条，拆完提炼共性框架，再用四层公式扩一批贴业务的选题" | 批量流水线（先 Top 3 校准口径） |
| 长录音 60min → 拆成多条 → 逐条二创 | "这段 60 分钟录音按三维打分拆成 5 条独立短视频素材，逐条走完整流程出二创脚本" | 步骤 0.9 拆条门 → 逐条主流程 |
| 拆 1 条 + 八维看我自己的那条 | "拆解这条爆款，同时按 8 维看看我发的那条同名视频哪里能改" | 归属① 拆解 + 归属② 八维自分析（分两次，各走确认门） |
| 一个热点 → N 个选题 → 每个出二创 | "这个热点用四层公式给我扩 10 个贴业务的选题，挑 3 个各出二创脚本" | 轻量选题线 §5.7 四层公式 → 步骤 5.5 |
| 第一次用，不知道本机缺啥 | "先帮我跑一下环境自检" | 运行 `scripts/check_env.py`，按结果补依赖 |

> **边界**：批量 / 组合 ≠ 自动产出。凡涉及二创脚本、进选题库、分平台诊断，AI 仍会在对应决策门**停下来问你**（四道决策门硬规矩不变）。本表只是把"先说哪句"替你想好了。
