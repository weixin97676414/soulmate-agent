# 真实开场白话术范例库（按心理机制分类）

> 本文件是 `video-script-dissect` 的**第三层钩子工具**。来源：他人总结的「16 个短视频万能开头钩子」，经采纳、按本技能钩子类型体系重新归类整理（v2.24.0 纳入）。它专补「第一句卡壳、占位骨架改不出真句子」的痛点——给的是**可直接改写念出口的完整开场白**，不是公式。

---

## 一、三套钩子工具的关系（避免重复造轮子）

| 层 | 工具 | 管什么 | 文件 |
|----|------|--------|------|
| ① 挖主 Hook | 六维钩子扫描法 | 从素材"挖"什么钩子（内容） | `copywriting_craft.md` §1 |
| ② 开口句式骨架 | 16 种开篇钩子句式模板 | 第一句"怎么开口"（占位骨架：XX 天 / 10 个里 9 个…） | `framework_rubric.md` 第一节 |
| ③ **真实话术范例（本文件）** | **可直接改写的完整开场白** | 按心理机制分类的真实句子 + 场景提示 | 本文件 |

> **用法顺序**：先用 ① 挖出本视频的主 Hook（内容）→ 用 ③ 挑一个贴合心理机制的真实开场白当底稿 → 用 ② 的句式骨架做变体 / A·B 测试。三层叠加，开口既有"真内容"又有"好句式"，不空套模板。

## 二、16 个真实开场白（按 4 种心理机制）

每种机制标注：① **对应技能钩子类型**（对齐步骤 3 判定口径，便于八维 D1 归类）② **适配二创用途标签**（赌爆 / 稳涨 / 矩阵测试，见核心原则 18）③ **适配场景**。

### 机制 A · 悬念钩子（对应技能类型：悬念 / 秘密）
> 适用：爆料、走心、避坑内容，勾起好奇心（对齐用户原提示「悬念钩子：适合爆料、走心、避坑」）。

| # | 真实开场白 | 对应技能类型 | 二创用途 | 适配场景 |
|---|-----------|-------------|---------|---------|
| A1 | 有个事我一直没敢拍，但今天决定拍了 | 悬念 | 赌爆 | 爆料 / 走心 |
| A2 | 今天这件事，我不讲以后可能再也不会讲了 | 悬念 | 赌爆 | 爆料 / 走心 |
| A3 | 拍这条视频之前，我真的犹豫了很久 | 悬念 | 稳涨 | 走心 / 个人经历 |
| A4 | 这件事我身边没有人知道，但我想告诉你 | 秘密 / 悬念 | 赌爆 | 爆料 / 内幕 |

> 与 ② 的重叠提示：A1 / A2 / A4 ≈ `framework_rubric` 模板 #4「悬念升级·好奇」、#12「秘密钩子」——本表给的是**可直接念的完整句子**，模板给的是骨架，二者互补不冲突。

### 机制 B · 情绪共鸣（对应技能类型：痛点共鸣）
> 适用：感悟、吐槽、个人经历，快速拉近距离（对齐「情绪共鸣：适合感悟、吐槽、个人经历」）。

| # | 真实开场白 | 对应技能类型 | 二创用途 | 适配场景 |
|---|-----------|-------------|---------|---------|
| B1 | 今天发生了一件事，我到现在还没缓过来 | 痛点共鸣 | 稳涨 | 走心 / 吐槽 |
| B2 | 我昨晚想了一整夜，想明白一件事 | 痛点共鸣 | 稳涨 | 感悟 / 观点 |
| B3 | 今天是我做这行以来，最崩溃的一天 | 痛点共鸣 | 赌爆 | 吐槽 / 个人经历 |
| B4 | 我做了一个决定，可能很多人都不理解 | 痛点共鸣 / 冲突 | 矩阵测试 | 个人经历 / 观点 |

> 与 ② 重叠：B1 / B3 ≈ 模板 #10「共鸣钩子」；B4 含「冲突 / 对立」属性（模板 #2）。

### 机制 C · 场景代入（对应技能类型：身份代入 / 场景）

| # | 真实开场白 | 对应技能类型 | 二创用途 | 适配场景 |

> 与 ② 重叠：C1 / C2 / C4 ≈ 模板 #6「场景钩子」、#16「身份点名钩子」。

### 机制 D · 反常识（对应技能类型：反常识 / 行业揭秘）
> 适用：干货、行业揭秘、认知破局，打破固有认知（对齐「反常识：适合干货、行业揭秘、认知破局」）。

## 三、八维自分析用法（D1 钩子强度归类 + 强度自检）

八维自分析（归属②）诊断**自己视频**时，把**前 3–5 秒开头**归到 A / B / C / D 四机制之一，再据此做 D1 钩子强度（0–100）判定：

1. **归类**：原片开头属于 悬念(A) / 共鸣(B) / 代入(C) / 反常识(D) 哪一类？——对应步骤 3 钩子类型判定口径。
2. **强度自检**（对齐 `framework_rubric.md` 第一节量化口径）：
   - **≥80 强钩子**：开头命中某机制且**具体、有冲突 / 反常识 / 强共鸣**，且**视听复合**（画面符号 + 旁白）。→ 保留，二创可复刻。
   - **60–79 中**：机制清晰但冲突一般、偏平铺。→ 建议用本表对应机制换一句更具象 / 更有张力的开场白（如把「大家好今天聊 XX」改成 C1「凌晨 X 点我还在…」）。
   - **<60 弱**：开头无机制、铺垫过长、或「先自我介绍再入题」。→ 必须重写开头，从本表 4 机制挑最贴的一条作底稿，套 ② 句式骨架出 2–3 候选。
3. **补强动作**：弱开头补强优先级——先定机制（A / B / C / D）→ 选本表一句作底稿 → 用 ② 模板变体 → 过 `copywriting_craft.md` §1 六测自检（3 秒 / 具体 / 好奇 / 不剧透 / 口语 / 合规）。

> ⚠️ 边界：八维自分析只优化**原片**，不进入二创生成；上面的补强建议是「给原视频重拍 / 重剪的开口方案」，不是新脚本。

## 四、使用小提示（沿用用户原总结 + 技能对齐）

- **悬念钩子**：适合爆料、走心、避坑，勾起好奇心 → 二创用途偏「赌爆」，八维自分析偏补强「铺垫过长」。
- **情绪共鸣**：适合感悟、吐槽、个人经历，快速拉近距离 → 二创偏「稳涨」，八维自分析偏补强「平铺无情绪」。
- **场景代入**：适合纪实、vlog、真实日常，瞬间带入画面 → 二创偏「稳涨」，八维自分析偏补强「无画面感」。
- **反常识**：适合干货、行业揭秘、认知破局，打破固有认知 → 二创偏「赌爆」，八维自分析偏补强「无认知冲突」。

## 五、反模式（必读）

- **勿硬套**：范例是「底稿」不是「照抄」。每条须过 `copywriting_craft.md` §1 六测（具体 / 口语 / 不剧透 / 合规…），改成自己的口播；照搬「99% 的人都搞错」这类泛句易被算法判模板化，且「99%」属限流词（标题硬规则已禁用）。
- **视听复合优先**：单纯口播念开场白，记忆点弱于「画面符号 + 旁白」（如 C1 配「手机时间截图 / 台灯夜景」画面）。八维 D1 强钩子要求视听复合，开口设计要连画面一起想。
- **B 端赛道**：优先用 `b2b_hook_formulas.md` 4 公式（你信不信 / 真没想到 / 想想都可怕 / 千万不要）定第一句，本表作补充，不冲突。
- **去 AI 味**：开场白要「像真人临场说的第一句」，忌书面腔、忌排比堆砌（对齐 de-ai-taste 去 AI 味纪律）。

## 六、口播专用 8 类升级（v2.27 零修新增 · 口播稿专用 · 结构化升级版）

> 来源：用户发的「短视频口播开场钩子」，按 8 大类（好奇/痛点/利益/极限/借势/警示/反差/共鸣）整理，每类给 3 个公式 + 3 个例子——比上节 A/B/C/D 4 桶**更结构化**。
> 关系：本节是上节 4 桶的「口播稿专用 · 结构化升级版」，**不是替代、而是补充**——做脚本时若需要"3 公式+3 例"的标准化产出，先用本节；若需要"更有人味的真句子"，回到上节 A/B/C/D。
> 适配：抖音 / 视频号口播稿（短视频文案脚本）首选；图文 / 小红书卡也通用。

### ① 好奇类
> 聊点大家很少接触或特别想实现的事，勾起好奇心。
- 公式1：你猜……是什么感觉？
- 公式2：有没有办法不用……也能……？
- 公式3：如果有一天你……，你会怎么做？
- 例：在清华读书到底是种什么体验？
- 例：不想节食也不想拼命运动，怎么轻松瘦十斤？
- 例：假如你在上海欠了一百万，接下来怎么办？

### ② 痛点类
> 问题越准，越让人想听下去。
- 公式1：你为什么明明……，结果却……？
- 公式2：你如果还不清楚……，建议一定要……
- 公式3：最近特别火的……，你该不会还没听说吧？
- 例：为什么那个能力不如你的人，反而混得更好？
- 例：怕上火，现在很多人都会喝王老吉。
- 例：最近超有效的美白方法，你不会还没试过吧？

### ③ 利益类
> 大家最关心的就是"对我有什么用"。
- 公式1：原来只需要……，就能……
- 公式2：自从用了……，再也不用操心……
- 公式3：推荐一个每月能赚……的副业。
- 例：原来调整这两个设置，就能让流 L 暴增。
- 例：有了这个网站，从此字体版权问题再也不怕了。
- 例：这 5 样好东西，军训时真的能救命！

### ④ 极限类
> 用具体数字或程度引发关注。
- 公式1：这可能是全网最……的
- 公式2：几乎无人知道的……
- 公式3：特别冷门但巨好用的……
- 例：99% 的人都不知道的长寿习惯。
- 例：反着来！10 个小众旅行地，人少景美。
- 例：全世界治安最让人担心的国家，是这里。

### ⑤ 借势类
> 沾热点、借名人、吸引眼球。
- 公式1：沾热点、借名人，吸引眼球。
- 公式2：他曾经被……点赞，现在 ……
- 公式3：最近那部剧超火，但我更想聊聊里面……
- 连……都在用的……
- 例：听完雷军的演讲，我记住了这几句话。
- 例：马云反复推荐的三本书，值得一看。
- 例：欧阳娜娜同款素颜霜，真的那么好吗？

### ⑥ 警示类
> 引起危机感、让人想看完避免踩坑。
- 公式1：关于……的真相，千万别……
- 公式2：如果你继续……，小心……
- 公式3：……马上要……，抓紧时间……
- 例：这五种人，最好别深交。
- 例：这四句话，永远不要对孩子说。
- 例：总是熬夜？当心头发越来越稀疏。

### ⑦ 反差类
> 打破常规认知，制造意外感。
- 公式1：别人总说……，其实……
- 公式2：我可以……，但却不能……
- 公式3：只要用对……，轻松就能……
- 例：会偷懒的人，反而更容易成功？
- 例：流量背后，可能是一场精心设计的游戏。
- 例：为什么有人每天躺着，收入却不停涨？

### ⑧ 共鸣类
> 真诚分享，唤起同理心。
- 公式1：今天是我……，能给我一句加油吗？
- 公式2：第一次尝试……，你们支持我吗？
- 公式3：已经很很久没……，可以帮帮我吗？
- 例：今天生日，可以祝我一句生日快乐吗？
- 例：人生第一次摆摊，大家给我一点鼓励吧。
- 例：人为什么总要面对离别呢……

> 用法：写口播稿时，从 8 类中先定 1 个主类（如"反差类"）+ 1 个副类（如"痛点类"）→ 用 3 公式生成 2–3 候选第一句 → 从例子里摘对应场景的"具象感" → 套 copywriting_craft §1 六测自检（具体 / 好奇 / 口语…）。
> 反模式：8 类与上节 A/B/C/D 不可混用（机制判定冲突）；副业 / 创作者 / 教培赛道仍优先走第四层（`hook_opener_examples_creator.md`），本节是大众生活感悟的口播专用。

## 七、v2.40.0 新增：三种句式升级（12 种结构图卡对位补强）

> 本节补的是 §二 / §六 没有覆盖的三类打法，与 `framework_rubric.md` §五「12 种结构速查索引」配套——**先查 §五 定结构类，再回本节挑句式**。

### ① 身份代入 · 4 步升级版（原「机制 C 场景代入」只有第 1 步）

原机制 C 只解决"框定对象"这一步，08 身份代入型给了完整 4 步：

| 步 | 动作 | 句式示例 |
|---|---|---|
| 1 | **框定对象** | "如果你是那种……的人" |
| 2 | **替对方说出感受** | "一开口脑子就空白，稿子背了十遍还是卡壳" |
| 3 | **命名问题** | "这不是你表达能力差，是……" |
| 4 | **给出专属解法** | "给你一个只适合这类人的办法：……" |

> 关键点：**第 2 步是关键**——替对方说出的感受越具体，代入感越强；笼统的"你是不是也这样"无效。

### ② 情绪共鸣 ·「向内给理解」型（与 §二 B / §六 ⑧ 区分）

§二 机制 B、§六 ⑧ 是**「向外求认同」型**（求鼓励 / 求支持 / 求加油）；本节是**「向内给理解」型**——不向观众索取，而是**先给出去**。副业 / 中年重启 / 宠物情感题材优先用本节。

| 步 | 动作 | 句式示例 |
|---|---|---|
| 1 | **接住情绪**（描普世场景，不急着教） | "你有没有过这种时候——明明很努力了，还是觉得自己不行" |
| 2 | **去羞耻感** | "你不是矫情，也不是不够努力" |
| 3 | **讲心理机制** | "你只是太早拿别人的成熟期，来要求自己的起步期" |
| 4 | **给可执行出口**（小但能立刻做） | "今晚就做一件事：把今天做成的一件小事写下来" |

> 反模式：**不得编造心理学术语撑场面**；情绪必须现场来、不预制（关联活人感拍摄建议）。完整 4 段结构见 `framework_rubric.md` §五「09 情绪共振型」。

### ③ 清单类 ·「每条独立可截图」原则

06 清单合集型的硬指标，补进钩子库（对位跨视频元规律「列名节奏 1s/名」）：

- **数量感 = 可收藏**：数字放标题最前（"5 个……"），不藏在句中
- **一条一结论 = 高效率阅读**：每条**独立成句、能单独成立**，不依赖上下文
- **每条都能独立截图传播**：单条被截出去也要讲得通，**禁止"上一条说到……"式衔接**
