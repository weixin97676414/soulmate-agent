# B端工厂开头公式库（b2b_hook_formulas）

> 本文件是 `video-script-dissect` 二创环节的 **B 端专用开头钩子库**，供**步骤 5.5 角度池发散**与**步骤 6 写二创开头**参考：当判定赛道为 **B 端 / 源头工厂 / 设备类 / 招商加盟 / 工程施工**（如安防弱电、停车改造、工厂设备、工程服务）时，优先从本库选公式。公式按本技能门禁体系收编。

---

## 一、4 条 B 端开头公式（源头工厂 / 设备类账号专用）

| 公式 | 开头句式 | 情绪触发 | 账号导向 | 适用场景 |
|------|----------|----------|----------|----------|
| **公式1** | "你信不信…" | 自信/挑战 | 卖货导向 | 源头工厂实力、设备效果展示 |
| **公式2** | "真没想到…" | 惊喜/反差 | 卖货导向 | 性价比、选型避坑 |
| **公式3** | "想想都可怕…" | 恐惧/后果 | 信任导向 | 不选源头的代价、选错设备的后果 |
| **公式4** | "千万不要…" | 警告/紧迫 | 信任导向 | 避坑、防踩雷 |

**示例（安防/停车/工程语境）**
- 公式1："你信不信，一套监控方案能省 3 万？关键不在设备，在布线设计。"
- 公式2："真没想到，停车场改造最贵的不是道闸，是没人告诉你的施工细节。"
- 公式3："想想都可怕，弱电工程验收前没人管，出问题全在三年后。"
- 公式4："千万不要找没做过同类项目的施工队，这 5 个坑等你踩。"

**示例（服务型 B 端 · 停车运营/招商加盟/维保语境 · v2.14 新增）**
- 公式1："你信不信，一套停车运营方案能省 3 万运维？关键不在道闸，在动线和诱导。"
- 公式3："想想都可怕，加盟了个没跑通过的品牌，保证金和装修全打水漂。"
- 公式4："千万不要信'零经验也能开'的招商话术，这 4 个坑专坑小白。"

## 二、应用规则（强制）

1. **公式只用于开头钩子**，正文保持 B 端专业内容，不能变成纯口播喊话（对齐六维钩子扫描法"挖主Hook"：公式负责"第一句抓人"，正文仍从素材/原片挖具体痛点与证据）。
2. **4 个公式穿插使用，避免同质化**：同一账号多条二创不要全套同一公式；角度池内至少覆盖 2 种公式。
3. **账号导向决定公式偏好**：
   - 卖货导向账号（源头工厂、设备直销、招商）→ 偏公式 1+2（自信/惊喜，亮实力）
   - 信任导向账号（工程服务、维保、咨询）→ 偏公式 3+4（恐惧/警告，立专业）
4. **与四基因校验**：公式 1/3（自信/恐惧）天然喂「情绪钩子」基因；公式 2（性价比/避坑）喂「信息差+行动触发」；公式 4（警告/避雷）喂「行动触发」。套公式后仍须命中四基因 ≥2，否则按步骤 5.5 淘汰。
5. **B 端合规红线**：公式 3/4 的"恐惧/警告"不得夸大后果、不得制造虚假紧迫感（对齐 12 心法 ⑩立场安全 + 步骤 6.5 合规检测）；"省 3 万"类数字须来自素材/真实案例，无数据用 XX 占位（对齐 `copywriting_craft.md` §4 不编数据）。

## 四、公式选择决策树（账号导向模糊时兜底 · v2.14 新增）

卖货导向偏 1+2、信任导向偏 3+4 是默认规则；但很多 B 端账号"既卖产品又做服务"（如既卖设备又做维保、既做招商又做陪跑），导向模糊时按以下决策树兜底：

1. **是否交付实体产品/设备，且用户首要诉求是"买得值"？** → 偏卖货导向，公式 1+2（你信不信/真没想到）亮实力、秀性价比。
2. **是否提供长期服务/工程/咨询，用户首要诉求是"别踩坑/别出事"？** → 偏信任导向，公式 3+4（想想都可怕/千万不要）立专业、避风险。
3. **两者都沾（如招商加盟：既要让人来，又要让人信）？** → **1+3 组合**：开头用公式 1 亮"你能得到什么"（利益 hook），中段转折用公式 3 点"选错代价"（恐惧 hook），一条里完成"吸引 → 信任"两段。
4. **仍判断不出？** → 用公式 2（真没想到，惊喜/反差）最稳妥：不踩恐惧红线、不硬喊卖货，适合多数"想让人看懂又想让人信"的 B 端账号。

**服务型 B 端特别提示**：停车运营/招商加盟/维保这类"服务型"账号，用户痛点偏"怕被坑/怕白干"，天然更贴公式 3+4；但纯喊"千万不要"易踩虚假紧迫感红线（见应用规则 5），建议公式 3 点真实代价、公式 4 给可验证的具体坑，不编造后果。
