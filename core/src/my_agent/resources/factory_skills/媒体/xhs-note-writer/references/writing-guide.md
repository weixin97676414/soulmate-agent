## 一、赛道与人群洞察

### 8 大主流赛道

| 赛道 | 高频选题方向 | 竞争度 | 合规风险 |
|---|---|---|---|
| 美妆护肤 | 妆教、护肤步骤、平价彩妆、成分党 | ⚠️ 高 | ⚠️⚠️ 极高（功效词重灾区） |
| 服饰穿搭 | OOTD、风格拆解、平价单品、衣橱整理 | 中 | 低 |
| 职场成长 | 行业入门、沟通技巧、副业、转行 | 中 | 中（培训类需避坑） |
| 家居生活 | 收纳、清洁、软装、家电测评 | 中 | 低 |
| 美食探店 | 食谱、餐厅、零食测评、减脂餐 | 中 | 中（减肥类敏感） |
| 旅行 | 行程、攻略、住宿、机酒 | 中 | 低 |
| 母婴亲子 | 育儿、辅食、教育、好物 | 中 | ⚠️⚠️ 高（未成年人保护） |
| 情绪心理 | 自愈、亲密关系、个人成长 | 低 | 低 |

### 目标人群速查（用于校准语气，不是写进正文）

| 人群 | 占比最大特征 | 文风调性 |
|---|---|---|
| 都市 GenZ | 19–25 岁，一线/新一线，学生或初职 | 口语化、爱 emoji、节奏快 |
| 都市白领 | 25–34 岁，月入 1 万+ | 求效率、反废话、爱清单 |
| 精致妈妈 | 28–40 岁，有孩子 | 求安心、认成分、爱对比 |
| 都市蓝领 | 18–30 岁，三四线多 | 求实用、爱折扣、口语 |
| 小镇青年 | 19–28 岁，下沉市场 | 求性价比、爱教程 |

> 📌 这些占比数字来自千瓜数据 2026 Q1 与多份行业报告，量级可信。不要把具体百分比写进笔记正文，会显得像报告而非真人。

## 二、爆款标题公式库

### 5 大公式 + 替换示例

#### 公式 1：数字冲击
**结构**：`[数字] + [关键词] + [结果/价值]`

**示例**（均 ≤20 字）：
- `3 步搞定副业第一单，新手可抄`
- `7 天瘦 3 斤的懒人食谱（实测）`
- `入职 1 个月融入团队，这 5 招真管用`

**要点**：
- 数字要具体（3、7 天、5 招），不要"几个""一些"
- 结果用形容词（管用、真香、轻松），不堆极限词
- 数字必须能在正文里凑齐——10 招里只有 6 招实质内容，读者立刻识破

#### 公式 2：痛点追问
**结构**：`[具体困境] + 怎么办/为什么`

**示例**：
- `开会插不上话？新人破冰其实有套路`
- `总是被同事排挤？可能踩了 3 个雷`
- `工资 5 千存不下钱？记账方法换一下`

**要点**：
- 困境要具体到场景（"插不上话"比"沟通难"高 10 倍点击）
- 暗示"我有解法"，但不要剧透
- 不用"为什么""怎么回事"这种大词开头

#### 公式 3：结果前置
**结构**：`[已实现结果] + [做到的方法/低成本]`

**示例**：
- `不加班也能被领导看见，我试了 3 个月`
- `面试 0 offer 拿下大厂 offer，靠这一招`
- `用对粉底液，伪素颜真的可以`

**要点**：
- 第一人称、口语化
- 留一个钩子让读者点进来看方法
- 警惕：**"必看""绝了""封神"是极限词**，直接限流

#### 公式 4：对比反差
**结构**：`[状态 A] vs [状态 B]`

**示例**：
- `月薪 5 千 vs 月薪 1 万 5，差的不是努力`
- `装修前 vs 装修后，这 5 千花得太值`
- `熬夜晚睡 vs 早睡早起，皮肤变化实录`

**要点**：
- 数字差异要真实可信，差距别太离谱（5 千到 50 万没人信）
- 对比项之间要有可解释的因果，不然就成标题党

#### 公式 5：悬念钩子
**结构**：`[反常识信息] + [暗示揭晓]`

**示例**：
- `90% 的新手都踩了这个护肤坑`
- `我去了一趟胖东来，发现 3 个真相`
- `原来不是菜难吃，是锅没选对`

**要点**：
- 反常识必须真反常识，不是"震惊体"
- 必须能在正文里兑现，不然就是标题党
- 避免 `99% 的人都不知道` 这类已经被用烂的开头

## 三、钩子开场模板

钩子就是正文前 3–5 行，决定用户继续看还是划走。**3 行内必须出现标题里的那个核心搜索词**。

### 模板 A：痛点共鸣
```
姐妹们，有没有遇到过这种情况？
[把痛点场景写 1–2 句，越具体越好]
我之前也是一样，直到发现 [你的解法]。
```

### 模板 B：数字吸引
```
今天分享 [数字] 个 [主题] 心得。
亲测有效，全部可以现学现用！
建议先收藏，用到再翻出来。
```

### 模板 C：结果前置
```
用了 [方法] 之后，我 [正向结果]。
真的惊到我了，今天把方法整理出来给你们。
不看真的会后悔（不是我夸张）。
```

> 🚫 `不看后悔` `必看` `炸裂` 已是极限词高发区，C 模板的第三行要换成"看完就能用"这种中性表达。

### 模板 D：身份/场景代入
```
作为 [身份]，我每周必做的一件事是 [动作]。
坚持了 [时长]，现在的变化是 [结果]。
```

## 四、正文主体结构

### 标准三段式

```
✨ Tip 1：[小标题，不超过 10 字]
[具体说明，40–80 字]
[可执行动作或例子]

💡 关键点：[补充提示]

✨ Tip 2：[小标题]
[同上结构]

✨ Tip 3：[小标题]
[同上结构]

（干货型可加 Tip 4、Tip 5，但总数别超 7 条，否则阅读疲劳）
```

### 节奏控制

| 项目 | 标准 |
|---|---|
| 每段行数 | ≤3 行 |
| 段间 | 必须空一行 |
| 每条 Tip 字数 | 40–80 字 |
| 正文总字数 | 干货 600–900 / 情绪 300–600 / 测评 500–800 |
| emoji 全文总数 | 8–15 个 |
| 同一个 emoji 复用 | ≤3 次 |
| 句中 emoji | ❌ 一律不放 |

## 五、互动结尾模板

### 模板 1：提问互动
```
姐妹们，你们平时是怎么 [解决同类问题] 的？
评论区聊聊，我每条都会看～
```

### 模板 2：收藏引导
```
觉得有用的话，记得 **点赞 + 收藏**
下回用到直接翻出来就行～
```

### 模板 3：下期预告
```
下期想看 [相关选题]？
点个关注，更新不迷路～
```

> ⚠️ **结尾的"点赞收藏"不是诱导互动的合规雷区**——小红书允许温和引导。雷区是"点赞解锁福利""评论抽奖"这类与利益挂钩的诱导。

## 六、话题标签策略

### 5 类标签的分工

| 类型 | 数量 | 作用 | 选错后果 |
|---|---|---|---|
| 大类词 | 2–3 | 蹭流量池 | 太大（如 `#生活`）会被淹没 |
| 长尾词 | 2–3 | 精准触达 | 太小（如 `#今天吃的这个蛋糕好好吃`）无人搜 |
| 场景词 | 1 | 关联需求 | — |
| 品牌/产品词 | 0–1 | 蹭站内搜索 | 无品牌则不放 |
| 流量词 | 0–1 | 蹭平台活动 | 不强求，匹配就用 |

### 组合示例（干货合集型）

```
#职场成长 #新人入职 #职场沟通 #打工人日常
#办公室生存 #北京职场 #校招
```

### 组合示例（美妆护肤型）

```
#护肤心得 #平价护肤 #学生党护肤 #护肤日常
#原相机 #好物分享
```

### 三条铁律

1. **必须中文**。`#OOTD` `#Skincare` 这种英文标签在小红书几乎没搜索量，反而显得不像真人。
2. **不堆砌**。一次 5–8 个够，10 个以上系统会判垃圾。
3. **不蹭完全无关的流量词**。标签要和正文真的相关，否则点进你主页的用户快速流失，权重下降。

## 七、封面文案设计

### 封面三要素

| 要素 | 用途 | 字数上限 |
|---|---|---|
| 主标题 | 第一眼抓注意力 | ≤12 字 |
| 副标题 | 补充价值或行动引导 | ≤18 字 |
| 视觉元素 | emoji / 线条 / 色块 | — |

### 三种结构模板

**A. 大字主标 + 副标**
```
主：5 招搞定职场破冰
副：新人都能用的沟通技巧
配：✨ 💡
```

**B. 问题 + 解决**
```
主：总是插不上话？
副：试试这 3 个破冰技巧
配：❓ 💪
```

**C. 数字 + 结果**
```
主：7 天入门副业
副：亲测有效的起步方法
配：🌟 ✨
```

### 设计原则

- 配色和笔记主题统一（情感类用暖色，技能类用冷色，美食用暖橘）
- 主标题字号 ≥ 副标题 2 倍
- 背景留白 ≥30%，别把图堆满
- **别在封面上堆极限词**——封面也算审核内容

## 八、排版与 emoji 标准

### 字号与强调（用于自检，不直接落到笔记里）

| 元素 | 处理 |
|---|---|
| 标题 | 18–20px 粗体 |
| 正文 | 14–16px 常规 |
| 强调 | 粗体或 #ff2442 红色（与小红书官方品牌色一致） |

### emoji 用法速查

| emoji | 用途 |
|---|---|
| ✨ | 关键亮点 / Tip 开头 |
| 💡 | 小技巧 / 知识提示 |
| 📝 | 注意事项 |
| 💪 | 行动号召 |
| 🌟 | 推荐 / 种草 |
| ❤️ | 情感表达 |
| 👍 | 认同 / 推荐 |
| 🍃 / 🌿 | 自然 / 清新主题 |

### 加粗规则

- 关键数字加粗（`3 招` `7 天` `¥299`）
- 关键结论加粗（**但不能整段加粗**）
- 同一条笔记里加粗 ≤5 处，否则失去强调效果

## 九、避坑清单（高频错误）

### ❌ 标题错误

| 错误 | 案例 | 正确 |
|---|---|---|
| 极限词 | `全网最好用的粉底液` | `我用了 3 年的真爱粉底液` |
| 标题党 | `震惊！原来 XX 还能这样用`（内容没兑现） | 直接写内容 |
| 制造焦虑 | `再不护肤就烂脸了` | 删 |
| 英文堆砌 | `OOTD daily style` | 改成中文标签 |

### ❌ 正文错误

| 错误 | 案例 | 正确 |
|---|---|---|
| 空话套话 | `每个人都值得拥有美好的生活` | 删 |
| 太像广告 | `本产品由 XXX 品牌提供` | 用第一人称感受代替 |
| 超字数 | 写 1500+ 字 | 砍到 1000 以内 |
| 段距拥挤 | 一段 8 行 | 每段 ≤3 行，必空行 |

### ❌ 标签错误

| 错误 | 正确 |
|---|---|
| 堆 20 个标签 | 5–8 个即可 |
| 全是大词（`#生活` `#日常`） | 大词 + 长尾混搭 |
| 全英文标签（`#OOTD`） | 中文标签为主 |
| 蹭完全不相关的词 | 删除 |

### ❌ 配图错误

| 错误 | 正确 |
|---|---|
| 重度 PS / 夸张美颜 | 自然光 + 真实场景 |
| 文字塞满 | 留白 ≥30% |
| 9 张图全是产品图 | 3 张产品 + 3 张场景 + 3 张细节 |
| 用其他博主的图（未授权） | 自己拍或用免版权素材 |

### ❌ 发布错误

| 错误 | 正确 |
|---|---|
| AI 生成未标注 | 勾选「AI 辅助创作」 |
| 商业合作未报备 | 走蒲公英下单 |
| 评论区放微信号 | 不放 |
| 短时间内发多篇 | 间隔 ≥1 小时 |

## 十、附录：完整流程速记卡

```
1. 判断笔记类型（干货/情绪/测评/避坑/教程/探店）
2. 按类型选标题公式（5 种，挑 3 种用）
3. 钩子开场 → 分点主体 → 互动结尾
4. 5–8 个中文标签
5. 首图 ≤12 字主标 + 副标
6. 6–9 张配图，3:4 竖版
7. 跑预览脚本 → 字数校验 → 违禁词扫描
8. 自查清单：搜索词进了标题/前 3 行/标签？
9. 提醒用户：勾选「AI 辅助创作」+ 替换 [待填]
```
