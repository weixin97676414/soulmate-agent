# 调研策略（WebSearch 多平台热点抓取）

> 热点数据统一用 `WebSearch` 从主流平台抓取，无外部 CLI 依赖。
> 优先用用户 `topics` 第一个垂类构造查询；每个垂类跑 2-4 组，覆盖不同平台维度。

## 各平台热点搜索词模板

| 平台 | 搜索词模板 | 抓什么 |
|------|-----------|--------|
| 知乎 | `知乎 热榜 {垂类}` / `知乎 {垂类} 高赞讨论` | 深度讨论、争议点、认知类切入 |
| 小红书 | `小红书 {垂类} 爆款笔记` / `小红书 {垂类} 热门` | 大众关注点、标题风格、情绪钩子 |
| 微信公众号 | `微信公众号 {垂类} 爆文` / `{垂类} 10万+ 文章` | 同行怎么写、成文选题、对标 |
| 微博 | `微博 热搜 {垂类}` / `{垂类} 微博 话题` | 实时热度、是否破圈 |
| 今日头条 | `今日头条 {垂类} 热点` / `{垂类} 头条 阅读量` | 下沉市场关注、资讯类热点 |
| 综合 | `今日热点 {垂类}` / `{垂类} 最新政策 2026` | 兜底 + 政策类硬热点 |

## SEO 信号搜索词

| 目的 | 搜索词模板 | 说明 |
|------|-----------|------|
| 搜索量/竞争 | `{关键词} 百度指数` | 估算 seo_score（1-10，标注"估算"） |
| 相关词 | `{关键词} 相关搜索 长尾词` | 丰富 SEO 友好度依据 |
| 常青词 | `{垂类} 教程 方法论 怎么学` | 找长尾、低竞争常青选题来源 |

## 判断规则

- **多平台命中**：同一话题在 ≥2 个平台出现 → 热度分 +2（封顶 10）。这是 WebSearch 抓取的核心优势，务必交叉比对。
- 搜索结果多且最新（近 7 天）→ 热度 5-7；仅零星旧闻 → 1-4；霸榜多平台 → 8-10。
- 明显有数据/工具/方法论可写 → 切入价值 +2（对应 content_style 加成）。
- SEO 分数无法精确时，按"搜索结果丰富度"给 1-10 估算值，并标注"估算"。
- 需要具体数据或完整论点支撑切入角度时，用 `WebFetch` 读高相关结果全文。

## 抓取节奏

- 单垂类：先跑综合 + 知乎/公众号 2-3 组定基本盘，再按需补小红书/微博/头条。
- 多垂类：每个垂类至少 2 组，确保各方向都有候选进入评分池。
- 不必穷尽所有平台，够 15-25 个候选话题进入第 3 步评分即可。
