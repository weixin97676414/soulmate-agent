# 输出格式（选题卡片）

> 每个选题按此卡片格式输出。Top 10 按总分降序排列。

---

### 选题 {序号}: {选题标题}（总分 X.X）{类型标记}

- **类型**：🔥热点 / 🌲常青 / 📚系列
- **对应标题候选（3-5 个，20-28 字）**：
  1. "{标题1}"
  2. "{标题2}"
  3. "{标题3}"
  （按 content_style 加权混排，至少含 1 个数字/反直觉型）
- **切入角度**：{1-2 句话说明怎么写、从什么角度切}
- **大纲预览**：
  - 开头钩子：{用什么引读者}
  - 要点1：{…}
  - 要点2：{…}
  - 要点3：{…}
  - 结尾：{行动号召/金句}
- **摘要候选**：{30-50 字，可直接贴公众号摘要}
- **热度**：X/10 | **相关度**：X/10 | **切入价值**：X/10
- **点击率潜力**：{高/中/低}，{原因，如"标题含数字+反直觉，点击率高"}
- **SEO 友好度**：{seo_score}/10，{引用数据，如"百度 8 + 360 10，相关词丰富"；无数据则注明"估算"}
- **SEO 优化建议**：
  - 核心关键词：{如"体制内副业"}
  - 推荐 5 标签：{2 行业大词 + 2 热点词 + 1 长尾词}
  - 摘要模板：{≤54 中文字，含核心词，带悬念/价值承诺，不重复标题}
  - 完读率提示：{如"建议清单型，2-4 个 H2，结尾 CTA 具体"}
- **合规提示**：{命中红线 → "🚫 合规风险：{具体风险}。改写方向：{…}"；否则"✅ 合规"}
- **推荐框架**：{痛点型/故事型/清单型/对比型/热点解读型}
- **推荐理由**：{为什么这个值得写}

## 系列策划附加格式（仅 D 模式）

### 系列总线：{系列名}

- **总主题**：{一句话}
- **读者学习路径**：{从入门到精通的递进逻辑}
- **规划篇数**：{N} 篇

#### 第 {k} 篇：{篇名}（总分 X.X）

（同上卡片格式，但标注「📚系列 第 k/N 篇」）

---

## 展示后交互

列出全部卡片后，提示用户：

```
请选择：
- 输入编号（如 1）→ 选定该选题
- 「调整 + 意见」→ 按意见修改后重新展示
- 「重新选」→ 换一批选题
- 「组合 1+3」→ 融合多个选题
- 系列模式：「先写第 N 篇」→ 按该篇进入写稿
```
