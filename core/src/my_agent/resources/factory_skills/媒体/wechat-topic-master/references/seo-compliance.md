# SEO 评分与合规闸门规则

> 本文件把 `seo-rules.md`（SEO 实操规范）与 `compliance-seo.md`（合规红线 + 微信低创作度标准）
> 转成选题阶段可用的「SEO 评分」与「合规闸门」。由 SKILL.md 第 2 步调用。
> 适用读者：体制内 / 公务员受众的公众号，合规优先级最高。

## 一、SEO 评分（seo_score，0-10）

seo_score = 搜索需求信号（0-4） + 结构可达性（0-6）。

### A. 搜索需求信号（0-4，来自 WebSearch 多平台）

用 WebSearch 搜「{关键词} 百度指数」「{关键词} 相关搜索 长尾词」「知乎 {关键词} 讨论量」，
结合第 1 步多平台抓取结果判断：

- 同垂类 3 个及以上平台有稳定讨论或搜索量，长尾词丰富 → 3-4 分
- 1-2 个平台有讨论、长尾词中等 → 2 分
- 仅零星提及，或搜一搜前 3 页全是高度同质爆文（竞争过饱和） → 0-1 分
- 常青选题不看热搜，看长尾搜索量（教程 / 方法论类搜索高 → 3-4 分）

### B. 结构可达性（0-6，按 seo-rules.md 判断该选题能否做好 SEO）

以下 4 项各 1.5 分，满足即得分：

1. **标题可控**：能提炼 20-28 中文字的核心关键词标题，不标题党（震惊 / 必看会被降权）、不学术、不模糊。
2. **关键词可布局**：有明确核心关键词，能放在前 200 字 + H2 标题 + 全文自然出现 3-5 次（用同义词替换避免堆砌）。
3. **标签可配**：能配齐 5 个精准标签（2 个行业大词 + 2 个热点词 + 1 个长尾词）。
4. **摘要可写**：能产出不超过 54 中文字、含核心关键词、带悬念或价值承诺、且不重复标题的摘要。

无真实搜索数据时，seo_score 标注「估算」。

## 二、合规闸门（compliance gate，来自 compliance-seo.md）

对每个选题做合规预检。命中任一条红线 → 标注「🚫 合规风险」，
同时在卡片给出具体风险点与改写建议，建议避开或改写后再用。体制内受众尤其要避开的排在前面。

### 红线清单（命中即触发扣分）

1. **夸大误导**：用「赚钱 / 搞钱 / 月入 X 万」等词。体制内受众改用「效率提升 / 合规增收 / 副业边界」。
2. **诱导分享或关注**：转发朋友圈得 XX、分享解锁、关注获取更多。
3. **诱骗点击**：震惊、不看后悔一辈子、必看等标题党话术。
4. **不实信息**：未注明出处的断言、过度承诺收益。引用数据须标来源。
5. **直接下载或外部导流**：放 .exe/.dmg 下载、外链拉人。
6. **编造不可验证经历**：低创作度标准明确禁止编造个人经历，属不实信息。
7. **短期灌水 / 同质化**：同结构同封面高频复刻。选题阶段标「需错峰，建议 3-4 天 1 篇」。
8. **过度营销 / 品牌硬广**：文末品牌露出、硬推产品。

### 成文阶段禁写（选题阶段标注提示）

文末禁用：「点个在看」「转发给朋友」「关注 XXX 获取更多」「品牌露出」。
图注禁用：「图片由 AI 生成」「配图 AI 生成，仅示意」。

### 低创作度规避（选题即定调）

微信低创作度官方标准：同质化、搬运抄袭、低信息量、低价值 AIGC 四类。
核心要求 = 真实个人经验 + 原创思考。
每个选题须能承载「个人经历 / 实测数据 / 独家对比」切入点，且含至少 30% 真实个人经验空间，
不能只做纯资讯搬运。

## 三、选题卡片新增字段（见 output-format.md）

每个选题卡片追加两块：

- **SEO 优化建议**：核心关键词 + 推荐 5 标签 + 摘要模板 + 完读率友好提示（清单型优先、H2 有信息量、结尾 CTA 具体）。
- **合规提示**：命中红线 → 具体风险 + 改写方向；否则标「✅ 合规」。
