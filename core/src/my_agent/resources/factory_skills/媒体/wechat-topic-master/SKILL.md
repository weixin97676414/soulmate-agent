# 公众号选题策划

> 一站式公众号选题引擎：把「量化评分」和「爆款标题 / 大纲 / 系列策划」合进一个自包含、零依赖的技能。
> 热点直接用 WebSearch 从知乎、小红书、公众号、微博、头条等主流平台抓取；SEO 评分与合规红线内置，
> 开箱即用，无需安装任何外部工具。

## 运行约定

- **热点数据源**：统一用 `WebSearch`（必要时配 `WebFetch` 读全文）从**知乎、小红书、微信公众号、
  微博、今日头条**等主流平台抓取，无任何外部 CLI 依赖，开箱即用。
- **`读取: <路径>`** = 用文件读取工具真实读完该文件再继续，不是注释。
- **references/**：本 skill 自带文档，`{skill_dir}` 即本目录。

## 前置（轻量）

- 方向 `topics`、风格 `content_style`、受众 `target_audience`、黑名单 `blacklist` 均由用户口述直接提供；
  都没给 → 用一句话问用户："你的公众号主要写哪几个方向？" 用回答临时代替 `topics`。
- 识别输入模式（决定后续数量与形态）：
  - **A 明确选题**：给了具体话题 → 围绕它给 3-4 个切入角度
  - **B 有方向**：给了领域没题目 → 筛 3-5 个
  - **C 无方向**：只说找选题 → 跑满 10 个（7-8 热点 + 2-3 常青）
  - **D 系列策划**：提到系列/专栏 → 给系列总线 + 拆篇

## 1. 热点抓取（WebSearch 多平台）

用 `WebSearch` 直接从主流平台抓取当前热点。**每个垂类跑 2-4 组查询**，覆盖不同平台维度
（详细搜索词模板见 `references/research-strategy.md`）：

- `知乎 热榜 {垂类}`、`知乎 {垂类} 讨论`
- `小红书 {垂类} 爆款笔记`、`小红书 {垂类} 热门`
- `微信公众号 {垂类} 爆文`、`{垂类} 热点文章`
- `微博 热搜 {垂类}`、`今日头条 {垂类} 热点`

**判据**：同一话题在多个平台同时出现 → 热度分 +2（评分见第 3 步）。必要时用 `WebFetch`
读高相关结果全文，为切入角度和数据支撑取料。

## 2. SEO 评分 + 合规闸门（WebSearch 多平台）

```
读取: {skill_dir}/references/seo-compliance.md
```

SEO 评分（0-10，规则见 `seo-compliance.md`）：

1. **搜索需求信号（0-4）**：用 WebSearch 搜「{关键词} 百度指数」「{关键词} 长尾词」「知乎 {关键词} 讨论量」，
   结合第 1 步多平台抓取结果判断搜索量与竞争度。无真实数据则标注「估算」。
2. **结构可达性（0-6）**：按 seo-rules 四要素（标题可控 / 关键词可布局 / 标签可配 / 摘要可写）逐项给分。
3. 汇总得 `seo_score`，写入选题卡片「SEO 友好度」字段。

合规闸门（compliance gate，规则见 `seo-compliance.md`）：

- 对每个候选选题预检 8 条合规红线。命中任一条 → 标注「🚫 合规风险」，并在卡片给具体风险点与改写方向，建议避开或改写后再用。体制内受众红线（夸大误导、编造经历、诱导分享）优先排查。
- 不命中的选题 → 标注「✅ 合规」，作为成稿素材的合规基线。

## 3. 生成选题（评分引擎）

```
读取: {skill_dir}/references/topic-selection.md
```

按 `topic-selection.md` 规则对每个候选打分，产出 **10 个选题**（C 模式）：

- **7-8 个热点选题**：基于第 1 步热点，三维加权评分后按总分降序。
- **2-3 个常青选题**：不依赖热点，从用户 `topics` 领域生成长尾内容（教程/方法论/经验/工具），标注「🌲 常青」。

## 4. 每个选题附「成稿素材」（本技能核心增量）

对**每一个**选题，额外产出（规则见 `references/title-presets.md`、`references/output-format.md`）：

- **3-5 个标题候选**：混合 5 种风格（悬念/干货/数字/反问/故事），按 `content_style` 加权。
- **切入角度**：1-2 句说明怎么写、从什么角度切。
- **大纲预览**：3-5 个要点骨架。
- **摘要候选**：1 段 30-50 字可贴摘要。
- **点击率潜力**（高/中/低）+ 原因。
- **SEO 友好度**（seo_score + 引用数据 / 标注「估算」）。
- **SEO 优化建议**：核心关键词 + 推荐 5 标签 + 摘要模板 + 完读率友好提示（规则见 `seo-compliance.md`）。
- **合规提示**：命中红线 → 具体风险 + 改写方向；否则「✅ 合规」。
- **推荐框架**：痛点型/故事型/清单型/对比型/热点解读型。
- **类型标记**：🔥热点 / 🌲常青 / 📚系列。

## 5. 系列策划（仅 D 模式）

给出系列总线（总主题 + 读者学习路径），再拆出每篇选题（每篇同样走第 3-4 步的评分与素材）。
系列规划直接输出，不落文件。

## 成品示例（选题卡片长这样）

展示时每个选题是一张卡片，样例如下（完整字段规则见 `references/output-format.md`）：

> **选题 1：体制内副业红绿灯（总分 9.4）🔥热点**
> - **标题候选**：① 体制内副业红绿灯：6 类能碰的，6 条绝对别碰 ② 想搞副业又怕丢铁饭碗？这份合规清单先收好
> - **切入角度**：用「绿灯 / 红灯」对照结构，把能做的和违纪的分开讲，主打信息差与安全感
> - **大纲预览**：开头钩子，从纪检干部送外卖切入；绿灯 6 类；红灯 6 条；结尾点题
> - **摘要候选**：体制内想搞副业怕踩线？6 类能做的加 6 条不能碰的，这份对照清单帮你安稳增收
> - **三维评分**：热度 9 / 相关度 10 / 切入价值 9
> - **点击率潜力**：高，标题含数字对照加安全感诉求，体制内人必点
> - **SEO 友好度**：10/10（搜索信号 4 与结构 6）
> - **SEO 优化建议**：核心词「体制内副业」加 5 标签加 ≤54 字摘要模板
> - **合规提示**：✅ 合规，成稿用「合规增收」替代「搞钱 / 月入」
> - **推荐框架**：清单型

## 6. 展示与选定

- 自动模式（用户说"直接给最好的"）→ 选最高分选题，附其全部成稿素材。
- 交互模式 / 单独激活 → 展示全部 10 个评分排序，等用户选。
- 展示后**必须停下等用户操作**（选编号 / 调整 / 重选 / 组合），禁止自作主张直接写稿。

选定后提示：
"可以直接说'就写这个'进入写作（配合排版工具成文）。"

## 完成

单独激活且用户只要选题列表时，展示 10 个即可。
