# 全网热榜查询与热点挖掘

把"今天大家都在关注什么"和"这个话题有没有内容机会"两件事一次做完：前者用热榜工具拉实时数据，后者用爆款挖掘方法论做多平台分析与创作角度输出。

## 适用场景

- 只想看热榜：指定平台（微博热搜、知乎热榜、B站热门……）。
- 指定主题汇总："看 AI 相关的热点并汇总"。
- 全网综合热点："帮我汇总今日热点"。
- 话题深挖："分析一下 XX 话题的热度、有哪些爆款、能从哪些角度切入"。
- 选题/定位：找热门选题、判断赛道是否还有蓝海。
- 竞品/传播追踪：某品牌、某事件在各平台的讨论度与传播路径。

## 一、热榜数据查询（工具）

数据来自本地 DailyHot API 服务，覆盖 56+ 中文平台，底层数据 60 分钟缓存。默认监听 `localhost:6688`，可用环境变量 `DAILYHOT_URL` 覆盖。

首次使用先确认服务在跑：

```bash
node scripts/query-hot.mjs zhihu
```

如果报"无法连接到 DailyHot 服务"，先启动服务（常驻后台，后续查询无需重启），启动后等 3–5 秒再查询：

```bash
node scripts/start-server.mjs
```

查询用法：

```bash
# 查询指定平台（默认显示 10 条）
node scripts/query-hot.mjs <platform>

# 自定义条数
node scripts/query-hot.mjs <platform> --limit 20

# 列出所有可用平台
node scripts/query-hot.mjs --all
```

依赖安装（首次，package.json 已声明依赖）：在技能目录执行 `npm install`。

### 常用平台速查

| 分类 | 平台键 |
|------|--------|
| 综合新闻 | `zhihu` 知乎、`weibo` 微博、`baidu` 百度、`douyin` 抖音、`kuaishou` 快手、`toutiao` 头条 |
| 科技/互联网 | `bilibili` B站、`36kr` 36氪、`sspai` 少数派、`ithome` IT之家、`csdn` CSDN、`juejin` 掘金、`v2ex` V2EX、`github` GitHub Trending |
| 媒体/社区 | `huxiu` 虎嗅、`thepaper` 澎湃新闻、`guokr` 果壳、`ifanr` 爱范儿、`douban` 豆瓣、`hupu` 虎扑、`tieba` 贴吧、`ngabbs` NGA |
| 其他 | `weread` 微信读书、`地震`、`历史上的今天` |

### 智能响应规则

1. 指定平台 → 直接查询该平台。
2. 指定主题 + 要求汇总（如 AI/科技）→ 并行查询 `36kr ithome zhihu sspai bilibili`，按关键词筛选后合并报告。
3. 要求综合汇总、未指定主题 → 并行查询 5 个头部平台 `zhihu weibo bilibili douyin baidu`，各取 Top 5，按平台分组输出。
4. 模糊请求（"看看热点"）→ 推荐 3–5 个常用平台，引导用户选择。
5. "有哪些平台" → 执行 `--all`。

用户同时查 3 个以上平台时**必须并行查询**，避免串行等待：

```bash
node scripts/query-hot.mjs zhihu --limit 5 &
node scripts/query-hot.mjs weibo --limit 5 &
node scripts/query-hot.mjs bilibili --limit 5 &
node scripts/query-hot.mjs douyin --limit 5 &
node scripts/query-hot.mjs baidu --limit 5 &
wait
```

单条热榜数据含：标题（必有）、描述（如有，截断 120 字）、热度值（如有，格式化为万/亿）、作者（如有）、数据来源、更新时间、总条数。

## 二、热点/爆款挖掘（方法论）

核心流程：

```
输入话题 → 关键词提取 → 多平台搜索 → 数据验证 → 关键词聚合 → 创作角度输出
```

### Step 1 关键词提取与扩展

提取核心关键词（人名/地名/事件名/产品名），再扩展关联词：相关人物与机构、地点与场景、话题与标签、情绪词与热词。输出：核心关键词、关联关键词、搜索关键词组合。

方法细则见 `references/keyword-extraction-guide.md`。

### Step 2 多平台搜索

按优先级检索，爆款标准与内容特点见下（完整标准见 `references/platform-standards.md`）：

| 优先级 | 平台 | 爆款标准（参考） |
|--------|------|------------------|
| P0 | 抖音 | 点赞 10w+ / 播放 100w+ |
| P0 | 小红书 | 收藏 1w+ / 点赞 5w+ |
| P0 | 公众号 | 阅读 10w+ / 点赞 1000+ |
| P0 | 快手 | 播放 50w+ / 点赞 5w+ |
| P0 | B站 | 播放 50w+ / 弹幕 5000+ |
| P1 | 微博 | 讨论 10w+ / 阅读 1 亿+ |
| P1 | 视频号 | 点赞 1w+ / 转发 5000+ |
| P1 | 知乎 | 点赞 1w+ / 收藏 5000+ |
| P2 | 新浪/搜狐 | 门户推荐 / 评论 1000+ |
| P2 | 百度 | 热搜上榜 / 搜索指数 |

P0 必查、P1 重要补充、P2 趋势验证。P0 平台结果不足 3 条必须换词重搜；P1 不足 2 条可标注"内容较少"；P2 不足 1 条可不显示。

搜索词组合模板（"基础热门/基础数据 + 平台名 + 内容类型"），逐条采集：文章话题、标题、描述（50–100 字）、平台、发布时间、互动数据、来源链接。

### Step 3 数据验证与清洗

- **时效性（强制）**：优先近 30 天内；实时热点（24h）、新鲜爆款（3 天）、持续升温（7 天）优先纳入；30 天以上丢弃/仅作历史参考；时间未知标注 🕐。
- **互动数据**：来自搜索结果，禁止编造；达到平台爆款标准才算爆款。
- **平台归属**：核对 URL 域名/平台标识。
- **数据真实性**：多来源交叉验证；待验证标 ⚠️，已验证标 ✅。

置信度与标注说明见 `references/data-confidence.md`。

### Step 4 关键词聚合分析

四个维度：高频词云（词频表）、情绪词分布（正面/负面/中性）、内容类型分布（攻略型/体验型/观点型/信息型）、平台热度对比。搜索频率等级（🔥 数量=频率）与内容策略联动：极高频竞争激烈需差异化、中高频是红利期、低频是机会窗口。

### Step 5 创作角度输出

四类角度挖掘：空白角度（高热度+内容少）、差异化角度（爆款的反向/补充）、热点结合（话题+节日/季节/社会热点）、人群细分（话题+特定人群）。挖掘指南见 `references/angle-mining-guide.md`。

角度评估矩阵（热度 30% / 竞争 25% / 差异化 20% / 实用性 15% / 传播性 10%，各 1–10 分），爆款潜力评级：≥90 极高、80–89 高、70–79 中、60–69 低、<60 不建议。

## 三、输出规范

至少产出下列模块（按需求取用）：

1. **关键词云报告**：核心关键词、关联关键词、高频词云表（词+次数+情绪属性+内容类型+搜索频率）。
2. **爆款作品库**：文章话题、标题、描述、平台、搜索频率、时效性、验证数据、爆款标准、来源链接。
3. **平台热度分析**：各平台爆款数量/平均互动/热门内容类型/风格特点/推荐指数；平台适配建议表。
4. **创作角度建议**：推荐角度汇总表 + 各角度五维评分 + 平台适配矩阵（✅强烈推荐 / ⚠️可以适配 / ❌不太适合）。
5. **爆款规律总结**：标题规律、内容规律、传播规律、各平台爆款公式。

输出格式模板与示例见本文件下方及原技能示例；保持表格化、可快速浏览。

## 四、两种处理模式

- **模式 A 全网热点模式**（无具体话题）：搜索各平台热榜 → 提取共性话题按频率排序 → TOP 热点简要分析 → 推荐创作角度。
- **模式 B 指定话题模式**（有具体话题/平台）：提取并扩展关键词 → 多平台精准搜索 → 数据验证清洗 → 聚合分析 → 输出创作角度。

## 五、注意事项

- 搜索工具无法获取所有平台的精确互动数据，部分数据需从搜索结果推断，均须标注来源与置信度；所有爆款内容必须有来源链接，互动数据禁止编造。
- 时效性以搜索时点的快照为准；结果均为历史内容时标注"近期内容较少，以下为历史参考"。
- 搜索工具不可用时报错时：说明当前无法获取实时数据 → 基于已有知识给一般性分析 → 建议稍后重试或提供具体话题。
- 热榜接口为第三方聚合服务，平台覆盖与可用性以实际返回为准（未验证项：具体平台清单随服务版本变动）。
