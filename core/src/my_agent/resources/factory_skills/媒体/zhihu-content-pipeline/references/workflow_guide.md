## 前置准备

2. 技能会自动从浏览器提取 Cookie

```bash

```

## 回答工作流

### 输入格式

```
开始知乎回答工作流，领域关键词：文献检索、论文下载、外文文献
```

### 流程

1. **数据抓取**：使用同族选题采集能力（`zhihu-topic-selection`）采集最新数据
2. **选题筛选**：按关键词匹配推荐问题和邀请回答，按浏览量排序
3. **知识库准备**：加载 `references/knowledge_base.md`，询问是否需要上传额外资料
4. **内容生成**：对每个选题调用同族回答写作能力（`zhihu-answer-writing`）生成回答
5. **草稿发布**：使用同族草稿能力（`zhihu-auto-publish`）逐篇保存草稿
6. **看板生成**：生成 `dashboard.html`

### 自定义项

- 选题数量：默认 5 个
- 回答字数：默认 300-600 字
- 关键词：可组合（AND/OR 逻辑）

## 文章工作流

### 输入格式

```
开始知乎文章工作流
```

### 流程

1. **数据抓取**：同回答工作流
2. **选题分析**：从热榜+推荐+邀请中归纳 5 个文章方向
3. **用户确认**：选择 1 个方向，其余存入备选库
4. **写作框架**：生成写作框架（结构+提示词+封面提示词），用户可调整
5. **知识库准备**：加载内置知识库，询问是否上传额外资料
6. **内容生成**：调用同族文章写作能力生成文章（去 AI 味）
7. **草稿发布**：使用同族草稿能力（`zhihu-auto-publish`）发布文章草稿
8. **看板更新**：更新 dashboard.html

### 自定义项

- 文章方向数：默认 5 个
- 文章字数：默认 800-1100 字
- 写作风格：口语化程度、是否用小标题等均可在写作框架阶段调整

## 知识库管理

### 持久化知识库

`references/knowledge_base.md` 是持久化的领域知识库，会在每次写作时自动加载。包含：

- 核心观点
- 产品/服务介绍
- 常见回答要点
- 写作风格偏好

### 临时参考资料

每次写作前，系统会提问：

```
📚 是否有参考资料需要上传？
  支持格式：文档(.pdf/.docx/.txt/.md)、链接(URL)、直接粘贴文本
  回复"跳过"或直接提供资料
```

临时资料仅在当次写作中生效，不会保存到知识库中。

### 多领域支持

如果要切换创作领域：

1. 备份当前 `knowledge_base.md`
2. 复制 `knowledge_base_template.md` 为新的 `knowledge_base.md`
3. 填充新领域知识

未来可通过配置插件目录方式管理多个知识库。

## 注意事项

1. **Cookie 有效期**：知乎 Cookie 一般 7-30 天有效，过期后需重新登录提取
2. **发布间隔**：回答发布时建议使用 `--delay 120` 参数，模拟真人间隔，避免触发风控
3. **去AI味检查**：每次发布前脚本会自动执行去AI味检查，检测到 HIGH 级别风险会阻止发布。检查清单包括：编号分层、AI高频词、总结收尾、夸张用词、缺少口语词等
4. **文章发布频率**：建议每天不超过 1 篇文章，避免触发平台审核
5. **草稿审核**：所有内容仅保存为草稿，需要用户在知乎后台手动审核发布
6. **看板数据**：运行 `python scripts/generate_dashboard_data.py` 生成数据后，`dashboard.html` 支持日期筛选查看历史记录

## 去AI味检查规则

发布脚本内置以下检查清单，内容生成后自动扫描：

| 检查项 | 风险 | 触发条件 | 处理 |
|--------|------|---------|------|
| 编号分层 | HIGH | 出现"第一层/第二层"等 | 改用自然叙述 |
| 序号列举 | HIGH | "首先...其次...最后"结构 | 用"然后/还有/另外" |
| AI高频词 | HIGH | "此外/确保/强调/关键/总之" | 删除或用口语替代 |
| 总结收尾 | HIGH | "总之/综上所述"开头 | 直接结束或用"反正" |
| 夸张用词 | MEDIUM | "颠覆/震撼/革命性/绝了" | 用克制表达 |
| 缺少口语 | LOW | 口语词<2个 | 增加"说实话/对吧"等 |

## 发布命令示例

```bash
# 单篇发布（带去AI检查和120秒间隔）
python scripts/publish_answer.py --url "https://www.zhihu.com/question/xxx" --content answer.txt --headless --delay 120

# 强制发布（忽略AI检查）
python scripts/publish_answer.py --url "..." --content answer.txt --headless --force --delay 120

# 仅检查不发布
python scripts/publish_answer.py --url "..." --content answer.txt --dry-run
```
