# 商业与行业研究写作

本技能聚焦研究长文的写作规范与引用体例（真实来源、编号脚注、表格与 Mermaid 图）；公众号财经体裁文章与公众号正文排版不由本技能承担。

## 适用场景

- 撰写行业研究报告、商业洞察、咨询分析、公司研究、竞品分析、用户研究、市场分析。
- 触发：需要产出商务/研究类长文的写作任务。

## 步骤

1. 明确主题与分析框架；收集可引用的资料。
2. 用**真实来源**支撑论点；引用须出现在逻辑相关位置，禁止无关或强行引用；**禁止编造任何数据或证据**。
3. 内容要详实、有深度。
4. 输出：全篇 Markdown；多属性条目用表格；趋势/关系用 Mermaid 图（数据源必须真实）。
5. 逐条标注引用并列出参考文献。

## 写作规范

- **语言**：默认用与用户提问相同的语言输出；除不可译的专有名词/术语外，不得中英混杂。
- **表格**：鼓励多用；当条目含多个可表格化的属性时使用 Markdown 表格（数据必须真实）。
- **图表**：鼓励多用 Mermaid 图（数据必须真实）。
- **引用**：引用他人具体信息/发现/观点时，在相应句子或短语后立即加引用标记；标记必须是可点击编号脚注 `[编号](URL)`，如 `[1](https://link-to-source-1.com)`；文末按 1~N 顺序列完整参考文献，每条可导航查看详情。
- 全篇使用 Markdown。

## 输入输出

- 输入：研究主题、行业/公司/竞品范围、可用资料。
- 输出：结构化 Markdown 长文（含表格、Mermaid 图、编号脚注与参考文献列表）。

## 注意事项

- 引用与数据必须真实、可核验；不为凑引用而引用。
- 本技能为**纯提示词规范**，无脚本依赖；输出质量取决于可用真实资料。

## 可复用示例

写"2026 年智能手表竞品分析"：先用真实资料 → 表格对比 Apple Watch vs Huawei GT（价格/续航/健康功能，数据真实）→ Mermaid 画竞争格局 → 每处结论后加 `[n](url)` 脚注 → 文末列参考文献。
