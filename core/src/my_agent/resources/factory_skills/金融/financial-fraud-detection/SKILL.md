# 财务造假 / 财报操纵风险识别


## 适用场景

- 分析年报、审计报告、财务报表，或怀疑存在会计操纵时，从 PDF 或已提取的报表文本做**有证据支撑**的造假风险评估。
- 触发：造假风险、操纵风险、盈利质量评估、从 PDF/文本中提取红旗信号、跨公司或跨期做有证据的对比。
- **不用于**：没有源文件的泛泛投资建议；大盘行情评论；与报告证据无关的估值建模。

核心规则：**结论必须绑定证据，缺失的证据必须保持可见。**

## 步骤（Workflow）

1. **确认源材料**：来源类型、公司名称、报告年度，输入是 PDF、提取文本还是两者都有。
2. **抽取可用事实**：聚焦主表关键科目、附注、审计意见、治理层披露。
3. **三分类归置发现**：明确异常 / 弱信号 / 缺失数据。
4. **为每条明确异常挂证据**：优先带页码的原文摘录；无页码时明确说明无页码。
5. **覆盖不全时下调确定性**：核心字段或附注证据缺失时，结论须写明「不完整」或「待复核」。

## 证据规则（硬性）

- 绝不编造数字、摘录、页码、比率或因果解释。
- 优先用报告一手证据，而不是用户写的摘要文字。
- 优先页码摘录，而不是转述。
- 若信号来自计算，必须同时给出源值 + 计算依据。
- 证据不完整时，信号保持「弱信号/待复核」，不得拔高。
- 抽取噪声大或不可靠时，直接说明。

## 输出结构（按此顺序）

1. **报告摘要**：公司、期间、审计意见、总体风险判断。
2. **明确异常**：仅有报告证据支持的信号。
3. **弱信号**：尚不足以支撑确定结论的疑点。
4. **缺失数据**：削弱可信度的字段/附注/证据缺口。
5. **证据摘录**：有页码时优先 `原文摘录（第X页）: ...`。
6. **复核建议**：下一步需要人工核查什么。

### 信号分类

**明确异常**（报告提供直接支撑）示例：审计意见问题；收入/利润/现金流互相矛盾；有数值或附注支撑的应收/存货异常；有明确披露的治理问题；有原文引用的会计政策/估计变更。

**弱信号**（有暗示但不完整）示例：比率恶化但无附注佐证；异常变动无附注披露；叙述前后不一致且无数字支撑。

**缺失数据**（分析通常依赖但缺失/不可读/无证据）示例：缺经营现金流支撑；缺销售收现；缺减值/补贴/或有负债的附注摘录；核心表行缺页码锚点。

## 输入 / 输出

- **输入**：年报/审计报告 PDF 或提取文本；公司名、报告年度、审计意见。
- **输出**：见 `assets/造假识别_报告大纲.md`；中文模板如下：

```text
报告摘要
- 公司/年度:
- 审计意见:
- 总体判断:

明确异常
- 信号名:
  证据:

弱信号
- 信号名:
  原因:

缺失数据
- 字段/附注:
  影响:
```

## 注意事项（常见错误）

- 把每个异常都当成已确认的造假信号。
- 需要数字证据时，拿叙述性文字当证据。
- 用自信的风险评级掩盖缺失数据。
- 证据不完整时给出买/持/卖式建议。
- 引用数值却不说明来源。

**交付自检**：见 `assets/造假识别_交付自检清单.md`（其中注明：不编造数字、缺失数据保持可见、结论必须绑定证据）。

## 可复用示例

**示例 1**
> 输入：某公司 2025 年报 PDF + 「帮我看看有没有造假风险」
> 流程：确认公司/年度/审计意见 → 按 `assets/造假识别_分析清单.md` 抽主表与附注字段并标页码 → 归入明确异常/弱信号/缺失数据 → 每条明确异常给「原文摘录（第X页）」→ 按报告大纲输出，末尾给复核建议。

**示例 2（信息不足）**
> 输入：只有一段二手摘要文字
> 流程：说明缺少一手报告证据，仅能输出弱信号与缺失数据，不出确定结论、不编造页码与数字。
