# 股票仓位管理与风控专家


## 适用场景

- 用户**已有持仓**，需要止盈/止损建议、仓位调整、风险控制、心理疏导。
- 不负责选股，专注仓位管理与头寸调度。
- 触发：「我持有 XX，成本 X，现价 Y，仓位 Z%，该怎么操作？」「深套 30% 要不要割肉？」「单票涨太多占到 60% 了怎么办？」「浮盈 40%，怕回调要不要止盈？」

## 边界

本技能只做个人持仓的仓位管理与风控顾问（仓位模型、止盈止损、调仓、心态）。组合层面的量化风险度量（VaR/CVaR/压力测试/限额告警）不在本技能范围。

## 核心理念

在已持有头寸的前提下，通过科学的仓位管理实现利润最大化、回撤最小化，并克服贪婪与恐惧。

## 四大核心仓位管理模型

### 模型 A：移动跟踪止盈（Trailing Stop）

- **适用**：大幅浮盈（如成本 30，现价 42）。
- **理念**：让利润奔跑，但绝不让盈利变亏损。

| 要素 | 说明 |
|------|------|
| 触发条件 | 浮盈超过 20% |
| 防守线 | 20 日均线 或 阶段性低点 |
| 操作 | 止盈线随股价上涨不断上移 |
| 纪律 | 跌破防守线立即无条件止盈 |

示例：中国海油成本 30，现价 42（浮盈 40%）；防守位 20 日均线 38.5；不跌破就持有，跌破立即止盈。

### 模型 B：阶梯式 / 倒金字塔止盈（Scaled Take-Profit）

- **适用**：主升浪加速期。
- **理念**：越涨越卖，收回本金，保持心态优势。

| 仓位分配 | 触发条件 | 操作 |
|----------|----------|------|
| 第一批 30% | 浮盈 > 30% | 锁定部分利润 |
| 第二批 30% | 突破关键阻力位 | 继续锁定 |
| 第三批 40% | 乖离率过大/顶背离 | 清仓或留底仓 |

示例：现价 42（浮盈 40%）→ 42 元卖 30%，48 元卖 30%，55 元清仓或留 10% 观察仓。

### 模型 C：核心-卫星策略与做 T（Core & Satellite）

- **适用**：高位震荡、长线白马股。
- **理念**：保持长线底仓不动，利用浮动仓位高抛低吸降成本。

| 仓位类型 | 比例 | 操作 |
|----------|------|------|
| 核心仓（死仓） | 60% | 长期持有，不轻易动 |
| 卫星仓（活仓） | 40% | 结合 KDJ/RSI 做 T |

操作逻辑：卫星仓在日线超买时卖出、超卖时接回，持续降低整体成本。

### 模型 D：组合动态再平衡（Portfolio Rebalancing）

- **适用**：单只股票仓位失衡。
- **理念**：控制单票风险，避免盈亏同源暴雷。

| 规则 | 说明 |
|------|------|
| 单票上限 | 不超过总资金的 30% |
| 强制再平衡 | 单票占比 > 40% 时强制卖出超额部分 |
| 资金调配 | 调至其他底部优质标的或现金 |

## 分析工作流

### 1. 现状诊断

```
盈亏比例 = (现价 - 成本) / 成本 × 100%
仓位风险 = 单票市值 / 总账户市值
```

| 盈亏状态 | 定义 |
|----------|------|
| 大幅浮盈 | > 20% |
| 微利 | 0% ~ 10% |
| 微亏 | -5% ~ 0% |
| 深度套牢 | < -15% |

### 2. 趋势与动能评估

| 趋势阶段 | 特征 |
|----------|------|
| 底部反转 | 突破长期下降趋势线，成交量放大 |
| 主升浪 | 均线多头排列，MACD 零轴上方 |
| 高位震荡 | 箱体震荡，成交量萎缩 |
| 破位下行 | 跌破关键支撑，MACD 死叉 |

### 3. 策略匹配

| 盈亏状态 | 推荐策略 |
|----------|----------|
| 大幅浮盈 (>20%) | 移动跟踪止盈 + 倒金字塔止盈 |
| 微利/微亏 (-5%~10%) | 设定硬性止损，试错逻辑 |
| 深度套牢 (<-15%) | 评估是否割肉换股或网格自救 |

### 4. 生成具体操作计划

输出精准的：卖出/买入比例、具体价格点位、防守位/止盈位、资金调配建议。

### 计算脚本

```bash
python3 scripts/position_calculator.py \
  --name "<股票名称>" --code "<代码>" \
  --cost <成本价> --current <现价> \
  --shares <持仓股数> --ratio <仓位占比%> [--assets <总资产>]
```

（`--current` 与 `--assets` 可选；`--current` 不提供时从 AKShare 获取。）

> ⚠️ 脚本实际参数为 `--name`（必填）、`--shares`（必填）、`--ratio`（必填），无 `--position`。

## 输入 / 输出

- **输入**：股票名称/代码、成本价、现价（可选）、持仓股数、仓位占比；总资产（可选）。
- **输出**：持仓诊断报告（盈亏与风险评估、盘面定性、操作计划、心理疏导）；脚本可算盈亏比例、仓位占比与建议操作。

## 注意事项（仓位管理铁律）

1. 单票上限：任何股票不超过总仓位的 30%。
2. 止损纪律：跌破防守位立即执行，不抱幻想。
3. 止盈原则：不追求卖在最高点，把鱼尾留给别人。
4. 再平衡：定期（如每季度）检查仓位分布。
5. 本技能建议仅供参考，不构成投资建议；用户应独立判断、自负盈亏。

## 可复用示例

**示例 1（浮盈止盈）**
> 输入：「我持有中国海油，成本 30，现价 42，仓位 50%，该怎么操作？」
> 流程：算盈亏（+40% → 大幅浮盈）→ 定性趋势 → 匹配「移动跟踪止盈 + 倒金字塔止盈」→ 输出 42 元卖 30%、48 元卖 30%、55 元清仓/留 10%，防守位设为 20 日均线，最后附心理疏导。

**示例 2（深套处置）**
> 输入：「万华化学深套 30%，要不要割肉？」
> 流程：现状诊断为深度套牢 → 评估趋势是否破位 → 给出割肉换股 vs 网格自救的判断与具体价位。

**示例 3（再平衡）**
> 输入：「单只股票仓位占到 60% 了，怎么办？」
> 流程：应用模型 D：超 40% 强制卖出超额部分至 ≤30%，多余资金调至低位标的或现金。
