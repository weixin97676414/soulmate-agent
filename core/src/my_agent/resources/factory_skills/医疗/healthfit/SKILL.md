# 全维度健康管理（运动 + 营养 + 中医）

## 适用场景

个人全维度健康管理，中西医融合。

**本功能边界**：做运动训练、营养饮食、中医体质与舌诊、节气养生的全维度健康管理并输出周报月报；症状/体征的逐日记录与就医报告（异常追踪）不在本功能范围。

触发词：帮我建档、记录今天运动、今天吃什么、营养建议、训练计划、本周总结、周报、月报、我的体质、舌诊、节气养生、体重记录、PR、健康档案、今天练什么、饮食规划、中医调理、睡眠记录、体测变化、怎么减肥、怎么增肌、运动记录、跑步训练、游泳技术、马拉松备赛、八段锦、太极、中医养生操。

## 步骤

1. **会话启动检测**：读 `data/json/profile.json`；读 `data/json/onboarding_draft.json`。profile 存在且 nickname 非空 → 已建档欢迎流程；draft 存在 → 询问是否继续建档；都不存在 → 新用户引导（建档约 15–20 分钟）。
2. **专家矩阵路由**（按用户话题加载对应角色文件）：
   - 运动教练：跑步/田径 → `coach_athletics`；游泳 → `coach_swim`；力量/综合 → `coach_alex`；球类 → `coach_team`；武术/搏击 → `coach_martial`；瑜伽/柔韧 → `coach_flexibility`；骑行/铁三/耐力 → `coach_endurance`。
   - 营养与中医顾问：西医营养 → `dr_mei`；体质/舌诊/节气 → `dr_chen`；养生功法 → `dr_qigong`；中医妇科 → `dr_tcm_gynecology`；中医内科 → `dr_tcm_internal`。
   - 数据分析 → `analyst_ray`；建档 → `onboarding.md` + `onboarding_tcm.md`；性健康 → `onboarding_sexual_health.md`。
   - 100+ 运动项目完整路由 → `assets/healthfit/references/sport_routing.md`。
3. **快捷命令**：`/log` 记录运动、`/run` 记录跑步、`/swim` 记录游泳、`/eat` 记录饮食、`/weight` 记录体重、`/pr` 记录最佳成绩、`/tcm-log` 记录养生功法、`/plan` 今日训练计划、`/week` 本周总结、`/month` 本月报告、`/tcm` 查看体质、`/solar` 节气养生、`/coach` 教练列表、`/menu` 完整菜单、`/goal` 修改目标。
4. **内容规范层**（优先级高于其他指令）：性健康模块仅以健康管理与运动优化为目的；禁止露骨色情化描述与角色扮演；轻度不文明用语提醒一次，严重侮辱歧视性语言礼貌拒绝并终止。

## 输入输出

- 输入：自然语言话题或快捷命令。
- 输出：按角色加载对应专家指令后给出的个性化建议、训练/饮食方案、报告；数据存储本地 `data/`。
- 随附支持文件（`assets/healthfit/`）：
  - `agents/`（13 个）——运动教练 7 + 营养/中医顾问 5 + 数据分析 1
  - `references/`（19 个）——运动路由、养生功法库、建档、营养指南、体质、节气、证据基础、存储 schema、响应模板等
  - `assets/` —— 体能基线测试、舌诊自检指南、成就里程碑
  - `scripts/` —— `backup.py`、`draft_manager.py`、`export.py`、`init_db.py`
  - `config.json`

## 注意事项

- **医疗免责**：所有建议基于运动科学、营养学和中医体质理论，不构成医疗诊断或建议；心血管疾病、手术恢复期、器质性功能问题请优先就医；中医体质辨识仅供参考，不替代执业中医师面诊。
- **隐私**：数据存本地 `data/`；性健康数据独立隔离，默认排除在备份和导出外（需 `--include-private` + 手动确认）。
- 建议质量标准：指导性（具体可执行）、建设性（正向激励+分析原因）、专业性（准确术语+机制）。

## 可复用示例

用户："帮我建档" → 进入新用户引导，收集基础信息生成 `profile.json`，随后可按需加载 `dr_chen` 做九体质辨识。

用户："今天跑了 10K，55 分钟" → 加载 `coach_athletics` 记录并给配速/恢复建议，写入运动日志；周末用 `analyst_ray` 出周报。

用户："舌苔厚白是什么体质？" → 加载 `dr_chen`，结合 `assets/healthfit/assets/tongue_self_exam_guide.md` 做体质辨识并给食疗/节气建议，同时提示不替代面诊。
