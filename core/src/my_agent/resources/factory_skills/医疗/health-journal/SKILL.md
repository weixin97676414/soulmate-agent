# 个人健康档案与数据管理

## 适用场景

持续逐日记录个人症状与体征，形成可追溯健康档案，做异常追踪并输出每日总结与风险分级。

**本功能边界**：只做症状/体征的逐日记录 + 就医报告（异常追踪）；运动训练、营养饮食、中医体质、节气养生等全维度健康管理不在本功能范围。

触发："帮我记一下今天症状"、"生成今天健康总结"、"结合最近趋势判断"、"整理就诊时间线"、"哪些情况要去医院"；以及"给我一份这个月的健康总结"、"帮我准备明天看医生的健康报告"、"我最近健康状况如何"。

## 步骤

1. 读取近 7–14 天记录，必要时回看 30 天，优先关注"变化趋势"。
2. 根据当天主诉提炼一个简洁"症状总结"用于目录命名。
3. 创建当日目录并写入 `记录.md`（或追加更新）。
4. 用户要求总结或晚间收尾时生成 `每日总结.md`。
5. 在聊天中同步精简摘要：当前趋势（改善/波动/加重）+ 当日处理建议 + 需尽快就医的红旗信号。
6. 生成"给医生的健康报告"时：汇集近期体征（血压、体重、血糖）、用药、症状、睡眠、运动 → 识别趋势（改善/稳定/恶化）→ 按 体征 / 用药 / 症状 / 生活方式 / 备注 分节 → 标出需就医注意项 → 询问是否导出或分享。

## 输入输出

- 档案目录规则：健康档案根目录 `./health-archive`（相对本技能目录，可按本机环境调整）；每日目录命名 `YYYY-MM-DD_症状总结`；每日文件 `记录.md`（当天原始与追加记录）、`每日总结.md`（当天结构化总结）。
- 随附模板（`assets/health-journal/`）：`symptom-template.md`（症状记录模板）、`daily-summary-template.md`（每日总结模板）、`risk-flags.md`（风险分级与就医提示）。
- 输出规范：每次分析先说明趋势依据（来自最近记录中的哪些变化）；建议分层为「居家观察与生活方式 / 短期复评节点（24h / 48h）/ 就医阈值（出现哪些表现立即线下就医）」；避免确定性诊断语气，用"可能性 + 证据 + 下一步验证"。

## 注意事项

- 安全边界：不记录身份证号、手机号、住址、账号口令等隐私敏感信息；不将真实姓名、具体医院号、检查条码发布到外部平台；涉及急症信号优先建议及时线下就医或急诊。
- 结果仅作健康管理与风险提示，不替代线下面诊。

## 血压参考标准

| 分类 | 收缩压 (mmHg) | 舒张压 (mmHg) |
|------|-------------|-------------|
| 正常 | < 120 | < 80 |
| 正常偏高 | 120-129 | < 80 |
| 高血压前期 | 130-139 | 80-89 |
| 高血压 1 级 | 140-159 | 90-99 |
| 高血压 2 级 | ≥ 160 | ≥ 100 |

## 可复用示例

输入："今天头有点晕，血压 145/92，早上忘吃降压药了。"

期望输出：读取近期记录核对血压趋势 → 写入 `记录.md` → 简明摘要（当前趋势：血压偏高且漏服；建议：补服遵医嘱、复测并记录；就医阈值：若持续 ≥160/100 或伴胸痛/视物模糊/肢体无力立即就医）→ 晚间生成 `每日总结.md` → 提示 `assets/health-journal/risk-flags.md` 中的红旗清单。
