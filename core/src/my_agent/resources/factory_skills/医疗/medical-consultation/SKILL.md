# 医疗咨询与就医建议

## 适用场景

面向普通用户的身体不适咨询与就医指引。触发场景：

- 症状分析（"我喉咙咳嗽，为什么"）
- 就医建议（"我应该挂什么科"）
- 疾病查询（"感冒的症状有哪些"）
- 健康建议（"如何预防流感"）
- 医学文献查询（"查找关于 XX 病的治疗研究"）
- 药品信息查询（"布洛芬的副作用是什么"）

## 步骤

1. **症状收集**：主要症状（哪里不舒服、什么感觉）、持续时间、症状特点（程度/频率/加重缓解因素）、伴随症状（发热/头痛/恶心等）、既往病史（疾病史、过敏史）、近期情况（饮食、作息、接触史）。
2. **权威数据查询（可选，按需调用脚本）**：
   - 医学文献：`python scripts/query_pubmed.py "cough treatment" --limit 5`（`--year YYYY` 限制发表年份，默认去年）。
   - 药品信息：`python scripts/query_openfda.py "ibuprofen" --type label`；不良事件：`--type events`；`--limit N` 默认 5。
   - 调用时机：问药品信息 → OpenFDA；问某病治疗/病因/研究 → PubMed；要求引用权威来源 → 两个都调。
   - 网络失败处理：告知"网络查询暂时不可用"，基于内置知识给一般性建议，建议用户访问官网查询。
3. **初步分析**：列可能原因、严重程度判断（是否需立即就医）、建议科室。
4. **提供建议**：家庭护理（饮食/休息/环境）、用药参考（仅非处方药，须说明仅供参考）、就医建议（何时去医院、可能检查）。
5. **安全警示（必须包含）**：
   > ⚠️ 重要提醒：我不是医生，以上建议仅供参考，不能替代专业医疗诊断。如果症状严重或持续不缓解，请及时就医。

## 输入输出

- PubMed 响应字段：`pmid`、`title`、`authors`、`journal`、`pubdate`、`abstract`、`link`。
- OpenFDA 响应字段：`brand_name`、`generic_name`、`manufacturer`、`indication`、`warning`、`dosage`、`active_ingredient`、`route`、`source_url`。
- 输出结构：`【症状分析】` → `【权威参考】（PubMed / OpenFDA）` → `【建议】` → 免责提醒。

## 注意事项

- **不提供确诊**（只给可能性与建议）；**不推荐处方药**（只可提及非处方药作参考）；持续或严重症状鼓励及时就医；识别紧急症状。
- 引用 API 时务必标注来源（PubMed / OpenFDA）；提醒医学数据可能滞后，以最新指南为准。
- 紧急症状立即就医清单：胸痛、呼吸困难；剧烈头痛、意识模糊；大量出血；高热不退（>39°C）；严重外伤；持续剧烈腹痛；过敏反应（呼吸困难、喉咙肿胀）。

## 常见症状对应科室参考

| 症状 | 推荐科室 |
|------|---------|
| 发热、咳嗽、感冒 | 呼吸内科 / 发热门诊 |
| 腹痛、腹泻 | 消化内科 |
| 头痛、头晕 | 神经内科 |
| 心悸、胸闷 | 心血管内科 |
| 皮肤问题 | 皮肤科 |
| 眼睛问题 | 眼科 |
| 耳朵问题 | 耳鼻喉科 |
| 牙齿问题 | 口腔科 |
| 女性妇科问题 | 妇科 |

## 可复用示例

用户："我咳嗽两周了，需要挂什么科？"

期望输出：`【症状分析】` 列可能原因（感染后咳嗽、过敏性咳嗽、上气道咳嗽综合征等）→ `【权威参考】` 可按需调用 `query_pubmed.py "cough treatment" --limit 5` 并标注来源 → `【建议】` 家庭护理 + 建议呼吸内科门诊 + 需尽快就医的红旗（咯血、呼吸困难、持续发热）→ 免责提醒。
