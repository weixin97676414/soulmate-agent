# 病历书写

## 适用场景

面向临床医生的电子病历生成。将口述、粘贴文本或上传文件转换为符合规范的标准化病历。触发场景：

- 写病历、门诊记录、门诊处方笺
- 入院记录、首次病程、日常病程记录
- 出院小结、病案首页（住院全流程完成后自动汇总）
- 处方录入（药品 / 检查 / 处置 / 材料全口径）
- 手术记录、知情同意书摘要

不适用（本功能不覆盖）：诊断推理与鉴别诊断、治疗方案与用药调整、药物相互作用与剂量判读、面向患者/家属的用药解释。本功能只做病历文书生成。

## 步骤

1. 接收输入：直接口述 / 粘贴文本 / 上传 `.txt` / `.pdf` / `.docx`；也接受已含诊断结论的输入。
2. **先出草稿再补全**：无论信息多寡，第一次响应先给病历/处方草稿，未提供字段标 `[信息缺失]`，**绝不编造**。
3. **缺失项追问**：草稿下方给待办清单（一次 ≤3 项），医生可选「回答任一项 / 跳过 / 完成归档」。
4. **安全类冲突优先**：如过敏–用药禁忌，待办中以 🔴 标记，先解决冲突再继续其他补录。
5. **模板确认**：首次生成草稿后追问一次「当前排版是否符合贵院/贵科模板？如不符合，请上传认可的模板文件（`.docx` / `.pdf` / `.txt` / 图片）」。上传后按模板的章节顺序、字段命名、表头、签名栏重新排版，字段值不变；模板整段会话沿用。
6. 口语转标准术语（"肚子疼"→"腹痛"、"stomach ache"→"abdominal pain"）。

## 输入输出

- 语言自适应：输入什么语言输出什么语言（段落标题、字段标签、追问提示同步切换；ICD 编码、单位等国际化符号保持原样），不生成中英混杂病历（除非明确要求 bilingual）。
- 输出标注约定：

| 标注 | 含义 |
|------|------|
| `[信息缺失]` | 未提供且无法推断 |
| `[推断]` | 基于上下文推断，需人工确认 |
| `[待编码]` | ICD 编码需人工补充 |
| `[异常]` | 数值超出正常范围 |

- 输入已包含明确诊断结论时，自动填入「初步诊断 / 诊断依据 / 鉴别诊断」段落：

```markdown
## 已有诊断结论：
### 疑似诊断列表
1. 冠心病 不稳定性心绞痛（可能性：高）
   - 依据：• 典型劳力性胸痛 • 高血压+吸烟高危因素 • 心电图ST-T改变
### 鉴别结论
- 需排除：心肌梗死、主动脉夹层、肺栓塞
```

## 注意事项

- **不做临床决策**，不新增诊断或治疗建议；不编造临床数据，缺失即标注。
- 涉及安全类冲突需人工确认，不自动通过。
- 不缓存不外传患者信息；使用专业中性医学术语。

## 可复用示例

用户输入（口述）："张三，男，60岁，昨天开始肚子疼、拉肚子，没发烧，血压130/80。"

首轮草稿输出要点：生成门诊病历草稿，口语转术语（腹部疼痛 / 腹泻 / 无发热），未提供字段标 `[信息缺失]`（如既往史、过敏史、用药史），下方给 ≤3 项待办，并追问模板确认。
