# 护理研究理论匹配

## 适用场景

面向护理学硕博论文、临床护理研究、护理教育研究、护理管理与实施研究。根据研究题目、对象、场景、设计和结局，推荐最合适的理论基础/框架/模型/方法论，并生成开题、论文、投稿可用输出。

## 步骤

1. 读取研究要素：题目、研究对象、场景、研究设计、结局指标。
2. 依据决策规则与理论目录匹配：主理论 + 备选理论。
3. 给出：选择理由 + 变量/维度映射 + 理论依据段落 + 不选其他理论的理由。
4. 按目标产出物套用模板生成：开题报告 / 学位论文 / 期刊投稿。

## 输入输出

- 输入：研究题目、对象、场景、设计、结局（可用自然语言描述）。
- 输出：主理论 + 备选理论 + 理由 + 变量/维度映射 + 理论依据段落 + 反选理由。
- 随附数据与模板（`assets/nursing-theory/`）：
  - `theory_catalog.json` — 理论目录
  - `theory_graph.json` — 理论关系图
  - `theory_synonyms.yaml` — 理论别名
  - `decision_rules.yaml` — 选型决策规则
  - `theory_selection_playbook.md` — 理论选型手册
  - `output_templates/proposal.md`、`dissertation.md`、`journal_article.md` — 开题/学位论文/期刊投稿输出模板

## 注意事项

- 输出强调"主理论 + 备选 + 反选理由"，避免只给单一理论。
- 变量/维度映射须与研究设计对应，不臆造未提供的结局变量。
- `theory_catalog.json` / `decision_rules.yaml` 为照实复制的源数据；若实际字段与描述不符，以文件内容为准。

## 可复用示例

输入："研究题目：基于症状自我管理的慢性心衰患者过渡期护理干预；对象：出院后 1 个月内心衰患者；设计：随机对照；结局：自我管理行为、再入院率"。

期望输出：主理论（如症状自我管理理论 / 过渡理论）+ 备选理论 + 选择理由 + 变量维度映射（自我管理行为维度、再入院指标归属）+ 开题可用的理论依据段落 + 不选其他理论的理由；并可直接套用 `output_templates/proposal.md` 生成开题稿。
