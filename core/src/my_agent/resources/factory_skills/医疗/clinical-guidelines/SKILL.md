# 医学指南共识查询

## 适用场景

整合三大权威医学指南知识库，提供临床诊疗指南、专家共识、诊疗规范的查询解读。触发词：临床指南、诊疗指南、专家共识、诊疗规范、临床规范、治疗方案、诊断标准、疾病诊疗、医学指南、指南解读、临床路径、疾病管理、共识声明、罕见病指南、医患共同决策、手术共识、循证医学、临床推荐、诊疗流程、一级/二级预防、筛查指南、用药指南、护理规范、康复指南、中医/儿科/外科/麻醉/影像/检验指南等。

不适用：具体个体处方开具、手术操作指导、医疗器械使用指导、药物购买建议；不代替执业医师临床决策；非循证的个人经验分享。

## 步骤

1. **Phase 1 需求识别与用户分层**：识别需求类型（指南查询/共识解读/规范查询/最新进展）；确定医学领域；识别用户身份（临床医生用专业术语+推荐等级；医学生/研究人员侧重系统性；患者家属用通俗语言并强调与医生沟通）；判断紧急性。疾病名称模糊时追问确认（≤2 个问题）。
2. **Phase 2 知识检索**：按优先级检索 📘2026 → 📗2025 → 📕经典；提取名称、发布机构、年份、证据等级；核对有效性（是否被更新替代）。优先采纳最新版；多指南差异时并列说明各自依据与适用情境；未检索到须明确告知而非编造。
3. **Phase 3 结构化输出**：按模块模板填入信息，标注年份/来源/证据等级，关键推荐附推荐等级（强/弱/共识性建议）。
4. **Phase 4 安全审核**：信息标注年份机构；区分强/弱推荐与共识建议；附免责提示；不提供个体化用药（仅给指南标准化方案）；罕见病标注适用条件与专科建议；面向家属做通俗化。

## 输入输出

四类输出模板（照实保留骨架）：

- 【临床诊疗指南】：指南基本信息（疾病、来源、年份、状态、证据等级）→ 诊断标准 → 治疗方案（一线/二线/特殊调整，带推荐等级）→ 临床分期/分级 → 提示。
- 【专家共识解读】：共识基本信息（名称、机构、时间、制定方法）→ 核心推荐意见（带推荐等级）→ 实施路径/流程 → 临床指导意义 → 知识库来源。
- 【指南更新动态】：领域 → 更新年份 → 新发布指南/共识 → 更新要点（旧版→新版对照）→ 对临床实践的影响。
- 【诊疗规范与法规查询】：医疗机构管理条例及实施细则、医疗纠纷预防和处理条例、护理相关法律法规及规范。

强制免责声明（每次输出末尾）：
> ⚠️ 重要提示：以上医学指南信息来源于权威知识库，仅供临床参考。诊疗决策应结合患者具体情况，由执业医师做出最终判断。

## 注意事项

- 回答自包含、纯文本结构，兼容 PC/移动端/临床信息系统，不依赖外部链接。
- 错误处理：疾病无对应指南 → 告知缺失并给替代方向；要求具体用药 → 仅给标准化方案并说明需执业医师按个体决定；指南年份 >5 年 → 提醒时效；多指南推荐不同 → 并列呈现；患者家属 → 通俗化；罕见病不全 → 给已有信息并建议专科。
- 已收录共识示例（照实保留）：2026 版含医患共同决策（SDM）、Laennec 间隙引导肝胆外科手术、直肠癌根治术保护自主神经、AI 在口腔医学应用、可切除肝细胞癌瘤内三级淋巴结构、肛瘘 MRI；2025 版含老年晚期肺癌治疗、HFA/EAPC 心功能障碍与心衰预防、ESVM 静脉血栓栓塞介入、儿童遗尿症管理、过敏性鼻炎分级预防；经典库含 NSTE-ACS 2024、心血管合并甲状腺功能异常、CCTA 在 CCS 应用、儿童泌尿系结石。
