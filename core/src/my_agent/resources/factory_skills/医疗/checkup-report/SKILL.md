# 体检报告解读

## 适用场景

用平实中文解读常规体检报告与化验结果，突出异常项、可能含义、紧迫度、随访问题与实用下一步。触发：用户发来体检报告、化验单、检查结果、检验指标、异常箭头项目，询问"异常结果是什么意思"，或需要结构化非诊断性解释。

本功能面向整份报告做整体解读与分层；针对单个术语/缩写/数值的词条式解释不在本功能范围。

## 步骤

1. **识别报告类型与上下文**：年度体检 / 血常规 / 尿常规 / 肝功能 / 肾功能 / 血脂 / 血糖 / 影像或超声小结 / 肿瘤标志物或专科检查。
2. **提取**：项目名称、数值、参考范围、高低标记、年龄/性别（如有）。
3. **先讲异常与临界项**，再酌情提主要正常项。
4. **成组解读**，不逐行孤立解释。参考模式：
   - ALT/AST/GGT → 肝相关
   - LDL-C/TC/TG/HDL-C → 血脂
   - 尿酸/肌酐/尿素 → 肾/代谢
   - Hb/WBC/PLT 及分类 → 血常规
   - TSH/FT3/FT4 → 甲状腺
   - 空腹血糖/HbA1c → 糖代谢
5. **给紧迫度分级**：观察即可 / 建议复查·门诊咨询 / 建议尽快就医。
6. **给具体下一步**，报告不完整时列出待澄清问题。

## 输入输出

默认输出结构：

```
### 先说结论        （一句整体判断）
### 重点异常项       （每项：项目 / 当前结果 / 怎么理解 / 常见相关原因 / 建议动作）
### 这些指标建议放在一起看
### 建议下一步       （观察 / 复查 / 门诊 / 急诊；酌情给生活方式或随访建议）
### 提醒            （本解读仅供参考，不替代医生诊断）
```

每项重要异常解释：这项是什么 / 偏高偏低通常意味着什么 / 常见但不唯一的原因 / 是否需结合其他指标 / 建议怎么处理。

澄清触发（需要时追问）：缺参考范围、只有项目名无数值、图片不清或项目不全、需年龄性别才更合理、用户只问"这个体检有问题吗"却没给内容。

常用澄清问句：方便把异常项目、数值和参考范围一起发我吗？／这是体检报告、抽血化验单还是影像检查结果？／你的年龄、性别，有没有医生已提示的重点问题？／最近有没有明显不舒服（头晕、胸闷、乏力、发热、腹痛等）？

## 注意事项

- 明确声明这是信息性解读，不是诊断；**不要让人忽视严重红旗**。
- 需升级提示的危险发现：伴症状的显著高/低血糖；重度贫血指标；显著肝肾功能异常；报告同时提及胸痛、呼吸困难、晕厥、神经症状或出血；影像明确建议紧急随访。
- 用户提及急性症状或警示信号 → 建议尽快就医，不做过细分析；避免虚假安慰。
- 措辞偏好：`这项轻度偏高，常见于……，但需要结合……一起看`、`单看这一项不能直接下诊断`、`从体检角度看，更像是需要复查确认`、`如果同时有明显不适，建议尽快线下就医`。
- 避免：`你就是得了……`、`肯定没事`、`完全不用管`。
- 单一轻度异常在整体背景低危时不要过度解读。

## 可复用示例

输入：`体检报告：ALT 78 U/L，AST 52 U/L，GGT 85 U/L，总胆红素 21 μmol/L，其余正常。男，40岁，体重偏胖，偶尔喝酒。`

期望输出（节选）：
```
### 先说结论
肝功能指标轻度异常，核心是 GGT 升高显著（＞2倍），结合 ALT/AST 同时升高，提示肝细胞损伤合并胆道/酒精相关影响。
### 重点异常项
- ALT（78↑）：肝细胞损伤的敏感指标。常见于脂肪肝、饮酒、药物影响。
- GGT（85↑）：显著升高是酒精/胆汁淤积的重要线索。
### 建议下一步
- 建议消化内科门诊，查腹部B超排除脂肪肝
- 复查前禁酒1周，清淡饮食
```
