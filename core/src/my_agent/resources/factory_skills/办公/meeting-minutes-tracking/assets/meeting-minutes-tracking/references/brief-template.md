# 工作简报模板事实切片

> 锚定原始样例：`甲方X 2025年11月辅导简报.docx`（2026-05-17 由 python-docx 解析回填）
> 与会议纪要模板的关系：**两者并存**——会议纪要走附件10 表格式（单场粒度），工作简报走本模板（月度/阶段粒度，信函格式）。

---

## §1 简报性质

| 项 | 值 |
|---|---|
| 颗粒度 | 月度或阶段（项目组按客户调） |
| 受众 | 甲方高层（外发） |
| 性质 | **正式信函**——有发函编号 / 抬头称呼 / 寒暄段 / 落款 |
| 主要内容 | 本期辅导工作汇总 + 上期计划完成情况 + 下期工作计划 + 文件附件 |
| 来源 | 多份会议/工作切片（`memory/projects/clients/{X}/*/`）+ 项目组本月日志 |

---

## §2 节序（结合信函样式 · 必含 vs 可选）

### §2.1 必含节序（按出现顺序）

| # | 节 | 内容 | 字体规则 |
|---|---|---|---|
| 1 | **大标题（项目名）** | "{客户名} {项目名}辅导项目" | 黑体 16pt 加粗居中 |
| 2 | **大标题（简报标识）** | "{年份}年{月份}月辅导简报" | 黑体 16pt 加粗居中 |
| 3 | **工作时间** | "（工作时间：YYYY年MM月DD日-MM月DD日）" | 仿宋 加粗居中 |
| 4 | **发函编号** | "【咨{年份}函】"（项目组按客户调具体编号） | 仿宋 14pt 不加粗 |
| 5 | **抬头称呼** | "尊敬的{X总、Y经理}：" | 仿宋 14pt 不加粗 |
| 6 | **寒暄段** | "两位好！非常感谢您两位对我司的信任和支持！\n有关{月份}的工作简报，以及{次月}份工作计划如下：" | 仿宋 14pt 不加粗 |
| 7 | **一、{月份}的辅导工作** | 一级标题 | 黑体 15pt 加粗 |
| 7.1 | 本月工作概要 bullet | "{月份}我司主要工作：" + 5±2 大主题概览 | 仿宋 14pt |
| 7.2 | "主要围绕着这{N}大板块展开一系列工作，具体内容如下：" | 衔接句 | 仿宋 14pt |
| 7.3 | **每个主题块（重复 N 次）** | 见 §2.2 主题块结构 | 见 §2.2 |
| 8 | **三、{月份}工作计划完成情况** | 一级标题（注意：跳过 "二、"，这是固定编号习惯） | 黑体 15pt 加粗 |
| 9 | **四、{次月}工作计划** | 一级标题 | 黑体 15pt 加粗 |
| 10 | **结尾询问段** | "若有疑问、意见或建议，请随时联系我们，谢谢！" | 仿宋 14pt 不加粗 |
| 11 | **联系人信息** | "{姓名}，{手机}，{邮箱}"（项目组填） | 仿宋 14pt 不加粗 |
| 12 | **附件：** | 标签行（黑体加粗或仿宋加粗） | 仿宋 14pt 加粗 |
| 13 | 附件分章列表 | 见 §2.3 附件区结构 | 仿宋 14pt |
| 14 | **落款** | "咨询项目组\n{YYYY年MM月DD日}"（项目组填发函日期） | 仿宋 14pt 加粗 |

### §2.2 单个主题块结构（在节 7 下重复 N 次）

```
{主题名}                                      ← 仿宋 14pt 加粗
{主题概述：1-3 句，介绍本月围绕该主题做了什么}      ← 仿宋 14pt 不加粗

{子事项 A}                                    ← 仿宋 14pt 加粗
{月份}{日期}，{动作动词}{对象}；                 ← 仿宋 14pt 不加粗
{月份}{日期}，{动作动词}{对象}。

{子事项 B}                                    ← 仿宋 14pt 加粗
{月份}{日期}，{动作动词}{对象}。

（{可选 · 备注/建议}）                          ← 仿宋 14pt 不加粗，括号包裹

相关文件：                                    ← 仿宋 14pt 加粗
《{文件名 1}》                                ← 仿宋 14pt 加粗
《{文件名 2}》
...
```

**关键纪律**：
- 子事项标题用**动名词或主题词**（如"大平台建设计划"/"产品规划评审"/"战略地图与平衡计分卡沟通"）
- 日志条目格式严格："{月份}月{日}日，{动作动词}{对象/客体}；"——动词开头（参加 / 沟通 / 汇报 / 修改 / 讨论 / 同步 / 发送 / 参与）
- 同一日多条用"、"连接（"11月4日、10日、17日，发送..."）
- 相关文件用书名号 + 加粗

### §2.3 附件区结构（节 13）

末尾附件区按**主题分章**再列文件，与节 7 内的"相关文件"重复——这是惯例（让甲方阅读时有"分散+汇总"两个视角）。

```
（一）{主题名 1}                              ← 仿宋 14pt 加粗
《文件 1.1》
《文件 1.2》

{主题名 2}                                    ← 仿宋 14pt 加粗（注意：第 2 个以后不用"（二）"编号）
《文件 2.1》
...
```

## §3 排版要点（已实测 · 与附件10 不同）

| 项 | 值 | 与附件10 对比 |
|---|---|---|
| 字体（正文） | **仿宋** | 附件10 用微软雅黑 |
| 字体（一级标题） | **黑体** | 同附件10 |
| 字号（大标题） | 16pt | 附件10 用 18pt |
| 字号（一级标题） | 15pt | 附件10 无对应 |
| 字号（正文） | 14pt | 附件10 用 ~10.5pt |
| 字号（工作时间） | 默认 | — |
| 页面 | A4 (21×29.7cm) | 同 |
| 页边距 | 上 2.5 / 下 3.0 / 左 3.9 / 右 3.2 cm | 附件10 是上 3.0 / 下 2.5 / 左右 3.0 |
| 页眉 | 无 | 同 |
| 页脚 | "{页} / {总页}" 居中（带空格） | 附件10 仅页码 |

**冲突处置**：会议纪要走附件10，工作简报走本模板——两套模板**字体/边距/版式全不一样**，不要混用。

## §4 信函元素（v1.3 新增 · 框架公司标准 / 内容项目组填）

### §4.1 公司标准（脚本硬编码）

- 大标题骨架："{客户} {项目名}辅导项目" + "{年}年{月}月辅导简报"
- 发函编号格式：`【咨{YYYY}{seq}函】` 或简化为 `【咨{YYYY}函】`
- 寒暄段模板："非常感谢您两位对我司的信任和支持！"
- 结尾询问段：固定 "若有疑问、意见或建议，请随时联系我们，谢谢！"
- 落款固定："咨询项目组"
- 邮箱后缀：`@example.com`
- 附件标签：固定 "附件："

### §4.2 项目组按客户/案例填（脚本占位）

- 抬头称呼对象（"X总、Y经理"——可 1-3 人）
- 函号 seq（项目组本年第几函）
- 联系人姓名 / 手机 / 邮箱（项目经理或主笔顾问）
- 客户名 / 项目名（在公司标准框架的 `{}` 占位填）
- 落款日期（发函日，默认当月最后一日 + N 工作日）
- "主要工作"主题数量（默认 5±2）

**项目组配置位**：`memory/projects/clients/{X}/README.md` §1 状态镜像里追加"简报签发参数"块。

## §5 内容字段映射（切片 → 简报）

每份切片必含以下字段才能进简报合成器（v1.3 切片新规）：

| 切片字段 | 简报字段 | 抽取方式 |
|---|---|---|
| `frontmatter: 客户` | 客户代号 | 直接读 |
| `frontmatter: 工作类型` | 决定归并到哪个主题 | 类型 → 主题映射表（见 §6） |
| `frontmatter: 工作主题` | 主题块标题 | 主题为空时退化为工作类型默认名 |
| `frontmatter: 日期` | 日志条目时间 | 转 "{月}月{日}日" |
| §1 议题速记 / 概述 | 主题概述 | LLM 合成 1-3 句 |
| §3 行动项跟踪表"内容"列 | 子事项 / 日志动作 | 动词开头 → 直接成日志条 |
| §4 我方承诺未交付项 | 主题块"建议/备注"段（括号） | 含"建议加强..."类语气 |
| §5 风险与信号 | 主题块"建议/备注"段（括号） | 同上 |
| `frontmatter: 相关产出物` | "相关文件：" 文件名清单 | 直接展开 |
| `frontmatter: 我方观察建议` | 主题块末尾括号备注 | 直接复用 |

## §6 工作类型 → 主题归并表

| 切片工作类型 | 默认主题名 |
|---|---|
| `sales` | 销售相关工作 |
| `ops-review` | 经营分析与业绩跟踪 |
| `project-mgmt` | 项目管理会议与跟进 |
| `research` | 调研与资料梳理 |
| `site-visit` | 现场走访与参观 |
| `process-mapping` | 流程梳理与优化 |
| `policy-design` | 制度方案设计 |
| `other` | 其他事项 |

切片可在 frontmatter 自定义 `工作主题`，覆盖默认归并——比如甲方X 11 月把"战略规划会议"作为独立主题，而不是归到 `ops-review` 默认名下。

---

## §7 红线复用

工作简报继承会议纪要的 PERMISSIONS：
- **P1 反幻觉**：日志条目必须能在某份切片或 daily-log 中 grep 到证据，编造的日期/动作整轮作废
- **P2 客户保密**：外发版必须用真名（项目组发函前手动替换代号 → 真名）；内部留档版保留代号 + 范围
- **P6 顶级红线**：未在切片中出现的工作不能凭空写进简报；用户人审是最后一道关
