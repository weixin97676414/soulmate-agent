## §1 代号规则

### 公司代号
- 第一个登记的客户 → 甲方A
- 第二个 → 甲方B
- ...

### 项目代号
- 第一个项目 → 项目X
- 第二个 → 项目Y
- ...

### 人员代号
- 格式：P-{角色}-{姓氏首字}
- 例：P-总经理-王、P-客户成功-李、P-财务总监-张
- 同姓同角色 → 加序号：P-客户经理-李1、P-客户经理-李2

### 部门代号
- D1 / D2 / D3...
- 同一客户内编号连续；跨客户复用编号无碍（D1 在甲方A 与甲方B 中可指不同部门）

### 金额范围
- 十万级 / 百万级 / 千万级 / 亿级 / 十亿级
- 不用具体数字
