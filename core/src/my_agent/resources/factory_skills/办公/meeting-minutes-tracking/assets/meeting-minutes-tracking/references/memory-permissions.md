# 记忆体写入红线（7 条）

> 7 条红线——任何写入 memory/ 之前必须检查。
> 触发任一红线 → 立即停手，输出违规清单，等用户决策。

---

## P1 · 反幻觉

- 事实句必带【实证】/【估算】/【常识】
- 【实证】必含 `[source: 文件名:位置]`
- 查不到证据 → 停-问 / 停-降为【估算】+ 推算路径 / 停-删
- 禁用模糊归因（"业内通行/据说/网传"）+ 不可证伪量词（"大概/大致/应该是"）+ AI 痕迹（"首先其次/综上所述/作为 AI"）

**违反时的动作**：阻塞写入，输出违规清单，让用户选"补证据 / 降态 / 删除"。

---

## P2 · 客户保密

- 真实公司全名 → 用代号（`甲方A / 甲方B / ...`）
- 精确金额 → 用范围（`百万级 / 千万级 / 亿级 / 十亿级`），不写具体数字
- 未公开战略 → 用"战略方向 X" + 一句话脱敏描述
- 内部组织调整 → 用"部门 D1/D2"
- 真实姓名 → 用 `P-角色-姓首字` 或姓氏代号

**违反时的动作**：阻塞写入，自动替换为代号 + 范围，提示用户确认。

---

## P3 · 原件保护

- 用户上传的文字稿原件**不动**——只读，不修改
- 不允许在文字稿上做"批注"、"重排"、"删节"
- 文字稿存放路径只能是 `outputs/_smoke/` 或 `outputs/{客户}/raw/`，不能进 `memory/`

**违反时的动作**：阻塞，提示用户"原件是只读资料，请新建衍生文件"。

---

## P4 · 禁用清单

不允许写入以下内容到 memory/：
- 客户真实公司全名 / 真名 / 真实金额
- 来自其他客户的切片内容（避免数据串味）
- 推测性的"行业惯例" / "通常做法"（除非有具体来源）
- 用户的个人隐私（家庭、健康、政治倾向）
- 与项目无关的闲聊内容

**违反时的动作**：阻塞 + 出禁用清单 + 用户选"删除 / 改写"。

---

## P5 · Agent 权限边界

- 子 Agent **只读不写**——所有 memory 写入由总控代行
- 不允许 LLM 直接调用 Write/Edit 改 `memory/doc/facts/client-codename.md`（脱敏映射最敏感）
- 不允许跨技能调用时绕过总控
- 已入库切片**不修改**——发现错误起 v2 文件

**违反时的动作**：阻塞 + 写 `lesson_违规_权限.md`。

---

## P6 · 顶级红线（一票否决）

- ① 甲方未公开数据**不直引**（用代号 + 范围表述）
- ② 未在文字稿/切片中出现的内容**禁止编造**（句级三态强制覆盖）

**违反时的动作**：整轮作废，写 `lesson_失败_*`，回到上一步重跑。

---

## P7 · Judge 工具白名单

C 档 Judge 阶段允许调用的工具：
- `Read`（读交付物、读 judge-rubric、读 plan §5 证据卡）
- `Grep`（在 uploads/ 抽样验证 source token）
- `Bash`（执行验证脚本，但不允许写文件）

Judge **不允许**：
- 调用 Executor-A / Executor-B / Executor-C（避免知情污染）
- 读 memory/ 中除 facts/ 外的任何文件（避免被 Writer 的记忆影响）
- 写任何文件（Judge 只评分，不修改）

**违反时的动作**：Judge 报告作废，重新调起独立 Judge 会话。
