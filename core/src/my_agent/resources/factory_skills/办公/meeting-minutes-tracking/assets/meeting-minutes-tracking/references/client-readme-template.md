## §2 维护规则

| 段 | 由谁维护 | 何时更新 |
|---|---|---|
| §1.1 状态镜像 | 项目组 / `meeting-minutes-tracking` 入库时同步 | 每次入库 |
| §1.2 签发参数 | 项目组手动 | 新客户登记时 |
| §2 子目录条数 | `meeting-minutes-tracking` | 每次入库 +1 |

| §5 关键跟踪 | 跨场问询 | 5 项清单出后同步 |

## §3 与切片 frontmatter 的关系

客户 README 是"客户级总览"；切片是"单场细节"。两者关系：

```
切片入库 → meeting-minutes-tracking 写入对应类型子目录 +
           读客户 README §1.1 当前项目状态 → 决定行动项默认追踪人 +
           写完后回写 §2 条数 +1 / §3 清单追加 / §1.1 最近会议字段
```

```
work-brief 触发 → 扫切片 + 读 README §1.2 签发参数 → 出简报 +
                  写完后追加 §4 简报历史
```

```
跨场问询触发 → 扫切片 + 读 README §1.1 当前项目 → 出 5 项清单 +
                     建议更新 §5 关键跟踪
```
