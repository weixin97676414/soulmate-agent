## §2 真实节序（已解析 附件10 回填 · 2026-05-17）

附件10 是**单页 A4 + 单张 7 列 10 行表格**的紧凑型纪要——不是传统报告式分章节布局。所有要素压在同一张表里。

### §2.1 表外（页面顶部）
- 标题：居中，"XXX 第 N 次会议纪要"（如"战略小组第二次会议纪要"）

### §2.2 表内行序（共 10 行 7 列；合并单元格按下表规则）

| 行 | 列结构 | 字段含义 |
|---|---|---|
| R0 | C0=标签 `会议时间`；C1-C4 合并=时间内容；C5=标签 `会议地点`；C6=地点内容 | 一行容两组键值 |
| R1 | C0=标签 `会议主持人`；C1-C6 合并=主持人 | 跨 6 列 |
| R2 | C0=标签 `与 会 者`；C1-C6 合并=与会者（按 "公司：xxx ¶ 集团：xxx" 分行；姓名按首字母排序） | 跨 6 列 |
| R3 | C0=标签 `会议议程`；C1-C6 合并=议程编号列表（"1、xxx ¶ 2、xxx"） | 跨 6 列 |
| R4 | C0-C6 全合并 | 块 `会议决议：` + 编号决议项 + `补充决议：` |
| R5 | C0-C1 合并=`会议安排事项`；C2=`责任人`；C3=`追踪人`；C4=`完成时限`；C5-C6 合并=`备注` | 行动项表头 |
| R6+ | 与 R5 同列结构 | 每行一个行动项（事项 / 责任人 / 追踪人 / 完成时限 / 备注） |
| 倒数1 | 空白预留行 | 增补行动项用 |
| 末行 | C0-C1 合并=`整理人` + C2=人名；C3=`抄送` + C4-C6 合并=抄送范围 | 一行容两组键值 |

### §2.3 段位映射（markdown 草稿 ↔ docx 表格）

Executor-A 写 markdown 草稿时按以下中间层结构组织；Formatter 落 docx 时按 §2.2 表格回填。

```markdown
# {项目代号} {第N次/类型} 会议纪要

## 表头键值
- 会议时间：YYYY-MM-DD HH:MM-HH:MM
- 会议地点：...（线上注明会议平台）
- 会议主持人：...
- 与会者：
  - 公司方（按姓首字母排序）：...
  - 集团/甲方方：...
- 会议议程：
  1. ...
  2. ...

## 会议决议
1. ...
2. ...

补充决议：
- ...

## 会议安排事项（行动项）
| # | 会议安排事项 | 责任人 | 追踪人 | 完成时限 | 备注 |
|---|---|---|---|---|---|
| 1 | ... | ... | ... | YYYY-MM-DD HH:MM | ... |

## 整理人 / 抄送
- 整理人：...
- 抄送：...
```

### §2.4 附录区（本 skill 附加，非附件10 原模板字段）

原模板**未含附录**，但本 skill 的 v2.1 反幻觉纪律强制要求每份纪要末尾追加（**外发版可裁剪**）：
- 文字稿来源 / 文件路径
- 本稿未核实清单（即使空也要写"（无）"）
- 代号对照表（内部传阅版才出）

外发版只输出 §2.2 表格；内部留档版追加 §2.4 附录。
