# 会议录音转写校对


## 适用场景

- 腾讯会议/钉钉/飞书等语音转文字（ASR）产出的文字稿错别字校对，再接入会议纪要整理。
- 触发条件（任一满足即自动执行）：文字稿含时间戳标记（如 `[00:01:23]` / `（01:23）`）；含说话人标注（`发言人1：` / `张三：` / `Speaker 1:`）；用户明说"这是腾讯会议转写/语音转的文字/ASR 出来的"；用户说"先校对一下 / 修正错别字 / 转写有错字 / 同音字纠正 / 纪要前先纠错"。
- 纯录音/视频：先经宿主转写能力（腾讯会议 tmeet / 语音转文字技能 / 本机 ASR）转写；本功能不做转写、不伪造转写。

## 步骤

1. **触发判定**：满足触发条件 → 执行校对；无明显 ASR 特征或稿件 <200 字 → 跳过，直接进纪要。
2. **Context**：识别客户、会议/工作类型、与会者；读客户代号映射表取专名，查不到走客户登记；读该客户 `术语表.md` 与历史切片 frontmatter 的"说话人口音"字段建口音画像。
3. **专名锁定（最高优先级）**：用对照表专名接口（客户代号表 + 客户术语表 + 咨询锚词）把真名/近音错名/错术语回贴为登记代号或正确专名。专名先锁死，后续规则不得覆盖。
4. **口音定向扫**：按口音画像启用口音规则行（R1 平翘舌 / R2 前后鼻音 / R3 l-n / R4 f-h / R5 鼻韵尾脱落）；对可疑词用拼音回推检验——只差一个声韵母维度判口音错则改，差很远转步骤 5。无籍贯线索时用语义断裂信号兜底（整句突然不通 / 冒生僻字组合 / 量词搭配反常）→ 标 `[?待核]`。
5. **通用兜底**：剩余可疑词查通用同音种子 + 自增长混淆集（在/再、的/得/地、做/作、象/像、他/她/它、是/十/四、反映/反应、须/需……），以句子语义与上下文语法为准逐句判别。
6. **三档处置 + 输出 + 回写**：
   - 高置信（命中专名表 / 口音规则且拼音回推成立）→ 直接改。
   - 中置信（同音可疑但上下文不能确定）→ 不静默改，标 `[?待核：原词→疑似]`。
   - 数字、金额、比例、日期、领导姓名职务 → 一律只标不改，回听音频人工定。
   - 格式归一无须改数值：百分比口语 → `20%`；上下文明确的"一千二" → 1200；"下周三" → 按会议日期推算 `YYYY-MM-DD`（附"（原话：下周三）"）。
   - 语义矛盾（数字前后不一致 / 态度反转 / 时间线矛盾）→ 标 `【待核实：前后矛盾】`，不自行修改。
   - 去重合并：同句转写两次（间隔 <30 秒）保留一句；说话人自纠保留修正版、删冗余。
   - 断句标点：按语义补逗号/句号/问号/引号/顿号，删口语填充词（那个/就是说/然后呢/嗯/啊，除非影响语义）。
   - 新确认的错→正回写对照表自增长混淆集（日期/客户/原错词/正确词/归因/来源 六列）。
   - 纠错三红线：三档处置、专名＞口音＞通用优先级、留痕可溯；纠错不得变脑补。

## 输入输出

- 输入：ASR 转写文字稿（`.txt` / `.docx` / `.md` 或直接粘贴）。
- 输出（落盘 `outputs/{客户代号}/`）：
  1. 清洗稿 `{原名}_proofread.md` — 顶部保留水印"[本文为 ASR 转写稿，已机器纠错；[?待核] 处与数字/专名以原音频为准]"。
  2. 纠错对照清单 `{原名}_diff.md` — 表头：`原词 | 改为 | 归因(专名/口音R#/同音/形似) | 处置(改/待核) | 位置`。
  3. 存疑清单 `{原名}_uncertain.md` — `[?待核]` 与 `【待核实】` 条目汇总，供人审/回听。
  回复用户给文件链接 + 一句话报：改了 N 处、待核 M 处、回听建议清单。
- 衔接：校对后以清洗稿作为会议纪要 Context 的输入（优先用 `_proofread.md`）。

## 注意事项

- 数字、金额、日期、领导姓名职务一律只标不改；领导姓名/职务/排序遵新华社最新表述，存疑只标不改。
- 周期性例会/有台账场景，语言层校对后追加**项目实体核验**（别名表 → 基准台账 → roster 三级匹配；确证静默改、拿不准一次问用户）；通用语言模型判断**不能单独**作为专名修改依据。
- 校对后存疑条目 >20 条 → 暂停，交用户审存疑清单后再继续。
- **上游预防**：转写前运行 `python scripts/gen_hint_words.py --client {客户代号}` 生成专名热词串（读客户代号表 + 客户术语表 → 去重截到约 200 字）→ 传给转写命令的 `--hint-words`（即 whisper initial_prompt）偏置识别专名，源头少错。热词串含甲方真名，仅本地离线用、数据不出域；脚本默认只写本地文件、不回显真名（除非 `--print`）。

## 可复用示例

- 粘贴腾讯会议转写 → 自动校对 → 得清洗稿 + 纠错对照清单 + 存疑清单 → 用户确认存疑项 → 进会议纪要。
- 例会前：「先生成这个客户的 ASR 热词」→ `gen_hint_words.py --client 甲方A` → 输出 `hint-words.txt` 喂给转写。
