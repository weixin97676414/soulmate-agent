# 能力边界清单（快速查阅）

本文件回答三个问题：**能做什么？不能做什么？要怎么输入？** 帮助用户 30 秒内判断某个需求是否适合丢给「本技能」。

**专业度 / 最佳搭档**两列用于管理预期：本技能是"统一入口与调度中枢"，纯文本/本地文件场景独立可达「高」水平；涉及专用引擎（表格/PPT/PDF/OCR/合同）或平台连接器时，由对应技能/连接器承担，**本技能负责调度而非重复实现**——所以"最佳搭档"标注了真正干活的组件，避免"样样松"的误解。

## 通用边界（所有场景一致）

- **不联网**：除非调用已授权的连接器，否则不主动联网抓取数据。
- **不自动执行敏感操作**：不发送邮件、不入账、不修改 ERP、不代替用户签字或审批。
- **中文优先**：默认简体中文；涉及中国股市等财务场景遵循红涨绿跌。
- **可降级**：缺失外部插件或未授权连接器时，自动退化为内置工作流或导出处理，不会卡死。
- **隐私/脱敏（询问式，不强制）**：检测到身份证号/税号/银行账号等敏感字段时，**先询问是否脱敏，绝不默认遮盖**。对内场景（入账/报销/对账）保留原文，对外分享/共享知识库时再脱敏。详见 `references/privacy_desensitization.md`。
- **移动端短读**：产出结论前置、要点化、表格优先、单段 ≤5 行，全角标点与中文排版规范，方便手机一眼读完。
- **AI 生成合成内容标识（2026-09-01 起强制）**：凡产出面向公众发布的内容，必须提示显式标识（文字/角标/画面提示）与隐式标识（文件元数据）义务。仅打话题标签不算合规。对内不强制，对外发布必须有。详见 `references/dispatch.md`。
- **组织级三要求：可认证 / 可访问 / 可审计**：输出标注来源、降级路径明确、关键结论标置信度并保留修改痕迹，全流程来源可追溯。
- **任务路由与成本控制**：纯文本场景不加载文件处理技能；分域文件按需加载（内容/数据/专业三域）；大文件先探后处；产出够用即止。
- **调用方式**：支持多轮对话与文件上传；不提供独立 CLI 或 HTTP API；定时任务由宿主 Agent 调度，本技能不自带。

## 什么时候不要用本 Skill

- 需要法律正式意见（请找执业律师）。
- 需要直接修改 ERP/财务系统数据（请人工在 ERP 中执行）。
- 需要联网实时查询股票/汇率/天气（本 skill 不主动联网）。
- 任务完全不在上述 25 场景内（建议用更专精的 skill）。
- 需要默认把内部敏感数据脱敏（本 skill 不默认脱敏，请见上"隐私/脱敏"）。
