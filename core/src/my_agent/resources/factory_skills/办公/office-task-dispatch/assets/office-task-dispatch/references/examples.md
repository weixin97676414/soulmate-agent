# 典型场景输入/输出示例

本文件提供 6 个高频场景的完整示例，照着输入即可得到对应输出。适合第一次使用「本技能」时快速模仿。

---

## 示例 1：会议纪要 → 行动项 → 跟进邮件 → 周报片段

**输入（直接粘贴文字）**

```
2026-07-20 产品周会录音稿
张三：下周要上线新功能，开发必须在周五前完成自测。
李四：市场部周三前要给推广文案，不然赶不上预热。
王五：客户 A 的售后问题还没闭环，最晚后天给人家回复。
```

**你再说一句**

```
整理这份会议纪要，提取行动项，并草拟一封给李四的跟进邮件。
```

**输出**

1. 结构化会议纪要
   - 决策：下周上线新功能；市场部周三前提供文案；客户 A 售后问题需后天回复。
   - 风险：文案交付时间紧，可能赶不上预热。
2. 行动项表

| 任务 | 负责人 | 截止时间 | 状态 |
|------|--------|----------|------|
| 新功能开发自测完成 | 开发 | 周五前 | 待完成 |
| 提供推广文案 | 市场部/李四 | 周三前 | 待完成 |
| 客户 A 售后闭环 | 王五 | 后天 | 待完成 |

3. 跟进邮件草稿（给李四）

```
主题：新功能推广文案 - 周三前交付确认

李四，

根据今天产品周会，新功能计划下周上线，需要你这边在周三前提供推广文案，以便赶上预热节奏。

请确认是否能按时交付；如有困难，我们提前协调资源。

感谢！
```

4. 周报片段（可直接贴进周报）

## 示例 2：Excel 销售数据分析（自然语言驱动）

**输入**

上传 `superstore-sales.xlsx` 文件，并说：

```
分析下销售数据，按地区看趋势，找出哪些子品类最赚钱。
```

**输出**

1. 数据体检报告
   - 行数：9994；缺失值：0；重复值：0；时间跨度：2014-2017。
2. 地区 × 品类 透视表（Top 3）

| 地区 | 销售额 | 利润 | 利润率 |
|------|--------|------|--------|
| West | 725,458 | 108,418 | 14.96% |
| East | 678,781 | 91,523 | 13.48% |
| Central | 501,239 | 39,706 | 7.92% |

3. 子品类帕累托分析
   - 9/17 个子品类贡献 80% 利润；其中 Phones 利润最高，Tables 亏损。
4. 月度销售趋势图（折线图）
5. 结论与建议：重点维护 West 区 Phones/Copiers；Central 区需提升利润率。

## 示例 3：采购合同审查

**输入**

上传 `采购合同.pdf` 文件，并说：

```
审查这份采购合同，从采购、法务、财务三个角度标风险。
```

**输出**

1. 通用结构检查
   - 合同主体、标的、金额、付款、交付、违约、争议解决 7 大要素是否完整。
2. 采购风险（示例）
   - 交付周期未明确罚则；验收标准模糊。
3. 法务风险（示例）
   - 争议管辖约定偏向乙方；知识产权归属未明确。
4. 财务风险（示例）
   - 预付款比例过高（50%）；发票类型未限定增值税专用发票。
5. 修改建议清单
6. 免责声明：本审查仅为 AI 辅助，不构成正式法律意见。

## 示例 4：发票 OCR 入账

**输入**

上传发票图片，并说：

```
识别这张发票并生成凭证草稿。
```

**输出**

1. 结构化发票字段

| 字段 | 值 |
|------|-----|
| 发票代码 | 011001900211 |
| 发票号码 | 12345678 |
| 开票日期 | 2026-07-15 |
| 销售方 | XX 科技有限公司 |
| 金额（不含税） | 1,000.00 |
| 税额 | 130.00 |
| 价税合计 | 1,130.00 |

2. 凭证草稿

| 借/贷 | 科目 | 金额 | 备注 |
|-------|------|------|------|
| 借 | 管理费用 - 办公费 | 1,000.00 | 发票不含税金额 |
| 借 | 应交税费 - 应交增值税（进项税额） | 130.00 | 税额 |
| 贷 | 银行存款 / 应付账款 | 1,130.00 | 价税合计 |

3. 异常校验：无异常。
4. 免责声明：金额以票面为准，入账前请人工复核。

## 示例 5：客户/项目跟进

**输入**

```
客户 B，上次联系是 7 月 10 日，沟通了采购 50 台设备。对方说本周给预算反馈。
```

**输出**

1. 客户状态卡

| 客户 | 阶段 | 风险 | 下一步动作 |
|------|------|------|------------|
| 客户 B | 预算确认 | 反馈延迟 | 本周五前确认预算反馈 |

2. 跟进建议
   - 今天是 7 月 20 日，已过去 10 天，建议温和催促并确认是否需要补充材料。
3. 跟进邮件草稿

```
主题：50 台设备采购 - 预算反馈确认

B 总，

距上次沟通已有一段时间，想确认一下 50 台设备的预算审批进度。是否需要我补充产品资料或报价明细？

期待你的回复。
```

## 示例 6：晨间作战简报

**输入**

```
帮我安排今天的工作，检查时间冲突，并给出战略静默建议。
```

（若已授权日历/连接器，会自动拉取今日日程；否则请手动粘贴或上传日程文件。）

**输出**

1. 今日重点（按优先级排序）
   - 09:30 产品周会
   - 11:00 客户 A 售后回复
   - 14:00 合同审查
   - 16:00 跟进客户 B 预算反馈
2. 时间冲突检测
   - 12:00-13:00 会议密集，建议预留午餐时间。
   - 15:30-17:00 已有两个会议，不建议再安排新会议。
3. 战略静默建议
   - 建议 10:00-11:00 留出 60 分钟专注块处理合同审查。
   - 建议 14:00 后连续工作不超过 4 小时，17:00 后休息。
4. 休息关怀
   - 今日会议密度高，注意留出 15 分钟休息。

---

## 使用提示

- 示例中的输入越具体，输出越贴合你的业务。
- 支持**一次串多个场景**，例如"整理这份会议纪要 + 提取行动项 + 写周报 + 排今日日程"。
- 遇到敏感场景（财务、合同、发票），输出会自动附带免责声明。
