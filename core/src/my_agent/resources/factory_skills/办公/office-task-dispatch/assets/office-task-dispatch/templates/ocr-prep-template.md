# PDF / 图片 OCR 文字提取预处理模板

## 目的
把图片（拍照、截图、扫描件）或 PDF 中的文字提取为可编辑、可进一步处理的标准化文本。本场景只做**输入层预处理**，提取完成后应自动或按用户意愿分流到对应下游工作流（纪要、总结、知识库、客户跟进、财务凭证等）。

## 适用素材
- 会议白板照片、纸质会议纪要扫描件、PPT 拍照
- 合同/发票/报销单 PDF 或图片
- 聊天记录截图、邮件截图
- 纸质表格扫描件（如 Excel 无法直接复制时）

## 执行步骤
1. 识别输入类型：图片（JPG/PNG/HEIC/BMP/TIFF）还是 PDF；是否多页；是否含手写。
2. 优先用内置 `pdf` 工作流提取文字；不可用时引导用户先自行提取文字再粘贴给本技能。
3. 结构化输出：
   - 标题/来源（文件名、页数）
   - 提取置信度（整体 / 每页）
   - 正文（按原文段落、列表、表格层级保留）
   - 识别异常标注（模糊、乱码、缺字、表格错位）
   - 建议下游分流（纪要/总结/知识库/财务/客户跟进/数据透视）
4. 表格处理：若原图是表格，输出 Markdown 表格 + 原始 CSV 文本，方便后续进 `xlsx` 做透视分析。

## 下游分流规则
| 提取内容 | 建议进入 | 处理 |
|---------|---------|------|
| 会议纪要素材（手写/打印） | §1 纪要提取 | 整理决策、行动项、负责人 |
| 长文档、文章、PDF | §2 文档总结 | 提炼要点、可附决策建议 |
| 客户名片、沟通记录截图 | §7 客户/项目跟进 | 生成客户跟进卡片 |
| 培训讲义、课程照片、视频字幕 | §8 培训/学习笔记 | 结构化笔记 + 知识卡片 |
| 待办、任务清单截图 | §9 行动项追踪 | 汇总去重、生成跟踪表 |
| 发票、凭证、对账单 | §10 财务/ERP | 清洗、对账、生成凭证 |
| 销售/运营数据截图 | §12 数据分析与透视 | 体检、透视、可视化 |
| 通用参考资料 | §5 知识库沉淀 | 归档、标签、可检索 |

## 交付检查清单
- [ ] 文件名、页数、总字数已标注
- [ ] 文字按原文结构保留，段落/列表/表格未乱序
- [ ] 识别异常处已高亮提示，未擅自猜测补字
- [ ] 表格已输出 Markdown 表格和 CSV 文本两种格式
- [ ] 已给出明确的下游分流建议
- [ ] 用户确认后再进入下游深加工，避免误读导致错误结论
