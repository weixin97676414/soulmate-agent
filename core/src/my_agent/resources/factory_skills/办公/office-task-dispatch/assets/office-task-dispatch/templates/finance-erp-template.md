# 财务 / ERP（金蝶·用友）办公任务模板

> 适用：处理金蝶（K3/云星空）、用友（U8/NC）等 ERP 导出的 Excel/CSV
> **边界**：本技能不直接登录或操作 ERP 系统（商业闭源、无公开 API），只处理导出的数据。

---

## 一、数据导出清洗

- **来源**：金蝶/用友的明细账、余额表、凭证列表、报表导出（Excel/CSV）
- **清洗项**：
  - 删除冗余表头、合计行、分页符、空行
  - 统一科目编码（去掉空格/全角、对齐科目表）
  - 金额文本 → 数值（去千分位符号、币种前缀）
  - 日期统一为 `YYYY-MM-DD`
- **输出**：标准化明细表（便于后续透视）

---

## 二、凭证整理结构

| 日期 | 凭证字号 | 摘要 | 科目编码 | 科目名称 | 借方 | 贷方 | 附件 |
|------|---------|------|---------|---------|------|------|------|
|      |         |      |         |         |      |      |      |

- **规则**：借贷必平（Σ借方 = Σ贷方）；科目编码与名称须对齐 ERP 科目表
- **摘要规范**：避免"杂费""其他"等模糊词，写明业务实质

---

## 三、对账

- **银行对账**：银行流水 vs 银行存款日记账 → 勾对已达账项，列未达账项
- **往来对账**：应收/应付明细 vs 客户/供应商对账单 → 差异清单
- **差异清单字段**：主体 | 我方金额 | 对方金额 | 差异 | 方向 | 可能原因

---

## 四、财务报表生成

- **三大表**：资产负债表、利润表、现金流量表
- **取数口径**：注明会计期间、账套、是否含未记账凭证
- **勾稽校验**：
  - 资产负债表：资产 = 负债 + 所有者权益
  - 利润表净利润 = 所有者权益变动表本期净利润
  - 现金流量表期末现金 = 资产负债表货币资金

---

## 五、交付检查清单（强制）

- [ ] 借贷平衡
- [ ] 科目编码/名称与 ERP 一致
- [ ] 报表勾稽关系通过
- [ ] 数据口径与期间已注明
- [ ] 差异/未达账项已单独列出
