# ASR 转写纠错对照表（骨架 v0.1）

> 定位：转录文字校对的配套词典。把"录音转文字"的错别字分三类来源——
> **专名错 / 口音错 / 通用同音形似错**——各给一张可定向查的表，外加一个越用越准的
> 自增长区。§2.5 在纠错时按 §0 顺序读取；上游转写用 §1+§4 做热词预防
> （`scripts/gen_hint_words.py`）。
>
> 元信息：v0.1 · 2026-07-26 · 初拟骨架，词条需团队使用中校准，非已验证频率。

---

## §0 纠错纪律（先读，三条红线 · 不可豁免）

1. **三档处置**
   - 高置信（命中专名表 / 命中口音规则且拼音回推成立）→ 直接改。
   - 中置信（同音可疑但上下文不能确定）→ **不静默改**，标 `[?待核：原词→疑似]`。
   - **数字、金额、比例、日期、领导姓名职务**→ 一律**只标不改**，回听音频人工定。
2. **优先级**：§4 领域专名 ＞ §1+§2 口音规则 ＞ §3 通用同音/形似。冲突时高优先级覆盖低。
3. **留痕可溯**：每改一处在纠错对照清单记 `原词→正词｜归因`；新确认的错→正追加到 §5，喂养下次。

> 与反幻觉红线一致：纠错不得变脑补。拿不准就标，不替音频做主。

---

## §1 说话人口音画像（纠错前先填 · 杠杆最高）

知道"谁在说、哪里人"，就能预判错误方向，命中率远高于盲查。会议场景通常认识与会者，
把籍贯/口音记进切片 frontmatter 的可选字段 `说话人口音:`，纠错时调取。

| 与会者代号 | 籍贯 / 口音 | 启用规则集（§2 行号） | 备注 |
|---|---|---|---|
| 例：P-财务总监-张 | 湖南 | R3 l/n、R4 f/h、R1 平翘舌 | 重口音，金额处必回听 |
| _（按客户填）_ | | | |

> 约定：切片 frontmatter 新增可选字段 `说话人口音:`（见 SKILL.md §9），§2.5 自动读取本表。

## §2 口音混淆规则表（按规则定向扫）

口音错是**系统性声韵母混淆**，可预测。检验法统一用"拼音回推"：把识别词与上下文应有词
都转拼音，**只差下表一个维度**即判口音错；差很远 → 转 §4/§3 另案。

| 行号 | 类型 | 混淆方向 | 高发口音区 | 错例 → 正例 |
|---|---|---|---|---|
| R1 | 平翘舌不分 | z/c/s ↔ zh/ch/sh | 江浙·湖南·福建·西南 | 资道→知道 ; 四场→市场 ; 私机→时机 |
| R2 | 前后鼻音不分 | n ↔ ng（in/ing、en/eng） | 西南·江淮·湖南 | 程→陈 ; 京→金 ; 丰→分 ; 灵→林 |
| R3 | l/n 不分 | l ↔ n | 湖南·四川·湖北 | 牛→刘 ; 腻润→利润 ; 兰方→南方 |
| R4 | f/h 不分 | f ↔ h | 湖南·福建 | 花展→发展 ; 胡利→福利 ; 灰机→飞机 |
| R5 | 鼻韵尾脱落 | -n/-ng/-m 丢失 | 粤·闽 | 整词走形、量词搭配反常（回听为主） |

**语义断裂信号**（无籍贯线索时的兜底）：整句突然不通、冒生僻字组合、量词/搭配反常
→ 多为口音叠加方言词被硬转成同音普通话字，标 `[?待核]`。

## §3 通用同音/形似种子（咨询语境 · 人工初拟，使用中校准）

通用底层。可后续拉 pycorrector 音似/形似词表、ChineseHomophones 扩充。
**下列为种子示例，非频率排序、非穷举。**

战略组织：占略→战略 ; 商业摸式→商业模式 ; 组织框构→组织架构 ; 管控膜式→管控模式
财务经营：盈收/营收（口径，标待核） ; 毛力→毛利 ; 现金留→现金流 ; 摊消→摊销 ; 计提（勿误改）
薪酬绩效：计效/级效→绩效 ; 宽待薪酬→宽带薪酬 ; 提承→提成 ; 考贺→考核 ; 鸡校→绩效（重口音）
治理党建：党位→党委 ; 三重一大（专名，勿拆） ; 国资为→国资委 ; 两个维护（专名固定）
并购股权：病够→并购 ; 古权/股全→股权 ; 对赌（勿误改为对堵） ; 尽调（勿改为进调）
通用动词：复判→复盘 ; 对标（勿改对表） ; 抓手（勿改抓守） ; 闭环（勿改必环）
高频单字：在/再、的/得/地、做/作、象/像、他/她/它、是/十/四、反映/反应、须/需（按上下文语法判别）

> 形似错（多见于 OCR/输入，ASR 较少）：己/已、未/末、戊/戌——ASR 场景低频，按需补。

## §4 领域专名接口（最高优先级 · 私有资产，别处买不到）

专名错（客户名/领导职务/项目名/行业术语）是危害最大的一类，任何通用词典都不收，
**只接你已有的记忆，不在此复制**（保密 + 防漂移）：

1. **客户 / 项目 / 人员代号** → 运行时读 `memory/doc/facts/client-codename.md`。
   纠错时：转写里出现的真名/近音错名，回贴为登记代号或正确专名。
2. **每客户术语表** → 约定 `memory/projects/clients/{客户代号}/术语表.md`
   （收该客户的产品线、子公司、项目缩写、行业黑话、关键人物职务；客户登记时创建，见 SKILL.md §6）。
3. **通用咨询锚词**（少量种子，防被转错）：
   尽职调查 · 价值链 · 护城河 · 第二曲线 · BLM · 战略解码 · 平衡计分卡 · 任职资格 ·
   宽带薪酬 · 海氏评估 · 三定（定岗定编定责） · 三重一大 · 两个维护 · 双碳。

> §2.5 第一遍就用本节把专名锁死，再往下跑 §1/§2/§3。

## §6 接线说明（挂到 skill / 上游预防）

**下游纠错（§2.5 读取顺序）**：§0 纪律 → §4 专名锁定 → §1 口音画像 + §2 规则定向扫
→ §3 通用兜底 → 命中 §5 直接复用 → 新确认项回写 §5。

**上游预防**：转写前跑 `scripts/gen_hint_words.py --client {客户代号}`，
把 §4 专名 + 术语表高频正词拼成 `--hint-words` 喂 whisperX；重口音录音改用支持方言的引擎
（FunASR/Paraformer 方言模型、讯飞方言识别）。源头少错，下游少改。

**边界**：本表只管"转写稿错别字纠正"，不做音频转写、不做去 AI 味
（stop-slop-zh）、不做交付前正式校对（plan-proofread）。
