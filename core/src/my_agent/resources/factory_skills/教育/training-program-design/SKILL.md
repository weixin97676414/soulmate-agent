# 功能：企业培训项目 / 课程包设计


## 适用场景

- 从零设计企业培训课程、工作坊、学习项目。
- 结构化课程大纲与时间线；改进既有培训项目。
- 一键产出可直接交付的完整培训物料包（含营销文案与测评材料）。
- 员工入职培训、合规培训（SOC 2 / HIPAA / GDPR / OSHA 等）、技能提升、领导力发展、认证备考路径。

触发词：设计培训课程、培训项目、课程包、企业培训、入职培训、合规培训、领导力培训、培训物料、培训通知文案。

## 步骤

### 1. 完成课程设计简报
填写标准简报（模板见 `assets/course-design-brief-template.md`），包含：培训主题、目标人群、时长、学习目标（3–5 条，行为动词）、交付形式、现有基础。一次拿全信息，避免反复追问。

### 2. 选择课程框架
按主要学习目标三选一：

| 框架 | 适用 | 互动时间占比 |
|------|------|--------------|
| 技能型 | 销售技巧、软件操作等可训练技能 | >50% |
| 知识型 | 产品知识、合规政策 | 20–30% |
| 态度/行为型 | 领导力、团队协作 | 40–50% |

### 3. 设计模块与内容
拆成 3–5 个逻辑模块。每个模块用四段结构：
1. 引入（5–10 分钟）：抓注意、说目标、建关联。
2. 核心内容（30–40% 时间）：讲清关键概念、框架、知识。
3. 练习与应用（40–60% 时间）：用互动活动库（`assets/interactive-activities-library.md`）做动手练习、案例研讨。
4. 小结与行动计划（5–10 分钟）：回顾要点，引导学员写个人行动计划。

### 4. 排详细时间表
把整门课排到分钟级。上午安排高耗能内容，下午增加互动；每 90 分钟安排 10–15 分钟休息；预留总时长 10% 作缓冲。

### 5. 产出交付包
用 `assets/` 下的模板生成完整物料包（见下）。详细流程见 `assets/one-click-generation-guide.md`。

## 一键课程包（标准交付物）

拿到 5 项输入（主题、目标人群、时长、学习目标、交付形式）后，生成 14 份文档，按 3 个文件夹组织：

```
[课程名] - Complete Training Package/
├── 01_Course_Design/
│   ├── Course_Outline.md              # 课程大纲（背景/受众/目标/日程/分模块）
│   ├── Instructor_Guide.md            # 讲师手册（逐分钟脚本、讲解点、活动指令、过渡语、Q&A）
│   ├── Participant_Handbook.md        # 学员手册（概念、笔记区、练习页、自评、行动计划）
│   ├── Activity_Sheets/               # 每个主要活动一页，含目标、步骤、时长、复盘问题
│   └── Evaluation_Plan.md             # 评估计划（Kirkpatrick L1/L2 + 30 天 L3 跟进）
├── 02_Marketing_Copy/
│   ├── Enrollment_Notice.md           # 报名通知（300–400 字）
│   ├── Pre_Training_Reminder_1Week.md # 开课前一周提醒（200–300 字）
│   ├── Pre_Training_Reminder_1Day.md  # 开课前一天提醒（150–200 字）
│   ├── Welcome_Message.md             # 欢迎词（250–350 字）
│   ├── Post_Training_Thank_You.md     # 结课致谢（200–300 字）
│   └── 30_Day_Follow_Up.md            # 30 天跟进（250–350 字）
└── 03_Assessments/
    ├── Pre_Training_Knowledge_Check.md # 训前知识检查（10–15 题）
    ├── Post_Training_Quiz.md           # 训后测验（20–25 题，40% 选择 / 20% 判断 / 20% 情景 / 20% 简答，70 分及格）
    └── Level_1_Evaluation_Survey.md    # L1 满意度评估（12–15 题，含 NPS，5–10 分钟）
```

营销与测评文案模板见 `assets/marketing-copy-templates.md`、`assets/assessment-templates.md`；讲师手册 / 学员手册模板见 `assets/instructor-guide-template.md`、`assets/participant-handbook-template.md`。

## 模块骨架与评估

**模块骨架**：

```
PROGRAM: [名称]   AUDIENCE: [角色/团队]   DURATION: [X 周]   FORMAT: [自学/讲师带/混合]

MODULE N: [主题]
- 学习目标（3–5 条可测量结果）
- 内容大纲（主题、子主题）
- 活动（动手练习、案例）
- 评估（测验 / 实操演示 / 项目）
- 时间估计：X 小时
- 所需资源：[工具、权限、材料]
```

**评估框架**（每模块）：知识检查（测验，70% 及格线）+ 实操评估（演示或项目交付物）+ 能力量表（各技能 1–5 分）。

**完成度追踪**：

| 员工 | 模块1 | 模块2 | 模块3 | 整体 | 状态 |
|------|-------|-------|-------|------|------|
| 姓名 | ✅ 92% | ✅ 88% | 🔄 进行中 | 60% | 正常 |

**合规培训补充项**：法规依据引用、复训频率、记录留存期限、审计追踪格式。

**ROI 指标**：达产时间（从开始到独立工作的天数）、错误率下降（培训前后对比）、留存影响、人均成本（项目成本 ÷ 参训人数）。

## 输入输出

- **输入**：培训主题、目标人群、时长、学习目标（3–5 条）、交付形式。
- **输出**：14 份文档组成的完整课程包（3 个文件夹 + README）。
- **模板**：全部在 `assets/`。

## 注意事项

1. 生成前先备齐 5 项输入，信息不全先列「待确认项」。
2. 交付前必须人工复核并按公司情况定制（加内部案例、术语、品牌）。
3. 内容需符合成人学习原则：内容与练习时间平衡、难度递进、目标清晰。
4. 引用行业数据（如留存率）时须标明来源；无法核实标「未验证」。

## 可复用示例

**输入**：
```
Topic: Effective Communication Skills for Remote Teams
Audience: Team leaders managing distributed teams
Duration: 1 day, 6 hours
Objectives: 演示主动倾听 / 写清晰邮件 / 主持线上会议 / 异步建设性反馈 / 远程团队凝聚
Format: Online via Zoom with breakout rooms
```

**输出**：5 份课程设计文档 + 6 份营销运营文案 + 3 份测评材料，按 `01_Course_Design / 02_Marketing_Copy / 03_Assessments` 组织，并给出可选的品牌化与难度调整项。
