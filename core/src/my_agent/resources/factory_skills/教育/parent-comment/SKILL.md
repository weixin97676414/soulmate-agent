# 功能：家长签字评语生成


## 适用场景

- 依据孩子表现，为成绩单、作业本、学校沟通表生成得体、温暖的家长签字评语。
- 用户提供或需要补充：年级、成绩、亮点、待改进项、使用场景、语气。

触发词：家长评语、签字评语、成绩单评语、作业本评语、家长寄语。

## 输入收集

| 字段 | 示例 | 是否必需 |
|------|------|----------|
| 年级 | 三年级 | 建议 |
| 成绩 | 语文/数学/英语：85/92/78 | 可选 |
| 亮点 | 数学进步；主动举手 | 建议 |
| 待改进项 | 容易分心；字迹潦草 | 可选 |
| 使用场景 | 成绩单 / 作业本 / 沟通表 | 可选 |
| 语气 | 鼓励 / 务实 / 正式 | 默认鼓励 |

信息有限时先生成通用版本，并注明所作假设。

## 输出

生成 **2–3 个**风格略有差异的版本：
- **版本1 温暖鼓励**：强调进步与努力。
- **版本2 务实建设**：肯定 + 明确期望。
- **版本3 简洁正式**：适合正式表格。

**长度**：作业本 / 沟通表 50–80 字；成绩单 80–150 字。

## 写作原则

✅ 要：
- 开头肯定努力或进步（哪怕很小）。
- 以家长视角（「我」）书写，语气真诚。
- 把不足正面化：不说「懒」→ 说「可以更主动一些」。
- 结尾给出具体期望或鼓励。

❌ 不要：
- 夸大成绩（「全班第一」「天才」）。
- 使用负面标签。
- 写成通用模板。

## 附加能力

- 可要求「微调版本2，加一句 XX」。
- `转换为繁体中文`（港澳台学校）。
- `Translate to English`（国际学校）。

## 输入输出

- **输入**：年级、成绩、亮点、待改进项、场景、语气（部分可选）。
- **输出**：2–3 版不同风格的评语。
- **脚本**：无。

## 注意事项

1. 不编造成绩或表现；缺失信息按假设生成并注明。
2. 不夸大、不贴负面标签。

## 可复用示例

**输入**：`三年级，数学进步明显，但写字潦草，作业本用，鼓励语气`

**输出（版本1 温暖鼓励，约 70 字）**：
> 这学期看到你在数学上的努力有了回报，进步让人欣慰。如果能把字写得更工整一些，就更棒了。妈妈相信你会越来越出色，继续加油！

**输出（版本2 务实建设，约 70 字）**：
> 数学进步看得出你下了功夫，值得表扬。字迹还需要再认真一些，写慢一点会更清楚。希望下阶段保持数学的劲头，同时把书写习惯改好。
