# 功能：课程 / 工作坊大纲设计


## 适用场景

- 设计工作坊或培训大纲、课程结构、培训议程、培训日程。
- 需要学员为中心、可落地、含时间分配与互动设计的大纲。
- 需要按 MECE 组织模块、用可测量的行为动词写学习目标。
- 用户提供现有课程大纲需要优化。

触发词：生成工作坊大纲、培训大纲、课程结构、培训议程、课程设计、工作坊设计、优化课程大纲。

## 核心设计原则

1. **MECE 结构**：模块之间相互独立、整体穷尽（不重叠、不遗漏）。
2. **TfBR 4C 设计**：Connection（连接）→ Concepts（概念）→ Concrete Practice（具体练习）→ Conclusion（总结）。
3. **VAK 感官覆盖**：每个模块都含 Visual（图/表/幻灯）、Auditory（故事/讲解/讨论）、Kinesthetic（角色扮演/动手/走动）。
4. **70% 活动 / 30% 讲授**；学习目标用行为动词（Apply / Demonstrate / Practice / Create / Design / Analyze / Evaluate / Deliver），不用「理解」。

## 步骤

1. **收集需求**：主题、学员（水平/背景/痛点）、时长（半天/全天/多天，默认 2 天）、形式（线下/线上/混合）、学完能做到什么、是否带真实案例练习、是否有参考大纲。
2. **MECE 拆模块**：把主题拆成 3–5 个不重叠、覆盖完整的模块。
3. **写学习目标**：`完成本模块后，学员能够 [行为动词] [具体技能]，在 [场景] 中 [结果]`。
4. **按 TfBR 4C 设计每个模块**：

   | 4C 阶段 | 时间占比 | 目的 |
   |---------|----------|------|
   | Connection | 5–10% | 欢迎、目标、议程、破冰 |
   | Concepts | 20–30% | 刚好够用、刚好及时的内容 |
   | Concrete Practice | 50–70% | 技能演练、角色扮演、应用 |
   | Conclusion | 5–10% | 承诺、行动计划、资源 |

   活动类型：测评（自评/诊断）、体验（模拟/角色扮演/游戏）、练习（技能演练）、反思（日志/结对分享/ORID 复盘）、应用（真实项目/行动计划）。
5. **嵌入 VAK 元素**：内容、活动、材料三层都覆盖视觉/听觉/动觉。
6. **有参考大纲时先出优化表**：原模块优缺点 → 重构后的模块流与顺序 → 每模块新 SMART 目标 → 增删建议 → 改进的教学法与互动 → 修订时间分配；然后再出详细大纲。

## 输出格式

按以下结构产出（示例见 `assets/leadership-workshop.md`）：

```markdown
# [工作坊名称]
## Overview
时长 | 学员 | 形式
课程背景 / 学习目标（1-3 条，行为动词）/ 课程收益 / 目标人群 / 课程优势
## Agenda Overview   （按半天/全天分段的表格：模块 | 内容 | 教学法）
## Detailed Outline （每模块：学习目标 + 4C 流程 + 时间）
## Materials & Preparation （材料、场地布置、前置作业）
```

## 常用时段结构

- **半天（4 小时）**：模块1 基础(60min) → 模块2 核心技能(90min) → 模块3 应用(60min) → 收尾(30min)。
- **全天（7–8 小时）**：上午模块1-2（各 90min）→ 午餐 60min → 下午模块3-4（各 90min）+ 收尾 30min。
- **多天**：Day1 基础与认知 → Day2 技能与练习 → Day3 应用与整合。

## 完成前自检

- [ ] MECE（无缺口、无重叠）
- [ ] 目标用行为动词
- [ ] 活动时间 ≥ 65%
- [ ] 每个模块含 VAK 元素
- [ ] 内容极简（just-enough / just-in-time）
- [ ] 活动配 ORID 复盘
- [ ] 开场含目标与议程，收尾含承诺
- [ ] 材料清单完整

## 输入输出

- **输入**：主题、学员、时长、形式、目标、是否带案例、参考大纲（可选）。
- **输出**：Markdown 大纲（Overview + Agenda + Detailed Outline + Materials）。
- **脚本/模板**：无脚本；示例见 `assets/leadership-workshop.md`。

## 注意事项

1. 方法细则（MECE / TfBR / ORID / VAK）按本文档与 `assets/leadership-workshop.md` 示例执行；拿不准的标「未验证」，不臆造。
2. 时长未指定时默认 2 天；必须用行为动词，不用「理解 / 了解」之类不可测动词。
3. 内容保持极简，不堆砌理论。

## 可复用示例

**输入**：主题「新任经理领导力」、学员「0–2 年管理经验的新经理」、时长「2 天」、目标「能用 SBI 模型给出建设性反馈」。

**输出要点**：MECE 拆为「角色认知 / 沟通与反馈 / 团队发展」三模块；Concrete Practice 占 ≥65%；每模块设角色扮演 + ORID 复盘；结尾行动承诺。
