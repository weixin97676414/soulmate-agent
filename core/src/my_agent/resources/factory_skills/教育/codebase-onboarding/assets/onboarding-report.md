# 交付自检清单

交付前逐条打勾，**任一为否则不能交付**：

- [ ] 章节 0「一句话结论」能让人 30 秒判断要不要用？
- [ ] 每个架构结论都有 `路径:行号`？无出处的是否标注了"推测"？
- [ ] 能力清单分了三级？核心 ≤8 条？高频度有依据？
- [ ] 每个 Demo 都有构建文件 + 版本锁定 + 运行命令 + 预期输出？
- [ ] **`check_demo.py` 跑过且无 ERROR？**
- [ ] 每条踩坑点四段齐全（尤其「如何避免」）？

- [ ] 上手指南六段齐全？每个命令有预期输出？
- [ ] 指南里的命令能否直接复制执行（无未替换占位符）？
- [ ] 附录里列了未验证项？（诚实标注比假装全知重要）
