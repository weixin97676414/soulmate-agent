# 功能：教学设计策略诊断


## 适用场景

- 企业 / 商业 / 能力类学习项目在动手做课件**之前**的战略诊断。
- 输入是需求简报、客户邮件、调研纪要、SME 访谈记录、政策文件、书稿内容、岗位能力说明。
- 需要判断「该不该培训」「是什么类型的问题」「用哪种教学框架」并输出工具无关的策略蓝图。
- 面向人类把关者，用于放大专业判断，而非替代它。

触发词：教学设计策略、培训诊断、要不要培训、学习策略蓝图、IDA、问题分类、框架选择、培训需求分析。

## 最小可用输入

至少具备其一：
- 明确的受众 **且** 有目标 / 期望结果；
- 一份可从中同时提取受众与目标的简报 / 记录 / 文档。

两者都没有时**先问澄清问题**再继续；信息部分缺失时只问必要问题，并把缺口标为「假设」。

## 步骤（严格按序）

1. **发现摘要**：提取并标注业务目标、受众、现状、期望状态、约束、风险、缺失信息；把「输入事实」与「推断假设」分开；不臆造指标、工具或约束。
2. **培训 or 不培训**：明确回答 是 / 否 / 不确定，用平实语言说明理由。若培训不是首选方案，给出替代：工作辅助工具、流程重设计、系统改进、管理者强化、能力标准、运营手册。
3. **问题分类**：知识缺口 / 程序技能缺口 / 行为决策缺口 / 合规要求 / 环境流程问题 / 混合。判为「混合」时，识别风险最高的缺口并以其对应框架为主导，同时说明次要缺口。
4. **框架推荐**（V1 支持三种）：
   - **A 行动映射（Action Mapping）**：适合领导力、行为改变、决策、能力提升。
   - **B 程序技能（认知负荷 + 范例）**：适合系统培训、技术流程、步骤型工作流、精度与一致性。
   - **C 合规覆盖**：适合监管强制、审计就绪、必修培训、风险缓释。
   为所选框架给出：检测到的信号、为何适配、学习科学依据（通俗）、为何其他框架欠佳、取舍。不要学术化，要应用、务实、清晰。
5. **策略蓝图**：按所选框架输出：
   - 行动映射：可测量目标、可观察行为、练习设计、最小支撑信息、强化计划、测量策略。
   - 程序技能：任务拆解、范例递进、练习排序、防错方法、强化方法、测量策略。
   - 合规：必需覆盖领域、风险分级、评估方法、证据采集、审计考量、测量方法。
6. **测量指引**：对齐框架——行动映射看岗位行为变化与管理反馈（Kirkpatrick L3–L4）；程序技能看准确率/速度基准、错误率下降、测评通过率（L2–L3）；合规看完成率、测评分数、审计覆盖证据（L1–L2）。能提具体指标就提；无数据时建议从什么开始追踪。
7. **人类复核清单**：需验证的假设、组织/政治敏感点、必须专家判断之处、不可盲自动化之处、过度设计风险。技能不产出「最终真理」，只产出供人验证的结构化思考。
8. **可选交付结构**（须显式请求）：幻灯片大纲 / eLearning 分镜 / 工作坊流程 / 工作辅助规格。
9. **可选 Agent 执行清单**（须显式请求）：交付物清单、生成顺序、工具示例、质量门（检查什么 / 谁批 / 通过标准）、人工审批点。保持工具无关，不假设 LMS API。

**默认输出**：仅策略蓝图。未指定形式时不做幻灯片 / 分镜 / 工作坊流程等。

**迭代协议**：收到修订后只重跑受影响步骤，不整份重生成；标明改了什么与原因；未被显式推翻就保留原假设。

## 输入输出

- **输入**：简报 / 邮件 / 纪要 / 访谈 / 政策 / 书稿 / 岗位说明，或明确的受众+目标。
- **输出**：策略蓝图 + 人类复核清单（+ 可选交付结构 / Agent 执行清单）。含：成功指标、工具无关的交付建议、工作量估计（S ≤2 周、M 2–6 周、L 6+ 周）、关键依赖。
- **脚本**：无。

## 注意事项（Guardrails）

1. 不跳过诊断；不无理由默认 ADDIE。
2. 未被显式要求时不产出完整课程。
3. 假设必须明确标注；输出简洁结构化；完成请求的部分即停。
4. 语气：专业、笃定、有挑战性但尊重、科学依据 + 通俗表达。

## 可复用示例

**输入**：一段销售团队调研纪要，提到新人「知道流程但成单率低、不敢在客户面前压单」。

**输出要点**：
- 发现摘要（受众=新销售；现状=成单率低；期望=会处理价格异议）。
- 培训 or 不培训：判断主因可能是行为/决策缺口而非知识缺口，培训 + 管理者强化并用。
- 问题分类：行为/决策缺口（主），知识缺口（辅）。
- 框架推荐：A 行动映射，给出信号与理由。
- 蓝图：可观察行为=在价格异议时按话术压单；练习设计=角色扮演；测量=成单率与主管观察（L3）。
- 复核清单：话术是否合规、指标基数是否可得。
