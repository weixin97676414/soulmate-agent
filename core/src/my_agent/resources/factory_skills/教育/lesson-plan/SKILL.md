# 功能：教案写作（教学评一致性）

**定位**：纯教案文本——课标对齐 + 教学评一致性。

## 适用场景

- 编写中小学各学科教案、教学设计、教学计划。
- 用户给出课题名称、学科关键词、年级、教学要求。
- 需要生成严格对齐《义务教育课程标准（2022年版）》且「目标—过程—评价」三者一致的教案。
- 需要参考优秀教案后做个性化调整（新授课 / 复习课 / 练习课 / 实验课）。

触发词：写教案、教学设计、教学计划、课时教案、某课怎么教。

## 步骤

1. **输入处理与学科判定**：接收课题名称、学科关键词、年级、教学要求；自动判定学科（语文 / 数学 / 英语 / 科学等）与课型（新授 / 复习 / 练习 / 实验）。
2. **资源搜索与整合**：以学科关键词检索，归纳优质教案在目标设定、活动组织、评价方式上的做法，提取符合教学评一致性的部分。
3. **教案生成**：以 `assets/optimized-template.md` 为框架，按下面的结构指南填充；确保教学目标、教学过程、教学评价三者一致，以学习任务为核心组织过程。
4. **输出与调整**：输出完整教案；按用户反馈做针对性修改。
5. **按需查阅**：学科教学特点看 `assets/subject-guides/`；角色要求看 `assets/role-requirements.md`；活动设计示例看 `assets/teaching-activities/`。

## 教案结构指南

### 一、基本信息
课题、日期、节次（第 X 章第 X 节第 X 课时）、教材来源、课型。

### 二、目标确立依据
- **课标分析**：课标摘录，再按「学什么 / 学到什么程度（能、会、理解、掌握）/ 怎么学」分解。
- **教材分析**：教材定位、已学—正学—将学的知识联系、编排特点。
- **学情分析**：优势、不足、重难点确定。

### 三、教学目标
知识目标 / 能力目标（观察、实践、思维、协作、表达）/ 素养目标（文化基础、自主发展、社会参与）/ 思政目标。

### 四、教学方法
讲授、讨论、演示、探究、练习、任务驱动等。

### 五、教学过程（40 分钟范例）
- 导入新课（3 分钟）：复习 / 情境 / 问题导入，写清设计意图。
- 讲授新课（32 分钟）：任务驱动（约 25 分钟）设 3 个递进任务，每个含任务描述、活动设计、评价量表、技术应用、预期效果；课堂练习（5 分钟）；板书设计（2 分钟）。
- 课堂小结（3 分钟）：知识回顾、方法总结、激励评价。
- 布置作业（2 分钟）：必做题、选做题、实践作业。

### 六、整节课学习评价
过程性评价 60% + 结果性评价 40%；优秀 / 良好 / 合格 / 需改进四等级；工具用观察记录表、任务评价量表、学习档案袋、数字化评价平台。

### 七、教学资源
教材、教具、数字化资源、参考资料。

### 八、教学反思
目标达成情况、过程实施效果、学生反馈、技术应用效果、改进建议。

## 输入输出

- **输入**：课题名称 / 学科关键词 / 年级 / 教学要求；可附教材版本、课型偏好、学生情况。
- **输出**：Markdown 完整教案（含上述八部分）；可按需导出 Word（见「可复用示例」）。
- **脚本**：本功能以文本生成方式产出，无独立脚本；模板与指南见 `assets/`。

## 注意事项

1. 严格遵循《义务教育课程标准（2022年版）》，不臆造课标条目。
2. 必须保证教学评一致性：目标、过程、评价相互对应，评价任务要对得上目标。
3. 根据学生实际调整任务难度，不做超出学段要求的超纲设计。
4. 缺失信息（教材版本、课时长度、学生基础）先列为「待确认项」，不编造。
5. 课程标准条目与官方表述若无法核实，标注「未验证」。

## 可复用示例

**输入**：`《背影》语文七年级上册`

**过程**：判定学科为语文 → 检索并归纳优质教案 → 按模板生成含目标、过程、评价的完整教案。

**调整示例**：`刚才的数学教案，请增加更多探究活动` → 检索探究式教学做法 → 调整教学过程增加探究环节 → 评价量表增加探究能力维度。

**教案结构骨架（可直接套用）**：

```markdown
# [课题] 教案
## 一、基本信息（课题/日期/节次/来源/课型）
## 二、目标确立依据（课标分析 / 教材分析 / 学情分析）
## 三、教学目标（知识 / 能力 / 素养 / 思政）
## 四、教学方法
## 五、教学过程（导入 / 讲授+任务驱动 / 练习 / 小结 / 作业）
## 六、整节课学习评价（过程性60% + 结果性40%）
## 七、教学资源
## 八、教学反思
```
