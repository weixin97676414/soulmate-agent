# 功能：培训记录转学习材料


## 适用场景

- 把培训会、入职会、知识传递类会议的文字记录，转成结构化学习材料与可执行复盘内容。
- 用户提供会议记录 / 培训录音转写 / 入职笔记，要求提取关键信息。
- 需要生成学习指南、速查表、清单、FAQ、行动项清单、培训效果评估。

触发词：会议记录转材料、培训记录整理、转录转内容、入职培训材料、SOP 文档、速查表、学习指南、行动项清单、FAQ 文档。

## 步骤

1. **理解请求**：按所需产出类型选择（见下表）。
2. **定位并分析来源**：若记录在项目目录，先 `ls` 目录、用 `grep -ri "关键词" <目录>/*.md` 检索；阅读并识别主要主题、分步流程、关键警告/细节、术语、实例、行动项与决定、问答。
3. **提取结构化内容（思维链处理）**：
   1. 通读全部记录，把握宏观语境与主题。
   2. 切分独立主题，归并相关信息。
   3. 精确提取事实、步骤、定义。
   4. 去除口语填充（"um""uh""I think""maybe""let's try" 等）。
   5. 转为祈使、权威语气（用动作动词）。
   6. 未知处用 `[MISSING INFO]` 标记，**不编造**。
4. **套用品牌（如适用）**：用户提供 Logo、品牌色、字体时按品牌规范统一应用；未提供则用干净专业的中性配色。
5. **产出交付物**：按所选类型生成（见「输出类型」）。

### 输出类型

| 输出类型 | 何时用 |
|----------|--------|
| 主知识源（Master Knowledge Source） | 含元数据、术语、SOP、关键细节、评估的结构化学习模块 |
| 演示 / 幻灯片 | 用于交付或参考的可视化培训演示 |
| SOP 文档 | 分步骤流程文档 |
| 速查表 | 要点与流程的一页式精简摘要 |
| 学习指南 | 面向学习者的复习材料 |
| 清单 | 从流程提取的可执行任务清单 |
| FAQ 文档 | 培训内容中的常见问答 |
| 行动项清单 | 会议讨论中的任务、负责人、截止时间 |

### 主知识源格式
完整 schema 见 `assets/master-knowledge-source-format.md`。提取区块：模块元数据（主题 + 一句话学习目标）、关键术语、标准作业流程（编号步骤，格式「动作 > 结果」）、关键细节（警告、后果、最佳实践、背景）、评估数据（严格基于内容的 3–5 道选择题）。**只输出结构化内容，无前后语；所有口语转权威指令；未知标 `[MISSING INFO]`。**

### 幻灯片
设计与创建细则见 `assets/presentation-guidelines.md`。结构：标题页 → 定义/概览 → 分步内容（4–6 步）→ 关键成功因素 → 常见坑 → 关键要点 → 结束页。设计：中性专业配色、内容控制在一屏高度内、网格布局、避免过度阴影/圆角/动画。

### SOP 文档
Markdown 层级（H1/H2/H3）+ 祈使编号步骤 + 引用块标注警告 + 参考数据表格。

## 输出格式要点

- **准确性**：一切内容严格基于来源；绝不编造步骤或数据；不完整流程用 `[MISSING INFO]` 标出。
- **清晰**：指令用祈使语气（"Click""Navigate""Set"）；标题与列表保证可扫读；去除口语填充。
- **一致性**：术语、结构、格式统一。

## 输入输出

- **输入**：会议 / 培训 / 入职的转写文本或笔记（用户提供或位于项目目录）。
- **输出**：上表任一类型的结构化文档（Markdown / 演示）。
- **参考**：`assets/master-knowledge-source-format.md`、`presentation-guidelines.md`。

## 注意事项

1. 幻灯片若导出后为空白，多为内容超出高度限制，需压缩间距 / 字号或拆页。
2. 内容不完整时用 `[MISSING INFO]` 标注并向用户确认关键缺口，不猜测。
3. 演示制作使用宿主可用的幻灯片能力；导出命令因平台而异，按宿主实际工具执行，勿照搬不存在的工具名。

## 可复用示例

**输入**：一段入职培训转写，讲「如何提交报销」。

**输出（SOP 片段）**：
```markdown
# 报销提交流程

## 前置条件
- 已完成费用发生并保留发票

## 步骤
1. 登录财务系统，进入「报销申请」。
2. 选择费用类型，上传发票扫描件。
3. **关键：** 金额与发票一致，否则审批会被退回。
4. 提交并记录单号。

## 排障
- **问题：** 上传后无法提交
  **解决：** 检查发票格式与大小限制
```
