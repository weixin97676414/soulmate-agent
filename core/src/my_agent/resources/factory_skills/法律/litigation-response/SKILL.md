# 应诉思路梳理与诉讼准备

## 适用场景

- 收到对方起诉状，需要梳理应诉思路、分析法律关系、确定答辩方向。
- 需要做庭前准备：流程指引、文书清单、证据整理、时间线、费用估算、小额诉讼判断。
- 触发语：「应诉」「答辩方向」「争议焦点」「庭前准备」「诉讼流程」「小额诉讼」。

## 步骤（应诉思路，主流程）

1. **起诉状内容解析**：提取原告主体资格与信息、代理人；解析诉讼请求（给付/确认/形成之诉、金额与计算依据、是否明确具体）；梳理原告主张的事实与法律依据；识别证据清单。
2. **法律关系识别**：判定案由（对照 `assets/litigation-elements.md` 常见案由构成要件）；分析法律关系主体、客体、内容；确定适用法规；审查管辖与时效（是否有管辖权异议事由、诉讼时效是否届满）。
3. **争议焦点提炼**：分别列事实争议、法律争议、证据争议，区分核心焦点与次要焦点；事实真伪不明时明确举证责任分配。
4. **应诉策略制定**：程序性事项（管辖异议、追加当事人、鉴定/调查取证、答辩与举证期限）；实体答辩方向（认可/部分认可/否认，针对各焦点的答辩意见，抗辩权与反诉考量）；证据准备计划（对照 `assets/evidence-guide.md` 的证据规则）；调解与和解考量。
5. **风险评估与建议**：胜诉可能性（证据充分性、法律适用确定性、司法实践倾向）；成本效益（诉讼费、律师费、鉴定费、时间与执行难度）；给出应诉/调解/和解/替代纠纷解决的建议。

输出按 `assets/response-strategy-template.md` 生成：案件基本信息 / 原告诉讼请求分析 / 争议焦点 / 应诉策略 / 证据准备清单 / 风险评估与建议。

## 步骤（诉讼准备，辅助）

用脚本快速产出准备清单、时间线与费用：

```bash
bash scripts/court-prep.sh checklist <civil|labor|contract|injury|divorce>
bash scripts/court-prep.sh timeline <立案日期> [类型]
bash scripts/court-prep.sh fee <标的额>
bash scripts/court-prep.sh evidence
```

（命令签名取自脚本 help，**未实测运行**。）脚本内置常见案件的阶段清单与文书清单，如民事案件阶段「立案→举证期限→开庭审理→判决→上诉期」，劳动争议阶段「仲裁申请→仲裁开庭→仲裁裁决→不服起诉→法院审理」。

## 步骤（案件七步分析法，可选框架）

本功能还提供一套证据矩阵式分析框架，可作为应诉思路的补充维度：

1. 事实 → 2. 关系 → 3. 要件 → 4. 映射 → 5. 矩阵 → 6. Bad Facts（不利事实）→ 7. 策略。

配套脚本（本地，**未实测运行**，需 Python 环境）：

```bash
python3 scripts/legal_analyst.py --file <法律文档> --output <报告路径>
python3 scripts/legal_analyst.py --text "<文本>"
```

七步法与「事实/要件/举证责任」的对应关系，可在焦点提炼与策略制定两步中使用；Bad Facts 与证据矩阵应输出为内参级材料，注意保护 PII 隐私。

## 输入输出

- 输入：起诉状 / 案件材料；或案件类型 + 立案日期 + 标的额。
- 输出：应诉思路文档（含争议焦点、答辩方向、证据清单、风险与决策建议）；或准备清单、时间线、费用估算。

## 注意事项

- 起诉状是原告单方主张，须结合证据客观分析，不可直接采信。
- 争议焦点应紧扣诉讼请求，避免偏离主题；策略须可操作，明确责任人与时间节点。
- 证据准备遵守举证期限，注意证据合法性。
- 风险评估应全面客观，避免盲目乐观或过度悲观。
- 保守案件秘密，遵守律师职业道德。
- 引用的判例/案号必须去中国裁判文书网等数据库核实，AI 生成的案号可能并不存在——逢案必验。

## 可复用示例

用户：「我被告了，对方要我还 20 万货款，我该怎么应诉？」
处理：解析起诉状 → 判定买卖合同纠纷案由 → 提炼焦点（是否存在交付、是否已付款、诉讼时效）→ 检查管辖与时效 → 制定答辩与证据计划（合同、送货单、付款凭证）→ 评估风险与调解空间 → 按 `assets/response-strategy-template.md` 输出。

用户：「听说我这个案子金额小，能走小额诉讼吗？」
处理：用 `court-prep.sh fee <金额>` 与脚本内的小额诉讼判断逻辑，结合标的额与案情复杂程度给出判断，并给出流程时间线。
