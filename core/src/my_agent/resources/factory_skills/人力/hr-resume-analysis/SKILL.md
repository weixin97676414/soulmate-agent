# 简历分析与筛选（事实底稿 → 时间线 → 信号 → 否决）

## 适用场景

- 丢来一份候选人简历，要「面否 / 可面」判断 + 面试问题 + 录用建议
- 需要对着 Job Card 做口径一致的结构化分析
- 候选人对比（仅在使用者明确要求时）

> 核心原则：**简历分析不是「看人」，是「列证据缺口」**。结论可能是信息不足，不是能力不够。

## 步骤

> 使用者主导，逐步推进：使用者每次只丢一步的东西，AI 给对应产出，不越级。

- **Step 0 简历 → 文本**：见 [hr-text-extraction](references/hr-text-extraction.md)。
- **Step 1 事实底稿**：基础（性别/年龄/籍贯/毕业届）/ 教育（学校/专业/学历/起止）/ 主修证书 / 实习工作经历（每段：公司/岗位/起止/职责/成果）/ 校内项目 / 求职意向 / 薪资期望。
- **Step 2 时间线完整性检查（必做，第一步不是亮点是对平时间）**：
  1. 入学年龄：本科入学 ≈ 出生年 + 18/19，晚 2–3 年 → 有 Gap（常见专升本 / 成人本科）
  2. 学历时长：本科正常 4 年，显示 2 年 → 必是专升本 / 插本 / 成人本科，简历省略了专科段
  3. 在职学历信号：非全日制常写「成人 / 函授」，或起止 2.5–3 年且与工作期重叠
  4. 空窗期：毕业到当前、或两段经历间 ≥3 个月空窗 → 记录，面试验证
- **Step 3 信号风险识别**：

  | 风险类型 | 识别信号 | 处理 |
  |---|---|---|
  | 信息省略 | 学历只写最高段、经历时间拼接有 Gap | 面试问 + 学历核验 |
  | 数字夸大 | 「效率提升 30%」无基准无方法 | 面试要具体场景、方法、度量 |
  | 事迹存疑 | 与常识 / 公开事实冲突 | 标注存疑，追问细节，其他描述打折听 |
  | 意向错位 | 简历意向 ≠ 投递岗位 | 入职动机待验，1–2 月复验稳定性 |
  | 经历注水 | 短经历但头衔大 | 面试验证实际职责边界 |
  | AI 生成痕迹 | 结构完美对称 / 全编号 / 零口语 / 产出时点不合理 | 按 AI 生成物证据排除处理 |

- **Step 4 AGM 信号层预判**：按 `assets/agf-analysis-logic.md`（12 格层级 / 8 维 / 行为证据 / 快速判定表 / 防误判过滤器）。简历写出的 → 显性信号（L1.5–L2.2 可给，高如 L2.2 需面试确认）；结构暗示的 → 待验证信号；无证据 → 「无法判定」，不猜。**置信度封顶 55%（面试前）/ 70%（面试后）**。
- **Step 5 岗位匹配（对着 Job Card）**：岗位认知需求 Lx ↔ 候选人信号 Lx、硬门槛逐项「满足/不满足」、方向匹配 + 证据、培养方向建议。
- **Step 6 否决项判定**：逐项对 Job Card ④，命中任一 → 直接「面否」，不再出面试清单；判断不了 → 标「待确认」问使用者，不自行下结论。
- **Step 7 面试问题清单**：见 [hr-interview-design](references/hr-interview-design.md)（拆线上 / 线下）。
- **Step 8 录用建议 + 风险控制**：见 [hr-hiring-decision](references/hr-hiring-decision.md)。
- **Step 9 归档**：收简历即建档 `resumes/{姓名}-简历分析-{年份}.md`，②③④ 每阶段即时回填；简历原件一并归档；多候选人对比表仅在使用者明确要求时做。

## 输入输出

- 输入：简历（PDF / 文字 / 平台截图）+ 对应岗位 Job Card
- 输出：事实底稿、时间线检查、信号风险表、层级预判、匹配结论、面试清单、录用建议，归档到 `resumes/`

## 注意事项

- **时间线检查是第一步**：先对平时间再谈亮点——教育年限、入学年龄、空窗期三根标尺。
- **信息省略 ≠ 造假**：双面解读，但省略的教育经历必须进面试问题 + 核验清单。
- **简历只能判「信号层」**：置信度封顶 55%（面试前）/ 70%（面试后），别把简历写得好等同能力高。
- **不替使用者做人事决策**：给证据、选项、验证方式。
- 逐步推进：①完才能②，③完才能④；②④ 判定要「回答原话」，不接受「他说得还行」这类总结。
- 只做单份 / 少量简历分析；打分口径引用 hr-jd-matching，不另立第二套权重。大量简历自动排序（批量）见 [hr-batch-screening](references/hr-batch-screening.md)。

## 可复用示例

```bash
python scripts/resume_to_text.py "张三.pdf" -o /tmp/zhangsan.md
# → Step1 事实底稿 → Step2 时间线（如：本科 2018 入学，出生 1999 → 正常）
# → Step3 信号（如："效率提升 30%" 无基准 → 面试要方法）
# → Step4 信号层预判 L1.3（高如 L2.2 需面试确认，置信度 ≤55%）
# → Step6 对 Job Card 否决项：未命中 → Step7 出面试清单
# → 归档 resumes/张三-简历分析-2026.md
```
