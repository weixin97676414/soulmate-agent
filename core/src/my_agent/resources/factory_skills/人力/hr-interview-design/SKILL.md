# 面试题设计（Scorecard → 取证 → 未来模拟）

## 适用场景

- 为一个岗位设计结构化面试指南
- 针对某份简历设计验证 / 深挖问题
- 准备线下深挖或线上初筛问题清单

## 步骤

1. **Step 1 定义 Scorecard（先不看简历）**：依据 JD 或岗位要求定义「A 级人才」标准——Mission（岗位使命一句话）、Outcomes（12 个月内必须达成的 3–5 项可量化结果）、Competencies（硬 / 软技能）。
2. **Step 2 取证式简历扫描**：用 Step 1 的标准扫简历，同时找**缺口**与**亮点**：
   - 「好到不真实」启发式：完美数据背后的逻辑缺口
   - 「乘客 vs 司机」启发式：大公司光环下的真实个人贡献
   - 「第一性原理」启发式：技术黑话背后的原理理解
   - 输出必须**同时**列 Red Flags（疑虑）与 Green Signals（亮点验证），保持客观、避免确认偏误。
3. **Step 3 压力测试 + 未来模拟**：
   - **压力测试脚本（面向过去）**：针对 Step 2 的疑虑设计取证式 STAR 追问。
   - **未来模拟（面向未来）**：设计具体 Performance Problem。示例：「我们明年要进入这个新市场，最大障碍是 X；如果由你负责，第一周你会怎么分析？」
4. **追问技巧（写进题目）**：
   - **6 层深**：对任何成果一路追问 "how exactly"，直到触底（如：提升销售额 30% → 具体做什么 → 流程怎么优化 → CRM 怎么选 → 竞品调研怎么做 → …）。
   - **PEARL**：Problem / Epiphany（洞察）/ Action / Result / Learning，用于复盘单个项目。
   - **STAR 剥洋葱**：第一层 STAR；第二层挖挑战与克服逻辑；第三层底层校验（重来会怎么改、学到什么）。
   - **收尾必问**：「还有什么是我们应该知道的吗？」常能挖出最重要信息。
   - **失败问题必问**：「最大的失败是什么？学到了什么？」
5. **题型编排与分型**：
   - A 技术 / 专业能力验证（3–5 题，针对简历技术栈与项目难点）
   - B 项目深挖 STAR（2–3 题）
   - C 软实力评估（2–3 题，结合 `assets/personalprefer-template.txt` 的基础素质要求）
   - D 待确认事项 / 风险澄清（1–2 题）
   - **按候选人分型**：应届生（毕业 ≤1 年）多考思维 / 态度；已工作（≥1 年）多考经历真实性。
   - **线上 / 线下拆分**：线上初筛以专业题为主（≥3 个）、简历核验为辅；线下深挖用 STAR 行为面试 + 情景假设 + AGM 层级信号。
6. **每条问题给三件套**：问题原文 + 验证什么 + 怎么判好坏（✅ 好 / ❌ 坏）。
7. **输出**：套用 `assets/interview_guide_template.md` 生成面试指南（含 Scorecard、Red Flags / Green Signals、Pressure Validation、Future Projection、Decision Matrix）。题型库与期望回答要点见 `assets/interview-questions-framework.md`。

## 输入输出

- 输入：JD / 岗位要求 + 候选人简历（+ 面试官偏好）
- 输出：结构化面试指南 / 面试问题清单（分线上、线下）

## 注意事项

- **先定义标准再看简历**——顺序反了会变成「围着候选人设岗位」。
- 保持中立：目的是求真，不是找茬；只设计能「验真 + 预测」的题，不设计羞辱性 / 无法回答的题。
- 题目要「不可背诵」：逼候选人现场思考（模拟）或回忆具体经历（压力测试）；必须能追问到「你画了什么图 / 当时原话是什么」的颗粒度。
- 「Anything else?」和「失败问题」是固定收尾，不要省。
- 判断要看实质而非表达：说得结构化 ≠ 有深度，要追问具体内容。

## 可复用示例

```
岗位：Java 后端（JD 已给）
Step1 Scorecard：Mission=保障订单系统稳定；Outcomes=QPS 提升/故障率下降…
Step2 扫简历：Red Flag=「重构订单系统」未写个人贡献；Green=有高并发 QPS 数据
Step3 出题：
 Pressure：Q1「订单重构的背景？原系统什么问题？」→ 追问「最大挑战？怎么解决？」
           Q2（6 层深）「你说重构后 QPS 提升 3 倍，具体怎么做到的？」→ 逐层追 why/how
 Future：  Q3「我们下季度要接一个新渠道订单，峰值未知。如果你入职第一周接这个，会怎么分析？」
 收尾：    Q4「最大的一次失败是什么？」+「还有什么我们应该知道的？」
```
