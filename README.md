# Soulmate Agent

面向**办公职场 + 日常生活**的**本地优先** AI 助手桌面应用。
Python 智能体核心（Skill / MCP / ReAct 引擎）+ Electron 桌面外壳，数据与密钥都留在你自己的机器上。

- 不是网页套壳：多窗口、托盘常驻、全局语音唤醒、桌面级交互
- 不是"聊天框 + 一个提示词"：内置 **13 类、237 个开箱即用的技能**，覆盖办公、自媒体、电商、医疗、法律、金融等场景
- 不锁定模型：**17 家服务商**一键接入，可自定义 OpenAI 兼容端点，也可用本地 Ollama
- 能力可扩展：**MCP**（Model Context Protocol）第三方工具自动变成技能，与内置技能共用同一套权限、确认、审计

---

## 亮点

| | |
|---|---|
| **本地优先** | 核心只监听 `127.0.0.1` 回环地址，令牌每次启动随机生成、重启即失效；会话与消息落在本机 SQLite（`%APPDATA%\Soulmate Agent\data\agent.db`） |
| **密钥不落盘明文** | API Key 用 Windows DPAPI（`safeStorage`）加密保存；核心侧通过"读完即删的临时文件"注入，仅驻内存 |
| **搭子（人格化助手）** | 把「人设五文档 + 模型 + 可用工具 + 权限策略」打包成可切换的整体；内置 3 个，界面可新建/编辑/导入导出 |
| **多搭子群聊** | 多个搭子进同一个群讨论协作，可分「只读观察窗」与「可操作窗」；群记忆在群内成员间共享 |
| **权限逐次确认** | 高危操作（写文件、发请求、执行命令）由 `PermissionGuard` 拦下，在同一个流里向界面请求确认；超时按**拒绝**处理 |
| **全程可回溯** | 每次技能调用写入审计表（参数写入前统一脱敏）；执行链路以 span 时间线呈现，含每步耗时与 token |

## 功能一览

### 对话与搭子

- **多会话**：会话列表按「今天 / 昨天 / 最近 7 天 / 更早」分组，支持搜索、改名、删除、清空、批量删除
- **搭子切换**：左侧助手栏随时切换；每个搭子的模型可以独立指定，也可以跟随全局默认
- **人设五文档**：`IDENTITY → SOUL → USER → MEMORY → RULES`，落在 `data/assistants/<id>/`，界面上可查看、可编辑
- **模型选择**：输入栏下方的选择器按会话记忆；上下文用量随对话实时显示
- **思考强度**：按各家服务商文档映射的推理档位，可逐次调整
- **工具调用可视化**：工具卡片显示运行中 / 成功 / 失败 / 被拒绝与耗时
- **计划与产物**：多步任务生成计划卡；产物在右侧抽屉直接预览，支持「另存为」
- **交互提问**：模型可以在中途向你提问选项（`ask_choice`），而不是自己猜

### 群聊

- 拉多个搭子进同一个群，由「总管」做策划与分工，各专职搭子执行
- 群聊可开**独立窗口**：只读观察窗（后台讨论自动弹出、不抢焦点）与可操作窗
- 群记忆独立成库，群内成员共享；单聊默认不读群记忆（避免串台）
- 讨论可中断、可续接，失败不会"全白干"

### 技能系统

- **内置技能库**：13 个分类、**237 个技能**随仓库分发，首次启动自动播种
  （人力 · 办公 · 医疗 · 媒体 · 学术 · 教育 · 法律 · 生活 · 电商 · 科技 · 营销 · 设计 · 金融）
- **通用技能格式**：一个技能包可以是一个目录，也可以带脚本与素材
  - `skill.json`（声明式 http / command 调用）
  - `SKILL.md`（YAML frontmatter + 正文说明，兼容 Claude / Anthropic Agent Skills 写法）
  - 规则文件（`AGENTS.md` / `CLAUDE.md` / `.cursorrules` / `.mdc`）
  - 含 `mcpServers` 的配置
  - 可执行脚本（`.py` / `.sh` / `.js` / `.ps1` …）
  - 通用提示词
- **安全执行**：技能执行前过权限校验、AST 白名单（防注入）、路径白名单、超时与确认
- **技能分组**：内置 / 自己的专属 / 通用 / 我的技能；可整包导入导出，可给单个技能单独配密钥（界面上只显示脱敏预览）

### 模型接入

- **17 家服务商预设**：硅基流动 · DeepSeek · OpenAI · 通义千问（百炼）· Kimi · 智谱 · 豆包（火山方舟）·
  MiniMax · 腾讯混元 · 百度文心（千帆）· 阶跃星辰 · Anthropic Claude · Google Gemini · xAI Grok ·
  OpenRouter · Groq · Mistral
- **自定义端点**：「添加服务商」三步向导支持任意 OpenAI 兼容端点
- **本地模型**：Ollama 自建（先试原生 `/api/tags`，再退回 OpenAI 兼容接口）
- **一键同步**：按 `base_url` 拉取真实可用模型清单；「测试连通性」真的请求一次并返回延迟
- **工程细节**：流式工具参数碎片拼接、备用模型降级、按任务选模型路由、缓存命中单独计费

### MCP（第三方能力）

- 图形化增删 MCP Server、导入 JSON 配置、查看工具与权限、重启 / 停止
- 第三方工具**自动包装成技能**，进入统一工具列表 —— 工具卡片、权限确认、审计日志全都自动生效
- **崩溃自愈**：每 30 秒主动探活（子进程死掉时命令循环只会静默等待），无响应即重连
- **状态实时同步**：连接状态变化即时推送；Server 掉线时它的工具立刻从模型可见列表消失
- **权限四级推断**：按「注解 → 写动词 → 读动词 → 保守默认」，判断不出来时归为需确认（按词元匹配，不会把 `prune_cache` 里的 `run` 误判成写操作）
- 目前支持 **stdio** 传输（本地子进程）

### 记忆

- **短期**：会话上下文，超出预算时按策略截断，且保证协议合法（不会产生孤立的 tool 消息）
- **长期**：向量检索式长期记忆，可选内置中文嵌入模型 / 外部 API / Ollama
- **溢出处理**：超长内容"无损外置"到文件并告知路径，而不是静默省略
- **群记忆**：群内共享，与单聊隔离

### 语音

- **语音输入**：前端做采集 / VAD / 断句，核心做识别（本地 SenseVoice 模型）
- **语音唤醒**：唤醒词用「识别结果 + 拼音匹配」，每个搭子 / 群可各配一个
- **语音命令**：用说话切页面、切群、添加技能等
- **朗读**：本地 TTS 模型
- **设置分两层**：全局 + 当前主体（搭子 / 群）
- ⚠️ 语音与嵌入模型**不随安装包分发**，首次使用时按需下载（国内 ModelScope / 国外 HuggingFace 自动选源）

### 任务与自动化

- **任务页**：定时 / 条件触发的自动化任务，可看"跑了没有、为什么没跑"
- 任务可以自己建 / 改 / 删 / 立刻跑，也可以由搭子在对话中创建
- 错过的补跑策略可配（如"关了一周的就算了，昨天的要补"）
- **记账与提醒**：记一笔账（自动推断分类）、花销统计；提醒到点由核心主动推送（`/v1/events` 长连接），应用关闭期间的提醒下次启动补发

### 日历

- 本地 `.ics`（默认，可与系统 / 手机日历互导）
- CalDAV（苹果日历 / Nextcloud 等），密码走系统加密存储

### 产物与工作区

- 附件上传后落在 `workspace/`，技能产生的文件归档到 `artifacts/`
- **存储名由服务端生成**（uuid + 后缀白名单），原始文件名只作展示，绝不参与路径拼接
- 屏蔽 `.exe` / `.bat` / `.ps1` / `.dll` 等危险后缀，单文件上限 50 MB
- 预览是**只读**的：Markdown / CSV / XLSX / Word / PDF / 图片 / JSON / SVG；超限如实标注"已截断"，解析失败返回可读原因而不是 500

### 桌面体验

- **独立窗口**：每个搭子或每段会话都可以单独开窗（单聊 900×720，群聊 780×680）
- **托盘常驻**；关闭行为三选一（每次询问 / 最小化到托盘 / 直接退出）
- **单实例**；多窗口共享一个核心
- **外观**：日 / 夜成对皮肤、壁纸、「我的资料」（头像昵称）
- **首启引导**：语音 → 长期记忆 → 服务厂商 → 开始；判据是"有没有一个真正能用的模型"
- **日志页**：审计日志查询 / 筛选 / 清空与统计

### 社区（可选）

应用内置社区账号入口（账号、安全、我的 Token、邀请、余额与赞助、线路）。这些是**可选的**——不登录也能完整使用本地功能。相关代码就在 `desktop/electron/account/` 下，可自行审阅。

## 快速开始

### 环境要求

| 依赖 | 版本 | 说明 |
|---|---|---|
| Windows | 10 / 11 x64 | 目前仅支持 Windows |
| Python | 3.13+ | 核心运行时（开发环境实测 3.14）。⚠️ 跑核心测试请用 `core\.venv\Scripts\python.exe` —— 系统 Python 通常没装 `sherpa_onnx`，会让语音真链路测试假红 |
| Node.js | 20+ | 桌面端构建 |

### 1. 核心（Python）

```powershell
cd core
py -3.13 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".[dev]"
# 需要长期记忆（向量检索）时：
.\.venv\Scripts\python.exe -m pip install -e ".[memory]"
```

### 2. 桌面端

```powershell
cd desktop
npm install
```

### 3. 开发运行

```powershell
cd desktop
npm run dev
```

这条命令会：启动 Vite 开发服务器（`:5173`，支持 HMR）→ 编译主进程 TypeScript → 启动 Electron，
并由**主进程自动拉起 Python 核心**（无需手工开后端）。

> 主进程（`electron/`）改动后需重启 `npm run dev`；渲染层（`src/`）自动热更新。

### 4. 首次使用：配置模型

首次启动若没有可用模型，会直接进入引导页：

1. 选一个服务商（DeepSeek / 通义 / Kimi / 智谱 / 本地 Ollama …）
2. 填 API Key —— 用 Windows DPAPI 加密存在本机，**不写进配置文件**
3. 点「测试连接」（真的请求一次服务商的模型列表，返回延迟与可用模型名）
4. 点「保存并开始使用」

之后想改配置，走 **模型** 页（左列服务商，右列该家的同步头 + 模型卡）。

> 出厂**没有任何预配置的模型条目**（刻意的：避免"凭空多出两个我没配的模型"）。

## 隐私与数据

数据都在本机，路径可在「关于」页看到：

| 位置 | 内容 |
|---|---|
| `%APPDATA%\Soulmate Agent\data\agent.db` | SQLite：会话、消息、审计日志、工作区文件元数据、记账与提醒 |
| `%APPDATA%\Soulmate Agent\data\assistants\` | 每个搭子的人格文档 |
| `%APPDATA%\Soulmate Agent\workspace\` / `artifacts\` | 附件与产物 |
| `%APPDATA%\Soulmate Agent\config\` | 配置（**不含密钥明文**） |
| `%APPDATA%\Soulmate Agent\models\` | 按需下载的语音 / 嵌入模型 |
| `%APPDATA%\Soulmate Agent\logs\` | 日志 |

三条安全底线：

1. **密钥归主进程所有**，渲染层通过受限 IPC 取用（渲染层要渲染模型输出与上传文件，是不可信边界）
2. **交接用临时文件而不是环境变量**（环境变量会被子进程继承，而核心会 spawn MCP Server —— Key 会直接漏给第三方进程）
3. **落盘剥离、内存保留**（配置里密钥字段恒为空串；MCP 环境变量只剥离"名字像密钥"的那些）

系统不支持加密时会降级为明文并在日志中告警 —— 宁可让用户知道风险，也不假装安全。

细节见 [`docs/架构与实现.md`](docs/架构与实现.md)。

## 已知限制

- **未做代码签名**：安装时 Windows SmartScreen 会给出警告（需要代码签名证书才能消除）
- 目前**仅支持 Windows**；MCP 仅支持 **stdio** 传输（本地子进程）
- MCP 的 resources 与 prompts 尚未接入，只用 tools
- 产物预览是**只读**的，需要改动请用「另存为」在本地打开
- `.xls`（旧二进制格式）不支持预览，请先转 `.xlsx`；扫描版 PDF 没有文字层，预览会明确提示
- 提醒只在应用运行时触发；关闭期间的到点提醒会在下次启动补发
