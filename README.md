# Soulmate Agent

面向**办公职场 + 日常生活**的**本地优先** AI 助手桌面应用。
Python 智能体核心（Skill / MCP / ReAct 引擎）+ Electron 桌面外壳，数据与密钥都留在你自己的机器上。

- 不是网页套壳：多窗口、托盘常驻、全局语音唤醒、桌面级交互
- 不是"聊天框 + 一个提示词"：**107 个内置工具** + **237 个出厂技能包（13 类）**，
  还能自己开浏览器、动鼠标键盘帮你把事做完
- 不锁定模型：预置 **4 家**服务商，另有 **17 家厂商**的平台适配，可自定义 OpenAI 兼容端点，也可用本地 Ollama
- 能力可扩展：**MCP**（Model Context Protocol）第三方工具自动变成技能，与内置技能共用同一套权限、确认、审计

---

## 两个旗舰搭子

内置 **5 个**搭子（Buddy Manager · Soulmate · Love Buddy · Relation Buddy · Fortune telling Buddy），
其中前两个是产品的主线能力。

### Buddy Manager —— 一句话，交付一个团队

你说清要做什么，它把「谁来做、怎么做」直接变成可运行的 Agent 或 Agent 团队：

- **一键创建**：描述需求 → 它设计搭子的身份（IDENTITY / SOUL）、规则（RULES）与可用技能，直接落成配置
- **组建团队**：需要协作时自动建群、定分工（一个统筹 + 若干专职），跑完把结果交付回来
- **持续优化**：对结果不满意就说一句，它改分工、换技能、再加人
- **每周自省 + 每月复盘**：自己整理记忆与人格（有「进化日志」可查），每月回看整体协作是否真的在变好

### Soulmate —— 越用越懂你的深度陪伴搭子

它的"了解你"不只来自聊天记录，还来自**心鉴学**服务给出的结构化画像：

- 按时间窗分层：**L2 今年 / L3 本月（近期）/ L4 今天 / L5 当下两小时**
- **约每两小时**拉取一次最新状态（L5 窗口结束 + 3 分钟，具体时刻以服务端返回的 `next_refresh_at_local` 为准）；
  应用每天首次开启、以及用户补全出生信息 / 改变常住地之后也会各拉一次
- 拿到新画像就**改写自己的文档**：`USER.md` 每次刷新，`SOUL.md` 只在首次录入时按模板改写
  （缺失的组留空并注明"本次信息未覆盖"，不会编造）
- 所以它不是"记得你说过什么"，而是"知道你现在正处在什么状态"

> 这两个能力都长在同一套搭子机制上：**人设五文档 + 进化日志 + 模型 + 可用工具 + 权限策略**。
> 每个搭子的人格文件都能在界面上查看、编辑，不是黑盒。

## 亮点

| | |
|---|---|
| **本地优先** | 核心只监听 `127.0.0.1` 回环地址，令牌每次启动随机生成、重启即失效；会话与消息落在本机 SQLite（`%APPDATA%\Soulmate Agent\data\agent.db`） |
| **密钥不落盘明文** | API Key 用 Windows DPAPI（`safeStorage`）加密保存；核心侧通过"读完即删的临时文件"注入，仅驻内存 |
| **搭子（人格化助手）** | 把「人设五文档 + 模型 + 可用工具 + 权限策略」打包成可切换的整体；内置 **5 个**（见上），界面可新建 / 编辑，也能让 AI 从官网搭子库导入现成的搭子 |
| **多搭子群聊** | 多个搭子进同一个群讨论协作，由 Buddy Manager 统筹分工；可分「只读观察窗」与「可操作窗」；群记忆在群内成员间共享 |
| **真的能操作电脑** | **10 个桌面控制 + 5 个浏览器控制**工具：点鼠标、敲键盘、切窗口、开程序、读界面元素、开网页填表。全部 `confirm` 级，每一步都由你点头 |
| **权限逐次确认** | 高危操作（写文件、发请求、执行命令）由 `PermissionGuard` 拦下，在同一个流里向界面请求确认；超时按**拒绝**处理 |
| **全程可回溯** | 每次技能调用写入审计表（参数写入前统一脱敏）；执行链路以 span 时间线呈现，含每步耗时与 token |

## 功能一览

### 对话与搭子

- **多会话**：会话列表按「今天 / 昨天 / 最近 7 天 / 更早」分组，支持搜索、改名、删除、清空消息
- **搭子切换**：左侧助手栏随时切换；每个搭子的模型可以独立指定，也可以跟随全局默认
- **内置 5 个搭子**：Buddy Manager（建 Agent / 带团队）、Soulmate（深度陪伴）、Love Buddy、Relation Buddy、
  Fortune telling Buddy（西占 / 八字 / 梅花 / 塔罗）；内置搭子的名称、简介与 RULES 写死，防止被误改
- **欢迎页快捷模板**：每个内置搭子三条，点一下**直接把问题发给它**（跳过输入框），不用自己想第一句
- **全员进化**：内置搭子每周整理一次记忆与人格、每月做一次复盘，过程写进各自的「进化日志」，可回溯
- **人设文档（六份）**：`IDENTITY → SOUL → RULES → MEMORY → USER → 进化日志`，
  落在 `data/assistants/<id>/`，界面上可查看、可编辑
- **模型选择**：输入栏下方的选择器按会话记忆；上下文用量随对话实时显示
- **思考强度**：按各家服务商文档映射的推理档位，可逐次调整
- **工具调用可视化**：工具卡片显示运行中 / 成功 / 失败 / 被拒绝与耗时
- **计划与产物**：多步任务生成计划卡；产物在右侧抽屉直接预览，支持「另存为」
- **交互提问**：模型可以在中途向你提问选项（`ask_choice`），而不是自己猜

### 群聊

- 拉多个搭子进同一个群、可定发言顺序；常见做法是把 **Buddy Manager** 也拉进来做统筹与分工，各专职搭子执行
- 群聊可开**独立窗口**：只读观察窗（后台讨论自动弹出、不抢焦点）与可操作窗
- 群记忆独立成库，群内成员共享；单聊默认不读群记忆（避免串台）
- 讨论可中断、可续接，失败不会"全白干"

### 技能系统

技能分三层，加起来 **约 350 个开箱即用的能力**：

| 层 | 数量 | 说明 |
|---|---|---|
| **内置工具** | **107 个** | 写在代码里的能力（浏览器、电脑操作、剪贴板、文档、日历、记忆、人格、心鉴学取数…），随核心出厂 |
| **出厂技能包** | **237 个 / 13 类** | 资源包形态，首次启动自动播种（人力 · 办公 · 医疗 · 媒体 · 学术 · 教育 · 法律 · 生活 · 电商 · 科技 · 营销 · 设计 · 金融）；磁盘上另有 5 个刻意不播种 |
| **专属技能** | **6 类** | 心鉴学相关（Soulmate专用 · 人际关系运营 · 西占 · 八字 · 梅花易数 · 塔罗），按线路二选一 |

- **通用技能格式**：一个技能包可以是一个目录，也可以带脚本与素材
  - `skill.json`（声明式 http / command 调用）
  - `SKILL.md`（YAML frontmatter + 正文说明，兼容 Claude / Anthropic Agent Skills 写法）
  - 规则文件（`AGENTS.md` / `CLAUDE.md` / `.cursorrules` / `.mdc`）
  - 含 `mcpServers` 的配置
  - 可执行脚本（`.py` / `.sh` / `.js` / `.ps1` …）
  - 通用提示词
- **专属技能**：上表那 6 类按线路自动二选一（大陆 / 国际），不属于该搭子的技能**既看不到也调不动**；
  配套工具也按归属**逐条**判定（取报告的工具不会漏给算命搭子）
- **安全执行**：危险动作逐次确认（`PermissionGuard`）· 命令**不经 shell**（`exec` 参数数组，杜绝拼接注入）·
  文件读写的路径白名单 · 端点校验（拒绝云元数据地址这类危险目标；本机回环放行，Ollama 要用）· 超时
- **技能分组**：**我的技能**（默认页：自己上传 / AI 创建 / AI 安装）· 通用技能 · 内置技能 · 专属技能；
  支持整包导入（目录 / zip / 单文件，六种格式自动识别）
- **密钥不外泄**：技能里的密钥写成 `{{secret:名字}}`，真正发请求那一刻才在本地替换成明文；
  模型可以主动向用户索要（`request_secret`），界面只显示脱敏预览

### 电脑与浏览器操作（会真的动你的键鼠）

不是"给你一段操作步骤"，而是**它自己上手操作**。这类能力全部是 `confirm` 级 ——
每一次点击、输入、启动程序都要你先点头，拒绝一次就停。

- **桌面控制（10 个）**：列出窗口 · 切换窗口 · 启动程序或打开文件 · 移动鼠标 · 点击 · 拖拽 ·
  滚动 · 按键 · 输入文字 · 读取界面元素
- **浏览器控制（5 个）**：打开网页读正文 · 查看页面上有哪些可点击/可输入的元素 ·
  在网页上点击 / 填表 / 滚动 · 截图 · 管理标签页
- **典型用法**：「打开这个网页把订单状态读给我」「在表格里把这几行填上」「把那个弹窗点掉」
- **安全边界**：读屏幕与截图也只在你确认后执行；配合语音命令，可以全程不动键盘鼠标

### 模型接入

- **预置 4 家**：硅基流动 · DeepSeek · OpenAI · 通义千问（百炼）——开箱带可用模型清单，填 Key 即可用
- **平台适配覆盖 17 家**（上面 4 家 + Kimi · 智谱 · 豆包（火山方舟）· MiniMax · 腾讯混元 ·
  百度文心（千帆）· 阶跃星辰 · Anthropic Claude · Google Gemini · xAI Grok · OpenRouter · Groq · Mistral）：
  其余各家在「添加服务商」里填自家 `base_url` 即可 —— 温度范围、思考字段、用量字段的差异由核心按域名自动适配
- **自定义端点**：「添加服务商」三步向导支持任意 OpenAI 兼容端点
- **本地模型**：Ollama 自建（先试原生 `/api/tags`，再退回 OpenAI 兼容接口）
- **一键同步**：按 `base_url` 拉取真实可用模型清单；「测试连通性」真的请求一次并返回延迟
- **工程细节**：流式工具参数碎片拼接、**辅助模型**（摘要/记忆这类轻任务可单独指定，配错自动退回主模型）、
  缓存命中单独计费

### MCP（第三方能力）

- 图形化增删 MCP Server、导入 JSON 配置、查看工具与权限、重启 / 停止
- 第三方工具**自动包装成技能**，进入统一工具列表 —— 工具卡片、权限确认、审计日志全都自动生效
- **崩溃自愈**：每 30 秒主动探活（子进程死掉时命令循环只会静默等待），无响应即重连
- **状态实时同步**：连接状态变化即时推送；Server 掉线时它的工具立刻从模型可见列表消失
- **权限四级推断**：按「注解 → 写动词 → 读动词 → 保守默认」，判断不出来时归为需确认（按词元匹配，不会把 `prune_cache` 里的 `run` 误判成写操作）
- 目前支持 **stdio** 传输（本地子进程）

### 记忆

- **短期**：会话上下文，超出预算时按策略截断，且保证协议合法（不会产生孤立的 tool 消息）
- **长期**：向量检索式长期记忆（默认随包外的中文嵌入模型 `Qwen3-Embedding-0.6B`，也可换厂商 `/embeddings` 或 Ollama）
- **溢出处理**：超长内容"无损外置"到文件并告知路径，而不是静默省略
- **群记忆**：群内共享，与单聊隔离

### 语音

- **语音输入**：前端做采集 / VAD / 断句，核心做识别（本地 SenseVoice 模型），不联网
- **语音唤醒**：唤醒词用「识别结果 + 拼音匹配」（不会因为同音字漏掉），每个搭子 / 群可各配一个
- **语音命令（36 条，命令词可自己改）**：对话 3 · 导航 17 · 面板 10 · 助手 1 · 确认 5
  - 对话：新对话 · 停止 · 继续
  - 导航：回到对话 / 打开群聊 · 任务 · 模型 · 技能 · MCP · 产物 · 消耗 · 日历 · 日志 · 安全
  - 助手：新建助手
  - 确认：允许 · 拒绝执行 · 改一下 · 不用了
  - 面板与其它：展开/收起抽屉 · 助手栏 · 会话栏 · 群列表 · 反馈 · 添加技能 · 关闭弹窗
- **朗读**：本地 TTS 模型
- **设置分两层**：全局 + 当前主体（搭子 / 群）
- ⚠️ 语音与嵌入模型**不随安装包分发**，首次使用时按需下载（国内 ModelScope / 国外 HuggingFace 自动选源）

### 任务与自动化

- **任务页**：定时 / 条件触发的自动化任务，可看"跑了没有、为什么没跑"
- 任务可以自己建 / 改 / 删 / 立刻跑，也可以由搭子在对话中创建
- 关着的时候错过的那次，启动后**补跑一次** —— 只补最近一次，不会把一周没跑的全补上（那会一口气烧掉大量 token）
- **记账与提醒**：记一笔账（自动推断分类）、花销统计；提醒到点由核心主动推送（`/v1/events` 长连接），应用关闭期间的提醒下次启动补发

### 日历

- 本地 `.ics`（默认，可与系统 / 手机日历互导）
- CalDAV（苹果日历 / Nextcloud 等），密码走系统加密存储

### 产物与工作区

- 附件上传后落在 `workspace/`，技能产生的文件归档到 `artifacts/`
- **存储名由服务端生成**（uuid + 后缀白名单），原始文件名只作展示，绝不参与路径拼接
- 屏蔽 `.exe` / `.bat` / `.ps1` / `.dll` 等危险后缀，单文件上限 50 MB
- 预览是**只读**的：Markdown / CSV / XLSX / Word / PDF / 图片 / JSON / SVG；超限如实标注"已截断"，解析失败返回可读原因而不是 500

### 桌面体验

- **独立窗口**：每个搭子或每段会话都可以单独开窗（单聊 900×720，群聊 780×680）
- **托盘常驻**；关闭行为三选一（每次询问 / 最小化到托盘 / 直接退出）
- **单实例**；多窗口共享一个核心
- **外观**：日 / 夜成对皮肤、壁纸、「我的资料」（头像昵称）
- **首启引导**：语音 → 长期记忆 → 服务厂商 → 开始；判据是"有没有一个真正能用的模型"
- **日志页**：审计日志按「结果 / 类型 / 搭子 / 时间范围」四类条件叠加筛选，可一键清空

### 社区（可选）

应用内置社区账号入口（账号、安全、我的 Token、邀请、余额与赞助、线路）。这些是**可选的**——不登录也能完整使用本地功能。相关代码就在 `desktop/electron/account/` 下，可自行审阅。

## 快速开始

### 环境要求

| 依赖 | 版本 | 说明 |
|---|---|---|
| Windows | 10 / 11 x64 | 桌面端支持平台之一 |
| macOS | 11+（arm64 / x64） | 桌面端支持平台之一（未公证，首次打开见下方「macOS 首次打开」） |
| Python | 3.13+ | 核心运行时（开发环境实测 3.14）。⚠️ 跑核心测试请用 `core\.venv\Scripts\python.exe` —— 系统 Python 通常没装 `sherpa_onnx`，会让语音真链路测试假红 |
| Node.js | 20+ | 桌面端构建 |

### 1. 核心（Python）

```powershell
cd core
py -3.13 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".[dev]"
# 需要长期记忆（向量检索）时：
.\.venv\Scripts\python.exe -m pip install -e ".[memory]"
```

### 2. 桌面端

```powershell
cd desktop
npm install
```

### 3. 开发运行

```powershell
cd desktop
npm run dev
```

这条命令会：启动 Vite 开发服务器（`:5173`，支持 HMR）→ 编译主进程 TypeScript → 启动 Electron，
并由**主进程自动拉起 Python 核心**（无需手工开后端）。

> 主进程（`electron/`）改动后需重启 `npm run dev`；渲染层（`src/`）自动热更新。

### 4. 首次使用：配置模型

首次启动若没有可用模型，会直接进入引导页：

1. 选一个服务商（DeepSeek / 通义 / Kimi / 智谱 / 本地 Ollama …）
2. 填 API Key —— 用 Windows DPAPI 加密存在本机，**不写进配置文件**
3. 点「测试连接」（真的请求一次服务商的模型列表，返回延迟与可用模型名）
4. 点「保存并开始使用」

之后想改配置，走 **模型** 页（左列服务商，右列该家的同步头 + 模型卡）。

> 出厂**没有任何预配置的模型条目**（刻意的：避免"凭空多出两个我没配的模型"）。

## 隐私与数据

数据都在本机，路径可在「关于」页看到：

| 位置 | 内容 |
|---|---|
| `%APPDATA%\Soulmate Agent\data\agent.db` | SQLite：会话、消息、审计日志、工作区文件元数据、记账与提醒 |
| `%APPDATA%\Soulmate Agent\data\assistants\` | 每个搭子的人格文档 |
| `%APPDATA%\Soulmate Agent\workspace\` / `artifacts\` | 附件与产物 |
| `%APPDATA%\Soulmate Agent\config\` | 配置（**不含密钥明文**） |
| `%APPDATA%\Soulmate Agent\models\` | 按需下载的语音 / 嵌入模型 |
| `%APPDATA%\Soulmate Agent\logs\` | 日志 |

三条安全底线：

1. **密钥归主进程所有**，渲染层通过受限 IPC 取用（渲染层要渲染模型输出与上传文件，是不可信边界）
2. **交接用临时文件而不是环境变量**（环境变量会被子进程继承，而核心会 spawn MCP Server —— Key 会直接漏给第三方进程）
3. **落盘剥离、内存保留**（配置里密钥字段恒为空串；MCP 环境变量只剥离"名字像密钥"的那些）

系统不支持加密时会降级为明文并在日志中告警 —— 宁可让用户知道风险，也不假装安全。

细节见 [`docs/架构与实现.md`](docs/架构与实现.md)。

## macOS 首次打开（未签名 / 未公证）

本项目是开源项目，**未购买 Apple Developer 签名证书**，因此 macOS 的 Gatekeeper 会拦截首次打开的下载应用
（提示「无法验证开发者」或「已损坏，无法打开」）。这是正常的，放行一次即可：

**方式一（推荐，图形界面）**
1. 打开「系统设置 → 隐私与安全性」；
2. 在「安全性」区域找到「已阻止使用 Soulmate Agent」，点「仍要打开」；
3. 再次打开应用，在弹窗里点「打开」。

**方式二（终端命令）**
```bash
xattr -cr "/Applications/Soulmate Agent.app"
```

> 只需放行一次，之后正常双击即可。

## 已知限制

- **未做代码签名**：Windows 安装时 SmartScreen 会警告；macOS 未签名/未公证，首次打开会被 Gatekeeper 拦截（见上方「macOS 首次打开」，放行一次即可）
- **Soulmate 与算命占卜依赖心鉴学服务**：拉取画像 / 排盘 / 起卦 / 洗牌都要登录该服务的账号（登录态由客户端托管）；不登录不影响其余功能
- 桌面端支持 **Windows / macOS**；MCP 仅支持 **stdio** 传输（本地子进程）
- MCP 的 resources 与 prompts 尚未接入，只用 tools
- 产物预览是**只读**的，需要改动请用「另存为」在本地打开
- `.xls`（旧二进制格式）不支持预览，请先转 `.xlsx`；扫描版 PDF 没有文字层，预览会明确提示
- 提醒只在应用运行时触发；关闭期间的到点提醒会在下次启动补发
